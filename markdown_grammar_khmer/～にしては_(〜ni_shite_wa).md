# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～にしては (〜ni shite wa)
**កម្រិត JLPT:** JLPT N3

---

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ **～にしては (〜ni shite wa)** គឺជាកន្សោមវេយ្យាករណ៍កម្រិត JLPT N3 ដ៏សំខាន់ ដែលត្រូវបានប្រើប្រាស់សម្រាប់បង្ហាញពីការវាយតម្លៃ ការភ្ញាក់ផ្អើល ឬអារម្មណ៍នឹកស្មានមិនដល់របស់អ្នកនិយាយ ដោយសារតែលទ្ធផល ឬស្ថានភាពជាក់ស្តែងមិនស៊ីគ្នា (ផ្ទុយស្រឡះ) ពីបទដ្ឋានទូទៅ ឬការរំពឹងទុកធម្មជាតិដែលកំណត់ដោយពាក្យខាងមុខ។

នៅក្នុងភាសាខ្មែរ យើងអាចបកប្រែជាទូទៅថា **«បើគិតទៅលើ... / ធៀបនឹង... / សមតែជា... បែរជា... / បើជា... វិញនោះ...»** ឬជាភាសាអង់គ្លេសស្មើនឹង **"for", "considering that", "given that"**។

ឧទាហរណ៍៖
- **子供にしては** (បើគិតថាជាក្មេងវិញ / ធៀបនឹងក្មេង) ➔ កម្រិតសមត្ថភាព ឬការយល់ដឹងបែរជាខ្ពស់គួរឱ្យភ្ញាក់ផ្អើល ខុសពីក្មេងទូទៅ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
**～にしては** ត្រូវបានប្រើនៅពេលដែលការពិតជាក់ស្តែង លទ្ធផល ឬទង្វើរបស់នរណាម្នាក់ មានភាពផ្ទុយស្រឡះ ឬខុសពីអ្វីដែលគេតែងតែគិត ឬរំពឹងទុកជាទូទៅផ្អែកលើស្តង់ដារ ឬលក្ខខណ្ឌដែលនៅពីមុខ **にしては**។
- វាបង្ហាញពីគម្លាតរវាង **«ការរំពឹងទុកជាទូទៅ (General Standard/Expectation)»** និង **«ការពិតជាក់ស្តែង (Actual Reality/Evaluation)»**។
- ពាក្យសមមូលជាភាសាខ្មែរ៖ «បើគិតថាជា... / បើធៀបនឹង... / សម្រាប់... គឺ... ណាស់ / មិនសមជា... សោះ»
- ពាក្យសមមូលជាភាសាអង់គ្លេស៖ "considering that...", "for a...", "judging by...", "despite being..."

---

### ទម្រង់វេយ្យាករណ៍ និង ក្បួនផ្សំ (Structure & Formation)

ទម្រង់នេះភ្ជាប់ជាមួយ **នាម (Noun)** ឬ **ទម្រង់ធម្មតា (Plain Form)** នៃកិរិយាសព្ទ និងគុណនាម៖

```plaintext
[នាម (Noun)] + にしては
[កិរិយាសព្ទ (Verb - Plain Form)] + にしては
[គុណនាម い (i-Adj)] + にしては
[គុណនាម な (na-Adj: である)] + にしては  (ឬកម្រប្រើ [Adj-stem] + にしては)
```

#### តារាងផ្សំទម្រង់ (Conjugation Table)

| ប្រភេទពាក្យ | ក្បួនផ្សំ | ឧទាហរណ៍ជាក់ស្តែង | អត្ថន័យជាភាសាខ្មែរ |
|---|---|---|---|
| **នាម (Noun)** | នាម + にしては *(គ្មាន だ ទេ)* | **子供** + にしては ➔ 子供にしては | បើគិតថាជាក្មេង... |
| | | **外国人** + にしては ➔ 外国人にしては | បើគិតថាជាជនបរទេស... |
| **កិរិយាសព្ទ (Verb)** | ទម្រង់ធម្មតា (辞書形/た形/ない形) + にしては | **たくさん食べた** + にしては | ញ៉ាំច្រើនដល់ម្ល៉ឹងហើយ បែរជា... |
| | | **練習した** + にしては | ខំប្រឹងហាត់ដល់ម្ល៉ឹងហើយ បែរជា... |
| **គុណនាម い (i-Adj)** | ទម្រង់ធម្មតា (い / かった) + にしては | **高い** + にしては | បើគិតថាតម្លៃថ្លៃដល់ម្ល៉ឹង បែរជា... |
| **គុណនាម な (na-Adj)** | គុណនាម な (である / だった) + にしては | **静かである** + にしては | បើគិតថាស្ងប់ស្ងាត់ដល់ម្ល៉ឹង បែរជា... |

*ចំណាំសំខាន់បំផុត៖ ចំពោះនាម គឺភ្ជាប់ដោយផ្ទាល់ជាមួយ `にしては` ភ្លាម ដោយមិនបាច់ដាក់ `だ` ឬ `である` ឡើយ (ឧទាហរណ៍៖ ❌ 子供だにしては ➔ ✔️ 子供にしては)។*

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance & Comparative Analysis)

### ន័យស៊ីជម្រៅ (Deep Nuance Breakdown)
រូបមន្តវាយតម្លៃនៃ **～にしては** គឺ៖
> **[ស្តង់ដារទូទៅ / ការពិតជាក់ស្តែង A] ➔ にしては ➔ [ការវាយតម្លៃផ្ទុយពីបទដ្ឋានទូទៅ B]**

១. **ការបំពានលើបទដ្ឋានទូទៅ (Defying General Standards):**  
កន្សោមខាងមុខ `にしては` គឺជា «ស្តង់ដារទូទៅក្នុងសង្គម ឬលក្ខខណ្ឌជាក់ស្តែង» ដែលមនុស្សភាគច្រើនតែងមានការរំពឹងទុករួចជាស្រេច។ ឧទាហរណ៍៖
- ស្តង់ដារទូទៅ៖ ជាធម្មតា «ក្មេង (子供)» មិនទាន់ចេះដឹងរឿងនយោបាយ ឬសង្គមច្រើនទេ។
- ការវាយតម្លៃជាក់ស្តែង៖ «子供にしてはよく知っている» (បើគិតថាជាក្មេងវិញ ដឹងរឿងច្រើនគួរឱ្យភ្ញាក់ផ្អើល) ➔ ស្ថានភាពជាក់ស្តែងបានបំពានលើបទដ្ឋានធម្មតានៃក្មេង។

២. **អារម្មណ៍ភ្ញាក់ផ្អើលរបស់អ្នកនិយាយ (Speaker's Surprise / Evaluation):**  
ឃ្លា B តែងតែឆ្លុះបញ្ចាំងពីការវាយតម្លៃផ្ទាល់ខ្លួនរបស់អ្នកនិយាយ ដែលបង្កប់នូវការភ្ញាក់ផ្អើល (Surprise) ការស្ងើចសរសើរ (Admiration) ឬការខកចិត្ត/រិះគន់ (Dissatisfaction/Criticism) ដោយសារតែលទ្ធផលមិនត្រូវគ្នានឹងការគិតទុកជាមុន។

---

### ការប្រៀបធៀបយ៉ាងតឹងរ៉ឹង៖ ～にしては vs. ～わりに / わりには

វេយ្យាករណ៍ទាំងពីរនេះមានអត្ថន័យស្រដៀងគ្នា ប៉ុន្តែមានចំណុចខុសគ្នាជាសារវន្តទាក់ទងនឹង **លក្ខណៈនៃស្តង់ដារ (Standard Nature)**, **ទម្រង់វេយ្យាករណ៍ (Grammar Formation)**, និង **ទំហំកម្រិតធៀប (Proportionality)**៖

| ចំណុចប្រៀបធៀប | ～にしては (〜ni shite wa) | ～わりに / ～わりには (〜wari ni / 〜wari ni wa) |
|---|---|---|
| **កម្រិត JLPT** | N3 | N3 |
| **លក្ខណៈនៃស្តង់ដារ** | ប្រើជាមួយ **ស្តង់ដារជាក់លាក់ ឬក្រុមច្បាស់លាស់** (Specific Category/Fact) ដូចជាកុមារ ជនបរទេស រដូវក្តៅ ឬការពិតជាក់ស្តែងមួយ។ | ប្រើជាមួយ **កម្រិតរង្វាស់ ឬពាក្យដែលមានទំហំទូលាយ/សមាមាត្រ** (Measurable scale: អាយុ តម្លៃ ប្រាក់ខែ ការប្រឹងប្រែង)។ |
| **ទម្រង់ផ្សំជាមួយនាម** | **[នាម] + にしては** (ភ្ជាប់ផ្ទាល់ គ្មាន の)  <br>*(ឧ. 子供にしては, 日本人にしては)* | **[នាម] + の + わりに(は)** (ត្រូវតែមាន `の`)  <br>*(ឧ. 子供のわりには, 年齢のわりには)* |
| **ទម្រង់ផ្សំជាមួយគុណនាម な** | [Adj な + である] + にしては | **[Adj な] + な + わりに(は)**  <br>*(ឧ. 静かなわりに)* |
| **ន័យបង្កប់ស្នូល** | **ផ្ទុយពីបទដ្ឋានទូទៅដែលគេរំពឹងទុកទាំងស្រុង** (Unexpected exception to a known standard)។ មិនអាចប្រើលើពាក្យរង្វាស់ទូលាយដូចជា "អាយុ" ឬ "តម្លៃ" បានឡើយ បើគ្មានបញ្ជាក់កម្រិតជាក់លាក់។ | **អតុល្យភាពនៃសមាមាត្រ** (Out of proportion / Proportional contrast)៖ ធៀបនឹងធាតុចូល A ផលដែលចេញ B គឺមិនសមាមាត្រគ្នា។ |
| **ឧទាហរណ៍ប្រៀបធៀប ១** | ❌ 彼は**年齢にしては**若く見える。<br>*(ខុស ព្រោះ 年齢 ជាពាក្យទូលាយ គ្មានកម្រិតជាក់លាក់)* | ✔️ 彼は**年齢のわりに**若く見える。<br>*(ត្រូវ៖ ធៀបនឹងអាយុ គាត់មើលទៅក្មេង ➔ សមាមាត្រ)* |
| **ឧទាហរណ៍ប្រៀបធៀប ២** | ✔️ 彼は**70歳にしては**若く見える。<br>*(ត្រូវ៖ 70歳 ជាតួលេខជាក់លាក់ ផ្ទុយពីស្តង់ដារមនុស្សអាយុ ៧០ ឆ្នាំ)* | ✔️ 彼は**70歳のわりに**若く見える。<br>*(ត្រូវ៖ ក្នុងសមាមាត្រអាយុ ៧០ ឆ្នាំ)* |
| **ឧទាហរណ៍ប្រៀបធៀប ៣** | ✔️ **新人にしては**仕事が速い。<br>*(បើគិតថាជាបុគ្គលិកថ្មី ធ្វើការលឿនខុសពីធម្មតា)* | ✔️ **給料のわりに**仕事が大変だ。<br>*(ធៀបនឹងប្រាក់ខែ ការងារលំបាកមិនសមាមាត្រគ្នា)* |

---

### ការប្រៀបធៀបជាមួយ ～としては (〜toshite wa)
- **～にしては**៖ បង្ហាញពី **ភាពផ្ទុយគ្នាពីស្តង់ដារ** («បើគិតថាជា A... បែរជា B គួរឱ្យភ្ញាក់ផ្អើល»)។
- **～としては**៖ បង្ហាញពី **តួនាទី ឋានៈ ឬទស្សនៈ** («ក្នុងនាមជា... / ក្នុងលក្ខខណ្ឌជា...»)។
  - *ឧទាហរណ៍៖*
    - 親**にしては**冷たい。 (បើគិតថាជាឪពុកម្តាយ គាត់បែរជាកាច/ព្រងើយកន្តើយគួរឱ្យភ្ញាក់ផ្អើល ➔ ផ្ទុយពីធម្មជាតិឪពុកម្តាយ)
    - 親**としては**心配だ。 (ក្នុងនាមជាឪពុកម្តាយ ខ្ញុំពិតជាបារម្ភ ➔ បង្ហាញពីតួនាទី)

---

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ប្រយោគគំរូ (Example Sentences)

១. **彼は日本人にしては背が高い。**  
   - *Kare wa Nihonjin ni shite wa se ga takai.*  
   - **ការបកប្រែ៖** បើគិតថាគាត់ជាជនជាតិជប៉ុន គាត់មានកម្ពស់ខ្ពស់ណាស់។ (ជាទូទៅជនជាតិជប៉ុនមិនសូវខ្ពស់ទេ ប៉ុន្តែគាត់ខ្ពស់ខុសពីស្តង់ដារទូទៅ)

២. **初めて作ったにしてはおいしくできた。**  
   - *Hajimete tsukutta ni shite wa oishiku dekita.*  
   - **ការបកប្រែ៖** បើគិតថានេះជាលើកដំបូងដែលបានធ្វើម្ហូបនេះ វាចេញមកឆ្ងាញ់គួរឱ្យភ្ញាក់ផ្អើល។

៣. **雨が降ったにしては道が乾いている。**  
   - *Ame ga futta ni shite wa michi ga kawaite iru.*  
   - **ការបកប្រែ៖** បើគិតថាមេឃបានភ្លៀងហើយ ផ្លូវបែរជាស្ងួតល្អទៅវិញ។

៤. **彼女は初心者にしてはとても上手に運転できます。**  
   - *Kanojo wa shoshinsha ni shite wa totemo jōzu ni unten dekimasu.*  
   - **ការបកប្រែ៖** បើគិតថានាងជាអ្នកទើបតែចាប់ផ្តើមរៀន នាងអាចបើកបរបានយ៉ាងស្ទាត់ជំនាញ។

៥. **今日は夏にしては涼しい。**  
   - *Kyō wa natsu ni shite wa suzushii.*  
   - **ការបកប្រែ៖** ថ្ងៃនេះបើគិតថាកំពុងស្ថិតក្នុងរដូវក្តៅ អាកាសធាតុត្រជាក់ស្រួលប្លែកខុសពីធម្មតា។

៦. **このアパートは家賃が安いにしては、部屋が広くて綺麗だ。**  
   - *Kono apāto wa yachin ga yasui ni shite wa, heya ga hirokute kirei da.*  
   - **ការបកប្រែ៖** អាផាតមិននេះបើគិតថាតម្លៃជួលថោកដល់ម្ល៉ឹង បន្ទប់បែរជាធំទូលាយហើយស្អាតទៀត។

៧. **彼はたくさん練習したにしては、あまり上達していない。**  
   - *Kare wa takusan renshū shita ni shite wa, amari jōtatsu shite inai.*  
   - **ការបកប្រែ៖** បើគិតថាគាត់បានខិតខំហ្វឹកហាត់ច្រើនដល់ម្ល៉ឹង គាត់បែរជាមិនសូវមានការរីកចម្រើនសោះ។ *(ប្រើក្នុងការរិះគន់ ឬខកចិត្ត)*

---

### បរិបទ និង កម្រិតនៃការប្រើប្រាស់ (Register & Context Variations)
- **ការសន្ទនាប្រចាំថ្ងៃ (Casual Speech):** ប្រើញឹកញាប់ក្នុងចំណោមមិត្តភក្តិ ឬក្រុមគ្រួសារ ដើម្បីបង្ហាញការស្ងើចសរសើរ ឬការភ្ញាក់ផ្អើលចំពោះរឿងអ្វីមួយ។
- **ការនិយាយបែបគួរសម (Polite Speech):** ទម្រង់ `～にしては` ខ្លួនឯងមានលក្ខណៈអព្យាក្រឹត (Neutral) ដូច្នេះកម្រិតគួរសមអាស្រ័យលើកិរិយាសព្ទបញ្ចប់ប្រយោគ (ឧទាហរណ៍បញ្ចប់ដោយ `〜です / 〜ます`)។
- **ការសរសេរ (Written Language):** អាចប្រើក្នុងអត្ថបទ របាយការណ៍ ឬតែងសេចក្តី នៅពេលអ្នកសរសេរចង់បង្ហាញពីលទ្ធផលស្រាវជ្រាវ ឬអង្គហេតុដែលផ្ទុយពីការសន្និដ្ឋានជាទូទៅ។

---

## ៥. ចំណាំបែបវប្បធម៌ និងការប្រុងប្រយ័ត្ន (Cultural Notes)

### ទំនាក់ទំនងវប្បធម៌ (Cultural Relevance)
ការយល់ដឹងអំពី **～にしては** ជួយឱ្យយើងយល់ពីផ្នត់គំនិត និងបទដ្ឋានសង្គមរបស់ជនជាតិជប៉ុន (Common Sense / 社会通念)។ នៅពេលជនជាតិជប៉ុននិយាយប្រយោគដូចជា «外国人にしては日本語が上手ですね» (បើគិតថាជាជនបរទេស និយាយជប៉ុនពូកែណាស់) គឺពួកគេផ្អែកលើការយល់ឃើញថា ភាសាជប៉ុនជាភាសាពិបាកសម្រាប់ជនបរទេស។

### ការប្រុងប្រយ័ត្នក្នុងការប្រើប្រាស់ (Etiquette Warning)
ទោះបីជា `～にしては` ច្រើនប្រើដើម្បីសរសើរក៏ដោយ ប៉ុន្តែដោយសារវាបង្កប់ន័យថា **«ស្តង់ដារធម្មតារបស់អ្នក ឬក្រុមរបស់អ្នកគឺទាប តែអ្នកធ្វើបានល្អជាងនោះ»** ការប្រើប្រាស់វាទៅកាន់ **ចៅហ្វាយនាយ ព្រឹទ្ធាចារ្យ ឬអតិថិជន (目上の人)** អាចចាត់ទុកជាការមិនគួរសម ឬមើលងាយកម្រិតស្តង់ដាររបស់គេ។
- ❌ មិនគួរនិយាយទៅកាន់ចៅហ្វាយនាយ៖ 部長、お忙しいにしては元気ですね。
- ✔️ គួរប្រើជាមួយមិត្តភក្តិ អ្នកដែលមានឋានៈស្មើគ្នា ឬក្មេងជាង។

## ៦. កំហុសទូទៅ និង គន្លឹះចងចាំ (Common Mistakes & Tips)

### កំហុសដែលតែងតែកើតមាន
១. **ច្រឡំជាមួយ ～としては (〜toshite wa):**
   - *ខុស:* 私は留学生**にしては**勉強している。(ន័យប្រែជា៖ ខ្ញុំបើគិតថាជានិស្សិតបរទេស រៀនសូត្រគួរឱ្យភ្ញាក់ផ្អើល - មិនសមហេតុផល)
   - *ត្រូវ:* 私は留学生**としては**...(ក្នុងនាមខ្ញុំជានិស្សិតបរទេស...)

២. **ប្រើដោយគ្មានបទដ្ឋាន ឬស្តង់ដារប្រៀបធៀបជាក់លាក់:**
   - *ខុស:* 彼は**にしては**優しい。(ខ្វះស្តង់ដារ មិនដឹងថាធៀបនឹងអ្វី)
   - *ត្រូវ:* 彼は**見た目にしては**優しい。(បើគិតតាមរូបរាងខាងក្រៅរបស់គាត់ គាត់មានចិត្តល្អគួរឱ្យភ្ញាក់ផ្អើល)

៣. **ប្រើពាក្យរង្វាស់ទូលាយគ្មានទំហំកំណត់ (ច្រឡំជាមួយ わりに):**
   - *ខុស:* **値段にしては**おいしい。(値段 មិនមែនជាតម្លៃជាក់លាក់)
   - *ត្រូវ:* **100円にしては**おいしい。(100円 ជាតម្លៃជាក់លាក់)
   - *ត្រូវ:* **値段のわりには**おいしい。(ប្រើជាមួយ わりに បានយ៉ាងត្រឹមត្រូវ)

៤. **ច្រឡំដាក់ particle の ឬ だ ជាមួយនាម:**
   - *ខុស:* 子供**のだ**にしては / 子供**の**にしては
   - *ត្រូវ:* 子供**にしては**

---

### គន្លឹះចងចាំ (Mnemonic Device)
- គិតថា **にしては** មកពី **«កំនត់ថាជា (にして) + បើនិយាយពី...វិញ (は)»** ➔ «បើគិតកំណត់លើករណីហ្នឹងវិញ គឺខុសពីគេទាំងស្រុង!»
- ផ្គូផ្គង៖ **[ក្មេង / តម្លៃថោក / លើកទីមួយ] + にしては ➔ [លទ្ធផលពូកែ / ឆ្ងាញ់ / ស្ទាត់ជំនាញហួសពីការស្មាន]**

## ៧. សង្ខេប និង កម្រងសំណួរខ្លីៗ (Summary & Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～にしては** បង្ហាញពីលទ្ធផល ឬការវាយតម្លៃដែលផ្ទុយស្រឡះពីបទដ្ឋានទូទៅដែលគេតែងតែរំពឹងទុក។
- បកប្រែជាភាសាខ្មែរ៖ **«បើគិតថាជា... / ធៀបនឹង... បែរជា...»**
- ទម្រង់ផ្សំ៖ **[នាម] / [កិរិយាសព្ទ Plain Form] + にしては** (នាមភ្ជាប់ផ្ទាល់ គ្មាន の ឬ だ)។
- ភាពខុសគ្នាពី **～わりに**៖ `にしては` ប្រើជាមួយស្តង់ដារជាក់លាក់ (Specific standard/fact) ចំណែក `わりに` ប្រើជាមួយមាត្រដ្ឋានទូលាយ និងសមាមាត្រ (Proportional scale)។

### កម្រងសំណួរខ្លីៗ (Quick Recap Quiz)

**១. ចូរជ្រើសរើសចម្លើយត្រឹមត្រូវដើម្បីបំពេញចន្លោះ៖**  
子供___しては、難しい漢字をよく知っている。  
a) に  
b) にしては  
c) としては  

**២. ត្រូវ ឬ ខុស (True or False):**  
កន្សោម `～にしては` និង `～としては` មានអត្ថន័យ និងមុខងារវេយ្យាករណ៍ដូចគ្នាទាំងស្រុង។  

**៣. ចូរជ្រើសរើសការបកប្រែត្រឹមត្រូវសម្រាប់ប្រយោគខាងក្រោម៖**  
彼は運動したにしてはあまり汗をかいていない。  
a) គាត់មិនសូវចេញញើសទេ បើទោះបីជាគាត់បានហាត់ប្រាណក៏ដោយ។  
b) ដោយសារតែគាត់ហាត់ប្រាណ ទើបគាត់ចេញញើសច្រើន។  
c) បើគិតថាគាត់មិនបានហាត់ប្រាណ គាត់ចេញញើសច្រើនណាស់។  

**៤. ប្រយោគណាខាងក្រោមនេះប្រើប្រាស់ត្រឹមត្រូវតាមក្បួនវេយ្យាករណ៍?**  
a) 彼は年齢にしては若く見える。  
b) 彼は70歳にしては若く見える。  
c) 彼は70歳のわりにしては若く見える。  

---

### ចម្លើយ (Answers)
១. **b) にしては** (បើគិតថាជាក្មេង ចេះអក្សរកាន់ជិពិបាកៗច្រើនណាស់)  
២. **ខុស (False)** (`にしては` បង្ហាញភាពផ្ទុយពីស្តង់ដារ ចំណែក `としては` បង្ហាញពីតួនាទី/ឋានៈ)  
៣. **a) គាត់មិនសូវចេញញើសទេ បើទោះបីជាគាត់បានហាត់ប្រាណក៏ដោយ (បើគិតថាបានហាត់ប្រាណដល់ម្ល៉ឹង បែរជាមិនសូវចេញញើស)។**  
៤. **b) 彼は70歳にしては若く見える。** (ព្រោះ `70歳` ជាតួលេខជាក់លាក់ អាចប្រើជាមួយ `にしては` បាន ចំណែក `年齢` ត្រូវប្រើជាមួយ `年齢のわりに`)
