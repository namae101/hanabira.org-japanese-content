# ចំណុចវេយ្យាករណ៍ជប៉ុន: ～を頼りに (〜wo tayori ni)
**កម្រិត JLPT:** JLPT N2

---

## ១. សេចក្តីផ្តើម (Introduction)

ទម្រង់វេយ្យាករណ៍ **～を頼りに** (〜をたよりに) គឺជាកន្សោមភាសាជប៉ុនកម្រិត N2 ដែលត្រូវបានប្រើប្រាស់ដើម្បីបញ្ជាក់អំពី «ការពឹងផ្អែកលើអ្វីមួយ ឬនរណាម្នាក់ជាជំនួយ / ជាតម្រុយ / ជាបង្អែក» ដើម្បីធ្វើសកម្មភាពមួយ ឬឆ្លងកាត់ស្ថានភាពលំបាក ស្មុគស្មាញ និងមិនធ្លាប់ស្គាល់។

កន្សោមនេះបង្ហាញឱ្យឃើញយ៉ាងច្បាស់អំពីមធ្យោបាយ ឬបង្អែកដ៏សំខាន់ (ជាញឹកញាប់ជាបង្អែកតែមួយគត់ ឬជាតម្រុយសំខាន់) ដែលជួយឱ្យបុគ្គលម្នាក់អាចបន្តសកម្មភាពទៅមុខបាន។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **～を頼りに**: *ដោយពឹងផ្អែកលើ...*, *ដោយយក...ជាបង្អែក/ជាតម្រុយ*, *ដោយមានជំនួយពី...*, *ដោយសារតែមាន...ជាទីពឹង*
- ទម្រង់នេះបង្ហាញថាសកម្មភាពនៅខាងក្រោយត្រូវបានធ្វើឡើង ដោយផ្អែកលើមនុស្ស វត្ថុ តម្រុយ ឬព័ត៌មានណាមួយដែលដើរតួជាជំនួយ ឬខ្សែជីវិតដ៏សំខាន់។

### ទម្រង់វេយ្យាករណ៍ និងការផ្សំ (Structure & Conjugation)

ទម្រង់វេយ្យាករណ៍នេះមានបំរែបំរួលទូទៅចំនួន ៣ អាស្រ័យលើមុខងារក្នុងប្រយោគ៖

1. **កែប្រែ ឬបន្ថែមន័យឱ្យកិរិយាសព្ទ (Adverbial modifier):**
```plaintext
[នាម (Noun)] + を頼りに + [កិរិយាសព្ទ / សកម្មភាព]
[នាម (Noun)] + を頼りにして + [កិរិយាសព្ទ / សកម្មភាព]
```

2. **កែប្រែនាមមួយទៀត (Noun-modifying form):**
```plaintext
[នាម ១ (Noun 1)] + を頼りとした + [នាម ២ (Noun 2)]
[នាម ១ (Noun 1)] + を頼りにした + [នាម ២ (Noun 2)]
```

- **[Noun]**: វត្ថុ មនុស្ស ឬតម្រុយដែលជាបង្អែក (ឧទាហរណ៍៖ 地図 - ផែនទី, かすかな明かり - ពន្លឺភ្លើងស្រអាប់ៗ, 記憶 - ការចងចាំ)។
- **を**: ធ្នាក់កម្មបទ (Object marker)។
- **頼り (たより)**: នាមដែលក្លាយមកពីកិរិយាសព្ទ **頼る (たよる - ពឹងពាក់/ពឹងផ្អែក)** មានន័យថា "បង្អែក / ទីពឹង"។
- **に / にして**: ធ្នាក់បញ្ជាក់របៀបរបបនៃការធ្វើសកម្មភាព។
- **[Action]**: សកម្មភាពដែលសម្រេចទៅបានដោយសារតែពឹងលើនាមនោះ។

### តារាងរចនាសម្ព័ន្ធ (Formation Diagram)

| សមាសភាគ | តួនាទីវេយ្យាករណ៍ | ការពន្យល់ |
|---|---|---|
| **នាម (Noun)** | បង្អែក / តម្រុយ | អ្វីមួយ ឬនរណាម្នាក់ដែលយកជាទីពឹង |
| **を** | ធ្នាក់ (Particle) | សម្គាល់កម្មបទនៃការពឹងពាក់ |
| **頼りに / 頼りにして** | កន្សោមជំនួយ | "ដោយយក...ជាបង្អែក / ជាតម្រុយ" |
| **កិរិយាសព្ទ (Action)** | សកម្មភាពចម្បង | សកម្មភាពដែលធ្វើឡើងដោយពឹងលើបង្អែកនោះ |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Nuance Analysis)

### ន័យស៊ីជម្រៅនៃ ～を頼りに

ចំណុចសំខាន់បំផុតនៃ **～を頼りに** គឺស្ថានភាពដែលប្រធានប្រយោគកំពុងស្ថិតនៅក្នុង **ភាពមិនច្បាស់លាស់ ភាពងងឹត ឬស្ថានភាពលំបាក** (Unfamiliar or difficult situation) ហើយមានតែកត្តា ឬតម្រុយនោះមួយប៉ុណ្ណោះជា **បង្អែក ឬខ្សែជីវិត (Lifeline / Guide / Clue)** ដើម្បីបន្តដំណើរ ឬដោះស្រាយបញ្ហា។
- ឧទាហរណ៍៖ `地図を頼りに` (ពឹងលើផែនទីដើម្បីដើរក្នុងព្រៃ ឬផ្លូវមិនដែលស្គាល់)
- ឧទាហរណ៍៖ `かすかな明かりを頼りに` (ពឹងលើពន្លឺស្រអាប់ៗតែមួយគត់ដើម្បីដើរក្នុងទីងងឹតស្លុប)

### ការប្រៀបធៀបជាមួយទម្រង់ស្រដៀងគ្នា

#### ១. ～を頼りに vs. ～をもとに (～をもとにして)
- **～を頼りに (យកជាបង្អែក / ជាតម្រុយដោះស្រាយការលំបាក):**
  - ប្រើនៅពេលយើងយករបស់ណាមួយធ្វើជាបង្អែក ជាជំនួយ ឬជាតម្រុយដើម្បីណែនាំផ្លូវឆ្លងកាត់ឧបសគ្គ ឬស្ថានភាពមិនច្បាស់លាស់។ បង្កប់នូវអារម្មណ៍ថាបើគ្មានរបស់នេះទេ សកម្មភាពនោះស្ទើរតែមិនអាចទៅមុខរួចឡើយ។
  - ឧទាហរណ៍៖
    ```plaintext
    かすかな明かりを頼りに、暗闇の中を進んだ。
    ខ្ញុំបានបន្តដំណើរទៅមុខក្នុងភាពងងឹត ដោយពឹងផ្អែកលើពន្លឺភ្លើងដ៏ស្រអាប់មួយ។
    ```
- **～をもとに (យកជាមូលដ្ឋានគ្រឹះ / ជាប្រភពគំនិតច្នៃប្រតិដ្ឋ):**
  - ប្រើនៅពេលយកទិន្នន័យ ហេតុការណ៍ពិត ឬរឿងរ៉ាវណាមួយមកធ្វើជាសម្ភារៈ/មូលដ្ឋានគ្រឹះដើម្បីបង្កើតអ្វីដែលថ្មី (Create something new) ដូចជា ការសរសេរប្រលោមលោក ការផលិតខ្សែភាពយន្ត ការរចនា។
  - ឧទាហរណ៍៖
    ```plaintext
    この映画は、実際の事件をもとにして作られた。
    ខ្សែភាពយន្តនេះត្រូវបានផលិតឡើងដោយផ្អែកលើ (យកជាមូលដ្ឋានពី) ព្រឹត្តិការណ៍ជាក់ស្តែង។
    ```

#### ២. ～を頼りに vs. ～に頼る
- **～に頼る**: ជាកិរិយាសព្ទផ្ទាល់ (`Noun + に頼る`) មានន័យទូទៅថា "ពឹងផ្អែកលើ..." ដែលអាចសំដៅលើការពឹងផ្អែកខាងហិរញ្ញវត្ថុ ការពឹងលើជំនួយអ្នកដទៃទូទៅ។
  - ឧទាហរណ៍៖ `彼は親友に頼った。` (គាត់បានពឹងពាក់មិត្តសម្លាញ់របស់គាត់។)
- **～を頼りに**: ជាកន្សោមគុណកិរិយាដែលភ្ជាប់ជាមួយសកម្មភាពមួយទៀត (`Noun + を頼りに + Action`) ដើម្បីបង្ហាញពីរបៀបរបបនៃការបំពេញសកម្មភាពនោះ។

#### ៣. ～を頼りに vs. ～を用いて
- **～を用いて (〜をもちいて)**: សង្កត់ធ្ងន់លើ «ការប្រើប្រាស់ឧបករណ៍ ឬវិធីសាស្ត្រ» ក្នុងន័យបច្ចេកទេស និងផ្លូវការ ដោយគ្មានបង្កប់ន័យអំពីការពឹងផ្អែក ឬអារម្មណ៍ស្វែងរកបង្អែកក្នុងគ្រាលំបាកនោះឡើយ។
  - ឧទាហរណ៍៖ `新しい技術を用いて、製品を開発した。` (បានអភិវឌ្ឍផលិតផលដោយប្រើប្រាស់បច្ចេកវិទ្យាថ្មី។)

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ឧទាហរណ៍ប្រយោគ (Example Sentences)

1. **地図を頼りに、山道を進んだ。**
   - *ちずをたよりに、やまみちをすすんだ。*
   - ខ្ញុំបានបន្តដំណើរទៅមុខតាមផ្លូវភ្នំ ដោយពឹងផ្អែកលើផែនទីជាបង្អែក។

2. **かすかな明かりを頼りに、出口を探した。**
   - *かすかなあかりをたよりに、でぐちをさがした。*
   - ខ្ញុំបានរាវរកផ្លូវចេញ ដោយយកពន្លឺភ្លើងដ៏ស្រអាប់មួយជាទីពឹង។

3. **彼女は記憶を頼りに、その曲をピアノで演奏した。**
   - *かのじょはきおくをたよりに、そのきょくをピアノでえんそうした。*
   - នាងបានលេងបទភ្លេងនោះនៅលើព្យាណូ ដោយពឹងផ្អែកលើការចងចាំរបស់នាង (ដោយគ្មានក្រដាសភ្លេង)។

4. **暗闇の中、懐中電灯を頼りに歩いた。**
   - *くらやみのなか、かいちゅうでんとうをたよりにあるいた。*
   - នៅកណ្តាលភាពងងឹតស្លុប ខ្ញុំបានដើរទៅមុខដោយពឹងផ្អែកលើពិលជាជំនួយ។

5. **友人の言葉を頼りに、大きな決断を下した。**
   - *ゆうじんのことばをたよりに、おおきなけつだんをくだした។*
   - ខ្ញុំបានធ្វើការសម្រេចចិត្តដ៏ធំមួយ ដោយយកពាក្យសម្តីរបស់មិត្តភក្តិជាបង្អែកផ្លូវចិត្ត។

6. **昔の人々は、夜空の星座を頼りにして航海を続けた。**
   - *むかしのひとびとは、よぞらのせいざをたよりにしてこうかいをつづけた。*
   - មនុស្សពីបុរាណបានបន្តការធ្វើដំណើរតាមសមុទ្រ ដោយពឹងផ្អែកលើក្រុមផ្កាយនៅលើមេឃពេលយប់ជាតម្រុយទិសដៅ។

7. **祖父は杖を頼りとした生活を送っている。**
   - *そふはつえをたよりとしたせいかつをおくっている。*
   - លោកតារបស់ខ្ញុំកំពុងរស់នៅដោយពឹងផ្អែកលើឈើច្រត់ជាជំនួយទ្រទ្រង់រាងកាយ។

## ៥. កំណត់សម្គាល់វប្បធម៌ និងការប្រើប្រាស់ (Cultural Notes)

### បរិបទនៃការប្រើប្រាស់ (Context & Politeness)
- កន្សោម **～を頼りに** មានលក្ខណៈកណ្តាល (Neutral) អាចប្រើបានទាំងនៅក្នុងការសរសេរជាផ្លូវការ (អត្ថបទ អក្សរសិល្ប៍ របាយការណ៍) និងការសន្ទនាប្រចាំថ្ងៃ។
- កម្រិតគួរសមត្រូវបានកំណត់ដោយកិរិយាសព្ទនៅចុងបញ្ចប់នៃប្រយោគ (ឧ. `進んだ` vs. `進みました`)។

### កន្សោមសំនួនវោហារពេញនិយម (Idiomatic Expressions)
- **運を頼りに (うんをたよりに)**: ដោយពឹងលើសំណាងព្រេងវាសនា
- **直感を頼りに (ちょっかんをたよりに)**: ដោយពឹងលើវិចារណញាណ / អារម្មណ៍ដឹងមុន
- **記憶を頼りに (きおくをたよりに)**: ដោយពឹងលើការចងចាំ

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes & Tips)

### កំហុសទូទៅដែលត្រូវប្រុងប្រយ័ត្ន
1. **ការប្រើធ្នាក់ខុស (Incorrect Particle)**
   - ✗ 地図**に**頼りに進んだ。(ខុស)
   - ✓ 地図**を**頼りに進んだ。(ត្រឹមត្រូវ)
   - *គន្លឹះ*: ត្រូវចាំថា មុនពាក្យ **頼りに** ត្រូវតែប្រើធ្នាក់ **を** ជានិច្ច ព្រោះវាជាកម្មបទដែលយើងពឹងផ្អែកលើ។

2. **ការច្រឡំរវាង ～を頼りに និង ～に頼る**
   - ✗ ガイド**を頼るに**旅した。(ខុស)
   - ✓ ガイド**を頼りに**旅した。(ត្រឹមត្រូវ)
   - ✓ ガイド**に頼って**旅した。(ត្រឹមត្រូវតាមទម្រង់ て)

### គន្លឹះក្នុងការរៀន
- ភ្ជាប់ពាក្យ **頼り (たより)** ទៅនឹងពាក្យខ្មែរថា "ទីពឹង / បង្អែក"។ ដូច្នេះ `[នាម] + を頼りに` គឺ "ដោយយក [នាម] ធ្វើជាទីពឹង/បង្អែក"។

## ៧. សេចក្តីសង្ខេប (Summary & Review)

### ចំណុចសំខាន់ៗដែលត្រូវចងចាំ
- **～を頼りに** បញ្ជាក់ពីការពឹងផ្អែកលើតម្រុយ ឬជំនួយណាមួយ ដើម្បីធ្វើសកម្មភាពមួយក្នុងស្ថានភាពលំបាក ឬមិនច្បាស់លាស់។
- ទម្រង់៖ **[នាម] + を頼りに / を頼りにして + [សកម្មភាព]** ឬ **[នាម ១] + を頼りとした / を頼りにした + [នាម ២]**។
- ប្រើធ្នាក់ **を** នៅពីមុខ **頼りに** ជានិច្ច។
- ខុសពី **～をもとに** (ដែលផ្តោតលើមូលដ្ឋានទិន្នន័យសម្រាប់បង្កើតអ្វីថ្មី) **～を頼りに** ផ្តោតលើតម្រុយ ឬបង្អែកដោះស្រាយការលំបាក (Guide / Lifeline)។

### សំណួរតេស្តខ្លីៗ (Quick Recap Quiz)

១. **ចូរជ្រើសរើសធ្នាក់ត្រឹមត្រូវបំពេញក្នុងចន្លោះ**: コンパス___頼りに、方向を確認した。
- **ចម្លើយ**: を

២. **ពិត ឬមិនពិត**: យើងអាចប្រើ **～を頼りに** ជាមួយកត្តាអរូបីខាងក្នុងដូចជា «ការចងចាំ (記憶)» ឬ «វិចារណញាណ (直感)» បានដែរឬទេ?
- **ចម្លើយ**: ពិត (True)

៣. **ចូរបកប្រែប្រយោគនេះទៅជាភាសាជប៉ុន**: "ពួកគេបានដោះស្រាយល្បែងប្រាជ្ញានោះ ដោយពឹងផ្អែកលើតម្រុយ (Hints)។"
- **ចម្លើយ**: 彼らはヒントを頼りにパズルを解いた。
