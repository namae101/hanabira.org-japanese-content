# ចំណុចវេយ្យាករណ៍ជប៉ុន: ～ば～のに (〜ba 〜noni)
**កម្រិត JLPT:** JLPT N3

---

## ១. សេចក្តីផ្តើម (Introduction)

ទម្រង់វេយ្យាករណ៍ **～ば～のに (〜ba 〜noni)** ត្រូវបានប្រើប្រាស់ជាទូទៅក្នុងភាសាជប៉ុន ដើម្បីបង្ហាញពីអារម្មណ៍សោកស្តាយ (regret) ការមិនពេញចិត្តចំពោះលទ្ធផលជាក់ស្តែង (dissatisfaction) ឬការស្រមើស្រមៃចង់ឱ្យរឿងរ៉ាវអ្វីមួយកើតឡើងផ្ទុយពីការពិត (wistful longing / counterfactual desire)។ 

ទម្រង់នេះមានន័យជាភាសាខ្មែរថា **«ប្រសិនបើ... ប្រហែលជាល្អ / តែគួរឱ្យស្តាយ...»** ឬ **«ឱ្យតែ... ម្ល៉េះសម... ទៅហើយ តែការពិតមិនដូច្នោះសោះ»**។ ការយល់ដឹងច្បាស់ពីទម្រង់នេះ ជួយឱ្យអ្នកអាចបង្ហាញពីមនោសញ្ចេតនា និងភាពខកបំណងយ៉ាងស៊ីជម្រៅចំពោះរឿងរ៉ាវដែលកន្លងផុតទៅ ឬលក្ខខណ្ឌដែលមិនអាចសម្រេចបានក្នុងការពិត។

---

## ២. ពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **បង្ហាញពីការសោកស្តាយ និងការស្រែកថ្ងូរចំពោះរឿងរ៉ាវដែលមិនបានកើតឡើងដូចការចង់បាន (Counterfactual Regret/Lamentation)។**
- បង្ហាញពីលក្ខខណ្ឌសន្មតផ្ទុយពីការពិត (Unrealized condition) និងលទ្ធផលល្អដែលគួរតែកើតមាន ប៉ុន្តែជាក់ស្តែងមិនបានកើតឡើងឡើយ។
- ប្រែថា៖ «ប្រសិនបើ... (ម្ល៉េះសមល្អ) តែគួរឱ្យស្តាយ...», «ឱ្យតែ... ម្ល៉េះសម... ទៅហើយ»។

### ទម្រង់វេយ្យាករណ៍ (Structure)

ទម្រង់នេះផ្សំឡើងដោយកិរិយាសព្ទ ឬគុណនាមក្នុងទម្រង់លក្ខខណ្ឌ **～ば** រួចភ្ជាប់ដោយឈ្នាប់ **のに** (ឬមានឃ្លាលទ្ធផលនៅចន្លោះ ដូចជា `[លក្ខខណ្ឌ-ば] + [លទ្ធផល] + のに`)៖

```
[កិរិយាសព្ទ/គុណនាម ទម្រង់លក្ខខណ្ឌ ～ば] + (ឃ្លាលទ្ធផល) + のに
```

> **ចំណាំ:** នៅក្នុងការសន្ទនាប្រចាំថ្ងៃ គេច្រើនបញ្ចប់ឃ្លាត្រឹម `[កិរិយាសព្ទ-ば] + (よかった) + のに` ឬកាត់ត្រឹម `〜ばのに` ដើម្បីបង្ហាញពីអារម្មណ៍សោកស្តាយដោយមិនបាច់រៀបរាប់លទ្ធផលវែងឆ្ងាយ។

### តារាងបំប្លែងទម្រង់ (Formation Diagram)

| ប្រភេទពាក្យ / ទម្រង់ដើម | របៀបបំប្លែងទៅជាទម្រង់ ～ば | ភ្ជាប់ជាមួយ のに |
| :--- | :--- | :--- |
| **កិរិយាសព្ទ (動詞)** | | |
| 買う (ទិញ) | 買えば | 買えばのに / 買えばよかったのに |
| 行く (ទៅ) | 行けば | 行けばのに / 行けばよかったのに |
| 食べる (ញ៉ាំ) | 食べれば | 食べればのに / 食べればよかったのに |
| する (ធ្វើ) | すれば | すればのに / すればよかったのに |
| 来る (មក) | 来れば（くれば） | 来ればのに / 来ればよかったのに |
| **គុណនាម い (い形容詞)** | | |
| 安い (ថោក) | 安ければ | 安ければ買うのに |
| いい (ល្អ) | よければ | よければ行くのに |
| **គុណនាម な / នាម** | | |
| 暇 (ទំនេរ) | 暇ならば / 暇であれば | 暇なら手伝うのに |
| 天気 (អាកាសធាតុ) | 天気ならば / 天気であれば | いい天気なら出かけるのに |

### របៀបបំប្លែងទៅជាទម្រង់លក្ខខណ្ឌ ～ば (How to Form the Conditional ～ば Form)

1. **កិរិយាសព្ទក្រុមទី ១ (五段動詞 - Godan):** ប្តូរសំឡេងស្រៈជួរ `-u` ទៅជាជួរ `-e` រួចថែម **ば**
   - 買う (kau) → **買えば (kaeba)**
   - 書く (kaku) → **書けば (kakeba)**
   - 話す (hanasu) → **話せば (hanaseba)**
2. **កិរិយាសព្ទក្រុមទី ២ (一段動詞 - Ichidan):** កាត់ **る** ចេញ រួចថែម **れば**
   - 食べる (taberu) → **食べれば (tabereba)**
   - 見る (miru) → **見れば (mireba)**
   - 起きる (okiru) → **起きれば (okireba)**
3. **កិរិយាសព្ទមិនទៀងទាត់ (不規則動詞):**
   - する → **すれば (sureba)**
   - 来る（くる） → **来れば（くれば - kureba)**
4. **គុណនាម い (い形容詞):** ប្តូរ **い** ទៅជា **ければ**
   - 早い → **早ければ (hayakereba)**
   - ない → **なければ (nakereba)**
5. **គុណនាម な និង នាម:** ថែម **なら(ば)** ឬ **であれば**
   - 元気 → **元気なら(ば)**

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance & Comparative Analysis)

### ១. លក្ខណៈផ្ទុយពីការពិត (Counterfactual Nature) នៃ ～ば～のに
- នៅក្នុងវេយ្យាករណ៍នេះ ឃ្លាខាងមុខ `[លក្ខខណ្ឌ-ば]` បង្ហាញពីស្ថានភាពដែល **ផ្ទុយស្រឡះពីការពិតជាក់ស្តែង** (unrealized condition)។
- ឃ្លាខាងក្រោយដែលមាន **のに** បង្ហាញពីលទ្ធផលល្អដែលគួរតែកើតឡើង (unrealized positive outcome) ប៉ុន្តែ **ជាក់ស្តែងមិនបានកើតឡើងឡើយ** ដោយសារតែលក្ខខណ្ឌខាងមុខមិនត្រូវបានបំពេញ។
- ឈ្នាប់ **のに** ដើរតួនាទីបញ្ជាក់ពីអារម្មណ៍ខកចិត្ត អស់សង្ឃឹម សោកស្តាយ ឬការរអ៊ូរទាំ («...ទៅហើយ តែការពិតគួរឱ្យស្តាយណាស់ដែលមិនដូច្នោះ»)។

### ២. ការប្រៀបធៀបរវាង ～ば～のに និង ～ばよかった (vs. 〜ばよかったのに)

| ចំណុចប្រៀបធៀប | ～ばよかった | ～ば～のに / ～ばよかったのに |
| :--- | :--- | :--- |
| **អត្ថន័យស្នូល** | «គួរតែបានធ្វើ... ទើបល្អ» (ការសោកស្តាយផ្ទាល់ខ្លួនចំពោះទង្វើដែលមិនបានធ្វើ) | «ប្រសិនបើ... ម្ល៉េះសម... ទៅហើយ (តែការពិតមិនដូច្នោះសោះ)» |
| **ការសង្កត់ធ្ងន់** | សង្កត់លើ **ជម្រើសល្អដែលគួរតែបានធ្វើ** ក្នុងអតីតកាល (ផ្តោតលើខ្លួនឯងច្រើន) | សង្កត់លើ **គម្លាតរវាងការរំពឹងទុក និងការពិតជាក់ស្តែងដ៏ជូរចត់** ដោយមានមនោសញ្ចេតនាសោកស្តាយ ឬរអ៊ូរទាំខ្លាំងតាមរយៈ **のに** |
| **ការប្រើប្រាស់បន្ទោសអ្នកដទៃ** | មិនសូវប្រើបន្ទោសអ្នកដទៃដោយផ្ទាល់ | អាចប្រើបន្ទោស ឬរអ៊ូរទាំដាក់អ្នកដទៃបាន (ឧ. «បើឯងប្រាប់ខ្ញុំមុន ម្ល៉េះសមមិនអីទេ!») |

*ឧទាហរណ៍:*
- **もっと勉強すればよかった。**  
  *(ខ្ញុំគួរតែខិតខំរៀនជាងនេះ - សោកស្តាយចំពោះកំហុសខ្លួនឯង)*
- **もっと勉強していれば合格できたのに。**  
  *(ប្រសិនបើខិតខំរៀនជាងនេះ ម្ល៉េះសមប្រឡងជាប់បាត់ទៅហើយ... តែការពិតធ្លាក់ គួរឱ្យស្តាយណាស់)*

### ៣. ការប្រៀបធៀបរវាង ～ば～のに និង ～たら～のに
- **～ば～のに:** ផ្តល់ការសង្កត់ធ្ងន់លើលក្ខខណ្ឌតក្កវិជ្ជា មានលក្ខណៈផ្លូវការ និងគួរសមជាងបន្តិច។
- **～たら～のに:** ផ្អែកលើទម្រង់អតីតកាល/លក្ខខណ្ឌ たら ដែលមានលក្ខណៈធម្មជាតិ និងពេញនិយមយ៉ាងខ្លាំងក្នុងការសន្ទនាប្រចាំថ្ងៃទូទៅ។
  - ឧទាហរណ៍៖ **行けばよかったのに** vs. **行ったらよかったのに** (សុទ្ធតែមានន័យថា «បើបានទៅ ម្ល៉េះសមល្អហើយ» ប៉ុន្តែ `行ったら` មានសម្លេងបែបសន្ទនាស្និទ្ធស្នាលជាង)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### បរិបទសន្ទនាទូទៅ និងស្និទ្ធស្នាល (Informal / Casual Spoken Context)

1. **もっと早く起きればのに。**  
   *Motto hayaku okireba noni.*  
   (ឱ្យតែភ្ញាក់ពីគេងលឿនជាងនេះបន្តិច ម្ល៉េះសមមិនយឺតទេ / គួរតែភ្ញាក់លឿនជាងនេះសោះ។)

2. **雨が降らなければのに。**  
   *Ame ga furanakereba noni.*  
   (បើកុំតែភ្លៀង ម្ល៉េះសមបានដើរលេងសប្បាយហើយ... គួរឱ្យស្តាយណាស់។)

3. **お金があればのに！**  
   *Okane ga areba noni!*  
   (ឱ្យតែមានលុយ ម្ល៉េះសមទិញបានបាត់ទៅហើយ!)

4. **彼女に会えればのに。**  
   *Kanojo ni aereba noni.*  
   (បើបានជួបនាង ម្ល៉េះសមល្អណាស់ទៅហើយ។)

### បរិបទគួរសម និងផ្លូវការ (Polite & Formal Context)

5. **もう少し時間があればのに。 / もう少し時間があればよかったのですが。**  
   *Mou sukoshi jikan ga areba noni. / Mou sukoshi jikan ga areba yokatta no desu ga.*  
   (ប្រសិនបើមានពេលវេលាច្រើនជាងនេះបន្តិច ប្រហែលជាល្អណាស់ ប៉ុន្តែគួរឱ្យស្តាយណាស់។)

6. **あなたも一緒に行ければのに。**  
   *Anata mo issho ni ikereba noni.*  
   (ប្រសិនបើអ្នកអាចទៅជាមួយគ្នាបាន ម្ល៉េះសមរីករាយខ្លាំងណាស់។)

7. **彼が参加すればよかったのに。**  
   *Kare ga sanka sureba yokatta noni.*  
   (ប្រសិនបើគាត់បានចូលរួម ម្ល៉េះសមជាការល្អណាស់។)

8. **この問題が解決できればのにと思っています。**  
   *Kono mondai ga kaiketsu dekireba noni to omotte imasu.*  
   (ខ្ញុំគិតថា ប្រសិនបើបញ្ហានេះអាចដោះស្រាយចេញបាន ប្រហែលជាប្រសើរខ្លាំងណាស់។)

## ៥. កំណត់សម្គាល់បែបវប្បធម៌ (Cultural Notes)

### ទំនាក់ទំនងវប្បធម៌ (Cultural Relevance)
- ការបង្ហាញពីអារម្មណ៍សោកស្តាយ (regret) ឬការស្រមើស្រមៃចង់ឱ្យរឿងរ៉ាវល្អប្រសើរជាងនេះ គឺជាទម្លាប់ទំនាក់ទំនងយ៉ាងសំខាន់ក្នុងវប្បធម៌ជប៉ុន។
- ការប្រើប្រាស់ **～ば～のに** ជួយបន្ថែមភាពទន់ភ្លន់ និងការបញ្ឆិតបញ្ឆៀង (indirectness) ស្របតាមតម្លៃនៃភាពសុភាពរាបសារ និងការរក្សាសុខដុមរមនា (和 - Wa) ក្នុងសង្គម ព្រោះការមិននិយាយចំៗអំពីការខកចិត្ត ជួយសម្រាលបរិយាកាសតានតឹង។

### កម្រិតនៃការគួរសម (Politeness Levels)
- ឃ្លាដែលបញ្ចប់ត្រឹម **のに** មានលក្ខណៈបែបអារម្មណ៍ផ្ទាល់ខ្លួន ដូច្នេះក្នុងការសន្ទនាបែបផ្លូវការ ឬនិយាយជាមួយអ្នកមានឋានៈខ្ពស់ គេច្រើនបន្ថែម **〜のですが / 〜のですが…** (ឧទាហរណ៍៖ `〜ばよかったのですが`) ដើម្បីកុំឱ្យស្តាប់ទៅដូចជាការរអ៊ូរទាំខ្លាំងពេក។

### កន្សោមពាក្យទម្លាប់ប្រើរួមគ្នា (Idiomatic Expressions)
- **残念だね。（ざんねんだね。）**  
  *Zannen da ne.*  
  (គួរឱ្យស្តាយណាស់មែនទេ?)  
  ពាក្យនេះច្រើនត្រូវបានគេប្រើប្រាស់បន្ទាប់ពីឃ្លា **～ば～のに** ដើម្បីចូលរួមសម្តែងការសោកស្តាយ និងយល់ចិត្តគ្នាក្នុងការសន្ទនា។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
- **កំហុស:** ប្រើទម្រង់អតីតកាលធម្មតាផ្ទាល់នៅពីមុខ **のに** ដោយគ្មានកិរិយាសព្ទលក្ខខណ្ឌ។
  - ❌ **行ったのに。** (ឃ្លានេះមានន័យថា «ទាំងដែលបានទៅហើយសោះ...» - ជាការបង្ហាញពីភាពផ្ទុយគ្នានៃការពិត មិនមែនជាការសន្មតសោកស្តាយឡើយ)។
- **កែតម្រូវ:** ត្រូវប្រើប្រាស់ទម្រង់លក្ខខណ្ឌ **～ば** (ឬ 〜ばよかった) នៅពីមុខ **のに**៖
  - ✔️ **行けばのに。** ឬ **行けばよかったのに。** («ប្រសិនបើបានទៅ ម្ល៉េះសមល្អហើយ...»)។

### គន្លឹះក្នុងការរៀន (Learning Strategies)
- **រូបមន្តចងចាំ:** ចងចាំថា **ば** គឺជាលក្ខខណ្ឌ «ប្រសិនបើ» ហើយ **のに** គឺជាអារម្មណ៍ «តែគួរឱ្យស្តាយ / បែរជាមិនដូច្នោះ»។ នៅពេលផ្គុំចូលគ្នា វានឹងបង្កើតបានជាអត្ថន័យ «ប្រសិនបើ... ម្ល៉េះសមល្អហើយ តែគួរឱ្យស្តាយណាស់»។
- **ការអនុវត្ត:** សាកល្បងបង្កើតប្រយោគអំពីស្ថានភាពជាក់ស្តែងក្នុងជីវិតប្រចាំថ្ងៃដែលមិនបានសម្រេចដូចបំណង ដើម្បីឱ្យមានភាពស្ទាត់ជំនាញ។

## ៧. សង្ខេប និងរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～ば～のに** ប្រើដើម្បីបង្ហាញពីការសោកស្តាយ អារម្មណ៍ខកបំណង ឬការស្រមើស្រមៃចង់ឱ្យស្ថានភាពផ្ទុយពីការពិត។
- កើតចេញពី **ទម្រង់លក្ខខណ្ឌ ～ば** បូកផ្សំជាមួយ **のに** (ឬភ្ជាប់ឃ្លាលទ្ធផលនៅកណ្តាល)។
- មានន័យសមមូលនឹងភាសាខ្មែរថា «ប្រសិនបើ... (ម្ល៉េះសមល្អ) តែគួរឱ្យស្តាយ...» ឬ «ឱ្យតែ... ម្ល៉េះសម... ទៅហើយ»។

### សំណួររំលឹកចំណេះដឹងរហ័ស (Quick Recap Quiz)

១. តើអ្នកអាចនិយាយថា «ប្រសិនបើខ្ញុំអាចនិយាយភាសាជប៉ុនបាន ម្ល៉េះសមល្អណាស់» ដោយប្រើ ～ば～のに យ៉ាងដូចម្តេច?  
   **ចម្លើយ:** 日本語が話せればのに。 (ឬ 日本語が話せればよかったのに。)

២. ចូរកំហុស និងកែតម្រូវប្រយោគនេះឱ្យត្រឹមត្រូវ៖ 早く寝たのに。  
   **ចម្លើយ:** ប្រយោគនេះប្រើប្រាស់ទម្រង់អតីតកាល `寝た` ជំនួសឱ្យទម្រង់លក្ខខណ្ឌ។ កែតម្រូវជា៖ **早く寝ればのに。** (ឬ **早く寝ればよかったのに。**)

៣. ចូរបកប្រែជាភាសាជប៉ុន៖ «បើកុំតែភ្លៀង ម្ល៉េះសមល្អហើយ (តែគួរឱ្យស្តាយដែលភ្លៀង)»  
   **ចម្លើយ:** 雨が降っていなければのに。 (ឬ 雨が降らなければのに。)
