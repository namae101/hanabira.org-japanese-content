# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～ままに (〜mama ni)
**កម្រិត JLPT:** JLPT N2

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ **～ままに (〜mama ni)** ត្រូវបានប្រើប្រាស់ដើម្បីបង្ហាញអំពីការធ្វើសកម្មភាពអ្វីមួយ «ទៅតាម...», «ស្របតាម...», «តាមតែ...» ឬ «បណ្តោយទៅតាម...»។ ទម្រង់នេះបង្កប់នូវអត្ថន័យនៃការធ្វើអ្វីមួយដោយឥតទប់ទល់ ធ្វើតាមការបញ្ជា ឬការទាញនាំពីកម្លាំងខាងក្រៅ (submission to external forces) ឬក៏ធ្វើទៅតាមការជំរុញនៃអារម្មណ៍ ចិត្តគំនិត និងទំនោរពីធម្មជាតិដោយសេរីឥតលាក់បាំង។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **ទៅតាម... / ស្របតាម... / តាមតែ... / បណ្តោយតាម...** (Just as / following one's heart, whim, or command)

### ទម្រង់តភ្ជាប់ (Structure)
ទម្រង់នេះភ្ជាប់ជាមួយកិរិយាសព្ទ (ទម្រង់ដើម/វចនានុក្រម, ទម្រង់អកម្ម 受身形, ឬទម្រង់អតីតកាល た) និងនាមភ្ជាប់ជាមួយឈ្នាប់ の៖

| ទម្រង់ពាក្យ (Word Form) | ការផ្គុំជាមួយ ままに | ឧទាហរណ៍ |
| :--- | :--- | :--- |
| **កិរិយាសព្ទ ទម្រង់វចនានុក្រម (Verb-る)** | + ままに | 思うままに, 吹くままに |
| **កិរិយាសព្ទ ទម្រង់អកម្ម (Verb-受身 / られる)** | + ままに | 言われるままに, 誘われるままに |
| **កិរិយាសព្ទ ទម្រង់អតីតកាល (Verb-た)** | + ままに | 感じたままに, 見たままに |
| **នាម (Noun) + の** | + ままに | 心のままに, 運命のままに |

### ដ្យាក្រាមទម្រង់ (Formation Diagram)
```
[ Verb (辞書形 / 受身形 / た形) ] + ままに
[ Noun + の ]                      + ままに
```

### ការពន្យល់លម្អិត (Detailed Explanation)
1. **កិរិយាសព្ទអកម្ម + ままに (Verb-受身 + ままに):**
   - ឧទាហរណ៍៖ `言われるがままに`, `言われるままに`, `促されるままに`
   - បង្ហាញពីការធ្វើតាមការប្រាប់ ការបង្គាប់បញ្ជា ឬការទាញនាំរបស់អ្នកដទៃទាំងស្រុង ដោយមិនមានការប្រឆាំង ឬគ្មានគំនិតជំទាស់ឡើយ (បណ្តោយតាមគេបង្គាប់)។
2. **កិរិយាសព្ទ/នាមទាក់ទងនឹងអារម្មណ៍ ឬចិត្តគំនិត + ままに:**
   - ឧទាហរណ៍៖ `心のままに`, `思うままに`, `気の向くままに`, `足の向くままに`
   - បង្ហាញពីការធ្វើអ្វីមួយតាមតែអារម្មណ៍ចង់ តាមតែការនឹកឃើញ ឬតាមទំនោរចិត្តដោយសេរី គ្មានការបង្ខិតបង្ខំ ឬការគិតគិតគូរវែងឆ្ងាយ។

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative & Nuance Analysis)

### ការប្រៀបធៀបរវាង ～ままに (〜mama ni) និង ～とおりに (〜toori ni)

| លក្ខណៈវិនិច្ឆ័យ | ～ままに (〜mama ni) | ～とおりに (〜toori ni) |
| :--- | :--- | :--- |
| **កម្រិត JLPT** | **JLPT N2** (កម្រិតខ្ពស់ / អក្សរសិល្ប៍) | **JLPT N3/N4** (កម្រិតមធ្យម / ជីវភាពប្រចាំថ្ងៃ) |
| **អត្ថន័យស្នូល** | ធ្វើតាមការជំរុញនៃចិត្ត/អារម្មណ៍ ឬបណ្តោយតាមកម្លាំងខាងក្រៅដោយគ្មានការទប់ទល់ | ធ្វើតាមគំរូ ការណែនាំ ផែនការ ឬលំដាប់លំដោយយ៉ាងជាក់លាក់ (១០០%) |
| **ស្មារតី/ការផ្ចង់គិត** | កើតឡើងដោយឯកឯង (spontaneous) គ្មានការប្រឆាំង ឬបណ្តោយខ្លួនទៅតាមយថាកម្ម | មានចេតនាផ្ចិតផ្ចង់ប្រុងប្រយ័ត្នដើម្បីកុំឱ្យខុសពីគំរូដើម (faithful reproduction) |
| **កម្រិតភាសា (Register)** | បែបអក្សរសិល្ប៍ (Literary), កំណាព្យ, ឬបង្កប់មនោសញ្ចេតនាស៊ីជម្រៅ | ភាសានិយាយទូទៅ និងការណែនាំផ្លូវការ (សៀវភៅណែនាំ, ធ្វើម្ហូប, ធ្វើតេស្ត) |
| **កន្សោមប្រើញឹកញាប់** | `思うままに` (តាមការគិត/ចង់)<br>`言われるがままに` (តាមតែគេប្រាប់)<br>`足の向くままに` (តាមតែជើងនាំទៅ) | `説明書のとおりに` (តាមសៀវភៅណែនាំ)<br>`計画のとおりに` (តាមផែនការ)<br>`言ったとおりに` (ដូចអ្វីដែលបាននិយាយ) |

#### ចំណុចខុសគ្នាសំខាន់ៗ៖
- **～とおりに:** ផ្តោតលើភាពត្រឹមត្រូវដូចគ្នាឥតលម្អៀងរវាងសកម្មភាព និងប្រភពដើម ដូចជាការដំឡើងគ្រឿងម៉ាស៊ីនតាមសៀវភៅណែនាំ (`マニュアルのとおりに組み立てる`)។ ក្នុងករណីនេះ គេ**មិនអាច**ប្រើ `マニュアルのままに` បានឡើយ។
- **～ままに:** ផ្តោតលើការ «គ្មានការទប់ទល់» ឬ «បណ្តោយតាមអារម្មណ៍/កម្លាំងខាងក្រៅ»។ ឧទាហរណ៍ `言われるがままに契約書にサインした` មានន័យថាចុះហត្ថលេខាលើកិច្ចសន្យាដោយបណ្តោយតាមតែគេប្រាប់ គ្មានស្មារតីទប់ទល់ ឬមិនបានពិចារណាឱ្យដិតដល់ឡើយ។ រីឯ `足の向くままに歩く` បង្ហាញពីការដើរដោយបណ្តោយតាមតែជើងចង់បោះទៅ ដោយគ្មានគោលដៅកំណត់ទុកជាមុន។

---

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ប្រយោគគំរូ (Example Sentences)

1. **言われるままに書類にサインしてしまった。**
   - *I signed the document just as I was told (without thinking/resisting).*
   - ខ្ញុំបានចុះហត្ថលេខាលើឯកសារទាំងបណ្តោយតាមតែគេប្រាប់ (ដោយមិនបានពិចារណា ឬទប់ទល់ឡើយ)។

2. **他人の意見に惑わされず、自分の心のままに生きたい。**
   - *I want to live following my own heart, without being swayed by the opinions of others.*
   - ខ្ញុំចង់រស់នៅតាមតែបេះដូងរបស់ខ្លួនឯង ដោយមិនខ្វល់ខ្វាយ ឬរវើរវាយតាមសម្តីរបស់អ្នកដទៃឡើយ។

3. **感じたままにキャンバスに絵を描いてみました。**
   - *I tried painting on the canvas just as I felt.*
   - ខ្ញុំបានសាកល្បងគូរគំនូរលើផ្ទាំងក្រណាត់ ទៅតាមអារម្មណ៍ដែលខ្ញុំទទួលបានជាក់ស្តែង។

4. **友達に誘われるままに、特に目的もなく旅行に行った。**
   - *I went on a trip just because my friend invited me, without any particular purpose.*
   - ខ្ញុំបានទៅដំណើរកម្សាន្តទាំងបណ្តោយតាមតែមិត្តភក្តិបបួល ដោយគ្មានគោលបំណងអ្វីជាក់លាក់ឡើយ។

5. **どうぞ、思うままに率直なご意見をお聞かせください。**
   - *Please feel free to share your candid opinions just as you think.*
   - សូមលោក/អ្នកបញ្ចេញមតិយោបល់ដោយឥតលាក់លៀម តាមតែចិត្តគិតដោយសេរី។

6. **波の寄せるままに、小舟は沖へと流されていった。**
   - *Drifting with the incoming waves, the small boat was carried out into the open sea.*
   - ទូកតូចបានរសាត់អណ្តែតទៅកាន់សមុទ្រធំ តាមតែការរុញច្រាននៃទឹករលក។

### បរិបទនៃការប្រើប្រាស់ (Usage Register)
- **បរិបទផ្លូវការ និងអក្សរសិល្ប៍ (Formal / Literary Context):** ប្រើប្រាស់ញឹកញាប់ក្នុងស្នាដៃអក្សរសិល្ប៍ ប្រលោមលោក អត្ថបទតែងសេចក្តី និងសុន្ទរកថាផ្លូវការ ដើម្បីបង្ហាញពីទស្សនវិជ្ជាជីវិត មនោសញ្ចេតនា ឬស្ថានភាពយថាកម្ម។
- **ការសន្ទនាប្រចាំថ្ងៃ (Conversational Context):** កម្រប្រើក្នុងការជជែកលេងទូទៅ ប៉ុន្តែត្រូវបានគេប្រើក្នុងទម្រង់ទូទៅមួយចំនួនដូចជា `言われるままに` (តាមតែគេប្រាប់) ឬ `気の向くままに` (តាមតែការនឹកឃើញ)។

## ៥. ចំណាំវប្បធម៌ និងការយល់ដឹងពីសង្គមជប៉ុន (Cultural Notes)

### ទំនាក់ទំនងវប្បធម៌ (Cultural Relevance)
នៅក្នុងសង្គមជប៉ុន ការរក្សាសុខដុមនីយកម្មសង្គម (和 - Wa) និងការគោរពតាមការដឹកនាំរបស់ក្រុមមានសារៈសំខាន់ខ្លាំង។ ការប្រើប្រាស់ទម្រង់ដូចជា `言われるがままに` ឬ `促されるままに` ជារឿយៗឆ្លុះបញ្ចាំងពីការសម្របខ្លួនតាមអ្នកដទៃ ឬការបណ្តោយតាមការចាត់ចែងរបស់មនុស្សជុំវិញខ្លួន។ ផ្ទុយទៅវិញ ក្នុងបរិបទសិល្បៈ និងការបញ្ចេញមតិ ឃ្លា `心のままに` ឬ `思うままに` បង្ហាញពីការដោះលែងចិត្តគំនិតឱ្យមានសេរីភាពពេញលេញផុតពីក្រឹត្យក្រមសង្គមតឹងរ៉ឹង។

### កម្រិតគួរសម (Politeness Levels)
ទម្រង់ ～ままに ខ្លួនឯងគឺជាទម្រង់កណ្តាល (neutral)។ កម្រិតគួរសមត្រូវបានកំណត់ដោយកិរិយាសព្ទបញ្ចប់ប្រយោគ (ឧទាហរណ៍ បញ្ចប់ដោយ `〜ました` / `〜てください` សម្រាប់គួរសម ឬ `〜た` សម្រាប់ស្និទ្ធស្នាល)។

### កន្សោម Idiomatic ពេញនិយម
- **身を任せるままに (み を まかせる まま に):** បណ្តោយខ្លួនទៅតាមយថាកម្ម / បណ្តោយទៅតាមព្រឹត្តិការណ៍ចំពោះមុខ។
- **足の向くままに (あし の むく まま に):** ដើរទៅតាមតែជើងនាំទៅ (ដើរដោយគ្មានទិសដៅ ឬផែនការទុកជាមុន)។
- **気の向くままに (き の むく まま に):** ធ្វើទៅតាមតែអារម្មណ៍នឹកឃើញ ឬតាមតែចំណង់ចិត្តនៅពេលនោះ។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes & Tips)

### ការវិភាគកំហុស (Error Analysis)
- **កំហុសទី ១៖** ប្រើប្រាស់ ～ままに ជាមួយគុណនាមដោយផ្ទាល់។
  - *ខុស:* 嬉しいままに踊った。
  - *ត្រូវ:* 嬉しさのあまり踊った。 (ប្រើ `〜あまり` សម្រាប់អារម្មណ៍លើសលប់) ឬ `思うままに踊った` (រាំតាមចិត្តចង់)។
  - *ការពន្យល់:* ～ままに ប្រើប្រាស់ជាមួយកិរិយាសព្ទ (Verb) ឬនាម (Noun + の) ប៉ុណ្ណោះ។
- **កំហុសទី ២៖** ច្រឡំ ～ままに ជាមួយ ～ながら (ខណៈពេល / ស្របពេល)។
  - *ការពន្យល់:* ～ながら បង្ហាញពីសកម្មភាពពីរដែលធ្វើឡើងក្នុងពេលដំណាលគ្នា (Simultaneous actions) រីឯ ～ままに បង្ហាញពីស្ថានភាពនៃការធ្វើសកម្មភាព «ស្របតាម / បណ្តោយតាម» ឥទ្ធិពលអ្វីមួយ។

### គន្លឹះចងចាំ (Mnemonic / Learning Strategy)
ចងចាំពាក្យ **まま (Mama)** ក្នុងន័យ «សភាពដើម / ស្រេចតែ» ដូចក្នុងពាក្យ `そのまま` (ទុកឱ្យនៅដដែល)។ ដូច្នេះ **～ままに** គឺការបណ្តោយឱ្យសកម្មភាពប្រព្រឹត្តទៅ «តាមសភាពដែលវាមាន ឬតាមតែការចង់បាន/ការបង្គាប់» ដោយគ្មានការផ្លាស់ប្តូរ ឬការទប់ទល់ឡើយ។

## ៧. សង្ខេប និងលំហាត់រំលឹកឡើងវិញ (Summary & Review)

### ចំណុចសំខាន់ៗដែលត្រូវចងចាំ
1. **～ままに** មានន័យថា «ធ្វើទៅតាម... / បណ្តោយតាម... / ស្របតាម...»។
2. ទម្រង់វេយ្យាករណ៍៖ **[Verb-る / Verb-受身 / Verb-た] + ままに** ឬ **[Noun + の] + ままに**។
3. បង្កប់ន័យធ្វើតាមការជំរុញនៃចិត្ត/អារម្មណ៍ (spontaneity) ឬបណ្តោយតាមកម្លាំង/ការបញ្ជាខាងក្រៅដោយគ្មានការប្រឆាំង (submission)។
4. ខុសពី **～とおりに** ត្រង់ថា ～とおりに សង្កត់ធ្ងន់លើការធ្វើតាមគំរូជាក់លាក់ ១០០% (faithful accuracy) ខណៈ ～ままに មានលក្ខណៈអក្សរសិល្ប៍ និងផ្តោតលើអារម្មណ៍/យថាកម្ម។

### កម្រងសំណួររហ័ស (Quick Recap Quiz)

**សំណួរទី ១:** ចូរជ្រើសរើសចម្លើយត្រឹមត្រូវដើម្បីបំពេញចន្លោះប្រហោង៖  
彼に命令される______、何も言えずに従った。  
(A) とおり  
(B) ままに  
(C) ながら  
*ចម្លើយ:* **(B) ままに** (បង្ហាញពីការបណ្តោយតាមបញ្ជាគេដោយគ្មានការប្រឆាំង)

**សំណួរទី ២:** ប្រែប្រយោគខាងក្រោមនេះជាភាសាខ្មែរ៖  
「心のままに選んでください。」  
*ចម្លើយ:* «សូមជ្រើសរើសទៅតាមតែបេះដូងរបស់អ្នកចង់បានចុះ។»

**សំណួរទី ៣:** តើប្រយោគ «レシピのままにケーキを焼いた» ត្រឹមត្រូវតាមក្បួនភាសាជប៉ុនដែរឬទេ?  
*ចម្លើយ:* **មិនត្រឹមត្រូវទេ**។ ការធ្វើនំតាមសៀវភៅរូបមន្តច្បាស់លាស់ ត្រូវប្រើ «レシピのとおりにケーキを焼いた» ពីព្រោះវាជាការធ្វើតាមការណែនាំជាជំហានៗយ៉ាងជាក់លាក់ មិនមែនជាការបណ្តោយតាមអារម្មណ៍ឡើយ។
