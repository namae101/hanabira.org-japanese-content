Processing keyword: Noun ごとき - Noun ごとく (〜gotoki-〜gotoku)
# ចំណុចវេយ្យាករណ៍ភាសាយ៉ាពីន: Noun ごとき - Noun ごとく (〜gotoki-〜gotoku)
**កម្រិត JLPT:** JLPT N1

---

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់ **〜ごとき** និង **〜ごとく** ត្រូវបានប្រើប្រាស់ក្នុងភាសាជប៉ុនសម្រាប់ធ្វើការប្រៀបធៀប (Simile/Metaphor) ដែលមានន័យថា «ដូចជា / ប្រៀបដូចជា / ហាក់បីដូចជា» ឬសម្រាប់បង្ហាញពីការបន្ទាបខ្លួន / មើលងាយវាយតម្លៃទាប «មនុស្សដូចជា... / កម្រិតត្រឹមតែ... / មុខដូចជា...»។ ទម្រង់នេះមានដើមកំណើតមកពីភាសាជប៉ុនបុរាណ (Classical Japanese 文語) ហើយផ្តល់នូវរំញោចបែបផ្លូវការ អក្សរសាស្ត្រ រូបារម្មណ៍កំណាព្យ ឬពាក្យស្លោកបុរាណ ព្រមទាំងត្រូវបានគេប្រើយ៉ាងទូលំទូលាយក្នុងអត្ថបទសរសេរ សុន្ទរកថាផ្លូវការ និងការបញ្ចេញអារម្មណ៍បែបផ្លូវការខ្លាំង។

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### ការពន្យល់លម្អិត (Detailed Explanation)
- **ごとき (如き):**  
  ដើរតួជាគុណនាមសម្រាប់កែប្រែនាម (Adnominal modifier) ដែលភ្ជាប់ទៅនឹងនាមខាងក្រោយ (`Noun + ごとき + Noun` ឬ `[Verb 辞書形 / た形] + (が)ごとき + Noun`) មានន័យថា «ដែលដូចជា... / ប្រៀបដូចជា...» ឬ «កម្រិតត្រឹម... / មនុស្សដូចជា... (ពេលបន្ទាបខ្លួន ឬមើលងាយ)»។
  
- **ごとく (如く):**  
  ដើរតួជាកិរិយាសព្ទវិសេសន៍ (Adverbial modifier) សម្រាប់កែប្រែកិរិយាសព្ទ ឬគុណនាម (`Noun + ごとく + Verb/Adj` ឬ `Noun + のごとく + Verb/Adj`) មានន័យថា «យ៉ាងដូចជា... / ប្រៀបដូចជា... / ហាក់បីដូចជា...»។

- **ごとし (如し):**  
  ជាទម្រង់បញ្ចប់ប្រយោគបុរាណ (Predicative form) ស្មើនឹង `〜ようだ` ក្នុងភាសាបច្ចុប្បន្ន (ឧទាហរណ៍៖ `光陰矢のごとし`)។

ទម្រង់ទាំងនេះក្លាយមកពីគុណនាមជំនួយបុរាណ «如し (ごとし)» នៅក្នុងវេយ្យាករណ៍បុរាណ (文語)។

---

### ទម្រង់ និងក្បួនផ្គុំ (Formation Patterns)

| ទម្រង់ (Pattern) | តួនាទីវេយ្យាករណ៍ (Function) | អត្ថន័យជាភាសាខ្មែរ (Khmer Meaning) |
|---|---|---|
| **Noun + ごとき + Noun**<br>*(ពេលខ្លះ: Noun + のごとき + Noun)* | កែប្រែនាម (Modifies a noun) | នាមដែលមានលក្ខណៈដូចជា... / នាមកម្រិតត្រឹម... |
| **Noun + ごとく + Verb/Adj**<br>*(ពេលខ្លះ: Noun + のごとく + Verb/Adj)* | កែប្រែកិរិយាសព្ទ ឬគុណនាម (Modifies a verb/adj) | ធ្វើសកម្មភាពយ៉ាងដូចជា... / ដូចជា... |
| **Noun / Clause + ごとし** | បញ្ចប់ប្រយោគ (Sentence-ending) | គឺប្រៀបដូចជា... (បញ្ចប់បែបបុរាណ) |

#### ឧទាហរណ៍នៃការផ្គុំរូបមន្ត
1. **Noun + ごとき + Noun**
   - **天使ごとき人**  
     *(មនុស្សដែលប្រៀបដូចជាទេវតា)*
   - **私ごとき若輩者**  
     *(មនុស្សក្មេងខ្ចីគ្មានបទពិសោធន៍ដូចជារូបខ្ញុំ)*
2. **Noun + ごとく + Verb**
   - **鳥のごとく空を飛ぶ**  
     *(ហោះហើរលើមេឃដូចជាសត្វបក្សី)*
   - **怒涛のごとく押し寄せる**  
     *(បោកបក់សម្រុកចូលមកដូចជារលកយក្ស)*

#### គំនូសតាងរូបភាព (Visual Diagram)
```
[Noun] + ごとき + [Noun]              ➔ កែប្រែនាម (ដូចជា / កម្រិតត្រឹម...)
[Noun] + (の)ごとく + [Verb / Adj]     ➔ កែប្រែកិរិយាសព្ទ/គុណនាម (យ៉ាងដូចជា...)
[Noun] + (の)ごとし                   ➔ បញ្ចប់ប្រយោគបែបបុរាណ (គឺប្រៀបដូចជា...)
```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance & Comparative Analysis)

### មុខងារស្នូលទាំងពីរនៃ 〜ごとき / 〜ごとく
ទម្រង់នេះមានមុខងារប្រើប្រាស់សំខាន់ ២ យ៉ាងដែលអ្នករៀនកម្រិត N1 ត្រូវតែញែកឱ្យដាច់ពីគ្នា៖

1. **ការប្រៀបធៀបបែបឧបមា ឬរូបារម្មណ៍កំណាព្យ (Classical Simile / Metaphor):**
   - ប្រើដើម្បីប្រៀបធៀបវត្ថុ ឬសកម្មភាពមួយទៅនឹងវត្ថុមួយទៀតយ៉ាងរស់រវើក ស្រដៀងនឹង `〜ようだ / 〜ように` ដែរ ប៉ុន្តែមានកម្រិតអក្សរសាស្ត្រខ្ពស់ (Literary/Poetic) និងផ្លូវការខ្លាំង។
   - ឧទាហរណ៍៖ `白百合のごとき少女` (ក្មេងស្រីដែលបរិសុទ្ធប្រៀបដូចជាផ្កាលីលីពណ៌ស)។

2. **ការបន្ទាបខ្លួន ឬការមើលងាយ/វាយតម្លៃទាប (Humble Belittling & Contemptuous Dismissal):**
   - **បន្ទាបខ្លួន (Humble / Self-deprecation):** ប្រើជាមួយខ្លួនឯង (第一人称) ដើម្បីបន្ទាបខ្លួនដោយសុជីវធម៌ ថាខ្លួនគ្រាន់តែជាមនុស្សតូចតាច គ្មានសមត្ថភាពធំដុំ (`私ごとき`, `自分ごとき`) ស្មើនឹង «មនុស្សតូចតាចដូចជាខ្ញុំ...»។
     - ឧទាហរណ៍៖ `私ごとき若輩者に、このような大役が務まるでしょうか。` (តើមនុស្សក្មេងខ្ចីតូចតាចដូចជារូបខ្ញុំ អាចបំពេញភារកិច្ចដ៏ធំធេងបែបនេះបានដែរឬទេ?)
   - **មើលងាយ ឬវាយតម្លៃទាបចំពោះគូប្រកួត/អ្នកដទៃ (Contempt / Disdainful Dismissal):** ប្រើលើសត្រូវ គូប្រកួត ឬឧបសគ្គតូចតាច ដើម្បីវាយតម្លៃទាប បង្ហាញការមើលស្រាល ឬកំហឹង (`お前ごとき`, `あいつごとき`, `失敗ごとき`) ស្មើនឹង «មុខដូចជាឯង... / កម្រិតត្រឹមអាក្រុមនោះ... / រឿងបរាជ័យកំប៉ិកកំប៉ុកត្រឹមប៉ុណ្ណឹង...»។
     - ឧទាហរណ៍៖ `あいつごときに負けるはずがない！` (កម្រិតត្រឹមអាម្នាក់នោះ គ្មានផ្លូវដែលខ្ញុំចាញ់វាជាដាច់ខាត!)

### តារាងប្រៀបធៀបជាមួយនឹងកន្សោមស្រដៀងគ្នា

| កន្សោមវេយ្យាករណ៍ | កម្រិតភាសា និងបរិបទ | មុខងារ និងរំញោចន័យ (Nuance) | កម្រិតនៃការបន្ទាប/មើលងាយ |
|---|---|---|---|
| **〜ごとき / ごとく** | ផ្លូវការខ្លាំង / អក្សរសាស្ត្របុរាណ (N1) | ប្រៀបធៀបបែបកំណាព្យ អក្សរសាស្ត្រ ឬប្រើសម្រាប់បន្ទាបខ្លួនខ្លាំង / មើលងាយខ្លាំង | ខ្លាំងបំផុត (បែងចែកច្បាស់រវាងខ្លួនឯង និងគូប្រជែង) |
| **〜ような / ように** | កម្រិតកណ្តាលទូទៅ (N3) | ការប្រៀបធៀបទូទៅអព្យាក្រឹត ប្រើបានទាំងនិយាយ និងសរសេរ | គ្មាន (គ្រាន់តែជាការប្រៀបធៀបសុទ្ធ) |
| **〜みたいな / みたいに** | ស្និទ្ធស្នាល / និយាយប្រចាំថ្ងៃ (N4-N3) | ការប្រៀបធៀបសាមញ្ញក្នុងភាសានិយាយ មិនផ្លូវការ | គ្មាន (ការប្រៀបធៀបធម្មតា) |
| **〜なんか / なんて** | ភាសានិយាយទូទៅ / មិនផ្លូវការ | ប្រើដើម្បីវាយតម្លៃទាប មើលស្រាល ឬបន្ទាបខ្លួនក្នុងការសន្ទនា | ស្រដៀងគ្នាក្នុងន័យមើលស្រាល តែជាភាសានិយាយសាមញ្ញ |

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ឧទាហរណ៍ប្រយោគ (Sentence Examples)
1. **忍者ごとき影**  
   *ស្រមោលមួយដែលរហ័សរហួនប្រៀបដូចជាអ្នកក្បាច់គុននីនចា*
2. **彼は風のごとく走った。**  
   *គាត់បានរត់យ៉ាងលឿនដូចជាខ្យល់បក់អញ្ចឹង។*
3. **ガラスのごとき繊細な心を持つ女性**  
   *ស្ត្រីដែលមានបេះដូងទន់ជ្រាយងាយបែកបាក់ប្រៀបដូចជាកញ្ចក់។*
4. **ライオンのごとく強い心**  
   *ចិត្តដ៏រឹងមាំអង់អាចប្រៀបដូចជាសត្វតោ។*
5. **彼らは夢幻のごとく消え去った。**  
   *ពួកគេបានរលាយបាត់ទៅហាក់បីដូចជាសុបិននិងស្រមោលបំភាន់ភ្នែក។*
6. **私ごとき未熟者に、温かい励ましのお言葉をいただき感謝いたします。**  
   *(បន្ទាបខ្លួន)* *ខ្ញុំសូមថ្លែងអំណរគុណយ៉ាងជ្រាលជ្រៅចំពោះពាក្យលើកទឹកចិត្តដ៏កក់ក្តៅដែលបានផ្តល់ឱ្យមនុស្សមិនទាន់គ្រប់ទឹកដូចជារូបខ្ញុំ។*
7. **一回の試験の失敗ごときで、夢を諦めてたまるか。**  
   *(វាយតម្លៃទាប)* *គ្រាន់តែបរាជ័យក្នុងការប្រឡងមួយដងកំប៉ិកកំប៉ុកប៉ុណ្ណឹង តើឱ្យខ្ញុំបោះបង់ក្តីស្រមៃយ៉ាងម៉េចនឹងកើត!*

### បម្រែបម្រួលតាមបរិបទ (Context Variations)
- **អត្ថបទសរសេរ/ផ្លូវការ (Formal/Written):** ការប្រើប្រាស់ **ごとき / ごとく** ស័ក្តិសមបំផុតនៅក្នុងអត្ថបទអត្ថបទតែងសេចក្តី អក្សរសិល្ប៍ របាយការណ៍កម្រិតខ្ពស់ ឬសុន្ទរកថាផ្លូវការ។
- **ការពិពណ៌នាបែបកំណាព្យ (Poetic Expressions):** ផ្តល់នូវរូបារម្មណ៍យ៉ាងរស់រវើក ធ្វើឱ្យប្រយោគមានសោភ័ណភាព និងទម្ងន់ទស្សនវិជ្ជា។

---

## ៥. កំណត់សម្គាល់វប្បធម៌ (Cultural Notes)

### ទំនាក់ទំនងវប្បធម៌ (Cultural Relevance)
- **ភាសាកំណាព្យ និងអក្សរសិល្ប៍:** អក្សរសិល្ប៍ជប៉ុនបុរាណនិងសម័យទំនើបតែងតែនិយមប្រើ **ごとき / ごとく** ដើម្បីបង្កើតរូបភាពអារម្មណ៍ជ្រាលជ្រៅ និងចលនាធម្មជាតិ។
- **វប្បធម៌បន្ទាបខ្លួន (Kenjou / 謙譲):** ការប្រើ `私ごとき` បង្ហាញពីការបន្ទាបខ្លួនយ៉ាងខ្លាំងតាមទំនៀមទម្លាប់ជប៉ុន នៅពេលដែលបុគ្គលម្នាក់ទទួលបានការសរសើរ តួនាទីធំ ឬកិត្តិយសពីអ្នកដទៃ។

### កម្រិតនៃការគួរសម និងភាពផ្លូវការ (Levels of Politeness and Formality)

| កន្សោម (Expression) | កម្រិតគួរសម (Politeness Level) | បរិបទនៃការប្រើប្រាស់ (Usage Context) |
|---|---|---|
| **〜ごとき / ごとく** | ផ្លូវការខ្លាំង / បុរាណ | អក្សរសិល្ប៍, សុន្ទរកថាផ្លូវការ, ការបន្ទាបខ្លួន/មើលងាយកម្រិតខ្ពស់ |
| **〜ような / ように** | កណ្តាល / គួរសមទូទៅ | ការសន្ទនាទូទៅ, អត្ថបទសារព័ត៌មាន, ភាសាសរសេរទូទៅ |
| **〜みたいな / みたいに** | មិនផ្លូវការ / ធម្មតា | ការសន្ទនាស្និទ្ធស្នាលជាមួយមិត្តភក្តិ |

### សុភាសិត និងកន្សោមពាក្យស្លោកល្បីៗ (Idiomatic Expressions)
- **光陰矢のごとし (こういんやのごとし):**  
  *ពេលវេលាហោះហើរលឿនដូចព្រួញ (ពេលវេលាកន្លងផុតទៅលឿនណាស់)។*
- **風林火山 - 速きこと風のごとく、徐かなること林のごとく (はやきことかぜのごとく、しずかなることやまのごとく):**  
  *យុទ្ធសាស្ត្រយោធារបស់ Takeda Shingen: «លឿនដូចខ្យល់ ស្ងប់ស្ងាត់ដូចព្រៃព្រឹក្សា»។*
- **鬼のごとき強さを持つ (おにのごときつよさをもつ):**  
  *មានកម្លាំងខ្លាំងក្លាអស្ចារ្យប្រៀបដូចជាយក្ស/បិសាច។*

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
1. **ប្រើច្រឡំក្នុងភាសានិយាយប្រចាំថ្ងៃ:**  
   ការយក **ごとき / ごとく** មកប្រើក្នុងការជជែកលេងជាមួយមិត្តភក្តិធម្មតា (លើកលែងតែមានបំណងនិយាយលេងសើចបែបតួអង្គគំនូរជីវចល Anime ឬមើលងាយគេខ្លាំង) អាចធ្វើឱ្យស្តាប់ទៅហាក់ដូចជាខុសសភាព ឬលើកតម្កើងខ្លួនពេក (pretentious)។ គួរប្រើ `〜みたい` ឬ `〜よう` ជំនួសវិញ។
2. **ការច្រឡំរវាង ごとき និង ごとく:**  
   - `ごとき` ត្រូវតែភ្ជាប់ជាមួយ **នាម** ខាងក្រោយ (Modifies Noun)។
   - `ごとく` ត្រូវតែភ្ជាប់ជាមួយ **កិរិយាសព្ទ ឬគុណនាម** ខាងក្រោយ (Modifies Verb/Adj)។  
   *(ខុស)* 彼女は花ごとき美しい。 ❌  
   *(ត្រូវ)* 彼女は花**ごとく**美しい。 / 彼女は花**のごとき**人だ。 ⭕

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះត្រូវចងចាំ (Key Takeaways)
- **ごとき** ប្រើកែប្រែនាម (Noun modifier); **ごとく** ប្រើកែប្រែកិរិយាសព្ទ ឬគុណនាម (Adverbial modifier)។
- មានន័យស្នូល ២៖
  1. «ដូចជា / ប្រៀបដូចជា» ក្នុងការប្រៀបធៀបបែបអក្សរសាស្ត្រ រូបារម្មណ៍កំណាព្យ។
  2. «មនុស្សដូចជា... / កម្រិតត្រឹម...» ក្នុងការបន្ទាបខ្លួន (`私ごとき`) ឬការមើលងាយវាយតម្លៃទាប (`あいつごとき`, `失敗ごとき`)។
- ក្លាយមកពីពាក្យបុរាណ `如し (ごとし)` ហើយជាវេយ្យាករណ៍កម្រិតខ្ពស់ JLPT N1។

### កម្រងសំណួររំលឹកចំណេះដឹងខ្លីៗ (Quick Recap Quiz)
1. **ចូរជ្រើសរើសពាក្យបំពេញចន្លោះ:** 彼女は花_____美しい。  
   *(នាងស្រស់ស្អាតដូចជាផ្កា)*  
   **ចម្លើយ:** ごとく  
   彼女は花**ごとく**美しい。
2. **ត្រូវ ឬខុស (True or False):** តើវាសមរម្យដែរឬទេក្នុងការប្រើ **ごとき** ក្នុងការសន្ទនាធម្មតាប្រចាំថ្ងៃជាមួយមិត្តភក្តិ?  
   **ចម្លើយ:** ខុស (False)។ **ごとき** ជាទម្រង់ផ្លូវការ/បុរាណ ឬបង្ហាញពីការមើលស្រាល/បន្ទាបខ្លួនជ្រៅ ដែលមិនសមស្របនឹងបរិបទសន្ទនាធម្មតាឡើយ។
3. **ចូរបកប្រែប្រយោគខាងក្រោមជាភាសាខ្មែរ:**  
   **時は矢のごとし。**  
   **ចម្លើយ:** ពេលវេលាកន្លងផុតទៅលឿនប្រៀបដូចជាព្រួញ (ស្មើនឹងភាសាអង់គ្លេស: Time flies like an arrow)។
