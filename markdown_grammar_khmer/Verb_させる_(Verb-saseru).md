# វេយ្យាករណ៍ភាសាញ៉បុ៉ន: កិរិយាសព្ទ させる (Verb-saseru) - ទម្រង់បង្គាប់បញ្ជា/អនុញ្ញាត (使役形)
**កម្រិត JLPT:** JLPT N4

---

## ១. សេចក្តីផ្តើម (Introduction)

នៅក្នុងមេរៀននេះ យើងនឹងសិក្សាអំពីទម្រង់វេយ្យាករណ៍កិរិយាសព្ទបង្គាប់បញ្ជា ឬអនុញ្ញាតក្នុងភាសាញ៉បុ៉ន ហៅថា **使役形 (Shiyekikei / Causative form)** ដែលសម្គាល់ដោយកន្ទុយកិរិយាសព្ទ **〜させる / 〜せる**។ 

ទម្រង់នេះត្រូវបានប្រើប្រាស់ជាទូទៅដើម្បីបង្ហាញថា ប្រធាននៃល្បះ (Causer) **"បង្ខំ / បង្គាប់ឱ្យនរណាម្នាក់ធ្វើអ្វីមួយ" (Make someone do something)** ឬ **"អនុញ្ញាត / បណ្តោយឱ្យនរណាម្នាក់ធ្វើអ្វីមួយ" (Let/Allow someone do something)**។ ការយល់ដឹងច្បាស់អំពីវេយ្យាករណ៍នេះ មានសារៈសំខាន់ខ្លាំងណាស់ក្នុងការបង្ហាញទំនាក់ទំនងនៃអំណាច ការទទួលខុសត្រូវ និងការអនុញ្ញាតក្នុងសង្គមជប៉ុន។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
ទម្រង់កិរិយាសព្ទបង្គាប់បញ្ជា/អនុញ្ញាត (**Verb させる / せる**) បង្ហាញអត្ថន័យស្នូលចំនួន ២ អាស្រ័យលើបរិបទជាក់ស្តែង៖
1. **ការបង្ខិតបង្ខំ ឬបង្គាប់បញ្ជា (Coercive Causation - "Make someone do"):** ប្រធានបង្គាប់ឱ្យ ឬបង្ខំឱ្យបុគ្គលម្នាក់ទៀតធ្វើសកម្មភាពមួយ (ជារឿយៗផ្ទុយពីបំណង ឬជាកាតព្វកិច្ច)។
2. **ការអនុញ្ញាត ឬបណ្តោយឱ្យធ្វើ (Permissive Causation - "Let / Allow someone do"):** ប្រធានអនុញ្ញាត យល់ព្រម ឬមិនរារាំងបុគ្គលម្នាក់ទៀតក្នុងការធ្វើសកម្មភាពដែលគេចង់ធ្វើ។

---

### ក្បួនបំប្លែងទម្រង់កិរិយាសព្ទ (Verb Conjugation)

របៀបបំប្លែងកិរិយាសព្ទទៅជាទម្រង់ Causative (使役形) អាស្រ័យលើក្រុមនៃកិរិយាសព្ទនីមួយៗ៖

#### ក. កិរិយាសព្ទក្រុមទី ១ (កិរិយាសព្ទ 五段 - Godan Verbs)
- ប្តូរសូរស្រៈចុងក្រោយ **-u (ជួរ う)** ទៅជាសូរស្រៈ **-a (ជួរ あ)** រួចថែម **せる (seru)**។
- *ចំណាំ:* ចំពោះកិរិយាសព្ទដែលបញ្ចប់ដោយ **う (u)** ត្រូវប្តូរទៅជា **わ (wa)** រួចថែម **せる**។

**រូបមន្ត:**
```
កិរិយាសព្ទប្តូរ (u → a) + せる
```

**ឧទាហរណ៍:**
- **書く (kaku)** (សរសេរ) → **書かせる (kakaseru)** (ឱ្យសរសេរ / អនុញ្ញាតឱ្យសរសេរ)
- **読む (yomu)** (អាន) → **読ませる (yomaseru)** (ឱ្យអាន)
- **行く (iku)** (ទៅ) → **行かせる (ikaseru)** (ឱ្យទៅ / អនុញ្ញាតឱ្យទៅ)
- **話す (hanasu)** (និយាយ) → **話させる (hanasaseru)** (ឱ្យនិយាយ)
- **待つ (matsu)** (រង់ចាំ) → **待たせる (mataseru)** (ឱ្យរង់ចាំ / ធ្វើឱ្យចាំ)
- **買う (kau)** (ទិញ) → **買わせる (kawaseru)** (ឱ្យទិញ)

---

#### ខ. កិរិយាសព្ទក្រុមទី ២ (កិរិយាសព្ទ 一段 - Ichidan Verbs)
- លុបកន្ទុយ **る (ru)** ចេញពីរូបរាងដើម (ទម្រង់វចនានុក្រម) រួចជំនួសដោយ **させる (saseru)**។

**រូបមន្ត:**
```
ឫសកិរិយាសព្ទ (កាត់ る) + させる
```

**ឧទាហរណ៍:**
- **食べる (taberu)** (ញ៉ាំ) → **食べさせる (tabesaseru)** (ឱ្យញ៉ាំ / បញ្ចុក)
- **見る (miru)** (មើល) → **見させる (misaseru)** (ឱ្យមើល)
- **起きる (okiru)** (ភ្ញាក់) → **起きさせる (okisaseru)** (ឱ្យភ្ញាក់ / ដាស់ឱ្យក្រោក)
- **教える (oshieru)** (បង្រៀន) → **教えさせる (oshiesaseru)** (ឱ្យបង្រៀន)

---

#### គ. កិរិយាសព្ទមិនទៀងទាត់ (Irregular Verbs - カ変・サ変)
កិរិយាសព្ទមិនទៀងទាត់ទាំងពីរមានទម្រង់ពិសេសដែលត្រូវចងចាំ៖
- **する (suru)** (ធ្វើ) → **させる (saseru)** (ឱ្យធ្វើ)
- **来る (kuru)** (មក) → **来させる (kosaseru)** (ឱ្យមក) *(សូមប្រយ័ត្នការអានសូរ: kuru ប្រែជា ko)*

---

### ក្បួនប្រើប្រាស់ធ្នាក់ក្នុងល្បះ Causative (Particle Usage: を vs に)

នៅក្នុងទម្រង់ Causative អ្នកបង្គាប់ (Causer) តែងតែដើរតួជាប្រធានសម្គាល់ដោយធ្នាក់ **は (wa)** ឬ **が (ga)**។ រីឯបុគ្គលដែលទទួលរងការបង្គាប់ ឬទទួលបានការអនុញ្ញាត (Agent/Doer) ត្រូវបានកំណត់ដោយធ្នាក់ **に (ni)** ឬ **を (o)** អាស្រ័យលើប្រភេទនៃកិរិយាសព្ទ៖

#### ១. កិរិយាសព្ទអកម្ម / មិនត្រូវការកម្មបទផ្ទាល់ (Intransitive Verbs - 自動詞)
នៅពេលកិរិយាសព្ទដើមមិនត្រូវការកម្មបទផ្ទាល់ (ដូចជា 行く, 走る, 泣く, 立つ, 帰る):
- បុគ្គលដែលធ្វើសកម្មភាពត្រូវសម្គាល់ដោយធ្នាក់ **を (o)** (ឬ **に (ni)** ក្នុងករណីមានធ្នាក់ を នៃចលនានៅក្នុងប្រយោគ)។
- **ទម្រង់:**
  ```
  [Causer អ្នកបង្គាប់] は/が + [Agent អ្នកធ្វើ] を + [កិរិយាសព្ទអកម្ម-させる/せる]
  ```
- **ឧទាហរណ៍:**
  - 先生は学生**を**走らせた。 (*Sensei wa gakusei o hashiraseta.* - លោកគ្រូបានឱ្យសិស្សរត់។)
  - 彼は私**を**待たせました。 (*Kare wa watashi o matasemashita.* - គាត់បានធ្វើឱ្យខ្ញុំរង់ចាំ។)

#### ២. កិរិយាសព្ទសកម្ម / ត្រូវការកម្មបទផ្ទាល់ (Transitive Verbs - 他動詞)
នៅពេលកិរិយាសព្ទដើមមានកម្មបទផ្ទាល់ទទួលរងអំពើដែលសម្គាល់ដោយ **を (o)** រួចទៅហើយ:
- បុគ្គលដែលធ្វើសកម្មភាព (Agent) ត្រូវតែសម្គាល់ដោយធ្នាក់ **に (ni)** ដើម្បីជៀសវាងការជាន់ធ្នាក់ を ពីរដងក្នុងល្បះតែមួយ (Double-o Constraint: をの重複回避)។
- **ទម្រង់:**
  ```
  [Causer អ្នកបង្គាប់] は/が + [Agent អ្នកធ្វើ] に + [Object កម្មបទ] を + [កិរិយាសព្ទសកម្ម-させる/せる]
  ```
- **ឧទាហរណ៍:**
  - 母は子ども**に**野菜**を**食べさせる。 (*Haha wa kodomo ni yasai o tabesaseru.* - ម្តាយឱ្យកូនញ៉ាំបន្លែ។)
  - 先生は学生**に**作文**を**書かせた。 (*Sensei wa gakusei ni sakubun o kakaseta.* - គ្រូឱ្យសិស្សសរសេរសំណេរ។)

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuances)

### ក. ន័យបង្ខំ (Coercive) ទល់នឹង ន័យអនុញ្ញាត (Permissive)

ទម្រង់ **〜させる** អាចមានន័យថា "បង្ខំ" ឬ "អនុញ្ញាត" អាស្រ័យលើបរិបទ ឋានៈសង្គម និងបំណងប្រាថ្នារបស់អ្នកធ្វើសកម្មភាព៖

| លក្ខណៈវិនិច្ឆ័យ | ន័យបង្ខំ (Coercive Causation) | ន័យអនុញ្ញាត (Permissive Causation) |
|---|---|---|
| **អត្ថន័យស្នូល** | បង្ខំ, បង្គាប់បញ្ជាឱ្យធ្វើ ទោះចង់ឬមិនចង់ | អនុញ្ញាត, បណ្តោយឱ្យធ្វើតាមការចង់បាន |
| **បំណងរបស់អ្នកធ្វើ (Agent)** | មិនចង់ធ្វើ ឬជាកាតព្វកិច្ចដែលត្រូវតែធ្វើ | ចង់ធ្វើដោយស្ម័គ្រចិត្ត ឬមានបំណងធ្វើ |
| **ការប្រើប្រាស់ធ្នាក់** | ភាគច្រើនប្រើធ្នាក់ **を** (បើជា Intransitive) ដើម្បីបញ្ជាក់ពីការបង្ខំផ្ទាល់ | ជារឿយៗប្រើរួមជាមួយ **〜てあげる / 〜てやる** ដើម្បីបញ្ជាក់ការអនុញ្ញាត |
| **ឧទាហរណ៍** | 医者は患者にお酒をやめさせた。<br>*(វេជ្ជបណ្ឌិតបង្ខំឱ្យអ្នកជំងឺផ្តាច់ស្រា)* | 父親は子どもを行きたい高校に行かせた。<br>*(ឪពុកអនុញ្ញាតឱ្យកូនទៅរៀនវិទ្យាល័យដែលកូនចង់រៀន)* |

> **គន្លឹះសំខាន់:** ដើម្បីបញ្ជាក់ន័យអនុញ្ញាតឱ្យកាន់តែច្បាស់ និងមិនច្រឡំនឹងការបង្ខិតបង្ខំ ជនជាតិជប៉ុននិយមបន្ថែម **〜てあげる / 〜てくれる / 〜てもらう**:
> - **子供に好きな本を読ませてあげた。** (ខ្ញុំបានអនុញ្ញាតឱ្យកូនអានសៀវភៅដែលគេចូលចិត្ត។ - បង្ហាញពីចិត្តល្អ និងការអនុញ្ញាត)
> - **行かせてください。** (សូមអនុញ្ញាតឱ្យខ្ញុំទៅផង! - សុំការអនុញ្ញាត)

---

### ខ. ការជ្រើសរើសធ្នាក់ を ទល់នឹង に ជាមួយកិរិយាសព្ទអកម្ម (Intransitive Nuance)

ជាមួយកិរិយាសព្ទអកម្ម (Intransitive) ពេលខ្លះអ្នកអាចប្រើបានទាំង **を** និង **に** ប៉ុន្តែន័យខុសគ្នា៖
- **ប្រើធ្នាក់ を (o):** បង្ហាញពី**ការបង្ខំដោយផ្ទាល់ ឬគ្មានជម្រើស** (High Compulsion / Lack of Will)។
  - 先生は生徒**を**走らせた。 *(គ្រូបង្ខំសិស្សឱ្យរត់ - សិស្សត្រូវតែរត់គ្មានជម្រើស)*
- **ប្រើធ្នាក់ に (ni):** បង្ហាញពី**ការទុកលទ្ធភាព ផ្តល់ស្វ័យភាព ឬការយល់ព្រម** (Permissive / Autonomous Will)។
  - 先生は生徒**に**走らせた。 *(គ្រូបើកដៃ ឬអនុញ្ញាតឱ្យសិស្សរត់ - ស្របតាមចិត្តសិស្ស)*

---

### គ. ភាពខុសគ្នារវាងទម្រង់ Causative (使役) និង Passive (受身)

| លក្ខណៈ | ទម្រង់ Causative (使役形 - させる) | ទម្រង់ Passive (受身形 - れる/られる) | ទម្រង់ Causative-Passive (使役受身 - させられる) |
|---|---|---|---|
| **អត្ថន័យ** | ឱ្យនរណាម្នាក់ធ្វើ / បង្ខំឱ្យធ្វើ | ត្រូវបានគេធ្វើសកម្មភាពដាក់ (រងអំពើ) | ត្រូវបានគេបង្ខំឱ្យធ្វើ (ទាំងមិនចង់ធ្វើ) |
| **តួអង្គសំខាន់** | ប្រធានជាអ្នកបង្គាប់ (Causer) | ប្រធានជាអ្នករងសកម្មភាព (Receiver) | ប្រធានជាជនរងគ្រោះដែលត្រូវគេបង្ខំ |
| **ឧទាហរណ៍** | 母は子に野菜を**食べさせる**。<br>*(ម្តាយបញ្ចុក/ឱ្យកូនញ៉ាំបន្លែ)* | ケーキが弟に**食べられた**。<br>*(នំខេកត្រូវបានប្អូនប្រុសញ៉ាំបាត់)* | 私は母に野菜を**食べさせられた**。<br>*(ខ្ញុំត្រូវបានម្តាយបង្ខំឱ្យញ៉ាំបន្លែ)* |

---

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Sentence Examples)

### ១. 母は子どもに野菜を食べさせる。
- **អាន:** *Haha wa kodomo ni yasai o tabesaseru.*
- **ន័យ:** ម្តាយឱ្យកូនញ៉ាំបន្លែ។ (ម្តាយបញ្ចុកបន្លែដល់កូន)
- **ការពន្យល់:** កិរិយាសព្ទ 食べる ជាកិរិយាសព្ទសកម្ម (Transitive) មានកម្មបទគឺ 野菜 (បន្លែ) ដូច្នេះអ្នកធ្វើសកម្មភាពគឺ 子ども ត្រូវភ្ជាប់ដោយធ្នាក់ に។

### ២. 先生は学生たちを立たせた。
- **អាន:** *Sensei wa gakusei-tachi o tataseta.*
- **ន័យ:** លោកគ្រូបានបញ្ជាឱ្យសិស្សទាំងអស់ក្រោកឈរ។
- **ការពន្យល់:** កិរិយាសព្ទ 立つ ជាកិរិយាសព្ទអកម្ម (Intransitive) ដូច្នេះអ្នកទទួលការបញ្ជាគឺ 学生たち ត្រូវបានសម្គាល់ដោយធ្នាក់ を ដើម្បីបង្ហាញការបញ្ជាផ្ទាល់។

### ៣. 彼は私を待たせました。
- **អាន:** *Kare wa watashi o matasemashita.*
- **ន័យ:** គាត់បានធ្វើឱ្យខ្ញុំរង់ចាំ។
- **ការពន្យល់:** ប្រើជាមួយកិរិយាសព្ទ 待つ បង្ហាញអារម្មណ៍ថាអ្នកនិយាយត្រូវបានគេទុកចោលឱ្យរង់ចាំ (សកម្មភាពបង្កឡើងដោយ 彼)។

### ៤. 社長は社員に残業させる。
- **អាន:** *Shachō wa shain ni zangyō saseru.*
- **ន័យ:** ប្រធានក្រុមហ៊ុនបង្ខំ/តម្រូវឱ្យបុគ្គលិកធ្វើការថែមម៉ោង (OT)។
- **ការពន្យល់:** 残業する ជាកិរិយាសព្ទមានលក្ខណៈសកម្ម ដែលបុគ្គលិក (社員) ទទួលរងសម្ពាធការងារពីប្រធានក្រុមហ៊ុន (社長)។

### ៥. 私は娘にピアノを習わせています。
- **អាន:** *Watashi wa musume ni piano o narawasete imasu.*
- **ន័យ:** ខ្ញុំកំពុងឱ្យកូនស្រីរៀនលេងព្យាណូ។
- **ការពន្យល់:** បង្ហាញពីការគាំទ្រ ជំរុញ ឬផ្តល់ឱកាសដល់កូនស្រី (娘) ក្នុងការរៀនសូត្រ។

---

## ៥. កំណត់សម្គាល់វប្បធម៌ និងការគួរសម (Cultural Notes & Politeness)

### ១. ឋានានុក្រមសង្គមជប៉ុន (Social Hierarchy)
នៅក្នុងវប្បធម៌ជប៉ុន កម្រិតឋានៈ តួនាទី និងទំនាក់ទំនងសង្គម (上下関係 - Jōge kankei) មានសារៈសំខាន់ខ្លាំងណាស់៖
- **ការប្រើចំពោះអ្នកតូចជាង:** ទម្រង់ **させる** អាចប្រើដោយសេរីពីមនុស្សដែលមានឋានៈខ្ពស់ជាង ទៅកាន់មនុស្សតូចជាង (ឧ. ឪពុកម្តាយទៅកូន, គ្រូទៅសិស្ស, ចៅហ្វាយនាយទៅបុគ្គលិក)។
- **ការហាមប្រាមចំពោះអ្នកធំជាង:** **ដាច់ខាតកុំប្រើ**ទម្រង់ 〜させる ចំពោះមនុស្សចាស់ជាង ឬថ្នាក់លើ ព្រោះវាស្តាប់ទៅដូចជាយើងកំពុងបញ្ជា ឬត្រួតត្រាលើពួកគាត់ ដែលជាអាកប្បកិរិយាឈ្លើយខ្លាំង។

### ២. កម្រិតគួរសម (Levels of Politeness)
- **ទម្រង់ស្និទ្ធស្នាល/ទូទៅ (Casual):** 食べさせる (*tabesaseru*)
- **ទម្រង់គួរសម (Polite):** 食べさせます (*tabesasemasu*)
- **ទម្រង់បន្ទាបខ្លួន/គួរសមខ្ពស់ (Humble / Kenjōgo):** 食べさせていただきます (*tabesasete itadakimasu*) ឬ 発表させていただきます (*happyō sasete itadakimasu* - សូមអនុញ្ញាតឱ្យខ្ញុំធ្វើបទបង្ហាញ)

### ៣. ឃ្លាគួរសម និងការសុំអនុញ្ញាតដែលពេញនិយម (Idiomatic Expressions)
- **お待たせしました (Omatase shimashita):**
  - "សុំទោសដែលបានធ្វើឱ្យលោកអ្នករង់ចាំ!" (ឃ្លានេះប្រើញឹកញាប់បំផុតក្នុងសេវាកម្ម ភោជនីយដ្ឋាន និងជំនួញ)។
- **〜させてください (〜Sasete kudasai):**
  - "សូមអនុញ្ញាតឱ្យខ្ញុំធ្វើ...ផង" (ប្រើនៅពេលយើងចង់សុំការអនុញ្ញាតពីថ្នាក់លើដើម្បីធ្វើអ្វីមួយ)។
  - ឧទាហរណ៍៖ 今日は早く帰らせてください。 (*Kyō wa hayaku kaerasete kudasai.* - សូមអនុញ្ញាតឱ្យខ្ញុំត្រឡប់ទៅផ្ទះមុនម៉ោងនៅថ្ងៃនេះផង។)

## ៦. កំហុសទូទៅ និងគន្លឹះដោះស្រាយ (Common Mistakes and Tips)

### ១. កំហុសក្នុងការបំប្លែងកិរិយាសព្ទក្រុមទី ១ (Group 1 Mistakes)
- ❌ **ខុស:** 書く → 書けさせる (*kakesaseru*)
- ✅ **ត្រូវ:** 書く → **書かせる (*kakaseru*)**
- 💡 **គន្លឹះ:** ចងចាំថា កិរិយាសព្ទក្រុមទី ១ ត្រូវប្តូរសូរ **-u** ទៅ **-a** ហើយថែមត្រឹមតែ **せる** ប៉ុណ្ណោះ (មិនមែន させる នោះទេ)។

### ២. ច្រឡំរវាងទម្រង់ Causative (使役) និង Passive (受身)
- **Causative (បង្ក/ឱ្យគេធ្វើ):** 読ませる (*yomaseru* - ឱ្យអាន)
- **Passive (រងអំពើ):** 読まれる (*yomareru* - ត្រូវបានគេអាន)
- 💡 **គន្លឹះ:** សង្កេតកន្ទុយសំឡេង៖ កន្ទុយ **-せる / -させる** បញ្ជាក់ការបង្គាប់/អនុញ្ញាត រីឯកន្ទុយ **-れる / -られる** បញ្ជាក់ការរងអំពើ។

### ៣. កំហុសជាន់ធ្នាក់ を ពីរដង (Double-o Error)
- ❌ **ខុស:** 先生は学生**を**本**を**読ませた。
- ✅ **ត្រូវ:** 先生は学生**に**本**を**読ませた。
- 💡 **គន្លឹះ:** នៅក្នុងភាសាញ៉បុ៉ន មិនត្រូវប្រើធ្នាក់ を ចំនួនពីរក្នុងឃ្លាកិរិយាសព្ទតែមួយឡើយ។ កាលណាមានកម្មបទផ្ទាល់ (本を) បុគ្គលដែលធ្វើសកម្មភាពត្រូវតែប្រើធ្នាក់ **に**។

## ៧. សេចក្តីសង្ខេប និងសំណួររំលឹកមេរៀន (Summary and Review)

### ចំណុចសំខាន់ៗដែលត្រូវចងចាំ
- **Verb させる / せる** បង្ហាញពីការ**បង្ខំឱ្យធ្វើ (Make)** ឬ **អនុញ្ញាតឱ្យធ្វើ (Let/Allow)**។
- **ក្បួនបំប្លែង:**
  - ក្រុម ១: សូរ **u → a + せる**
  - ក្រុម ២: កាត់ **る + させる**
  - ក្រុម ៣: **する → させる**, **来る → 来させる (こさせる)**
- **ក្បួនធ្នាក់:**
  - កិរិយាសព្ទអកម្ម: `[Causer] は [Agent] を [Verb-させる]`
  - កិរិយាសព្ទសកម្ម: `[Causer] は [Agent] に [Object] を [Verb-させる]`
- ប្រយ័ត្នក្នុងការប្រើប្រាស់ឱ្យសមស្របតាមឋានានុក្រមសង្គម។

---

### សំណួរតេស្តសមត្ថភាពរហ័ស (Quick Recap Quiz)

១. តើកិរិយាសព្ទក្រុមទី ២ ត្រូវបំប្លែងទៅជាទម្រង់ Causative យ៉ាងដូចម្តេច?  
២. ចូរបំប្លែងកិរិយាសព្ទ **読む (yomu)** និង **話す (hanasu)** ទៅជាទម្រង់ Causative។  
៣. ចូរបកប្រែប្រយោគនេះទៅជាភាសាញ៉បុ៉ន៖ *"ប្រធានផ្នែកបានអនុញ្ញាតឱ្យបុគ្គលិកសម្រាកមួយថ្ងៃ។"*

#### ចម្លើយ៖
១. **លុប る ចេញ រួចបន្ថែម させる:**  
   - 食べる → 食べさせる (*tabesaseru*)  
   - 見る → 見させる (*misaseru*)  
២. **កិរិយាសព្ទបំប្លែងរួច:**  
   - 読む → **読ませる (*yomaseru*)**  
   - 話す → **話させる (*hanasaseru*)**  
៣. **ប្រយោគភាសាញ៉បុ៉ន:**  
   - **部長は社員に休みを取らせた。**  
     (*Buchō wa shain ni yasumi o toraseta.*)
