Processing keyword: Noun + 中 (Noun + ちゅう)
# ចំណុចវេយ្យាករណ៍ជប៉ុន: Noun + 中 (Noun + ちゅう)
**កម្រិត JLPT:** JLPT N4

---

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងភាសាជប៉ុន ទម្រង់វេយ្យាករណ៍ **នាម + 中（ちゅう - chū）** ត្រូវបានប្រើប្រាស់ជាទូទៅដើម្បីបញ្ជាក់ថាសកម្មភាព ឬស្ថានភាពណាមួយកំពុងតែដំណើរការ ឬកំពុងប្រព្រឹត្តទៅ។ វាមានន័យប្រហាក់ប្រហែលនឹងពាក្យខ្មែរថា **«កំពុងតែ...»**, **«នៅក្នុងអំឡុងពេល...»** ឬ **«កំពុងស្ថិតក្នុងដំណើរការ...»**។ ការយល់ដឹងច្បាស់អំពីចំណុចវេយ្យាករណ៍នេះ នឹងជួយបង្កើនសមត្ថភាពរបស់អ្នកក្នុងការពិពណ៌នាអំពីសកម្មភាព និងស្ថានភាពដែលកំពុងកើតឡើងជាក់ស្តែងក្នុងភាសាជប៉ុន។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)
### អត្ថន័យ (Meaning)
ទម្រង់ **នាម + 中（ちゅう）** ប្រើសម្រាប់បង្ហាញថាសកម្មភាព ឬព្រឹត្តិការណ៍ណាមួយកំពុងកើតឡើងនៅពេលបច្ចុប្បន្ន ឬកំពុងស្ថិតក្នុងដំណើរការប្រព្រឹត្តទៅ។ វាសង្កត់ធ្ងន់លើសកម្មភាព ឬសភាពដែលកំពុងបន្ត។

### ទម្រង់ផ្សំ (Structure)
ដើម្បីបង្កើតទម្រង់នេះ គ្រាន់តែភ្ជាប់បច្ច័យ **中（ちゅう）** ដោយផ្ទាល់ពីក្រោយនាមណាដែលតំណាងឱ្យសកម្មភាព (Action noun / Suru noun) ឬព្រឹត្តិការណ៍ (Event)។

**រូបមន្តផ្សំ (Formation Diagram):**
```
[នាមសកម្មភាព/ព្រឹត្តិការណ៍] + 中（ちゅう）
```

### ឧទាហរណ៍នៃនាមដែលនិយមប្រើញឹកញាប់:
- **会議（かいぎ）** : ការប្រជុំ → **会議中（かいぎちゅう）** : កំពុងប្រជុំ
- **勉強（べんきょう）** : ការរៀនសូត្រ → **勉強中（べんきょうちゅう）** : កំពុងរៀន
- **使用（しよう）** : ការប្រើប្រាស់ → **使用中（しようちゅう）** : កំពុងប្រើប្រាស់
- **準備（じゅんび）** : ការរៀបចំ/ត្រៀម → **準備中（じゅんびちゅう）** : កំពុងរៀបចំ/ត្រៀម
- **工事（こうじ）** : ការដ្ឋានសំណង់/ជួសជុល → **工事中（こうじちゅう）** : កំពុងសាងសង់/ជួសជុល
- **授業（じゅぎょう）** : ម៉ោងរៀន → **授業中（じゅぎょうちゅう）** : កំពុងរៀន/ក្នុងម៉ោងសិក្សា

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuances)

### ការប្រៀបធៀបរវាងបច្ច័យ «中» អានថា ちゅう (chū) និង じゅう (jū)
តួអក្សរចិនកានជី **中** ពេលដើរតួជាបច្ច័យ (Suffix) នៅខាងចុងនាម អាចមានការបញ្ចេញសំឡេងពីរខុសគ្នាស្រឡះ គឺ **ちゅう (chū)** និង **じゅう (jū)** ដោយអត្ថន័យ និងមុខងារវេយ្យាករណ៍ក៏ខុសគ្នាទាំងស្រុងដែរ៖

#### ១. អានថា ちゅう (chū) — កំពុងប្រព្រឹត្តទៅ (Action in progress):
- **លក្ខណៈ:** ប្រើភ្ជាប់ជាមួយ **នាមសកម្មភាព (Action nouns)** ឬនាមកិរិយា (Suru-nouns)។
- **អត្ថន័យ:** បង្ហាញថាសកម្មភាព ឬស្ថានភាពនោះ **«កំពុងតែប្រព្រឹត្តទៅ»** ឬ **«កំពុងស្ថិតក្នុងដំណើរការ»** (In the middle of / Currently doing)។
- **ឧទាហរណ៍:**
  - **会議中（かいぎちゅう）**: កំពុងប្រជុំ (In a meeting)
  - **授業中（じゅぎょうちゅう）**: ក្នុងម៉ោងរៀន / កំពុងរៀន (In class)
  - **工事中（こうじちゅう）**: កំពុងសាងសង់ / កំពុងជួសជុល (Under construction)
  - **電話中（でんわちゅう）**: កំពុងនិយាយទូរស័ព្ទ (On the phone)
  - **營業中（えいぎょうちゅう）**: កំពុងបើកដំណើរការអាជីវកម្ម (Open for business)
- **ចំណាំលើពេលវេលាពិសេស:** នៅពេល 中 ភ្ជាប់ជាមួយពាក្យពេលវេលាខ្លះដូចជា **午前中（ごぜんちゅう - ពេញមួយព្រឹក）** ឬ **今週中（こんしゅうちゅう - ក្នុងសប្តាហ៍នេះ / មិនឱ្យហួសសប្តាហ៍នេះ）** ក៏អានថា ちゅう ដែរ ដោយបង្ហាញពីកាលកំណត់នៅក្នុងអំឡុងពេលនោះ។

#### ២. អានថា じゅう (jū) — ពេញផ្ទៃ / ពេញមួយ (Spatial & Temporal Span):
- **លក្ខណៈ:** ប្រើភ្ជាប់ជាមួយ **នាមពេលវេលា (Time span)** ឬ **នាមទីកន្លែង/លំហ (Spatial span)**។
- **អត្ថន័យ:** បង្ហាញពីការគ្របដណ្តប់ **«ពេញមួយ... / មួយ...ទាំងមូល»** (Throughout / All across / All over)។
- **ឧទាហរណ៍:**
  - **一日中（いちにちじゅう）**: ពេញមួយថ្ងៃ / មួយថ្ងៃវាល់ល្ងាច (All day long)
  - **一年中（いちねんじゅう）**: ពេញមួយឆ្នាំ / មួយឆ្នាំពេញ (All year round)
  - **世界中（せかいじゅう）**: ពេញពិភពលោក / ទូទាំងពិភពលោក (All over the world)
  - **部屋中（へやじゅう）**: ពេញបន្ទប់ទាំងមូល (Throughout the entire room)
  - **体中（からだじゅう）**: ពេញខ្លួនប្រាណ / មួយខ្លួនទាំងមូល (All over the body)
  - **今日中（きょうじゅう）**: ក្នុងថ្ងៃនេះ (គិតត្រឹមថ្ងៃនេះឱ្យចប់)

| ទម្រង់វេយ្យាករណ៍ | ការអាន | អត្ថន័យ | ប្រភេទនាមដែលភ្ជាប់ | ឧទាហរណ៍ជាក់ស្តែង |
|---|---|---|---|---|
| **នាម + 中** | **ちゅう (chū)** | កំពុងប្រព្រឹត្តទៅ / កំពុងធ្វើ (In the middle of) | នាមសកម្មភាព (Action/Event) | **勉強中（べんきょうちゅう）** : កំពុងរៀន |
| **នាម + 中** | **じゅう (jū)** | ពេញមួយ... / ទូទាំង... (Throughout span) | នាមពេលវេលា / នាមទីកន្លែង | **世界中（せかいじゅう）** : ទូទាំងពិភពលោក<br>**一日中（いちにちじゅう）** : ពេញមួយថ្ងៃ |

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ស្ថានភាពផ្លូវការ (Formal Situations)
1. **会議中につき、お電話に出ることができません。**
   - *かいぎちゅう につき、おでんわ に でる こと が できません。*
   - ដោយសារតែកំពុងប្រជុំ ខ្ញុំមិនអាចទទួលទូរស័ព្ទបានទេ។
2. **ただいま、システムのメンテナンス中です。**
   - *ただいま、システム の メンテナンスちゅう です。*
   - ពេលនេះប្រព័ន្ធកំពុងស្ថិតក្នុងការថែទាំនិងជួសជុល (Maintenance)។

### ស្ថានភាពក្រៅផ្លូវការ / ស្និទ្ធស្នាល (Informal Situations)
3. **ごめん、今テレビ見てる最中なんだ。**
   - *ごめん、いま テレビ みてる さいちゅう なんだ。*
   - សុំទោសផង ឥឡូវនេះខ្ញុំកំពុងតែមើលទូរទស្សន៍។
   *(ចំណាំ: 最中（さいちゅう）ប្រើជាមួយកិរិយាសព្ទដើម្បីបញ្ជាក់ពីសកម្មភាពកំពុងកើតឡើងខ្លាំង)*
4. **彼女は電話で話し中だよ。**
   - *かのじょ は でんわ で はなしちゅう だよ。*
   - នាងកំពុងតែជាប់និយាយទូរស័ព្ទ។

### ភាសាសរសេរ / សេចក្តីជូនដំណឹង (Written Language)
5. **店内改装中のため、休業しております。**
   - *てんない かいそうちゅう の ため、きゅうぎょう して おります。*
   - ហាងសូមផ្អាកដំណើរការបណ្តោះអាសន្ន ដោយសារកំពុងជួសជុលកែលម្អខាងក្នុងហាង។

### ភាសានិយាយទូទៅ (Spoken Language)
6. **今、準備中だから、ちょっと待って。**
   - *いま、じゅんびちゅう だから、ちょっと まって。*
   - ឥឡូវនេះខ្ញុំកំពុងរៀបចំ/ត្រៀមខ្លួន ចាំបន្តិចសិនណា។

## ៥. កំណត់សម្គាល់បែបវប្បធម៌ និងការប្រើប្រាស់ (Cultural Notes)

### កម្រិតគួរសម (Politeness Levels)
ទម្រង់ **នាម + 中（ちゅう）** គឺមានលក្ខណៈអព្យាក្រឹត (Neutral) អាចប្រើបានទាំងក្នុងស្ថានភាពផ្លូវការ និងក្រៅផ្លូវការ។ កម្រិតនៃការគួរសមគឺអាស្រ័យលើពាក្យបញ្ចប់ប្រយោគ (ដូចជា です, でございます ឬ だ) និងកម្រិតភាសាដែលប្រើរួមគ្នា។

### ឃ្លា និងពាក្យដែលនិយមជួបប្រទះញឹកញាប់ (Common Expressions & Signs):
- **話し中（はなしちゅう）** : ខ្សែទូរស័ព្ទកំពុងជាប់រវល់ (The line is busy)
- **使用中（しようちゅう）** : កំពុងប្រើប្រាស់ (ឧ. ស្លាកសញ្ញានៅមាត់ទ្វារបន្ទប់ទឹក)
- **募集中（ぼしゅうちゅう）** : កំពុងជ្រើសរើស / កំពុងរើសបុគ្គលិក / កំពុងទទួលពាក្យ
- **準備中（じゅんびちゅう）** : កំពុងរៀបចំ (ឧ. ស្លាកនៅមុខហាងមុនម៉ោងបើក)
- **営業中（えいぎょうちゅう）** : កំពុងបើកដំណើរការ (Open for business)
- **工事中（こうじちゅう）** : ការដ្ឋានកំពុងសាងសង់ / កំពុងជួសជុលផ្លូវ

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
- **កំហុសទី ១:** ច្រឡំការបញ្ចេញសំឡេងរវាង **中（ちゅう）** និង **中（じゅう）**
  - **ខុស:** 一日中（いちにち**ちゅう**）寝ていました。
  - **ត្រូវ:** 一日中（いちにち**じゅう**）寝ていました。
  - *អត្ថន័យ:* «ខ្ញុំបានគេងពេញមួយថ្ងៃ។» (សំដៅលើរយៈពេលពេញមួយថ្ងៃ)
- **កំហុសទី ២:** យក **中（ちゅう）** ទៅភ្ជាប់ពីក្រោយកិរិយាសព្ទដោយផ្ទាល់
  - **ខុស:** 食べる中（たべるちゅう）
  - **ត្រូវ:** 食事中（しょくじちゅう） ឬ 食べ**ているところ**
  - *អត្ថន័យ:* «កំពុងទទួលទានអាហារ» (ត្រូវប្រើនាមសកម្មភាព 食事 ឬប្រើទម្រង់កិរិយាសព្ទ ているところ)

### វិធីសាស្ត្ររៀន និងគន្លឹះចងចាំ (Learning Strategies)
- **គន្លឹះចងចាំ:** ចងចាំថា **中（ちゅう - chū）** ភ្ជាប់ជាមួយនាមសកម្មភាព ដើម្បីបញ្ជាក់ថា «កំពុងធ្វើ...»។
- **គន្លឹះ:** ប្រសិនបើអ្នកចង់បង្ហាញពីលំហ ឬពេលវេលាពេញមួយ «ពេញមួយថ្ងៃ/ពេញមួយឆ្នាំ/ពេញពិភពលោក» ត្រូវប្តូរទៅប្រើ **中（じゅう - jū）**។

---

## ៧. សង្ខេប និងរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចសំខាន់ៗ (Key Takeaways)
- **នាម + 中（ちゅう）** ប្រើសម្រាប់បង្ហាញថាសកម្មភាព ឬព្រឹត្តិការណ៍ណាមួយកំពុងតែដំណើរការ។
- ភាគច្រើនភ្ជាប់ដោយផ្ទាល់ជាមួយនាមដែលតំណាងឱ្យសកម្មភាព (Action/Event nouns)។
- ត្រូវប្រុងប្រយ័ត្នកុំច្រឡំរវាង **中（ちゅう）** (កំពុងធ្វើសកម្មភាព) និង **中（じゅう）** (ពេញមួយរយៈពេល ឬទូទាំងលំហ)។

### លំហាត់សាកល្បងសមត្ថភាព (Quick Recap Quiz)
១. តើអ្នកនិយាយថា «បន្ទប់ទឹកកំពុងមានមនុស្សប្រើប្រាស់» ដោយប្រើ **中（ちゅう）** យ៉ាងដូចម្តេច?  
២. តើ **勉強中（べんきょうちゅう）** និង **勉強中（べんきょうじゅう）** មានភាពខុសគ្នាយ៉ាងដូចម្តេច?  
៣. ចូរជ្រើសរើសពាក្យបំពេញចន្លោះ៖ ただいま、________中です。("ពេលនេះពួកយើងកំពុងតែរៀបចំ/ត្រៀម។")

**ចម្លើយ (Answers):**
១. **トイレは使用中です。（トイレはしようちゅうです。）**  
២. **勉強中（べんきょうちゅう）** មានន័យថា «កំពុងរៀន» ចំណែកឯ **勉強中（べんきょうじゅう）** គឺជាការប្រើប្រាស់ខុសវេយ្យាករណ៍ ព្រោះ **中（じゅう）** មិនភ្ជាប់ជាមួយនាមសកម្មភាពដូចជា 勉強 នោះទេ។  
៣. **準備（じゅんび）** → ただいま、**準備中**です。
