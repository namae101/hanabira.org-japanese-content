# ចំណុចវេយ្យាករណ៍ជប៉ុន: ～ちゃった (〜chatta)
**កម្រិត JLPT:** JLPT N3

---
## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់ **～ちゃった (〜chatta)** គឺជាទម្រង់កាត់បែបសន្ទនាធម្មតា (casual spoken contraction) នៅក្នុងភាសាជប៉ុន ដែលត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយក្នុងការសន្ទនាប្រចាំថ្ងៃ។ វាបង្ហាញពី **ការបញ្ចប់សកម្មភាពទាំងស្រុង (completion of an action)** ដោយច្រើនតែបង្កប់នូវអារម្មណ៍ **សោកស្តាយ វិប្បដិសារី (regret)**, **រឿងកើតឡើងដោយអចេតនា/ភ្លាត់ស្នៀត (unintended occurrence / blunder)** ឬពេលខ្លះបង្ហាញពី **ភាពធូរស្រាលក្នុងចិត្ត (relief)** ដែលបានបញ្ចប់រួចរាល់។ ការយល់ដឹងពីចំណុចវេយ្យាករណ៍នេះ នឹងជួយអ្នកឱ្យចេះបញ្ចេញអារម្មណ៍ចំពោះសកម្មភាពដែលបានកើតឡើងរួចរាល់ទាំងស្រុង ជាពិសេសសកម្មភាពដែលកើតឡើងដោយមិនបានគ្រោងទុក ឬមានទម្ងន់ផ្លូវចិត្ត។

---
## ២. ការពន្យល់វេយ្យាករណ៍គោល (Core Grammar Explanation)
### អត្ថន័យ (Meaning)
- **ការបញ្ចប់សកម្មភាពទាំងស្រុង (Completion)**: បញ្ជាក់ថាសកម្មភាពមួយត្រូវបានធ្វើចប់សព្វគ្រប់ ១០០% (ស្រដៀងពាក្យខ្មែរថា «...បាត់ទៅហើយ», «...អស់រលីងហើយ»...)។
- **ការសោកស្តាយ ឬសកម្មភាពកើតឡើងដោយអចេតនា (Regret / Accident / Blunder)**: បង្ហាញថាសកម្មភាពនោះកើតឡើងដោយការធ្វេសប្រហែស អចេតនា ឬនាំមកនូវលទ្ធផលមិនល្អ ដែលនាំឱ្យអ្នកនិយាយមានអារម្មណ៍ស្តាយក្រោយ ឬទាស់ចិត្ត («ភ្លាត់...បាត់», «ជ្រុល...បាត់»)។

### រូបមន្ត និងទម្រង់បង្កើត (Structure & Formation)
ទម្រង់នេះបំប្លែងចេញពី **ទម្រង់ て (て-form) + しまった**:
1. **ចំពោះកិរិយាសព្ទបញ្ចប់ដោយ "〜て" (て-form):**
   ```
   កិរិយាសព្ទ て-form + しまった → កាត់មកជា [លុប て] + ちゃった
   (〜てしまった → 〜ちゃった)
   ```
2. **ចំពោះកិរិយាសព្ទបញ្ចប់ដោយ "〜で" (て-form):**
   ```
   កិរិយាសព្ទ て-form + しまった → កាត់មកជា [លុប で] + じゃった
   (〜でしまった → 〜じゃった)
   ```

### ដ្យាក្រាមនៃការកាត់ទម្រង់ (Formation Diagram)
តោះពិនិត្យមើលដំណើរការបំប្លែងកាត់ពាក្យឱ្យកាន់តែច្បាស់៖
#### ករណី "〜てしまった" → "〜ちゃった"
```plaintext
កិរិយាសព្ទ て-form + しまった
        ↓ (កាត់ "てしまった" ទៅជា "ちゃった")
កិរិយាសព្ទ て-form (កាត់ "て" ចេញ) + "ちゃった"
ឧទាហរណ៍: 忘れて + しまった → 忘れちゃった
```
#### ករណី "〜でしまった" → "〜じゃった"
```plaintext
កិរិយាសព្ទ て-form + しまった
        ↓ (កាត់ "でしまった" ទៅជា "じゃった")
កិរិយាសព្ទ て-form (កាត់ "で" ចេញ) + "じゃった"
ឧទាហរណ៍: 飲んで + しまった → 飲んじゃった
```

### តារាងបំប្លែងកិរិយាសព្ទ (Conjugation Table)
| កិរិយាសព្ទ (ទម្រង់វចនានុក្រម) | កន្ទុយទម្រង់ て | + しまった | ទម្រង់កាត់សន្ទនា (Contraction) | អត្ថន័យជាភាសាខ្មែរ |
|--------------------------------|-----------------|------------|--------------------------------|-------------------|
| 食べる (taberu) | 食べて | 食べてしまった | 食べ**ちゃった** | ញ៉ាំអស់បាត់ទៅហើយ / ជ្រុលញ៉ាំបាត់ |
| 行く (iku) | 行って | 行ってしまった | 行っ**ちゃった** | ទៅបាត់ហើយ (ស្តាយក្រោយ/មិនទាន់គេ) |
| 飲む (nomu) | 飲んで | 飲んでしまった | 飲ん**じゃった** | ផឹកអស់រលីង / ជ្រុលផឹកបាត់ |
| 読む (yomu) | 読んで | 読んでしまった | 読ん**じゃった** | អានចប់សព្វគ្រប់ / ជ្រុលលួចអានបាត់ |
| 書く (kaku) | 書いて | 書いてしまった | 書い**ちゃった** | សរសេរចប់ / ជ្រុលដៃសរសេរខុសបាត់ |
| 死ぬ (shinu) | 死んで | 死んでしまった | 死ん**じゃった** | ស្លាប់បាត់ទៅហើយ (គួរឱ្យសោកស្តាយ) |
| 忘れる (wasureru) | 忘れて | 忘れてしまった | 忘れ**ちゃった** | ភ្លេចបាត់ទៅហើយ (ភ្លាត់ភ្លេច) |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance, Semantic Contrasts & Deep Analysis)
### ១. ការវិភាគស៊ីជម្រៅរវាង ～てしまった និង ～ちゃった / ～じゃった
- **កម្រិតគួរសម និងបរិបទប្រើប្រាស់ (Register & Formality):**
  - **～てしまった**: ជាទម្រង់អព្យាក្រឹត (Neutral Standard) អាចប្រើបានក្នុងសំណេរ រឿងនិទាន ឬការសន្ទនាស្ដង់ដារទូទៅ។ បើប្រើក្នុងបរិបទគួរសម/ផ្លូវការ ត្រូវប្តូរទៅជា **～てしまいました**។
  - **～ちゃった / ～じゃった**: ជាទម្រង់កាត់ក្នុងការសន្ទនាផ្ទាល់មាត់ (Spoken Casual Contraction) ប្រើសម្រាប់តែការជជែកគ្នាក្នុងចំណោមមិត្តភក្តិ សមាជិកគ្រួសារ ឬមនុស្សស្និទ្ធស្នាលប៉ុណ្ណោះ។ ដាច់ខាតមិនត្រូវប្រើក្នុងរបាយការណ៍ សំណេរផ្លូវការ ឬនិយាយទៅកាន់ចៅហ្វាយនាយ/មនុស្សចាស់ឡើយ។
- **ស្រទាប់នៃអារម្មណ៍ (Emotional Nuances):**
  - **ភាពសោកស្តាយ និងកំហុសភ្លាត់ស្នៀត (Regret & Blunder):** នៅពេលប្រើ ～ちゃった អារម្មណ៍ស្តាយក្រោយ (regret) ហាក់ដូចជាលេចចេញភ្លាមៗស្រស់ៗតាមរយៈការនិយាយ ដូចជាពាក្យខ្មែរយើងឧទានថា «ងាប់ហើយ ភ្លាត់ដៃធ្វើបែកកែវបាត់!» ឬ «ជ្រុលមាត់និយាយរឿងសម្ងាត់ប្រាប់គេបាត់!»។
  - **ការចប់សព្វគ្រប់ទាំងស្រុង (Completeness):** សកម្មភាពត្រូវបានបញ្ចប់ ១០០% ដោយគ្មានសេសសល់ (ដូចជា ញ៉ាំនំអស់គ្មានសល់ ឬធ្វើកិច្ចការចប់)។
  - **ភាពធូរស្រាលក្នុងចិត្ត (Relief):** បើប្រើជាមួយកិច្ចការលំបាក ឬបន្ទុកធ្ងន់ធ្ងរ វាបង្ហាញពីអារម្មណ៍ថា «ទីបំផុតរលាស់បន្ទុកនេះរួចរាល់ហើយ!» (ឧ. やっと書き終えちゃった)។

### ២. ទម្រង់ពាក់ព័ន្ធ និងទម្រង់បច្ចុប្បន្នកាល
- **～ちゃう / ～じゃう (〜chau / 〜jau)**:
  - ជាទម្រង់មិនមែនអតីតកាល (Non-past: Present/Future) នៃ ～てしまう / ～でしまう។
  - បង្ហាញថាសកម្មភាពណាមួយនឹងត្រូវបញ្ចប់ទាំងស្រុង ឬអាចនឹងជ្រុលដៃ/ភ្លាត់ធ្វើនៅពេលបន្តិចទៀតនេះ។
  - ឧទាហរណ៍: *これ、全部食べちゃうよ* (ខ្ញុំនឹងញ៉ាំរបស់នេះឱ្យអស់រលីងហើយណា / ប្រយ័ត្នខ្ញុំញ៉ាំអស់បាត់ទៅ!)។
- **～ちゃダメ / ～ちゃいけない (ទម្រង់ហាមឃាត់សន្ទនា):**
  - កាត់ចេញពី **～てはだめ / ～てはいけない** (កុំធ្វើ... / មិនត្រូវធ្វើ... ឡើយ)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)
### ឧទាហរណ៍ប្រយោគ (Sentence Examples)
#### ការប្រៀបធៀបទម្រង់ផ្លូវការ និងទម្រង់សន្ទនាស្និទ្ធស្នាល (Formal vs. Casual)
1. **ផ្លូវការ (Formal/Neutral)**:
   - **ភាសាជប៉ុន**: 彼は宿題を忘れてしまった。
   - **រ៉ូម៉ាជិ**: Kare wa shukudai o wasurete shimatta.
   - **អត្ថន័យជាភាសាខ្មែរ**: គាត់បានភ្លេចកិច្ចការផ្ទះបាត់ទៅហើយ។
2. **សន្ទនាធម្មតា (Casual)**:
   - **ភាសាជប៉ុន**: 彼、宿題を忘れちゃった。
   - **រ៉ូម៉ាជិ**: Kare, shukudai o wasurechatta.
   - **អត្ថន័យជាភាសាខ្មែរ**: គាត់ភ្លេចកិច្ចការផ្ទះបាត់ទៅហើយ។

#### ការបង្ហាញពីការសោកស្តាយ ឬសកម្មភាពកើតឡើងដោយអចេតនា (Expressing Regret / Accident)
3. **សកម្មភាពអចេតនា (Unintentional Action / Blunder)**:
   - **ភាសាជប៉ុន**: 大切な書類を破っちゃった。
   - **រ៉ូម៉ាជិ**: Taisetsu na shorui o yabucchatta.
   - **អត្ថន័យជាភាសាខ្មែរ**: ខ្ញុំជ្រុលដៃធ្វើរហែកឯកសារសំខាន់បាត់ទៅហើយ។
4. **ការបាត់បង់ឱកាស / យឺតពេល (Missed Opportunity)**:
   - **ភាសាជប៉ុន**: 電車が行っちゃった。
   - **រ៉ូម៉ាជិ**: Densha ga icchatta.
   - **អត្ថន័យជាភាសាខ្មែរ**: រថភ្លើងចេញទៅបាត់ហើយ (ឡើងមិនទាន់ឡើយ)។

#### បរិបទផ្សេងៗ (Various Contexts)
5. **ការបង្ហាញពីភាពធូរស្រាលក្នុងចិត្ត (Expressing Relief)**:
   - **ភាសាជប៉ុន**: やっとレポートを書き終えちゃった。
   - **រ៉ូម៉ាជិ**: Yatto repōto o kaki o-echatta.
   - **អត្ថន័យជាភាសាខ្មែរ**: ទីបំផុតខ្ញុំសរសេររបាយការណ៍ចប់សព្វគ្រប់បាត់ហើយ!
6. **ការសន្ទនាលេងប្រចាំថ្ងៃ (Casual Conversation / Apology)**:
   - **ភាសាជប៉ុន**: ごめん、飲みすぎちゃった。
   - **រ៉ូម៉ាជិ**: Gomen, nomisugichatta.
   - **អត្ថន័យជាភាសាខ្មែរ**: សុំទោសផង ខ្ញុំជ្រុលផឹកច្រើនហួសកម្រិតបាត់ទៅហើយ។
7. **សំណួរក្នុងការសន្ទនាផ្ទាល់មាត់ (Spoken Question)**:
   - **ភាសាជប៉ុន**: その映画、もう見ちゃった？
   - **រ៉ូម៉ាជិ**: Sono eiga, mō michatta?
   - **អត្ថន័យជាភាសាខ្មែរ**: រឿងកុនហ្នឹង ឯងមើលចប់រួចហើយមែនទេ?

## ៥. កំណត់សម្គាល់វប្បធម៌ (Cultural Notes)
### ទំនៀមទម្លាប់នៃការបញ្ចេញអារម្មណ៍បែបជប៉ុន (Indirect Expression)
ជនជាតិជប៉ុននិយមប្រើការបង្ហាញអារម្មណ៍ដោយប្រយោល (indirect expressions) ដើម្បីបញ្ជាក់ពីវិប្បដិសារី ការសោកស្តាយ ឬការសុំទោស។ ការប្រើប្រាស់ **～ちゃった** បង្កប់ន័យស្រាលៗដោយស្វ័យប្រវត្តិក្នងចិត្តថា អ្វីមួយដែលមិនគួរឱ្យចង់បានបានកើតឡើងរួចទៅហើយ ដោយសារការធ្វេសប្រហែស ឬកាលៈទេសៈហួសពីការគ្រប់គ្រង ដែលជួយកាត់បន្ថយភាពតានតឹង និងបង្ហាញភាពបន្ទាបខ្លួនក្នុងការសន្ទនា។

### កម្រិតគួរសម និងឋានានុក្រមសង្គម (Politeness Levels & Hierarchy)
- **ការសន្ទនាស្និទ្ធស្នាល (Informal Speech)**: ប្រើ **～ちゃった** តែជាមួយមិត្តភក្តិ សមាជិកគ្រួសារ ក្មេងៗ ឬអ្នកដែលមានឋានៈស្មើគ្នា។
- **កាលៈទេសៈផ្លូវការ/ការងារ (Formal Situations)**: ត្រូវប្រើ **～てしまいました** ជានិច្ចជាមួយមនុស្សចាស់ គ្រូបង្រៀន អតិថិជន ឬថ្នាក់លើ។
  - **ឧទាហរណ៍**: 申し訳ありません、資料を忘れてしまいました。
  - **រ៉ូម៉ាជិ**: Mōshiwake arimasen, shiryō o wasurete shimaimashita.
  - **អត្ថន័យ**: សូមអភ័យទោសជាពន់ពេក ខ្ញុំបានភ្លេចយកឯកសារមកបាត់ទៅហើយ។

### ឃ្លាសន្ទនាពេញនិយម (Idiomatic Expression)
- **やっちゃった (Yacchatta)**:
  - **អត្ថន័យ**: «ងាប់ហើយ ខ្ញុំធ្វើខុសបាត់ហើយ!» ឬ «ភ្លាត់ស្នៀត/ជ្រុលដៃបាត់ទៅហើយ!» (I messed up!)។
  - **របៀបប្រើ**: ប្រើសម្រាប់ឧទានភ្លាមៗនៅពេលដឹងខ្លួនថាបានបង្កើតកំហុសអ្វីមួយ។
    ```plaintext
    ភាសាជប៉ុន: ああ、やっちゃった！
    រ៉ូម៉ាជិ: Ā, yacchatta!
    អត្ថន័យខ្មែរ: ងាប់ហើយ ភ្លាត់ស្នៀតបាត់! / ខូចការអស់ហើយ!
    ```

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)
### ការវិភាគកំហុស (Error Analysis)
1. **ការច្រឡំប្រើ ～ちゃった ក្នុងបរិបទផ្លូវការ (Mixing Casual & Polite)**
   - **កំហុស**: 先生、レポートを忘れちゃいました。 ❌
   - **បញ្ហា**: ការយកទម្រង់កាត់បែបស្និទ្ធស្នាល (ちゃ) មកផ្សំជាមួយកន្ទុយគួរសម (〜ました) ធ្វើឱ្យប្រយោគស្តាប់ទៅមិនសមរម្យ និងខ្វះការគោរពចំពោះគ្រូ។
   - **កែតម្រូវ**: 先生、レポートを忘れてしまいました。 ✔️
2. **ការបំប្លែងកិរិយាសព្ទខុស (Incorrect Conjugation)**
   - **កំហុស**: 行く → *行いてちゃった* ❌
   - **កែតម្រូវ**: 行く → 行って (て-form) → 行ってしまった → **行っちゃった** ✔️
   - ចងចាំ: ត្រូវបំប្លែងកិរិយាសព្ទទៅជាទម្រង់ て ជាមុនសិន ទើបកាត់ て ចេញហើយជំនួសដោយ っちゃった / ងាកទៅ で ចេញជំនួសដោយ んじゃった។

### គន្លឹះក្នុងការរៀន និងចងចាំ (Learning Strategies)
- **ភ្ជាប់អារម្មណ៍ជាមួយទម្រង់ (Remember the Emotion)**:
  - នៅពេលណាដែលអ្នកចង់និយាយពាក្យថា «...បាត់ទៅហើយ (ស្តាយក្រោយ/ភ្លាត់ស្នៀត)» ឬ «ជ្រុលដៃ...បាត់» ក្នុងភាសាខ្មែរ សូមនឹកឃើញដល់ **～ちゃった** (ចំពោះ て) និង **～じゃった** (ចំពោះ で) ភ្លាម!

## ៧. សង្ខេប និងលំហាត់អនុវត្ត (Summary and Review)
### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～ちゃった** គឺជាទម្រង់កាត់បែបសន្ទនាប្រចាំថ្ងៃនៃ **～てしまった** (ហើយ **～じゃった** កាត់ចេញពី **～でしまった**)។
- ប្រើសម្រាប់បញ្ជាក់ពី **ការបញ្ចប់សកម្មភាពទាំងស្រុង** ដោយបង្កប់នូវអារម្មណ៍ **សោកស្តាយ វិប្បដិសារី** ឬ **ការធ្វើខុសដោយអចេតនា**។
- ស័ក្តិសមសម្រាប់តែ **ការសន្ទនាស្និទ្ធស្នាលធម្មតា** ប៉ុណ្ណោះ។ ជៀសវាងការប្រើក្នុងបរិបទផ្លូវការ ឬជាមួយថ្នាក់លើ។

### លំហាត់សាកល្បងសមត្ថភាពរហ័ស (Quick Recap Quiz)
១. **ចូរបំប្លែងប្រយោគខាងក្រោមទៅជាទម្រង់ ～ちゃった / ～じゃった:**
   a) 書いてしまった。
   b) 食べてしまった。
   c) 飲んでしまった。
២. **ចូរជ្រើសរើសទម្រង់ដែលសមរម្យបំផុតសម្រាប់ការសន្ទនាផ្លូវការ:**
   - a) 忘れちゃいました。
   - b) 忘れてしまいました。
៣. **ចូរបកប្រែប្រយោគខាងក្រោមមកជាភាសាខ្មែរ:**
   a) 電話をなくしちゃった。
   b) 宿題をやらなきゃいけないのに、寝ちゃった。

### ចម្លើយ (Answers):
១. **ការបំប្លែង:**
   a) 書いちゃった。
   b) 食べちゃった。
   c) 飲んじゃった。
២. **ទម្រង់ផ្លូវការសមរម្យ:**
   - **ចម្លើយ**: b) 忘れてしまいました。
៣. **ការបកប្រែ:**
   a) ខ្ញុំជ្រុលធ្វើបាត់ទូរសព្ទបាត់ទៅហើយ។
   b) ទាំងដែលត្រូវតែធ្វើកិច្ចការផ្ទះសោះ បែរជាជ្រុលដេកលក់បាត់។
