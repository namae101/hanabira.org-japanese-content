# ចំណុចវេយ្យាករណ៍ជប៉ុន: កិរិយាសព្ទ + させられる (~saserareru)

**កម្រិត JLPT:** JLPT N1

---

## ១. សេចក្តីផ្តើម (Introduction)

នៅក្នុងភាសាជប៉ុន ទម្រង់បញ្ជា-កម្ម (Causative-Passive Form) តំណាងដោយ **～させられる** (`~saserareru`) ត្រូវបានប្រើប្រាស់ដើម្បីបង្ហាញពីស្ថានភាពដែលប្រធាន **ត្រូវបានគេបង្ខំ ដាក់កំហិត ឬធ្វើឱ្យត្រូវតែធ្វើ** សកម្មភាពអ្វីមួយដោយអ្នកដទៃ។ ទម្រង់នេះកើតឡើងដោយការរួមបញ្ចូលគ្នារវាងទម្រង់បញ្ជា/ឱ្យធ្វើ (Causative: 使役 - បញ្ជា ឬអនុញ្ញាតឱ្យនរណាម្នាក់ធ្វើ) និងទម្រង់រងអំពើ/កម្ម (Passive: 受身 - ការទទួលរងអំពើ)។ 

លើសពីនេះ ក្នុងកម្រិតខ្ពស់ (JLPT N1/N2) ទម្រង់នេះមិនត្រឹមតែសំដៅលើការបង្ខិតបង្ខំពីខាងក្រៅប៉ុណ្ណោះទេ ប៉ុន្តែថែមទាំងប្រើប្រាស់សម្រាប់ពណ៌នាអំពី **អារម្មណ៍ភ្ញាក់រលឹក ការដឹងខ្លួនឡើងវិញ ឬការរំជួលចិត្តដោយឯកឯង (Spontaneous Emotional Awakening)** ដូចជា `考えさせられる` (ធ្វើឱ្យត្រូវគិតពិចារណាយ៉ាងស៊ីជម្រៅ) ផងដែរ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
1. **ការបង្ខិតបង្ខំដោយអ្នកដទៃ (External Coercion):** ប្រធានត្រូវបានគេបង្ខំ ឬដាក់កំហិតឱ្យធ្វើសកម្មភាពមួយដោយទាល់ចិត្ត មិនចង់ធ្វើ ឬគ្មានជម្រើសបដិសេធ។
2. **ការជំរុញចិត្ត/ភ្ញាក់រលឹកដោយឯកឯង (Spontaneous Awakening):** ព្រឹត្តិការណ៍ ឬទស្សនីយភាពណាមួយធ្វើឱ្យប្រធានកើតមានអារម្មណ៍ គំនិត ឬការពិចារណាឡើងមកដោយមិនអាចទប់ទល់បាន (ឧទាហរណ៍៖ ធ្វើឱ្យភ្ញាក់រលឹក, ធ្វើឱ្យក្រៀមក្រំ, ធ្វើឱ្យចាប់អារម្មណ៍)។

### រចនាសម្ព័ន្ធវេយ្យាករណ៍ (Structure)

```
[អ្នកបង្ខំ/ភ្នាក់ងារ] に + [ប្រធាន] は/が + [កិរិយាសព្ទបំប្លែងជាទម្រង់បញ្ជា-កម្ម (使役受身形)]
```

#### របៀបបំប្លែងតាមក្រុមនៃកិរិយាសព្ទ (Verb Groups):

1. **កិរិយាសព្ទក្រុមទី១ (Godan Verbs - 五段動詞):**
   - **ទម្រង់វែង/ស្តង់ដារ (Standard Form):** ប្តូរសម្លេងជួរ **-u** ទៅជួរ **-a** រួចថែម **せられる** (`-aserareru`)។
     - ឧទាហរណ៍: 書く (kaku) ➔ 書か + せられる = **書かせられる** (kakaserareru)
     - ឧទាហរណ៍: 飲む (nomu) ➔ 飲ま + せられる = **飲ませられる** (nomaserareru)
   - **ទម្រង់កាត់/សន្ទនាទូទៅ (Contracted Spoken Form):** ប្តូរសម្លេងជួរ **-u** ទៅជួរ **-a** រួចថែម **される** (`-asareru`) *(ចំណាំ៖ លើកលែងតែកិរិយាសព្ទបញ្ចប់ដោយ `す` ដូចជា `話す` គឺត្រូវប្រើ `話させられる` ជានិច្ច មិនអាចបំប្លែងជា `話さされる` បានឡើយ)*។
     - ឧទាហរណ៍: 書く ➔ **書かされる** (kakasareru)
     - ឧទាហរណ៍: 待つ ➔ **待たされる** (matasareru)
     - ឧទាហរណ៍: 読む ➔ **読まされる** (yomasareru)

2. **កិរិយាសព្ទក្រុមទី២ (Ichidan Verbs - 一段動詞):**
   - លុប **る** រួចបន្ថែម **させられる** (`-saserareru`) (គ្មានទម្រង់កាត់ទេ)។
     - ឧទាហរណ៍: 食べる (taberu) ➔ **食べさせられる** (tabesaserareru)
     - ឧទាហរណ៍: 見る (miru) ➔ **見させられる** (misaserareru)

3. **កិរិយាសព្ទមិនទៀងទាត់ (Irregular Verbs):**
   - **する** ➔ **させられる** (saserareru)
   - **来る** (kuru) ➔ **来させられる** (kosaserareru)

### តារាងសង្ខេបការបំប្លែង (Formation Table)

| ប្រភេទកិរិយាសព្ទ | ទម្រង់វចនានុក្រម (Dictionary) | ទម្រង់បញ្ជា-កម្ម (使役受身形) | ទម្រង់កាត់ក្នុងសន្ទនា (Contracted) |
|---|---|---|---|
| **ក្រុមទី១ (Godan)** | 読む (អាន) | 読ませられる | **読まされる** |
| | 書く (សរសេរ) | 書かせられる | **書かされる** |
| | 待つ (រង់ចាំ) | 待たせられる | **待たされる** |
| | 話す (និយាយ) | **話させられる** | *(គ្មានទម្រង់កាត់)* |
| **ក្រុមទី២ (Ichidan)** | 見る (មើល) | **見させられる** | *(គ្មានទម្រង់កាត់)* |
| | 食べる (ញ៉ាំ) | **食べさせられる** | *(គ្មានទម្រង់កាត់)* |
| **មិនទៀងទាត់ (Irregular)** | する (ធ្វើ) | **させられる** | *(គ្មានទម្រង់កាត់)* |
| | 来る (មក) | **来させられる** | *(គ្មានទម្រង់កាត់)* |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance & Comparative Analysis)

### ៣.១. ការប្រៀបធៀបរវាងទម្រង់រងអំពើ ទម្រង់បញ្ជា និងទម្រង់បញ្ជា-កម្ម

| ទម្រង់វេយ្យាករណ៍ | ការផ្តោត និងអត្ថន័យ | ឧទាហរណ៍ប្រយោគ |
|---|---|---|
| **ទម្រង់រងអំពើ (受身形 - ~られる)** | ប្រធានទទួលរងសកម្មភាពពីអ្នកដទៃ (សកម្មភាពធ្វើមកលើប្រធានផ្ទាល់) | 先生に叱られた。<br>*(ខ្ញុំត្រូវបានគ្រូស្តីបន្ទោស។)* |
| **ទម្រង់បញ្ជា (使役形 - ~させる)** | អ្នកមានអំណាចបង្គាប់បញ្ជា ឬអនុញ្ញាតឱ្យអ្នកក្រោមបង្គាប់ធ្វើសកម្មភាព | 母が子どもに野菜を食べさせる。<br>*(ម្តាយឱ្យកូនញ៉ាំបន្លែ / បង្ខំកូនឱ្យញ៉ាំបន្លែ។)* |
| **ទម្រង់បញ្ជា-កម្ម (使役受身形 - ~させられる)** | ប្រធានរងការបង្ខិតបង្ខំពីអ្នកដទៃឱ្យ**ធ្វើសកម្មភាពនោះដោយខ្លួនឯង** ទាំងមិនចង់ធ្វើ | 私は母に野菜を食べさせられた。<br>*(ខ្ញុំត្រូវបានម្តាយបង្ខំឱ្យញ៉ាំបន្លែ។)* |

### ៣.២. ន័យស៊ីជម្រៅ៖ ការបង្ខិតបង្ខំពីខាងក្រៅ ទល់នឹង ការរំជួលចិត្ត/ភ្ញាក់រលឹកដោយឯកឯង (External Coercion vs. Spontaneous Emotional Awakening)

នៅក្នុងកម្រិតខ្ពស់ (JLPT N1) កិរិយាសព្ទ `〜させられる` បង្ហាញពីទស្សនវិជ្ជាពីរផ្ទុយគ្នា៖

1. **ការបង្ខិតបង្ខំ និងការចុះចាញ់ (Forced Submission / External Coercion):**
   - ប្រើជាមួយកិរិយាសព្ទសកម្មភាពកាយវិការជាក់ស្តែង (ឧ. `残業させられる`, `待たされる`, `走らされる`)។
   - បង្ហាញពីអារម្មណ៍រងទុក្ខ អាក់អន់ស្រពន់ចិត្ត (迷惑 - meiwaku) និងការបាត់បង់សិទ្ធិស្វ័យសម្រេច ដោយសារអំណាច ឬសម្ពាធពីឋានានុក្រមសង្គម។

2. **ការជំរុញចិត្ត និងការភ្ញាក់រលឹកផ្លូវចិត្តដោយឯកឯង (Spontaneous Awakening / Psychological Resonance):**
   - ប្រើជាមួយកិរិយាសព្ទអារម្មណ៍ គំនិត ឬការយល់ដឹង (Verbs of perception & emotion) ដូចជា `考える` (គិត), `感じる` (មានអារម្មណ៍), `泣く` (យំ), `驚く` (ភ្ញាក់ផ្អើល), `感動する` (រំភើបចិត្ត)។
   - **អត្ថន័យ:** មិនមែនមាននរណាម្នាក់យកកាំភ្លើងមកភ្ជង់ក្បាលបង្ខំឱ្យយើងគិតនោះទេ ប៉ុន្តែគឺស្ថានការណ៍ ការពិត ឬសកម្មភាពរបស់អ្នកដទៃ **បានដាស់ញាណ និងអង្រួនបេះដូងយើង** រហូតដល់យើងទប់មិនជាប់ ហើយបង្ខំចិត្តត្រូវតែគិត ឬត្រូវតែរំជួលចិត្តដោយចៀសមិនរួច។
   - *ឧទាហរណ៍:*
     - **このドキュメンタリー映画を見て、平和の尊さについて深く考えさせられた。**  
       *(ការទស្សនាខ្សែភាពយន្តឯកសារនេះ បានធ្វើឱ្យខ្ញុំត្រូវគិតពិចារណាយ៉ាងស៊ីជម្រៅអំពីតម្លៃនៃសន្តិភាព។)*
     - **彼のひたむきな努力には、本当に頭を下げさせられる。**  
       *(ការខិតខំប្រឹងប្រែងឥតងាករេរបស់គាត់ បានធ្វើឱ្យខ្ញុំត្រូវតែឱនក្បាលគោរពដោយស្មោះ។)*

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### បរិបទផ្លូវការ (Formal Context)

1. **新入社員の研修では、長時間のスピーチを聞かせられました。**  
   *នៅក្នុងវគ្គបណ្តុះបណ្តាលបុគ្គលិកថ្មី ពួកយើងត្រូវបានគេតម្រូវឱ្យអង្គុយស្តាប់សុន្ទរកថាយ៉ាងយូរ។*

2. **本日のシンポジウムは、教育のあり方について深く考えさせられる内容でした。**  
   *សិក្ខាសាលាក្នុងថ្ងៃនេះ មានខ្លឹមសារដែលបានធ្វើឱ្យយើងគ្រប់គ្នាត្រូវគិតពិចារណាយ៉ាងស៊ីជម្រៅអំពីទម្រង់ និងអនាគតនៃការអប់រំ។*

3. **会議において、自分の担当外の業務まで引き受けさせられた。**  
   *នៅក្នុងកិច្ចប្រជុំ ខ្ញុំត្រូវបានគេបង្ខំឱ្យទទួលរ៉ាប់រងការងារដែលនៅក្រៅភារកិច្ចរបស់ខ្លួនឯងទៀតផង។*

### បរិបទក្រៅផ្លូវការ / ជីវិតប្រចាំថ្ងៃ (Informal / Daily Context)

1. **兄に部屋の掃除を手伝わされた。**  
   *ខ្ញុំត្រូវបានបងប្រុសបង្ខំឱ្យជួយបោសសម្អាតបន្ទប់។*

2. **飲み会で、先輩に無理やり歌を歌わせられた。**  
   *នៅក្នុងពិធីជប់លៀងផឹកស៊ី ខ្ញុំត្រូវបានរៀមច្បង (Senpai) បង្ខំឱ្យច្រៀងទាំងទាល់ចិត្ត។*

3. **遊園地でジェットコースターに乗せられて、怖くて泣きそうだった。**  
   *នៅឯសួនកម្សាន្ត ខ្ញុំត្រូវបានគេបង្ខំឱ្យជិះរថភ្លើងរំកិលភ្នំ ភ័យស្ទើរតែស្រក់ទឹកភ្នែក។*

### បរិបទសំណេរ និងសារព័ត៌មាន (Written & News Context)

1. **被災地の子どもたちのたくましい姿に、私たちは大いに勇気づけさせられた。**  
   *ភាពរឹងមាំនិងអង់អាចរបស់កុមារនៅតំបន់រងគ្រោះមហន្តរាយ បានធ្វើឱ្យពួកយើងទទួលបានការលើកទឹកចិត្ត និងភាពក្លាហានយ៉ាងខ្លាំងក្លាឡើងវិញ។*

2. **選手たちは監督から過酷な練習を課され、限界まで走らされた。**  
   *ក្រុមកីឡាករត្រូវបានគ្រូបង្វឹកដាក់កំហិតការហ្វឹកហាត់យ៉ាងតឹងរ៉ឹង ហើយត្រូវបានបង្ខំឱ្យរត់រហូតដល់អស់កម្លាំងពីខ្លួន។*

### បរិបទសន្ទនាផ្ទាល់មាត់ (Spoken Context)

1. **昨日、駅前でアンケートに答えさせられて、電車に乗り遅れちゃったよ。**  
   *ម្សិលមិញត្រូវបានគេឃាត់ឱ្យឆ្លើយកម្រងសំណួរនៅមុខស្ថានីយ ទើបបណ្តាលឱ្យរត់មិនទាន់រថភ្លើងបាត់ទៅ!*

2. **こんなにたくさんの料理を食べさせられたら、もうお腹がはちきれそうだよ。**  
   *បើគេបង្ខំឱ្យញ៉ាំម្ហូបច្រើនដល់ម្ល៉ឹងៗ ច្បាស់ជាបែកពោះស្លាប់មិនខានទេ។*

## ៥. កំណត់សម្គាល់វប្បធម៌ជប៉ុន (Cultural Notes)

### ឋានានុក្រមសង្គម និងកាតព្វកិច្ច (Social Hierarchy & Obligations)
នៅក្នុងសង្គមជប៉ុន ប្រព័ន្ធឋានានុក្រម (目上 - meue អ្នកលើ និង 目下 - meshita អ្នកក្រោម) និងទំនាក់ទំនងរៀមច្បង-ប្អូន (Senpai-Kōhai) មានឥទ្ធិពលយ៉ាងខ្លាំង។ ការប្រើប្រាស់ទម្រង់ **～させられる** ឆ្លុះបញ្ចាំងពីស្ថានភាពដែលអ្នកក្រោមបង្គាប់ មិនអាចបដិសេធបញ្ជា ឬសំណូមពររបស់អ្នកធំជាងបានឡើយ។ ការប្រកែកតវ៉ាចំពោះមុខអាចបង្កជាការបែកបាក់ភាពចុះសម្រុង (和 - Wa) ដូច្នេះបុគ្គលជប៉ុនតែងតែជ្រើសរើសការទទួលយកទាំងទាល់ចិត្ត ហើយបង្ហាញពីការមិនពេញចិត្តរបស់ខ្លួនតាមរយៈទម្រង់វេយ្យាករណ៍ `させられた` នេះនៅពេលរៀបរាប់ប្រាប់អ្នកដទៃ។

### កម្រិតគួរសម និងការបង្ហាញការត្អូញត្អែរដោយប្រយោល (Politeness & Subtle Complaints)
ទម្រង់នេះច្រើនតែបង្កប់នូវ **អារម្មណ៍ត្អូញត្អែរ ឬការរំខានចិត្ត (迷惑 - Meiwaku)**។ ហេតុនេះ មិនគួរប្រើទម្រង់នេះចំពោះមុខអ្នកដែលបានបង្គាប់យើងឱ្យធ្វើសកម្មភាពនោះឡើយ (ឧទាហរណ៍៖ មិនត្រូវនិយាយទៅកាន់ចៅហ្វាយនាយថា `社長に仕事をさせられました` នៅចំពោះមុខគាត់ឡើយ ព្រោះវាស្តាប់ទៅដូចជាការស្តីបន្ទោស ឬចោទប្រកាន់ថាគាត់ធ្វើបាបយើង)។

### ឃ្លា idioms ដែលជួបញឹកញាប់បំផុត
- **待たされる (matasareru):** ត្រូវបានគេទុកឱ្យរង់ចាំ (ខាតពេលដោយសារអ្នកដទៃ)
- **考えさせられる (kangaesaserareru):** ធ្វើឱ្យត្រូវគិតពិចារណាយ៉ាងជ្រាលជ្រៅ (ជួបញឹកញាប់ក្នុងកម្រិត N1)
- **嫌な思いをさせられる (iya na omoi o saserareru):** ត្រូវបានគេធ្វើឱ្យមានអារម្មណ៍មិនល្អ ឬទើសទាល់ចិត្ត

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes & Tips)

### កំហុសទូទៅ (Common Mistakes)

1. **ការច្រឡំរវាងទម្រង់រងអំពើ (受身) និងទម្រង់បញ្ជា-កម្ម (使役受身):**
   - ❌ **មិនត្រឹមត្រូវ:** 部長に残業された。 *(មានន័យថាចៅហ្វាយធ្វើការថែមម៉ោង ហើយខ្ញុំរងទុក្ខដោយសារគាត់ធ្វើការថែមម៉ោងនោះ - 間接受身)*
   - ✅ **ត្រឹមត្រូវ:** 部長に残業**させられた**。 *(ខ្ញុំត្រូវបានចៅហ្វាយបង្ខំឱ្យធ្វើការថែមម៉ោង)*

2. **ការបំប្លែងខុសសម្រាប់កិរិយាសព្ទក្រុមទី១ បញ្ចប់ដោយ `す`:**
   - ❌ **មិនត្រឹមត្រូវ:** 話す ➔ 話さされる
   - ✅ **ត្រឹមត្រូវ:** 話す ➔ **話させられる** *(ចងចាំថា កិរិយាសព្ទបញ្ចប់ដោយ `す` មិនអាចប្រើទម្រង់កាត់ `される` បានឡើយ ព្រោះវានឹងជាន់សម្លេង `ささ`)*

3. **ការច្រឡំការបំប្លែងកិរិយាសព្ទក្រុមទី២:**
   - ❌ **មិនត្រឹមត្រូវ:** 食べる ➔ 食べらせる / 食べらされる
   - ✅ **ត្រឹមត្រូវ:** 食べる ➔ **食べさせられる**

### គន្លឹះជំនួយការចងចាំ (Tips & Mnemonics)
- **ក្បួនសមីការគិត:**  
  `កិរិយាសព្ទបញ្ជា (させる) + កិរិយាសព្ទរងអំពើ (られる) = させられる`  
  *(មានន័យថា "រងអំពើពីការបង្គាប់បញ្ជា" ➔ ត្រូវគេបង្ខំឱ្យធ្វើ)*
- **ទម្រង់កាត់កិរិយាសព្ទក្រុមទី១:**  
  `書く (kaku) ➔ 書か (kaka) + される (sareru) = 書かされる (kakasareru)`  
  *(សន្សំសំចៃពេលនិយាយក្នុងសន្ទនាប្រចាំថ្ងៃ)*

## ៧. សង្ខេប និងសំណួររំលឹកមេរៀន (Summary & Review)

### ចំណុចគន្លឹះសំខាន់ៗ
- **～させられる** ប្រើដើម្បីបង្ហាញថាយើងត្រូវបានអ្នកដទៃបង្ខំឱ្យធ្វើសកម្មភាពមួយទាំងមិនចង់ធ្វើ ឬគ្មានសិទ្ធិជ្រើសរើស។
- ក្នុងកម្រិត N1 វាត្រូវបានប្រើសម្រាប់បង្ហាញពី **ការភ្ញាក់រលឹក ការរំជួលចិត្ត ឬការទាញអារម្មណ៍ដោយឯកឯង (Spontaneous Awakening)** ដូចជា `考えさせられる`។
- កិរិយាសព្ទក្រុមទី១ អាចបំប្លែងជាទម្រង់កាត់ `〜される` (លើកលែងកិរិយាសព្ទបញ្ចប់ដោយ `す`)។

### សំណួររំលឹកការយល់ដឹង (Quick Recap Quiz)

១. ចូរពន្យល់ពីរបៀបបំប្លែងទម្រង់បញ្ជា-កម្មនៃកិរិយាសព្ទក្រុមទី២ (Ichidan Verbs)?  
២. ចូរបកប្រែប្រយោគខាងក្រោមនេះជាភាសាខ្មែរ៖  
   **母に野菜を食べさせられた。**  
៣. ហេតុអ្វីបានជាឃ្លា **「考えさせられる」** ក្នុងកម្រិត N1 មិនត្រូវបានចាត់ទុកជាការបង្ខិតបង្ខំខាងរាងកាយ?

#### ចម្លើយ៖
១. លុបកន្ទុយ **る** នៃទម្រង់វចនានុក្រម រួចបន្ថែម **させられる** (ឧ. 見る ➔ 見させられる)។  
២. *ខ្ញុំត្រូវបានម្តាយបង្ខំឱ្យញ៉ាំបន្លែ។*  
៣. ពីព្រោះវាជាការប្រើប្រាស់ក្នុងន័យ **ភ្ញាក់រលឹកផ្លូវចិត្តដោយឯកឯង (Spontaneous Awakening)** ពោលគឺព្រឹត្តិការណ៍ ឬទស្សនីយភាពណាមួយបានជះឥទ្ធិពល ឬអង្រួនបេះដូងឱ្យយើងត្រូវតែគិតពិចារណាដោយចៀសមិនរួច មិនមែនជាការបង្ខំកាយវិការនោះឡើយ។
