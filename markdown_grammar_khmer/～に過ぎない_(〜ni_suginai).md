# ចំណុចវេយ្យាករណ៍ជប៉ុន: ～に過ぎない (〜ni suginai)
**កម្រិត JLPT:** JLPT N2

---

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងភាសាជប៉ុន ទម្រង់ **～に過ぎない (〜ni suginai)** ត្រូវបានប្រើប្រាស់ដើម្បីបញ្ជាក់ថា អ្វីមួយ **«គ្រាន់តែជា... ប៉ុណ្ណោះ / គ្មានអ្វីលើសពី... ឡើយ»** (nothing more than / merely / just / only)។ វាជាទម្រង់វេយ្យាករណ៍ផ្លូវការ និងគួរសម ដែលប្រើសម្រាប់បន្ទាបសារៈសំខាន់ បង្ហាញពីកម្រិតកម្រិតទាប ឬជាការបន្ទាបខ្លួន (modesty) របស់វាគ្មិន ដើម្បីបញ្ជាក់ថាបញ្ហា ឬទង្វើនោះមិនមែនជាការអស្ចារ្យ ពិសេស ឬធំដុំដូចការស្មានឡើយ។

---

## ២. ការពន្យល់វេយ្យាករណ៍គោល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **អត្ថន័យជាភាសាខ្មែរ**: *គ្រាន់តែជា... ប៉ុណ្ណោះ / គ្មានអ្វីក្រៅពី... ឡើយ / ត្រឹមតែជា...*
- **ការប្រើប្រាស់**: បង្ហាញពីការវាយតម្លៃថាអ្វីមួយស្ថិតក្នុងកម្រិតទាប មិនលើសពីការរៀបរាប់ ប្រើសម្រាប់បន្ទាបសារៈសំខាន់ វាយតម្លៃកម្រិតធម្មតា ឬសម្តែងការបន្ទាបខ្លួនមិនអួតអាង។

### ទម្រង់ផ្សំ (Structure / Formation)
ទម្រង់ **～に過ぎない** ផ្សំជាមួយទម្រង់ធម្មតា (Plain Form) នៃកិរិយាសព្ទ, នាម, និងគុណនាម៖

| ប្រភេទពាក្យ (Word Type) | ទម្រង់តភ្ជាប់ (Formation) | ឧទាហរណ៍ (Example) |
|:-----------------------|:-------------------------|:-------------------|
| **នាម (Noun)** | នាម + **に過ぎない** (ឬ នាម + である + に過ぎない) | 冗談 + に過ぎない (គ្រាន់តែជារឿងកំប្លែង) |
| **កិរិយាសព្ទ (Verb)** | ទម្រង់ធម្មតា (Plain Form: 辞書形/た形/ない形) + **に過ぎない** | 言った + に過ぎない (គ្រាន់តែបាននិយាយប៉ុណ្ណោះ) |
| **គុណនាម な (Na-Adj)** | គុណនាម な (語幹) + **であるに過ぎない** | 簡単である + に過ぎない (គ្រាន់តែជារឿងងាយស្រួល) |
| **គុណនាម い (I-Adj)** | គុណនាម い (Plain Form) + **に過ぎない** | 珍しい + に過ぎない (គ្រាន់តែជារឿងចម្លែកប៉ុណ្ណោះ) |

#### ដ្យាក្រាមទម្រង់ (Diagram)
```
[ នាម / កិរិយាសព្ទ (ទម្រង់ធម្មតា) / គុណនាម な である / គុណនាម い ] + に過ぎない / に過ぎません
```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Deep Nuances)

### និរុត្តិសាស្ត្រ និងទស្សនវិជ្ជានៃពាក្យ (Origin & Semantic Mechanics)
ពាក្យ **過ぎない** ក្លាយមកពីកិរិយាសព្ទ **過ぎる (sugiru - ហួស / លើស / ហួសព្រំដែន)** ក្នុងទម្រង់បដិសេធ **過ぎない (មិនហួស / មិនលើសពី)**។ ដូច្នេះ ន័យចំនៃ «A に過ぎない» គឺ **«មិនហួស ឬមិនលើសពីកម្រិត A ឡើយ»**។

### ការវិភាគប្រៀបធៀបជាមួយទម្រង់ស្រដៀងគ្នា (Nuance Comparison)

| ទម្រង់វេយ្យាករណ៍ | អត្ថន័យ | កម្រិតផ្លូវការ និងការប្រើប្រាស់ជាក់ស្តែង |
|:---|:---|:---|
| **～に過ぎない** | គ្រាន់តែជា... ប៉ុណ្ណោះ (គ្មានអ្វីលើសពីនេះ) | **ផ្លូវការ / សរសេរ និងនិយាយថ្លៃថ្នូរ (N2):** បន្ទាបសារៈសំខាន់ដោយផ្ទាល់ (downplay significance) ឬសម្តែងការបន្ទាបខ្លួន (modesty) ថាសមិទ្ធផល ឬទង្វើនោះតូចតាច គ្មានអ្វីអស្ចារ្យ។ |
| **～だけで (〜だけ)** | ត្រឹមតែ... / គ្រាន់តែ... ដោយសារតែ... | **ទូទៅ / កណ្តាល (Neutral):** បញ្ជាក់កម្រិតកំណត់ ឬលក្ខខណ្ឌសុទ្ធសាធ ដោយមិនបង្កប់អារម្មណ៍បន្ទាបតម្លៃ ឬបន្ទាបខ្លួនឡើយ (ឧទាហរណ៍៖ 聞くだけで = គ្រាន់តែឮក៏...)។ |
| **～にほかならない** | ពិតជាគ្មានអ្វីក្រៅពី... ឡើយ (គឺច្បាស់ជា...) | **ផ្លូវការខ្លាំង / សរសេរ (N2/N1):** បញ្ជាក់សង្កត់ធ្ងន់ពីឫសគល់ ឬមូលហេតុពិតប្រាកដ ១០០% ដោយម៉ឺងម៉ាត់ (assertive / definitive conclusion) ផ្ទុយស្រឡះពីការបន្ទាបខ្លួននៃ に過ぎない។ |
| **～しか～ない** | មានតែ... ប៉ុណ្ណោះ (ក្រៅពីនេះគ្មានទេ) | **ទូទៅ / ផ្ទាល់មាត់:** សង្កត់ធ្ងន់លើកង្វះខាត ឬភាពខ្សត់ខ្សោយខ្លាំង (scarcity)។ |
| **ただ～だけだ** | គ្រាន់តែ... ប៉ុណ្ណោះ | **ទូទៅ / សន្ទនាប្រចាំថ្ងៃ:** ប្រើពាក្យ ただ នៅដើមប្រយោគដើម្បីបញ្ជាក់ន័យ «ត្រឹមតែ» ធម្មតា។ |

### ចំណុចស៊ីជម្រៅក្នុងការប្រើប្រាស់ (Deep Pragmatics)
1. **ការបន្ទាបខ្លួនតាមវប្បធម៌ជប៉ុន (Kenjou / Modesty):** នៅពេលគេសរសើរពីភាពជោគជ័យ ជនជាតិជប៉ុននិយមឆ្លើយថា `運が良かったに過ぎません` (គ្រាន់តែសំណាងល្អប៉ុណ្ណោះ) ឬ `私は手伝ったに過ぎません` (ខ្ញុំគ្រាន់តែបានជួយបន្តិចបន្តួចប៉ុណ្ណោះ) ដើម្បីរក្សាសុខដុមនីយកម្ម និងមិនអួតខ្លួន។
2. **ការបន្ទាបតម្លៃ ឬកាត់បន្ថយទម្ងន់បញ្ហា (Minimizing Impact):** ប្រើនៅពេលចង់រំងាប់អារម្មណ៍អ្នកដទៃ ឬពន្យល់ថាបញ្ហាមិនធ្ងន់ធ្ងរ ដូចជា `ただの風邪に過ぎない` (គ្រាន់តែជាផ្តាសាយធម្មតាប៉ុណ្ណោះ កុំបារម្ភ)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទ (Examples in Context)

### ប្រយោគគំរូ (Sentence Examples)

1. **ផ្លូវការ - ភាសាសរសេរ (Formal - Written)**
   - **ជប៉ុន**: これは序章に過ぎません。
   - **រ៉ូម៉ាជី**: Kore wa joshō ni sugimasen.
   - **ខ្មែរ**: នេះគ្រាន់តែជាអារម្ភកថា (សេចក្តីផ្តើម) ប៉ុណ្ណោះ (នៅមានរឿងរ៉ាវជាច្រើនទៀតនៅខាងមុខ)។

2. **មិនផ្លូវការ - ភាសានិយាយ (Informal - Spoken)**
   - **ជប៉ុន**: 彼は友達に過ぎないよ。
   - **រ៉ូម៉ាជី**: Kare wa tomodachi ni suginai yo.
   - **ខ្មែរ**: គាត់គ្រាន់តែជាមិត្តភក្តិធម្មតាម្នាក់ប៉ុណ្ណោះ (គ្មានទំនាក់ទំនងអ្វីពិសេសឡើយ)។

3. **ផ្លូវការ - ភាសានិយាយបន្ទាបខ្លួន (Formal - Spoken Modesty)**
   - **ជប៉ុន**: 私は自分の意見を述べたに過ぎません。
   - **រ៉ូម៉ាជី**: Watashi wa jibun no iken o nobeta ni sugimasen.
   - **ខ្មែរ**: ខ្ញុំគ្រាន់តែបានបញ្ចេញមតិយោបល់ផ្ទាល់ខ្លួនបន្តិចបន្តួចប៉ុណ្ណោះ។

4. **មិនផ្លូវការ - ភាសាសរសេរ/និយាយ (Informal)**
   - **ជប៉ុន**: それは冗談に過ぎない。
   - **រ៉ូម៉ាជី**: Sore wa jōdan ni suginai.
   - **ខ្មែរ**: រឿងនោះគ្រាន់តែជារឿងលេងសើចប៉ុណ្ណោះ (កុំប្រកាន់ ឬយកជាការអី)។

5. **ការវាយតម្លៃកម្រិតទិន្នន័យ/សម្មតិកម្ម (Analytical Context)**
   - **ជប៉ុន**: この調査結果は、一つの可能性を示したに過ぎない。
   - **រ៉ូម៉ាជី**: Kono chōsa kekka wa, hitotsu no kanōsei o shimeshita ni suginai.
   - **ខ្មែរ**: លទ្ធផលនៃការស្រាវជ្រាវនេះ គ្រាន់តែបង្ហាញពីលទ្ធភាពមួយប៉ុណ្ណោះ (មិនទាន់អាចសន្និដ្ឋានជាផ្លូវការបានឡើយ)។

## ៥. កំណត់សម្គាល់វប្បធម៌ និងកម្រិតគួរសម (Cultural Notes & Registers)

### តម្លៃវប្បធម៌ជប៉ុន (Cultural Relevance)
- **ភាពបន្ទាបខ្លួន (謙遜 - Kenson):** សង្គមជប៉ុនឱ្យតម្លៃខ្ពស់លើការបន្ទាបខ្លួន។ ការប្រើ **～に過ぎない** ជួយឱ្យអ្នកនិយាយមិនបង្ហាញការអួតអាងពីស្នាដៃ សមត្ថភាព ឬទ្រព្យសម្បត្តិឡើយ។

### កម្រិតគួរសម (Politeness Levels)
- **に過ぎない (Plain Form)**: ប្រើក្នុងបរិបទសាមញ្ញ និយាយជាមួយមិត្តភក្តិ ឬប្រើក្នុងការសរសេរអត្ថបទ របាយការណ៍ និក្ខេបបទ និងសារព័ត៌មាន។
- **に過ぎません (Polite Form - ます形)**: ប្រើក្នុងការសន្ទនាការងារ ជំនួញ ឬការឆ្លើយតបជាមួយមនុស្សចាស់/ថ្នាក់លើ ដើម្បីបង្ហាញការគួរសម និងការបន្ទាបខ្លួន។

### ឃ្លា និងកន្សោមពាក្យពេញនិយម (Idiomatic Collocations)
- **形式に過ぎない** (*keishiki ni suginai*): គ្រាន់តែជាទម្រង់ការ / ពិធីការប៉ុណ្ណោះ (គ្មានខ្លឹមសារពិតប្រាកដ)។
- **偶然に過ぎない** (*gūzen ni suginai*): គ្រាន់តែជាការចៃដន្យសុទ្ធសាធ។
- **氷山の一角に過ぎない** (*hyōzan no ikkaku ni suginai*): គ្រាន់តែជាចុងផ្ទាំងទឹកកកប៉ុណ្ណោះ (ជាចំណែកតូចមួយនៃបញ្ហាធំទាំងមូល)។
- **言い訳に過ぎない** (*iiwake ni suginai*): គ្រាន់តែជាលេសដោះសារប៉ុណ្ណោះ។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes & Tips)

### ការវិភាគកំហុស (Error Analysis)
1. **ការប្រើប្រាស់ទម្រង់កិរិយាសព្ទខុស (Incorrect Verb Form)**
   - **កំហុស**: 彼は言いますに過ぎない。❌
   - **កែតម្រូវ**: 彼は**言う**に過ぎない。 (ឬ 言ったに過ぎない) ⭕
   - **គន្លឹះ**: ត្រូវប្រើ**ទម្រង់ធម្មតា (Plain Form / 辞書形)** នៃកិរិយាសព្ទនៅពីមុខ に過ぎない ជានិច្ច មិនអាចប្រើ ます形 នៅកណ្តាលប្រយោគបានឡើយ។ ប្រសិនបើចង់គួរសម ត្រូវប្តូរនៅខាងចុង (`〜に過ぎません`)។

2. **ការច្រឡំរវាង に過ぎない និង すぎる (Exceed / Too Much)**
   - **កំហុស**: 食べすぎない。 (មានន័យថា «កុំញ៉ាំច្រើនជ្រុល» - មកពីកិរិយាសព្ទ 食べすぎる)។
   - **ការពន្យល់**: `V-stem + すぎる` មានន័យថា «...ជ្រុល/ពេក» ចំណែកឯ `[Plain Form / នាម] + に過ぎない` ជាវេយ្យាករណ៍មានន័យថា «គ្រាន់តែជា... ប៉ុណ្ណោះ»។

## ៧. សង្ខេប និងលំហាត់រំលឹក (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～に過ぎない** មានន័យថា **«គ្រាន់តែជា... ប៉ុណ្ណោះ / គ្មានអ្វីលើសពី... ឡើយ»** (nothing more than, merely, just, only)។
- ប្រើសម្រាប់បន្ទាបតម្លៃ បន្ទាបសារៈសំខាន់ ឬសម្តែងការបន្ទាបខ្លួន។
- រូបមន្តចងចាំ៖
  - **នាម + に過ぎない**
  - **កិរិយាសព្ទ (Plain Form) + に過ぎない**
  - **គុណនាម な + であるに過ぎない**
  - **គុណនាម い + に過ぎない**

### លំហាត់ខ្លីៗ (Quick Recap Quiz)

1. **ចូរប្រែប្រយោគនេះទៅជាភាសាជប៉ុនដោយប្រើ ～に過ぎない៖** "រឿងនោះគ្រាន់តែជាពាក្យចចាមអារ៉ាមប៉ុណ្ណោះ។"
   - **ចម្លើយ**: それは噂に過ぎない。 (Sore wa uwasa ni suginai.)
2. **ត្រូវ ឬខុស (True/False)៖** យើងអាចប្រើកិរិយាសព្ទ Polite form (ます形) នៅពីមុខ に過ぎない បាន។
   - **ចម្លើយ**: ខុស (False)។ ត្រូវប្រើ Plain form (辞書形/た形/ない形) ប៉ុណ្ណោះ។
3. **ចូរបំពេញចន្លោះ៖** 彼女は助けようとした_______。 (នាងគ្រាន់តែបានព្យាយាមជួយប៉ុណ្ណោះ)
   - **ចម្លើយ**: 彼女は助けようとした**に過ぎない** (ឬ に過ぎません)។
