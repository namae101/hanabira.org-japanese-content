# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～ものだ (〜mono da)
**កម្រិត JLPT:** JLPT N2

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ **～ものだ (〜mono da)** គឺជាកន្សោមពាក្យដ៏សំខាន់ និងសម្បូរបែបបំផុតមួយក្នុងភាសាជប៉ុនកម្រិត N2 ដែលបង្កប់អត្ថន័យ និងកម្រិតស្រមោលន័យ (nuance) ខុសៗគ្នាជាច្រើនអាស្រ័យលើបរិបទនៃការប្រើប្រាស់។ ទម្រង់នេះត្រូវបានប្រើជាទូទៅដើម្បី៖
- បង្ហាញពីការពិតទូទៅ ធម្មជាតិពិតនៃវត្ថុ/មនុស្ស ឬបទដ្ឋានសីលធម៌សង្គម («វាជាធម្មជាតិទៅហើយដែល... / គួរតែ...»)។
- រំលឹកឡើងវិញដោយក្តីនឹករលឹកពីទម្លាប់ ឬស្ថានភាពកាលពីអតីតកាល («ធ្លាប់... កាលពីមុន / តែងតែ...»)។
- បញ្ចេញអារម្មណ៍រំជួលចិត្តយ៉ាងជ្រាលជ្រៅ ឬការភ្ញាក់ផ្អើលស្ងើចសរសើរ («ពិតជា... មែនហើយហ្ន៎! / យ៉ាងក្រៃលែង»)។
- បង្ហាញពីបំណងប្រាថ្នាដ៏ជ្រាលជ្រៅ (នៅពេលប្រើជាមួយ [Verb-たい] ものだ ៖ «ពិតជាចង់... ខ្លាំងណាស់»)។

ការយល់ដឹងច្បាស់ពីរបៀបប្រើ **～ものだ** នឹងជួយលើកកម្ពស់សមត្ថភាពរបស់អ្នកក្នុងការបញ្ចេញអារម្មណ៍ និងភាពស៊ីជម្រៅនៃភាសាជប៉ុនឱ្យកាន់តែមានលក្ខណៈធម្មជាតិដូចជនជាតិដើម។

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ និងការប្រើប្រាស់ (Meaning and Usage)

ទម្រង់ **～ものだ** ក្នុងកម្រិត JLPT N2 មានមុខងារស្នូលចំនួន ៤ ដូចខាងក្រោម៖

1. **ការពិតសកល ឬធម្មជាតិពិតនៃវត្ថុ/មនុស្ស (Universal Human Truth / General Nature)**
   - ប្រើដើម្បីថ្លែងពីការពិតទូទៅ ក្រឹត្យក្រមធម្មជាតិ ឬអ្វីដែលកើតឡើងជាធម្មតាក្នុងលោក។
   - *«វាជាធម្មជាតិនៃ... / ធម្មតាទៅហើយដែល...»* (It is in the nature of things to... / naturally...)

2. **ការរំលឹកដាស់តឿនសីលធម៌ និងបទដ្ឋានសង្គម (Moral Advisory / Social Norms)**
   - ប្រើដើម្បីបញ្ជាក់ពីអ្វីដែលមនុស្សគ្រប់រូបគួរតែធ្វើតាមទស្សនៈសីលធម៌ បទដ្ឋានសង្គម ឬសុភវិនិច្ឆ័យទូទៅ (មិនមែនជាការបង្គាប់បញ្ជាផ្ទាល់ខ្លួនចំពោះបុគ្គលជាក់លាក់ឡើយ)។
   - *«មនុស្សយើងគួរតែ... / តាមក្បួនខ្នាតត្រូវតែ...»* (One ought to / people should naturally...)

3. **ការរំជួលចិត្ត និងការឧទានយ៉ាងជ្រាលជ្រៅ (Emotional Exclamatory Reflection)**
   - ប្រើនៅពេលដែលអ្នកនិយាយមានអារម្មណ៍រំជួលចិត្តខ្លាំង ស្ងើចសរសើរ ឬដកដង្ហើមធំចំពោះស្ថានភាពជាក់ស្តែងណាមួយ។ ជាញឹកញាប់ប្រើជាមួយគុណនាម ឬកិរិយាសព្ទបំណងប្រាថ្នា (〜たいものだ)។
   - *«ពិតជា... មែនហ្ន៎! / ពិតជា... ខ្លាំងណាស់!»* (How truly... indeed! / deep emotional sigh)

4. **ការនឹករលឹកពីទម្លាប់កាលពីអតីតកាល (Nostalgic Past Recollection)**
   - ប្រើជាមួយកិរិយាសព្ទអតីតកាល (た形) ដើម្បីរំលឹកឡើងវិញនូវទម្លាប់ដែលតែងតែកើតឡើងញឹកញាប់កាលពីអតីតកាល ប៉ុន្តែបច្ចុប្បន្នលែងមានទៀតហើយ។
   - *«កាលពីមុនធ្លាប់តែ... / តែងតែ... កាលពីដើម»* (Used to do / would often do...)

### ទម្រង់ផ្សំ (Structure)

#### ១. ការពិតទូទៅ / ដាស់តឿនសីលធម៌ (General Truths / Moral Advice)
```
[កិរិយាសព្ទ ទម្រង់វចនានុក្រម (辞書形)] + ものだ
[កិរិយាសព្ទ ទម្រង់ ない (ない形)] + ものだ
```

#### ២. ការនឹករលឹកពីទម្លាប់អតីតកាល (Nostalgic Recollection)
```
[កិរិយាសព្ទ ទម្រង់ た (た形)] + ものだ
```

#### ៣. ការរំជួលចិត្ត និងការឧទាន (Deep Emotion / Exclamation)
```
[កិរិយាសព្ទ ទម្រង់辞書形 / た形 / たい形] + ものだ
[គុណនាម い] + ものだ
[គុណនាម な + な] + ものだ
```

### តារាងសង្ខេបទម្រង់ផ្សំ (Formation Diagram)

| មុខងារនៃការប្រើប្រាស់ (Usage) | ទម្រង់វេយ្យាករណ៍ (Formation) | ឧទាហរណ៍ខ្លី |
|---|---|---|
| **ការពិតទូទៅ / បទដ្ឋានសីលធម៌** (General Truth / Morality) | 動詞 辞書形 / ない形 + ものだ | 人の悪口は言わない**ものだ**。 |
| **ការរំលឹកអតីតកាលដោយនឹករលឹក** (Nostalgic Recollection) | 動詞 た形 + ものだ | 子供の頃はよく川で泳いだ**ものだ**。 |
| **ការរំជួលចិត្ត / ការឧទាន** (Emotional Exclamation) | 形容詞 / 動詞辞書形 / たい形 + ものだ | 時間が経つのは本当に早い**ものだ**。<br>一度日本へ行きたい**ものだ**。 |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance & Comparative Analysis)

### ការវិភាគស៊ីជម្រៅលើមុខងារទាំង ៤ នៃ ～ものだ

1. **មុខងារទី ១៖ ធម្មជាតិពិត និងការពិតសកល (Verb-る ものだ)**
   - បង្ហាញពីក្រឹត្យក្រមដែលចៀសមិនផុតនៃពិភពលោក ឬជីវិតមនុស្ស។ ឧទាហរណ៍៖ «មនុស្សចាស់ទៅ កម្លាំងតែងតែថយចុះ» (人は年をとると、体力が衰える**ものだ**)。 នេះជាសច្ចភាពធម្មជាតិ មិនមែនជាការបង្ខិតបង្ខំទេ។

2. **មុខងារទី ២៖ ដាស់តឿនសីលធម៌ និងទំនៀមទម្លាប់សង្គម**
   - ប្រើទម្រង់ `Verb-る ものだ` ឬ `Verb-ない ものだ` ដើម្បីបញ្ជាក់ពីទំនួលខុសត្រូវ ឬការប្រព្រឹត្តដែលសង្គមរំពឹងទុកជាទូទៅ។
   - **ការប្រុងប្រយ័ត្នខ្ពស់៖** មិនត្រូវប្រើដើម្បីបញ្ជា ឬទូន្មានមនុស្សចាស់ ឬថ្នាក់លើដោយផ្ទាល់នោះទេ ព្រោះវាស្តាប់ទៅដូចជាការបង្រៀនសីលធម៌ពីលើចុះក្រោម។

3. **មុខងារទី ៣៖ ការឧទាន និងអារម្មណ៍រំជួលចិត្តយ៉ាងជ្រាលជ្រៅ ([Adj / Verb-たい] ものだ)**
   - បង្ហាញពីការដកដង្ហើមធំ ការស្ញប់ស្ញែង ឬសេចក្តីប្រាថ្នាផ្ទាល់ខ្លួនយ៉ាងជ្រៅ។
   - នៅពេលប្រើ `〜たいものだ` (ឧទាហរណ៍៖ のんびり暮らしたいものだ ៖ ចង់រស់នៅបែបស្រួលចិត្តណាស់ហ្ន៎) វាបង្ហាញពីក្តីប្រាថ្នាដ៏ជ្រាលជ្រៅ និងមានភាពទន់ភ្លន់ជាង `〜たい` ធម្មតា។

4. **មុខងារទី ៤៖ ការរំលឹកអនុស្សាវរីយ៍អតីតកាល (Verb-た ものだ)**
   - ប្រើសម្រាប់តែសកម្មភាព ឬស្ថានភាពដែលកើតឡើងជាទម្លាប់ដដែលៗកាលពីអតីតកាលប៉ុណ្ណោះ។
   - មិនអាចប្រើសម្រាប់ព្រឹត្តិការណ៍ដែលកើតឡើងតែម្តងគត់ក្នុងអតីតកាលបានឡើយ (បើកើតឡើងតែម្តង ត្រូវប្រើ `〜た` ធម្មតា ឬ `〜たことがある`)។

### ការប្រៀបធៀបរវាង ～ものだ និង ～ことだ (Crucial Distinction)

អ្នករៀនភាសាជប៉ុនកម្រិត N2 តែងតែច្រឡំរវាង **～ものだ** និង **～ことだ** ព្រោះអ្នកទាំងពីរអាចបកប្រែជាភាសាខ្មែរថា «គួរតែ...» បានដូចគ្នា ប៉ុន្តែកម្រិតស្រមោលន័យ និងបរិបទខុសគ្នាស្រឡះ៖

| ចំណុចប្រៀបធៀប | ～ものだ (Mono da) | ～ことだ (Koto da) |
|---|---|---|
| **មូលដ្ឋាននៃដំបូន្មាន** | ផ្អែកលើ **សីលធម៌ទូទៅ បទដ្ឋានសង្គម និងការពិតសកល** (អ្វីដែលមនុស្សទូទៅដឹងគ្រប់គ្នា) | ផ្អែកលើ **ស្ថានភាពជាក់ស្តែង និងការវិនិច្ឆ័យផ្ទាល់ខ្លួនរបស់អ្នកនិយាយ** ចំពោះអ្នកស្តាប់ |
| **គោលដៅនៃការប្រើ** | ដាស់តឿនជាទូទៅថា «ជាមនុស្សគួរតែ...» (General norm) | ផ្តល់ការណែនាំចំៗទៅកាន់អ្នកស្តាប់ថា «ក្នុងរឿងនេះ ឯងគួរតែធ្វើបែបនេះទើបល្អ» (Direct situational advice) |
| **ឧទាហរណ៍ជាក់ស្តែង** | 目上の人には敬意を払う**ものだ**。<br>*(មនុស្សយើងគួរតែគោរពចាស់ទុំ — ជាសីលធម៌សង្គម)* | 風邪を早く治したければ、よく寝る**ことだ**。<br>*(បើចង់ឆាប់ជាផ្តាសាយ ឯងគួរតែគេងឱ្យច្រើន — ជាដំបូន្មានជាក់ស្តែងចំពោះបុគ្គល)* |
| **ទម្រង់បដិសេធ** | **〜ものではない** (មិនគួរធ្វើបែបនោះឡើយ / គ្មានសីលធម៌ទេបើធ្វើអញ្ចឹង) | **〜ことのないように** / **〜ないことだ** (កុំធ្វើបែបនេះឱ្យសោះ) |

---

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ក. ការពិតទូទៅ ឬបទដ្ឋានសង្គម (General Truths / Social Norms)
1. **時間は大切にするものだ。**

## ៥. កំណត់សម្គាល់វប្បធម៌ (Cultural Notes)

### ភាពស៊ីសង្វាក់គ្នានឹងវប្បធម៌ជប៉ុន
- **ការឆ្លុះបញ្ចាំង និងភាពសុភាពរាបសារ (Contemplation & Humility)**៖ ការប្រើ **～ものだ** ក្នុងការរំលឹកអតីតកាល ឬការថ្លែងពីសច្ចភាពទូទៅ បង្ហាញពីទស្សនវិជ្ជាជប៉ុនដែលឱ្យតម្លៃលើការសញ្ជឹងគិត ភាពរាបសារ និងការទទួលស្គាល់សច្ចភាពនៃធម្មជាតិ និងជីវិត។
- **កម្រិតគួរសម (Politeness Levels)**៖ ទម្រង់ **～ものだ** អាចប្រើបានទាំងក្នុងការសរសេរ និងការនិយាយ។ នៅពេលចង់បង្កើនកម្រិតគួរសម និងផ្លូវការ យើងគ្រាន់តែប្តូរទៅជា **～ものです** (ឧទាហរណ៍៖ 困ったものです / 早いものですね)។

### កន្សោមពាក្យសំនួនវោហារពេញនិយម (Idiomatic Expressions)
- **困ったものだ (Komatta mono da) / 困ったもんだ**  
  *ការបកប្រែ*: ពិបាកចិត្តមែនហ្ន៎! / ពិបាកដោះស្រាយណាស់តើ! (ប្រើពេលជួបបញ្ហាគួរឱ្យធុញទ្រាន់ ឬទាល់គំនិត)
- **不思議なものだ (Fushigi na mono da)**  
  *ការបកប្រែ*: ពិតជាចម្លែកអស្ចារ្យមែន! / ជារឿងគួរឱ្យឆ្ងល់ណាស់ហ្ន៎!

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)

1. **ការច្រឡំទម្រង់កិរិយាសព្ទពេលរំលឹកអតីតកាល**
   - ❌ *ខុស*: 昔はよく映画を**見るものだ**。  
   - ✅ *ត្រូវ*: 昔はよく映画を**見たものだ**。  
   *(គន្លឹះ៖ នៅពេលរំលឹកពីទម្លាប់កាលពីអតីតកាល ត្រូវតែប្រើកិរិយាសព្ទ **ទម្រង់ た (た形)** ជាដាច់ខាត)*

2. **ការច្រឡំរវាងការទូន្មានសីលធម៌ទូទៅ និងដំបូន្មានជាក់ស្តែងផ្ទាល់ខ្លួន**
   - ❌ *ខុស*: (ប្រាប់មិត្តភក្តិដែលកំពុងអស់កម្លាំង) 早く**寝るものだ**。  
   - ✅ *ត្រូវ*: 早く**寝ることだ**。  
   *(គន្លឹះ៖ ប្រើ **～ことだ** សម្រាប់ដំបូន្មានជាក់ស្តែងផ្ទាល់ខ្លួន។ ប្រើ **～ものだ** សម្រាប់តែគោលការណ៍សីលធម៌ទូទៅប៉ុណ្ណោះ មិនអាចយកមកប្រាប់បុគ្គលឱ្យធ្វើរឿងជាក់ស្តែងភ្លាមៗបែបនេះបានទេ)*

3. **ការប្រើ ～たものだ លើព្រឹត្តិការណ៍ដែលកើតឡើងតែម្តង**
   - ❌ *ខុស*: 去年、富士山に**登ったものだ**。  
   - ✅ *ត្រូវ*: 去年、富士山に**登った** (または **登ったことがある**)。  
   *(គន្លឹះ៖ `〜たものだ` ប្រើបានតែចំពោះសកម្មភាពដែលជា «ទម្លាប់ដដែលៗ» ប៉ុណ្ណោះ មិនប្រើសម្រាប់ព្រឹត្តិការណ៍ដែលកើតឡើងតែម្តងនោះទេ)*

### យុទ្ធសាស្ត្រសិក្សា (Learning Strategies)
- **ទស្សនទាននៃពាក្យ もの (Thing/Nature)**៖ ពាក្យ **もの** មានន័យជាមូលដ្ឋានថា «វត្ថុ / របស់»។ ដូច្នេះ សូមចងចាំថា **～ものだ** គឺការថ្លែងអំពី «ធម្មជាតិនៃវត្ថុ ឬធម្មជាតិនៃរឿងរ៉ាវក្នុងលោក»។
- **ការអនុវត្តតែងប្រយោគអតីតកាល**៖ សាកល្បងសរសេរប្រយោគរំលឹកពីវ័យកុមារភាពរបស់អ្នកដោយប្រើ `[Verb-た] + ものだ` ដើម្បីឱ្យស៊ាំនឹងការបញ្ចេញអារម្មណ៍នឹករលឹក។

## ៧. សង្ខេប និងរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～ものだ** មានមុខងារសំខាន់ ៤ យ៉ាង៖
  1. ថ្លែងពីការពិតសកល និងធម្មជាតិនៃជីវិត (`Verb-る / ない + ものだ`)
  2. រំលឹកដាស់តឿនសីលធម៌ និងបទដ្ឋានសង្គម (`Verb-る / ない + ものだ` / បដិសេធ៖ `〜ものではない`)
  3. ឧទាន និងរំជួលចិត្តយ៉ាងជ្រាលជ្រៅ (`[Adj / Verb-たい] + ものだ`)
  4. នឹករលឹកពីទម្លាប់កាលពីអតីតកាល (`Verb-た + ものだ`)
- **ការបែងចែកកម្រិតច្បាស់លាស់**៖ កុំច្រឡំជាមួយ **～ことだ** ដែលប្រើសម្រាប់ដំបូន្មានជាក់ស្តែងផ្ទាល់ខ្លួន។
