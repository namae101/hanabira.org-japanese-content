# វេយ្យាករណ៍ជប៉ុន: なにも～ません (nanimo~masen)
**កម្រិត JLPT:** JLPT N5

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ **なにも～ません** (nanimo~masen) ត្រូវបានប្រើប្រាស់ដើម្បីបញ្ជាក់ន័យថា «មិន...អ្វីទាំងអស់ / គ្មាន...អ្វីសោះ» (nothing / not anything) ជាភាសាជប៉ុន។ វាជាទម្រង់បដិសេធដាច់ខាតទាំងស្រុង (total negation) ចំពោះកម្មវត្ថុ ឬសកម្មភាពណាមួយ។

---
## ២. ការពន្យល់វេយ្យាករណ៍គោល (Core Grammar Explanation)
### អត្ថន័យ (Meaning)
- **なにも～ません** មានន័យថា «មិន...អ្វីទាំងអស់» ឬ «គ្មាន...អ្វីទាល់តែសោះ» ជាភាសាខ្មែរ។
- ប្រើសម្រាប់បញ្ជាក់ពីការមិនធ្វើអ្វីមួយទាល់តែសោះ ឬគ្មានរបស់អ្វីសោះឡើយ។

### ទម្រង់ផ្សំ (Structure)
| ភាសាជប៉ុន | ភាសាខ្មែរ |
| :--- | :--- |
| **なにも** (nanimo) | អ្វីក៏ដោយ / អ្វីទាំងអស់ |
| **＋** | |
| **[កិរិយាសព្ទបដិសេធ (~ません)]** | [ទម្រង់បដិសេធគួរសមនៃកិរិយាសព្ទ] |
| **なにも＋～ません** | មិន...អ្វីទាំងអស់ / គ្មាន...អ្វីសោះ |

### ដ្យាក្រាមទម្រង់ (Formation Diagram)
```
[なにも (nanimo)] --> [កិរិយាសព្ទបដិសេធ (~ません / ~masen)]
```

### ការពន្យល់លម្អិត (Detailed Explanation)
- **なにも (nanimo / 何も)** ផ្សំឡើងពីពាក្យសួរ **なに (អ្វី)** បូកជាមួយធ្នាក់ **も (ក៏/ទាំងអស់)** ដែលដើរតួជាសព្វនាមមិនច្បាស់លាស់ (indefinite pronoun)។
- នៅពេលផ្គុំជាមួយកិរិយាសព្ទបដិសេធគួរសម (**～ません**) វានឹងបង្កើតជាទម្រង់បដិសេធទាំងស្រុងលើកម្មវត្ថុ (total negation)។
- ធ្នាក់ **も** នៅក្នុង **なにも** នឹងជំនួសធ្នាក់កម្មវត្ថុ **を (o)** ឬធ្នាក់ប្រធាន **が (ga)** ទាំងស្រុង ដោយមិនចាំបាច់សរសេរ `なにをも` ឬ `なにがも` ឡើយ។

---
## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance & Comparative Analysis)
### ច្បាប់លុបធ្នាក់ (Particle Dropping Rules)
- ក្នុងប្រយោគស្រប កម្មវត្ថុផ្ទាល់ត្រូវភ្ជាប់ដោយធ្នាក់ **を** (ឧទាហរណ៍៖ パンを食べます = ញ៉ាំនំបុ័ង)។
- ប៉ុន្តែនៅពេលប្រើទម្រង់បដិសេធទាំងស្រុងជាមួយ **なにも** ធ្នាក់ **も** ត្រូវស្រូបទាញ និងជំនួសធ្នាក់ **を** និង **が** ទាំងស្រុង៖
  - **ខុស៖** なにをも食べませんでした (មិនត្រឹមត្រូវតាមវេយ្យាករណ៍ស្តង់ដារ)
  - **ត្រូវ៖** なにも食べませんでした (ត្រឹមត្រូវ៖ «មិនបានញ៉ាំអ្វីទាំងអស់»)
- **ចំណាំលើធ្នាក់ដទៃទៀត៖** ធ្នាក់ទិសដៅ ឬទីកន្លែងមួយចំនួន ដូចជា **へ (he)** ឬ **に (ni)** ឬ **で (de)** មិនត្រូវបានលុបចេញទេ តែត្រូវដាក់មុន **も** (ឧទាហរណ៍៖ どこ**へも**行きません = មិនទៅណាទាំងអស់) ខុសពីកម្មវត្ថុរបស់ **なにも** ដែលលុប **を/が** ចោល។

### កម្រិតគួរសម និងទម្រង់ស្រដៀងគ្នា (Politeness & Similar Expressions)
- **なにも～ない (nanimo~nai):**
  - កម្រិតស្និទ្ធស្នាល/ទូទៅ (Casual / Plain Form) ប្រើជាមួយមិត្តភក្តិ ឬអ្នកជិតស្និទ្ធ។
  - ឧទាហរណ៍៖ なにもない。(គ្មានអ្វីទាំងអស់។)
- **全然～ません (zenzen~masen):**
  - មានន័យថា «មិន...ទាល់តែសោះ» ដោយសង្កត់ធ្ងន់លើ **កម្រិត/ទំហំ** (degree) នៃសកម្មភាព ឬការយល់ដឹង មិនមែនសង្កត់ធ្ងន់លើកម្មវត្ថុឡើយ។
  - ឧទាហរណ៍៖ 全然わかりません。(មិនយល់ទាល់តែសោះ - បញ្ជាក់ពីកម្រិតនៃការមិនយល់) vs. なにもわかりません。(មិនដឹងអ្វីទាំងអស់ - បញ្ជាក់ពីចំនួនព័ត៌មានដែលគ្មានសូម្បីតែមួយ)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)
### បរិបទផ្លូវការ / គួរសម (Formal Situations)
1. **私はなにも知りません。**
   - *Watashi wa nanimo shirimasen.*
   - **ប្រែសម្រួល:** ខ្ញុំមិនដឹងអ្វីទាំងអស់។
2. **彼はなにも言いませんでした。**
   - *Kare wa nanimo iimasen deshita.*
   - **ប្រែសម្រួល:** គាត់មិនបាននិយាយអ្វីសូម្បីតែមួយម៉ាត់ (មិនបាននិយាយអ្វីទាំងអស់)។

### បរិបទទូទៅ / មិនផ្លូវការ (Informal Situations)
1. **なにも食べなかった。**
   - *Nanimo tabenakatta.*
   - **ប្រែសម្រួល:** ខ្ញុំមិនបានញ៉ាំអ្វីទាំងអស់។
2. **なにも見えない。**
   - *Nanimo mienai.*
   - **ប្រែសម្រួល:** មើលមិនឃើញអ្វីសោះឡើយ។

### បរិបទភាសាសរសេរ (Written Context)
1. **その件について、なにもコメントしません。**
   - *Sono ken ni tsuite, nanimo komento shimasen.*
   - **ប្រែសម្រួល:** ទាក់ទងនឹងបញ្ហានោះ ខ្ញុំនឹងមិនធ្វើការអធិប្បាយអ្វីឡើយ។

### បរិបទសន្ទនាផ្ទាល់មាត់ (Spoken Context)
1. **A: どうしたの？**
   - *A: Dō shita no?*
   - **A:** តើមានរឿងអ្វីកើតឡើងមែនទេ? / កើតអីហ្នឹង?
2. **B: なにもありません。**
   - *B: Nanimo arimasen.*
   - **B:** គ្មានរឿងអ្វីទាំងអស់។ / គ្មានអីទេ។

## ៥. កំណត់សម្គាល់វប្បធម៌ និងការប្រើប្រាស់ (Cultural Notes)
### កម្រិតគួរសម (Politeness Levels)
- ការប្រើប្រាស់កន្ទុយកិរិយាសព្ទ **～ません** ឬ **～ませんでした** ជាទម្រង់គួរសមស្តង់ដារ (Teineigo) ស័ក្តិសមបំផុតក្នុងការសន្ទនាការងារ ជាមួយមនុស្សចាស់ ឬមនុស្សដែលមិនស្និទ្ធស្នាល។
- នៅក្នុងការសន្ទនាស្និទ្ធស្នាលប្រចាំថ្ងៃ គេច្រើនប្រើទម្រង់ធម្មតា **～ない** ឬ **～なかった** ជំនួសវិញ។

### ឃ្លា និងកន្សោមពាក្យពិសេស (Idiomatic Expressions)
- **なにもかも (nanimo kamo):** មានន័យថា «គ្រប់បែបយ៉ាង / ទាំងអស់» (everything - ប្រើក្នុងប្រយោគស្រប ឬបញ្ជាក់ការបាត់បង់ទាំងស្រុង)។
  - ឧទាហរណ៍៖ なにもかも失った。(ខ្ញុំបានបាត់បង់គ្រប់បែបយ៉ាងទាំងអស់។)

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)
### កំហុសទូទៅ (Common Mistakes)
- **ការប្រើកិរិយាសព្ទស្របជាមួយ なにも៖**
  - **ខុស:** *なにもあります。*
  - **ត្រូវ:** *なにもありません。* (なにも ត្រូវតែផ្គុំជាមួយកិរិយាសព្ទបដិសេធជានិច្ច ដើម្បីបង្កើតន័យថា «គ្មាន/មិន...អ្វីទាំងអស់»)
- **ការរក្សាទុកធ្នាក់ を ឬ が នៅពីក្រោយ なにも៖**
  - **ខុស:** *なにもを食べません。*
  - **ត្រូវ:** *なにも食べません。* (ធ្នាក់ を ត្រូវតែលុបចេញជានិច្ច)

### យុទ្ធសាស្ត្រសិក្សា (Learning Strategies)
- **រូបមន្តចងចាំ:** ចងចាំជានិច្ចថា **なにも** + **កិរិយាសព្ទបដិសេធ** = **មិន/គ្មាន...អ្វីទាំងអស់**។
- **គន្លឹះអនុវត្ត:** សាកល្បងផ្លាស់ប្តូរកិរិយាសព្ទដូចជា ញ៉ាំ (食べません), មើល (見ません), ទិញ (買いません) ដើម្បីឱ្យស្ទាត់ជំនាញក្នុងបរិបទផ្សេងៗគ្នា។

## ៧. សង្ខេប និងរំលឹកឡើងវិញ (Summary and Review)
### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **なにも～ません** ប្រើដើម្បីបង្ហាញការបដិសេធទាំងស្រុងលើកម្មវត្ថុ មានន័យថា «មិន...អ្វីទាំងអស់» ឬ «គ្មាន...អ្វីសោះ»។
- ផ្សំឡើងដោយដាក់ **なにも** នៅពីមុខកិរិយាសព្ទក្នុងទម្រង់បដិសេធ (**～ません** សម្រាប់ទម្រង់គួរសម ឬ **～ない** សម្រាប់ទម្រង់ស្និទ្ធស្នាល)។
- ធ្នាក់ **も** ជំនួសធ្នាក់ **を** និង **が** ដោយស្វ័យប្រវត្តិ មិនបាច់សរសេរធ្នាក់ទាំងនោះឡើយ។

### កម្រងសំណួររំលឹកខ្លីៗ (Quick Recap Quiz)
1. **តើពាក្យ «ខ្ញុំមិនបានទិញអ្វីទាំងអស់» និយាយជាភាសាជប៉ុនយ៉ាងដូចម្តេច?**
   - ចម្លើយ៖ *なにも買いませんでした。 (Nanimo kaimasen deshita.)*
2. **បកប្រែជាភាសាខ្មែរ៖ 彼女はなにも話しませんでした。**
   - ចម្លើយ៖ នាងមិនបាននិយាយអ្វីទាល់តែសោះ / នាងមិនបាននិយាយអ្វីទាំងអស់។
3. **តើទម្រង់សាមញ្ញ (Casual form) នៃ なにも知りません គឺជាអ្វី?**
   - ចម្លើយ៖ *なにも知らない。 (Nanimo shiranai.)*
