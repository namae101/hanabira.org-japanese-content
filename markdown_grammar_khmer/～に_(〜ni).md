Processing keyword: ～に (〜ni)
# ចំណុចវេយ្យាករណ៍ជប៉ុន: ～に (〜ni)
**កម្រិត JLPT:** JLPT N4

## ១. សេចក្តីផ្តើម (Introduction)
សូមស្វាគមន៍មកកាន់មេរៀនស្តីពីធ្នាក់ ឬឈ្នាប់ជំនួយ **に (ni)** នៅក្នុងភាសាជប៉ុន។ ធ្នាក់ដ៏សំបូរបែបនេះ គឺជាមូលដ្ឋានគ្រឹះដ៏សំខាន់បំផុតមួយនៅក្នុងវេយ្យាករណ៍ភាសាជប៉ុន ហើយការយល់ច្បាស់ពីមុខងារផ្សេងៗរបស់វា គឺចាំបាច់ណាស់សម្រាប់ការប្រាស្រ័យទាក់ទងប្រកបដោយប្រសិទ្ធភាព។ នៅក្នុងមេរៀនកម្រិត N4 នេះ យើងនឹងសិក្សាស្វែងយល់យ៉ាងលម្អិតអំពីមុខងារចម្រុះជាច្រើនរបស់វា ព្រមទាំងមានការពន្យល់ និងឧទាហរណ៍យ៉ាងច្បាស់លាស់ ដើម្បីជួយអ្នកប្រើប្រាស់ **に** ឱ្យបានត្រឹមត្រូវ និងបែបធម្មជាតិ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ និងការប្រើប្រាស់ (Meaning and Usage)
ធ្នាក់ **に (ni)** ត្រូវបានប្រើប្រាស់សម្រាប់បញ្ជាក់អំពី៖
1. **ទីតាំងនៃអត្ថិភាព (Location of existence):** កន្លែងដែលមានវត្តមានរបស់មនុស្ស សត្វ ឬវត្ថុ (ប្រើជាមួយ ある/いる)។
2. **ទិសដៅ ឬទិសដៅចុងក្រោយ (Direction/Destination):** គោលដៅនៃការផ្លាស់ទី ឬធ្វើដំណើរ។
3. **ពេលវេលាជាក់លាក់ (Specific Time):** ពេលវេលាកំណត់ដែលសកម្មភាពមួយកើតឡើង។
4. **គោលបំណងនៃចលនា (Purpose of movement):** គោលបំណងក្នុងការចេញទៅធ្វើអ្វីមួយ (ដើរទៅ... មកដើម្បី...)។
5. **កម្មបទប្រយោល ឬអ្នកទទួលសកម្មភាព (Indirect Object / Recipient):** បុគ្គល ឬអ្វីមួយដែលទទួលសកម្មភាពពីគេ។
6. **ការផ្លាស់ប្តូរស្ថានភាព ឬការសម្រេចចិត្ត (Change of state / Result / Decision):** លទ្ធផលនៃការប្រែប្រួល ឬការជ្រើសរើស។
7. **ភ្នាក់ងារ/អ្នកធ្វើសកម្មភាពក្នុងប្រយោគអកម្ម និងបង្គាប់បញ្ជា (Agent in Passive and Causative sentences):** អ្នកដែលធ្វើសកម្មភាពមកលើប្រធាន។
8. **កម្រិតប្រេកង់ ឬអត្រាក្នុងមួយឯកតាពេលវេលា (Frequency / Rate per time unit):** ចំនួនដងក្នុងមួយថ្ងៃ សប្តាហ៍ ខែ ឆ្នាំ។

---

### ទម្រង់ និងរចនាសម្ព័ន្ធ (Structure and Formation)

#### ១. បញ្ជាក់ទីតាំងនៃអត្ថិភាព (Location of Existence)
ប្រើជាមួយកិរិយាសព្ទ **ある (aru)** (សម្រាប់វត្ថុគ្មានជីវិត) និង **いる (iru)** (សម្រាប់មនុស្ស/សត្វមានជីវិត) ដើម្បីបង្ហាញពីវត្តមាននៅកន្លែងណាមួយ។
**ទម្រង់:**
```plaintext
នាម (ទីកន្លែង) + に + ある / いる
```
**ឧទាហរណ៍:**
- 駅の前にコンビニがある。
  - *មានហាងទំនិញងាយស្រួលមួយនៅមុខស្ថានីយរថភ្លើង។*
- 教室に学生がいます。
  - *មានសិស្សនៅក្នុងបន្ទប់រៀន។*

#### ២. បញ្ជាក់ទិសដៅ ឬគោលដៅផ្លាស់ទី (Direction or Destination)
ប្រើជាមួយកិរិយាសព្ទបញ្ជាក់ចលនា (ដូចជា 行く, 来る, 帰る) ដើម្បីបង្ហាញពីទីកន្លែងដែលបុគ្គល ឬវត្ថុកំពុងធ្វើដំណើរទៅដល់។
**ទម្រង់:**
```plaintext
នាម (ទីកន្លែង) + に + 行く / 来る / 帰る
```
**ឧទាហរណ៍:**
- 学校に行きます。
  - *ខ្ញុំទៅសាលារៀន។*
- 家に帰る。
  - *ត្រឡប់ទៅផ្ទះវិញ។*

#### ៣. បញ្ជាក់ពេលវេលាជាក់លាក់ (Specific Time)
ប្រើនៅពីក្រោយពាក្យបញ្ជាក់ពេលវេលាដែលមានលេខ ឬកាលបរិច្ឆេទជាក់លាក់។
**ទម្រង់:**
```plaintext
នាម (ពេលវេលា) + に + កិរិយាសព្ទ
```
**ឧទាហរណ៍:**
- 午後5時に会いましょう。
  - *ជួបគ្នានៅម៉ោង ៥ ល្ងាច។*
- 7時に起きる。
  - *ភ្ញាក់ពីគេងនៅម៉ោង ៧។*

#### ៤. បញ្ជាក់គោលបំណងនៃចលនា (Purpose of Movement)
ប្រើជាមួយទម្រង់ឫសកិរិយាសព្ទ (Verb Stem / កាត់ ます ចោល) ឬនាមសកម្មភាព ដើម្បីបញ្ជាក់ពីគោលបំណងនៃការទៅ មក ឬត្រឡប់មកវិញ។
**ទម្រង់:**
```plaintext
កិរិយាសព្ទ (Verb Stem - កាត់ ます) / នាម + に + 行く / 来る / 帰る
```
**ឧទាហរណ៍:**
- 本を買いに行く。
  - *ទៅទិញសៀវភៅ។*
- 日本へ勉強に来ました。
  - *បានមកប្រទេសជប៉ុនដើម្បីរៀនសូត្រ។*

#### ៥. បញ្ជាក់កម្មបទប្រយោល ឬអ្នកទទួល (Indirect Object / Recipient)
ប្រើដើម្បីបង្ហាញពីបុគ្គលដែលជាអ្នកទទួលសកម្មភាព ការផ្ទេរវត្ថុ ឬព័ត៌មាន (ដូចជា ជូន, ឱ្យ, ផ្ញើ, ប្រាប់)។
**ទម្រង់:**
```plaintext
នាម (អ្នកទទួល) + に + កិរិយាសព្ទ
```
**ឧទាហរណ៍:**
- 友達にプレゼントをあげた。
  - *ខ្ញុំបានជូនកាដូទៅមិត្តភក្តិ។*
- 母に電話する。
  - *ទូរស័ព្ទទៅម្តាយ។*

#### ៦. បញ្ជាក់ការផ្លាស់ប្តូរស្ថានភាព ឬការសម្រេចចិត្ត (Change of State / Decision)
ប្រើជាមួយកិរិយាសព្ទ **なる (naru - ក្លាយជា/ប្រែជា)** ដើម្បីបង្ហាញពីការប្រែប្រួលលទ្ធផល ឬប្រើជាមួយ **する (suru - សម្រេចយក)** សម្រាប់ការសម្រេចចិត្តជ្រើសរើស។
**ទម្រង់:**
```plaintext
នាម / គុណនាម な + に + なる / する
```
**ឧទាហរណ៍:**
- 医者になりました。
  - *បានក្លាយជាវេជ្ជបណ្ឌិត។*
- これにします。
  - *ខ្ញុំសម្រេចយកមួយនេះ (ពេលកម្ម៉ង់ម្ហូប ឬទិញទំនិញ)។*

#### ៧. បញ្ជាក់ភ្នាក់ងារក្នុងប្រយោគអកម្ម និងបង្គាប់បញ្ជា (Agent in Passive and Causative)
នៅក្នុងកម្រិត N4 ធ្នាក់ **に** ដើរតួនាទីយ៉ាងសំខាន់ក្នុងការសម្គាល់អ្នកធ្វើសកម្មភាព (Agent / Doer) នៅក្នុងប្រយោគរងអំពើ (受身形 - Passive) និងប្រយោគបញ្ជា/អនុញ្ញាត (使役形 - Causative)។
**ទម្រង់:**
```plaintext
នាម (ភ្នាក់ងារ/អ្នកធ្វើ) + に + កិរិយាសព្ទអកម្ម (Passive) / បង្គាប់បញ្ជា (Causative)
```
**ឧទាហរណ៍:**
- 犬に足を噛まれた。
  - *ខ្ញុំត្រូវបានឆ្កែខាំជើង។*
- 先生に褒められた。
  - *ខ្ញុំត្រូវបានគ្រូសរសើរ។*
- 子供に野菜を食べさせた。
  - *ខ្ញុំបានឱ្យ (បង្ខំ/អនុញ្ញាតឱ្យ) កូនញ៉ាំបន្លែ។*

#### ៨. បញ្ជាក់កម្រិតប្រេកង់ក្នុងមួយឯកតាពេលវេលា (Frequency per Time Unit)
ប្រើដើម្បីកំណត់បរិមាណ ឬចំនួនដងនៃសកម្មភាពដែលកើតឡើងក្នុងចន្លោះពេលជាក់លាក់មួយ។
**ទម្រង់:**
```plaintext
ឯកតាពេលវេលា + に + ចំនួនដង/កម្រិត + កិរិយាសព្ទ
```
**ឧទាហរណ៍:**
- 1日に3回薬を飲みます。
  - *លេបថ្នាំ ៣ ដងក្នុង ១ ថ្ងៃ។*
- 1週間に2回テニスをします。
  - *លេងតេន្នីស ២ ដងក្នុងមួយសប្តាហ៍។*

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance, Semantic Contrasts & Advanced N4 Functions)

ធ្នាក់ **に (ni)** ជាធ្នាក់ដែលមានមុខងារទូលំទូលាយបំផុត។ ដើម្បីប្រើប្រាស់ឱ្យបានត្រឹមត្រូវកម្រិត N4 ចាំបាច់ត្រូវយល់ច្បាស់ពីភាពខុសប្លែកគ្នារវាងមុខងារនីមួយៗ និងការប្រៀបធៀបជាមួយធ្នាក់ដទៃ៖

### ១. មុខងារកម្រិតខ្ពស់ N4 នៃធ្នាក់「に」
1. **ភ្នាក់ងារក្នុងប្រយោគអកម្ម និងបង្គាប់បញ្ជា (Agent in Passive/Causative):**
   - **ប្រយោគអកម្ម (受身 - Passive):** ប្រធាននៃប្រយោគទទួលរងនូវអំពើពីអ្នកដទៃ។ ភ្នាក់ងារដែលជាអ្នកប្រព្រឹត្តអំពើនោះត្រូវភ្ជាប់ដោយធ្នាក់ **に** ជានិច្ច (ឧទាហរណ៍៖ `先生に褒められた` - ខ្ញុំត្រូវបានគ្រូសរសើរ; `泥棒にお金を盗まれた` - ត្រូវបានចោរលួចលុយ)។
   - **ប្រយោគបង្គាប់បញ្ជា (使役 - Causative):** អ្នកបញ្ជា (Causer) ប្រើធ្នាក់ **が/は** រីឯអ្នកដែលត្រូវគេបង្គាប់ ឬអនុញ្ញាតឱ្យធ្វើសកម្មភាព (Agent/Causee) ប្រើធ្នាក់ **に** នៅពេលកិរិយាសព្ទនោះជាសកម្មភាពឆ្លង (Transitive Verb មាន を) ដើម្បីជៀសវាងការជាន់គ្នានៃធ្នាក់ を ពីរដង (ឧទាហរណ៍៖ `子供に野菜を食べさせた` - ឱ្យកូនញ៉ាំបន្លែ, មិនប្រើ 子供を野菜を ឡើយ)។

2. **គោលបំណងនៃចលនា (Purpose of Movement: Verb Stem + に + 行く/来る/戻る):**
   - ប្រើសម្រាប់តែចលនាផ្លាស់ទីពីកន្លែងមួយទៅកន្លែងមួយទៀតប៉ុណ្ណោះ។ កិរិយាសព្ទខាងមុខត្រូវតែកាត់ ます ចោល (ឧទាហរណ៍៖ `買いに行く` - ទៅទិញ; `遊びに来る` - មកលេង)។
   - បង្ហាញពីគោលដៅច្បាស់លាស់នៃសកម្មភាព មិនមែនគ្រាន់តែជាការធ្វើដំណើរធម្មតាឡើយ។

3. **លទ្ធផលនៃការផ្លាស់ប្តូរ និងការសម្រេចចិត្ត (Result of Change / Decision):**
   - **～になる (ក្លាយជា / ប្រែជា):** សម្គាល់ការប្រែប្រួលស្ថានភាពដោយឯកឯង ឬតាមដំណើរធម្មជាតិ (ឧទាហរណ៍៖ `医者になる` - ក្លាយជាវេជ្ជបណ្ឌិត; `春になると暖かくなる` - ពេលដល់រដូវផ្ការីក អាកាសធាតុប្រែជាកក់ក្តៅ)។
   - **～にする (សម្រេចចិត្តជ្រើសរើស):** សម្គាល់ការជ្រើសរើសដោយឆន្ទៈរបស់បុគ្គល (Volitional Decision) ដូចជាពេលកម្ម៉ង់ម្ហូប ជម្រើសទិញទំនិញ (ឧទាហរណ៍៖ `これにする` - ខ្ញុំសម្រេចយកអាមួយនេះ; `昼ご飯はラーメンにする` - បាយថ្ងៃត្រង់ខ្ញុំសម្រេចញ៉ាំមីរ៉ាមេន)។

4. **កម្រិតប្រេកង់ក្នុងមួយឯកតាពេលវេលា (Frequency / Rate per Unit):**
   - បញ្ជាក់ពីអត្រា ឬសមាមាត្រនៃសកម្មភាពក្នុងកំឡុងពេលមួយ (ឧទាហរណ៍៖ `1日に3回` - ៣ដងក្នុងមួយថ្ងៃ; `1ヶ月に1回` - ១ដងក្នុងមួយខែ)។
   - **ចំណាំសំខាន់:** ពាក្យដែលបញ្ជាក់ពីប្រេកង់ទូទៅស្រាប់ (ដូចជា 毎日, 毎週, いつも) មិនត្រូវបន្ថែម **に** ឡើយ (❌ 毎日に行きます ➔ ⭕ 毎日行きます)។

### ២. ការប្រៀបធៀបធ្នាក់「に」ជាមួយធ្នាក់ដទៃ

#### に (ni) vs. で (de)
- **に (ni):** បញ្ជាក់ពី **ចំណុចអត្ថិភាព (Point of Existence)** ឬទីតាំងលទ្ធផលដែលវត្ថុ/មនុស្សស្ថិតនៅ (ប្រើជាមួយ ある, いる, 住む, 置く)។
- **で (de):** បញ្ជាក់ពី **ទីកន្លែងដែលសកម្មភាព ឬព្រឹត្តិការណ៍កើតឡើង (Location of Action)**។
- **ការប្រៀបធៀប:**
  - 図書館**で**本を読む。(ខ្ញុំអានសៀវភៅ**នៅឯ**បណ្ណាល័យ - "អាន" ជាសកម្មភាព ➔ ប្រើ で)
  - 図書館**に**本がある。(មានសៀវភៅ**នៅ**បណ្ណាល័យ - គ្រាន់តែបញ្ជាក់ពីវត្តមានសៀវភៅ ➔ ប្រើ に)
  - 椅子**に**座る。(អង្គុយ**លើ**កៅអី - លទ្ធផលនៃសកម្មភាពអង្គុយគឺស្ថិតនៅលើកៅអី ➔ ប្រើ に)

#### に (ni) vs. へ (e)
- ធ្នាក់ទាំងពីរអាចប្រើសម្រាប់បញ្ជាក់ទិសដៅចលនាដូចគ្នា ប៉ុន្តែមានភាពខុសគ្នានៃការផ្តោតអារម្មណ៍ (Nuance)៖
  - **へ (e):** ផ្តោតសំខាន់លើ **ទិសដៅឆ្ពោះទៅកាន់ (Direction toward)** (ដូចជាព្រួញចង្អុលទៅមុខ)។
  - **に (ni):** ផ្តោតសំខាន់លើ **គោលដៅចុងក្រោយនៃការមកដល់ (Destination / Final arrival point)**។
- **ការប្រៀបធៀប:**
  - 日本**へ**行きたい。(ចង់ទៅ**ទិសដៅឆ្ពោះទៅ**ប្រទេសជប៉ុន - សង្កត់ធ្ងន់លើដំណើរឆ្ពោះទៅ)
  - 日本**に**行ったことがある。(ធ្លាប់បានទៅ**ដល់**ប្រទេសជប៉ុន - សង្កត់ធ្ងន់លើការទៅដល់គោលដៅ)

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ការសន្ទនាផ្លូវការ / គួរសម (Formal Speech)
- **ទីតាំងអត្ថិភាព:**
  - 公園に誰もいません。
  - *គ្មាននរណាម្នាក់នៅក្នុងសួនច្បារនោះទេ។*
- **ទិសដៅចលនា:**
  - 明日、会社に参ります。
  - *ថ្ងៃស្អែកខ្ញុំនឹងអញ្ជើញទៅកាន់ក្រុមហ៊ុន។ (ប្រើកិរិយាសព្ទបន្ទាបខ្លួន 参る)*
- **ពេលវេលាជាក់លាក់:**
  - 会議は10時に始まります。
  - *ការប្រជុំនឹងចាប់ផ្តើមនៅម៉ោង ១០។*
- **គោលបំណងនៃចលនា:**
  - 資料を届けに参りました。
  - *ខ្ញុំបានមកដើម្បីប្រគល់ឯកសារជូន។*
- **កម្មបទប្រយោល:**
  - 部長に報告いたします。
  - *ខ្ញុំនឹងរាយការណ៍ជូនប្រធានផ្នែក។*
- **ការផ្លាស់ប្តូរស្ថានភាព:**
  - 状況がより明確になりました。
  - *ស្ថានភាពបានប្រែជាច្បាស់លាស់ជាងមុន។*
- **ភ្នាក់ងារ (ប្រយោគអកម្ម):**
  - その仕事は彼女に任されました。
  - *ការងារនោះត្រូវបានប្រគល់ទុកចិត្តឱ្យនាងទទួលខុសត្រូវ។*

### ការសន្ទនាក្រៅផ្លូវការ / ស្និទ្ធស្នាល (Informal Speech)
- **ទីតាំងអត្ថិភាព:**
  - 部屋に猫がいるよ。
  - *មានឆ្មាមួយក្បាលនៅក្នុងបន្ទប់តើ!*
- **ទិសដៅចលនា:**
  - 映画館に行かない？
  - *តោះទៅរោងកុនអត់?*
- **ពេលវេលាជាក់លាក់:**
  - 土曜日に遊ぼう。
  - *ថ្ងៃសៅរ៍ដើរលេងគ្នាមក។*
- **គោលបំណងនៃចលនា:**
  - 新しいカフェを試しに行く。
  - *ទៅសាកហាងកាហ្វេថ្មីមួយនោះ។*
- **កម្មបទប្រយោល:**
  - 彼にメッセージを送った。
  - *ខ្ញុំផ្ញើសារទៅគាត់ហើយ។*
- **ការផ្លាស់ប្តូរស្ថានភាព:**
  - 彼は有名人になった。
  - *គាត់បានក្លាយជាមនុស្សល្បីឈ្មោះម្នាក់ហើយ។*
- **ភ្នាក់ងារ (ប្រយោគអកម្ម):**
  - 先生に褒められた！
  - *ត្រូវបានគ្រូសរសើរហ្ន៎!*
- **ភ្នាក់ងារ (ប្រយោគបង្គាប់បញ្ជា):**
  - 弟に部屋を掃除させた。
  - *ខ្ញុំបានប្រើប្អូនប្រុសឱ្យបោសសម្អាតបន្ទប់។*

## ៥. កំណត់សម្គាល់បែបវប្បធម៌ (Cultural Notes)

### សារៈសំខាន់ក្នុងវប្បធម៌ជប៉ុន (Cultural Relevance)
- នៅក្នុងសង្គមជប៉ុន ការបញ្ជាក់ទិសដៅ ពេលវេលា និងអ្នកទទួលឱ្យបានច្បាស់លាស់ និងគួរសម គឺជាគន្លឹះដ៏សំខាន់សម្រាប់ទំនាក់ទំនងរលូន និងបង្ហាញការគោរព។
- ការប្រើប្រាស់ **に** ឱ្យបានត្រឹមត្រូវឆ្លុះបញ្ចាំងពីការយល់ដឹងអំពីច្បាប់ទម្លាប់សង្គម និងការយល់ចិត្តអ្នកដទៃ (気配り - Kikubari)។

### កម្រិតគួរសម និងការប្រើប្រាស់ពាក្យលើកតម្កើង (Keigo)
នៅពេលប្រើជាមួយកិរិយាសព្ទគួរសម ឬកិរិយាសព្ទលើកតម្កើង/បន្ទាបខ្លួន ធ្នាក់ **に** បញ្ជាក់យ៉ាងច្បាស់អំពីអ្នកទទួលដែលជាបុគ្គលជាន់ខ្ពស់ ឬអតិថិជន៖
- お客様**に**ご案内いたします。
  - *ខ្ញុំបាទ/នាងខ្ញុំសូមអនុញ្ញាតនាំផ្លូវជូនអតិថិជន។ (គួរសម និងបន្ទាបខ្លួនខ្លាំង)*
- 先生**に**ご相談したいことがあります。
  - *ខ្ញុំមានរឿងមួយចំនួនចង់សុំពិគ្រោះយោបល់ជាមួយលោកគ្រូ។*

### សំនួនវោហារស័ព្ទគួរចងចាំ (Idiomatic Expressions)
- **目に見える (me ni mieru):** មើលឃើញច្បាស់នឹងភ្នែក, ស្តែងឱ្យឃើញជាក់ស្តែង
  - 成長が目に見える。
    - *ការរីកចម្រើនអាចមើលឃើញយ៉ាងច្បាស់។*
- **耳に入る (mimi ni hairu):** ឮដំណឹងមកដល់ត្រចៀក, បានឮដំណឹង
  - 面白い噂が耳に入った。
    - *ដំណឹងចចាមអារ៉ាមដ៏គួរឱ្យចាប់អារម្មណ៍មួយបានឮមកដល់ត្រចៀកខ្ញុំ។*
- **気にする (ki ni suru):** ប្រកាន់ក្នុងចិត្ត, ខ្វល់ខ្វាយ, យកទុកដាក់ក្នុងចិត្ត
  - そんなに気にしないでください。
    - *កុំខ្វល់ខ្វាយ/ប្រកាន់ក្នុងចិត្តច្រើនពេកអី។*
- **気に入る (ki ni iru):** ពេញចិត្ត, ត្រូវចិត្ត
  - この服が気に入りました。
    - *ខ្ញុំពេញចិត្តខោអាវមួយកំប្លេនេះខ្លាំងណាស់។*

---

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### កំហុសដែលសិស្សតែងតែកាន់ញឹកញាប់
1. **ច្រឡំរវាង に និង で ចំពោះទីកន្លែង:**
   - ❌ **ខុស:** 学校**で**行く。
   - ⭕ **ត្រូវ:** 学校**に**行く。 *(សាលាគឺជាគោលដៅចុងក្រោយ មិនមែនជាកន្លែងដែលកំពុងធ្វើសកម្មភាពនោះទេ)*
   - ❌ **ខុស:** 部屋**に**勉強する。
   - ⭕ **ត្រូវ:** 部屋**で**勉強する。 *(ការរៀនគឺជាសកម្មភាព ត្រូវប្រើ で)*

2. **ការប្រើ ឬលុប に ជាមួយពាក្យពេលវេលា:**
   - ពាក្យពេលវេលាដែលមានលេខជាក់លាក់ (ម៉ោង, ថ្ងៃខែ, ឆ្នាំ, ថ្ងៃនៃសប្តាហ៍) **ត្រូវតែប្រើ に**៖
     - ⭕ 5時に会います。(ជួបគ្នានៅម៉ោង ៥)
     - ⭕ 日曜日に出かけます。(ចេញទៅក្រៅនៅថ្ងៃអាទិត្យ)
   - ពាក្យពេលវេលាដែលប្រែប្រួលតាមពេលវេលាបច្ចុប្បន្ន (Relative time ដូចជា 今日, 明日, 昨日, 今週, 来月) **មិនត្រូវប្រើ に ឡើយ**៖
     - ❌ 明日に会います。
     - ⭕ 明日会います。(ជួបគ្នាថ្ងៃស្អែក)

3. **ច្រឡំប្រើ に ជាមួយពាក្យប្រេកង់ទូទៅ:**
   - ❌ 毎日**に**勉強する。
   - ⭕ 毎日勉強する。(រៀនរាល់ថ្ងៃ - 毎日 មិនត្រូវការ に ទេ)
   - ⭕ 1日**に**2時間勉強する。(រៀន ២ ម៉ោងក្នុងមួយថ្ងៃ - ប្រើ に ព្រោះបញ្ជាក់អត្រាឯកតា)

### គន្លឹះជំនួយការចងចាំ (Learning Tips)
- **ចងចាំរូបភាព "គោលដៅ" (Target Marker):** គិតថា **に** គឺជា "ព្រួញបាញ់ចំផ្ទាំងស៊ីប" — មិនថាជាម៉ោងជាក់លាក់ (៧:០០), គោលដៅចុងក្រោយ (សាលារៀន), មនុស្សដែលទទួលអំណោយ, ឬគោលបំណងនៃចលនាឡើយ វាសុទ្ធតែជាចំណុចស៊ីបដែលសកម្មភាពចង្អុលទៅរក!

## ៧. សង្ខេប និងកម្រងសំណួរ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ
- **に (ni)** គឺជាធ្នាក់ពហុមុខងារដ៏សំខាន់៖ បញ្ជាក់ទីតាំងអត្ថិភាព, គោលដៅធ្វើដំណើរ, ពេលវេលាជាក់លាក់, គោលបំណងនៃចលនា, អ្នកទទួល, ការប្រែប្រួលស្ថានភាព, ភ្នាក់ងារក្នុងប្រយោគអកម្ម/បង្គាប់បញ្ជា និងប្រេកង់ក្នុងមួយឯកតា។
- ការបែងចែកដាច់រវាង **に**, **で**, និង **へ** គឺជាគន្លឹះគ្រឹះក្នុងការសរសេរ និងនិយាយភាសាជប៉ុនឱ្យបានត្រឹមត្រូវ។
- ក្នុងកម្រិត N4 ត្រូវចងចាំច្បាស់ពីទម្រង់៖ `គោលបំណង (Verb Stem + に行く)`, `ប្រយោគអកម្ម (Agent に Passive)`, `ប្រយោគបង្គាប់បញ្ជា (Agent に Causative)`, និង `ការសម្រេចចិត្ត (Noun + にする)`។

### កម្រងសំណួររំលឹកឡើងវិញ (Quick Recap Quiz)

**ចូរជ្រើសរើសធ្នាក់ដែលត្រឹមត្រូវ (に, で, へ) បំពេញក្នុងចន្លោះទំនេរ៖**
1. 図書館___本を読みました。
2. 来週の月曜日___会議があります。
3. 友達___手紙を送った。
4. 美術館___行きたい。
5. 日本語を勉強し___来ました。
6. 1日___3回、ご飯を食べます。

**ចម្លើយ និងការពន្យល់:**
1. 図書館**で**本を読みました。 *(កន្លែងនៃសកម្មភាពអាន ➔ ប្រើ で)*
2. 来週の月曜日**に**会議があります。 *(ពេលវេលាជាក់លាក់ដែលមានឈ្មោះថ្ងៃ ➔ ប្រើ に)*
3. 友達**に**手紙を送った。 *(អ្នកទទួលកម្មបទប្រយោល ➔ ប្រើ に)*
4. 美術館**へ / に**行きたい。 *(គោលដៅចលនា ➔ អាចប្រើ に ឬ へ)*
5. 日本語を勉強し**に**来ました。 *(គោលបំណងនៃចលនាមកដល់ ➔ ប្រើ Verb stem + に)*
6. 1日**に**3回、ご飯を食べます。 *(ប្រេកង់ក្នុងមួយឯកតាពេលវេលា ➔ ប្រើ に)*
