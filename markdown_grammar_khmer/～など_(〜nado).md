# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～など (〜nado)
**កម្រិត JLPT:** JLPT N3

## ១. សេចក្តីផ្តើម (Introduction)
ធ្នាក់ **～など (*nado*)** គឺជាទម្រង់វេយ្យាករណ៍ទូទៅ និងសំខាន់មួយក្នុងភាសាជប៉ុន ដែលត្រូវបានប្រើសម្រាប់លើកឧទាហរណ៍មួយចំនួនក្នុងចំណោមរបស់ ឬសកម្មភាពជាច្រើន។ វាមានន័យស្មើនឹង «ដូចជា... ជាដើម / ...ជាអាទិ៍ / និងផ្សេងៗទៀត» ("such as", "and so on", "etc.")។ ការយល់ដឹងច្បាស់ពីរបៀបប្រើប្រាស់ *nado* ជួយឱ្យអ្នកអាចរៀបរាប់បញ្ជីឈ្មោះ ឬឧទាហរណ៍ដោយបញ្ជាក់ថា នៅមានចំណុចដទៃទៀតជាច្រើនដែលមិនបានលើកយកមកនិយាយក្នុងបរិបទនោះ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **～など (*nado*)** ប្រើសម្រាប់លើកជាឧទាហរណ៍ ដោយមិនចាំបាច់រៀបរាប់ឈ្មោះវត្ថុ ឬសកម្មភាពទាំងអស់នោះឡើយ (Non-exhaustive listing)។
- វាបង្កប់ន័យថា អ្វីដែលបានរៀបរាប់ គ្រាន់តែជាផ្នែកតូចមួយនៃក្រុមធំមួយប៉ុណ្ណោះ។
- បង្កប់ន័យបន្ទាបខ្លួន ឬបន្ទាបតម្លៃ (Downplaying / Humility) អាស្រ័យលើបរិបទ ជាពិសេសនៅពេលប្រើជាមួយខ្លួនឯង ឬរបស់ផ្ទាល់ខ្លួន។

### ទម្រង់វេយ្យាករណ៍ (Structure)
ទម្រង់ជាមូលដ្ឋាននៃការប្រើប្រាស់ *nado* រួមមាន៖
1. **នាម (Noun) + など**
2. **កិរិយាសព្ទ (ទម្រង់ដើម/វចនានុក្រម - 辞書形) + など**
3. **[នាម / ឈ្នាប់ / ធ្នាក់] + など** (ឧទាហរណ៍៖ 〜になど, 〜でなど)

### តារាងទម្រង់វេយ្យាករណ៍ (Formation Diagram)
| ទម្រង់ (Structure) | របៀបប្រើប្រាស់ (Usage) | ឧទាហរណ៍ (Example) |
|---|---|---|
| **នាម (Noun) + など** | លើកជាឧទាហរណ៍នៃឈ្មោះនាម | りんご**など** (ដូចជាផ្លែប៉ោមជាដើម) |
| **កិរិយាសព្ទ (ទម្រង់ដើម) + など** | លើកជាឧទាហរណ៍នៃសកម្មភាព | 本を読む**など** (ដូចជាការអានសៀវភៅជាដើម) |
| **កិរិយាសព្ទ (ទម្រង់ て) + など** | លើកសកម្មភាពភ្ជាប់ជាមួយកិរិយាសព្ទបន្ទាប់ | 掃除をし**たり**、洗濯をし**たりなど**する |

### ការពន្យល់លម្អិត (Detailed Explanation)
- **នាម + など**: ប្រើដើម្បីលើកឈ្មោះនាមមួយ ឬច្រើនធ្វើជាឧទាហរណ៍តំណាងឱ្យក្រុមរបស់វា។
- **កិរិយាសព្ទ + など**: ប្រើបន្ទាប់ពីកិរិយាសព្ទ (ច្រើនប្រើទម្រង់ `〜などする` ឬ `〜などして`) ដើម្បីលើកសកម្មភាពណាមួយធ្វើជាឧទាហរណ៍។
- នៅពេលលើកឧទាហរណ៍ច្រើន ច្រើនប្រើគូជាមួយធ្នាក់ `や` ដូចជា `A や B など` (A និង B ជាដើម)។
- *など* អាចប្រើដើម្បីបង្ហាញពីការបន្ទាបខ្លួន (Humility/Modesty) ដូចជា `私など` (មនុស្សតូចតាចដូចជាខ្ញុំ)។

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuance)

### ការប្រៀបធៀប ～など ជាមួយ ～なんか និង ～なんて

| កន្សោមវេយ្យាករណ៍ | កម្រិតគួរសម / របៀបប្រើ (Register) | លក្ខណៈពិសេស និង ន័យស៊ីជម្រៅ (Nuance) |
|---|---|---|
| **～など (nado)** | ផ្លូវការ / សរសេរ / ការសន្ទនាគួរសមទូទៅ (Formal / Neutral / Written) | ប្រើសម្រាប់លើកឧទាហរណ៍មិនអស់ (and so on, etc.) ក្នុងឯកសារផ្លូវការ សារព័ត៌មាន និងការសន្ទនាទូទៅ។ បង្ហាញការបន្ទាបខ្លួនយ៉ាងសមរម្យ (`私など`)។ |
| **～なんか (nanka)** | ស្និទ្ធស្នាល / ភាសានិយាយ (Casual / Spoken) | ជាទម្រង់សន្ទនាទូទៅនៃ *など*។ ប្រើក្នុងចំណោមមិត្តភក្តិ គ្រួសារ។ ជារឿយៗបង្កប់ន័យមើលស្រាល មើលងាយ បន្ទាបតម្លៃ ឬបដិសេធស្រាលៗ ("របស់បែបហ្នឹង...", "រឿងដូចជា...")។ |
| **～なんて (nante)** | ភាសានិយាយ / អក្សរសិល្ប៍ / បង្ហាញអារម្មណ៍ (Emphatic / Emotional) | ប្រើសម្រាប់សង្កត់អារម្មណ៍ភ្ញាក់ផ្អើល មិននឹកស្មានដល់ មាក់ងាយ ឬបន្ទាបខ្លួនយ៉ាងខ្លាំង ("របស់ដូចជា...", "មនុស្សដូចជា...")។ អាចភ្ជាប់ជាមួយប្រយោគទាំងមូលបាន (`〜だなんて`)។ |

#### ការប្រៀបធៀបជាមួយធ្នាក់បញ្ជីឧទាហរណ៍ដទៃទៀត (～や, ～とか)
1. **～や**: ជាធ្នាក់ភ្ជាប់នាមជាមួយនាម (`A や B`) បង្ហាញពីការរៀបរាប់មិនអស់ ប៉ុន្តែ *や* មិនអាចឈរនៅចុងបញ្ចប់នៃបញ្ជីបានទេ ខណៈដែល *など* អាចនៅចុងបញ្ចប់បាន (ឧទាហរណ៍៖ `A や B など`)។
2. **～とか**: ប្រើក្នុងភាសានិយាយស្និទ្ធស្នាល (`A とか B とか`) សម្រាប់ទាំងនាម និងកិរិយាសព្ទ។ *など* មានលក្ខណៈផ្លូវការ គួរសម និងត្រឹមត្រូវតាមក្បួនវេយ្យាករណ៍ជាង។

#### ន័យបន្ទាបខ្លួន និងបន្ទាបតម្លៃ (Humble Self-Deprecation)
- នៅពេល *など* ភ្ជាប់ជាមួយសព្វនាមផ្ទាល់ខ្លួន ដូចជា **私など (watashi nado)** វាបង្កប់ន័យថា «មនុស្សតូចតាច គ្មានសមត្ថភាព ឬមិនសំខាន់ដូចជាខ្ញុំ» ("someone insignificant like me")។ នេះជាទម្រង់គួរសមបែបបន្ទាបខ្លួនដ៏ជ្រាលជ្រៅក្នុងវប្បធម៌ជប៉ុន ដើម្បីកុំឱ្យមើលទៅហាក់ដូចជាអួតអាង។
- ផ្ទុយទៅវិញ បើប្រើចំពោះអ្នកដទៃ វាអាចក្លាយជាន័យមើលស្រាល ដូច្នេះត្រូវប្រុងប្រយ័ត្នកុំប្រើចំពោះអ្នកមានឋានៈខ្ពស់ជាងខ្លួន។

## ៤. ឧទាហរណ៍ក្នុងបរិបទ (Examples in Context)

### ឧទាហរណ៍ទី ១៖ នាម + など (Noun + など)
**ភាសាជប៉ុន:**  
動物園では、ライオンやゾウ**など**を見ることができます。  
**រ៉ូម៉ាជី:**  
Dōbutsuen de wa, raion ya zō **nado** o miru koto ga dekimasu.  
**ការបកប្រែជាភាសាខ្មែរ:**  
នៅឯសួនសត្វ អ្នកអាចទស្សនាសត្វនានាដូចជា តោ និងដំរី**ជាដើម**។

---

### ឧទាហរណ៍ទី ២៖ កិរិយាសព្ទ + など (Verb + など)
**ភាសាជប៉ុន:**  
週末は本を読む**など**して過ごします。  
**រ៉ូម៉ាជី:**  
Shūmatsu wa hon o yomu **nado** shite sugoshimasu.  
**ការបកប្រែជាភាសាខ្មែរ:**  
នៅចុងសប្តាហ៍ ខ្ញុំចំណាយពេលធ្វើសកម្មភាព**ដូចជា**ការអានសៀវភៅ**ជាដើម**។

---

### ឧទាហរណ៍ទី ៣៖ ការបន្ទាបខ្លួន (Emphasizing Modesty)
**ភាសាជប៉ុន:**  
私**など**にできることは限られています。  
**រ៉ូម៉ាជី:**  
Watashi **nado** ni dekiru koto wa kagirarete imasu.  
**ការបកប្រែជាភាសាខ្មែរ:**  
អ្វីដែលមនុស្សតូចតាច**ដូចជា**ខ្ញុំអាចធ្វើបាន គឺមានកម្រិតណាស់។

---

### ឧទាហរណ៍ទី ៤៖ ការលើកជាឧទាហរណ៍តំណាង (Example Representation)
**ភាសាជប៉ុន:**  
日本の食べ物、寿司**など**が好きです。  
**រ៉ូម៉ាជី:**  
Nihon no tabemono, sushi **nado** ga suki desu.  
**ការបកប្រែជាភាសាខ្មែរ:**  
ខ្ញុំចូលចិត្តម្ហូបជប៉ុន **ដូចជា**ស៊ូស៊ី**ជាដើម**។

---

### ឧទាហរណ៍ទី ៥៖ បរិបទផ្លូវការ (Formal Context)
**ភាសាជប៉ុន:**  
この書類には氏名、生年月日**など**を記入してください。  
**រ៉ូម៉ាជី:**  
Kono shorui ni wa shimei, seinengappi **nado** o kinyū shite kudasai.  
**ការបកប្រែជាភាសាខ្មែរ:**  
សូមបំពេញឈ្មោះ ថ្ងៃខែឆ្នាំកំណើត **និងព័ត៌មានផ្សេងៗទៀត**នៅលើឯកសារនេះ។

---

## ៥. កត់សម្គាល់ខាងវប្បធម៌ (Cultural Notes)

### ទំនាក់ទំនងខាងវប្បធម៌ (Cultural Relevance)
- **ការបង្ហាញការបន្ទាបខ្លួន (Humble / Kenjou Nuance):** ការប្រើ *など* ជាមួយសព្វនាមផ្ទាល់ខ្លួនដូចជា *私など* បង្ហាញពីចរិតលក្ខណៈបន្ទាបខ្លួនបែបជប៉ុន ដោយមិនលើកតម្កើងខ្លួនឯងហួសហេតុ។
- **ការបន្ទន់សម្តី (Softening Statements):** ជនជាតិជប៉ុននិយមប្រើ *など* ដើម្បីកុំឱ្យសម្តីមានលក្ខណៈដាច់ខាតពេក ដោយបើកផ្លូវឱ្យជម្រើសផ្សេងទៀត ដែលជួយរក្សាសុខដុមរមនា (和 - *wa*) ក្នុងការទំនាក់ទំនង។

### កន្សោមឃ្លាគួរចងចាំ (Idiomatic Expressions)
- **～などと言う / ～などと思う:**  
  ប្រើសម្រាប់ដកស្រង់សម្តី ឬគំនិតរបស់អ្នកដទៃ ដោយជារឿយៗបង្កប់នូវអារម្មណ៍សង្ស័យ មិនសូវជឿ ឬភ្ញាក់ផ្អើល។  
  **ឧទាហរណ៍:**  
  彼が来る**などと言った**が、結局来なかった。  
  *Kare ga kuru **nado to itta** ga, kekkyoku konakatta.*  
  (គាត់បាននិយាយ**អ្វីមួយដូចជា**គាត់នឹងមកដែរ ប៉ុន្តែចុងក្រោយមិនឃើញមកសោះ។)

## ៦. កំហុសទូទៅ និងគន្លឹះជំនួយ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
- **ការប្រើ *nado* ច្រើនហួសហេតុ:**  
  មិនចាំបាច់ដាក់ *など* នៅពីក្រោយរាល់គ្រប់ពាក្យក្នុងបញ្ជីរៀបរាប់នោះទេ។  
  - **ខុស:** ペン**など**、ノート**など**、消しゴム**など**を買いました。  
  - **ត្រូវ:** ペンやノート、消しゴム**など**を買いました。 (ខ្ញុំបានទិញប៊ិច សៀវភៅសរសេរ និងជ័រលុប**ជាដើម**។)
- **ការប្រើ *nado* ផ្ទាល់ពីក្រោយគុណនាម:**  
  *など* មិនត្រូវភ្ជាប់ផ្ទាល់ពីក្រោយគុណនាមឡើយ។ ត្រូវភ្ជាប់បន្ទាប់ពីនាមដែលគុណនាមនោះបញ្ជាក់ន័យ។  
  - **ខុស:** 美しい**など**景色。  
  - **ត្រូវ:** 美しい景色**など**を見ました。 (ខ្ញុំបានទស្សនាទេសភាពដ៏ស្រស់ស្អាត**ជាដើម**។)

### យុទ្ធសាស្ត្រសិក្សា (Learning Strategies)
- **គន្លឹះចងចាំ:** ចងចាំជានិច្ចថា នៅពេលឃើញ *など* មានន័យថានៅមានរបស់ ឬសកម្មភាពផ្សេងទៀតជាច្រើនដែលមិនទាន់រៀបរាប់អស់។
- **រូបមន្តងាយស្រួល:** គិតថា `[A や B] + など` = «A និង B ជាដើម / ...ជាអាទិ៍»។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចសំខាន់ៗដែលត្រូវចងចាំ
- **គោលបំណងនៃ ～など (*nado*):** ប្រើសម្រាប់លើកឧទាហរណ៍មិនអស់ក្នុងចំណោមក្រុមធំមួយ ប្រែថា «ដូចជា... ជាដើម / ជាអាទិ៍ / និងផ្សេងៗទៀត»។
- **ទម្រង់:** ប្រើជាចម្បងជាមួយនាម (Noun + など) និងម្តងម្កាលជាមួយកិរិយាសព្ទ (Verb-dictionary form + など)។
- **ន័យស៊ីជម្រៅ:** បញ្ជាក់ថាបញ្ជីមិនទាន់អស់ ព្រមទាំងអាចបង្ហាញពីការបន្ទាបខ្លួន ឬបន្ទាបតម្លៃសមរម្យ។
- **ការប្រៀបធៀប:** ផ្លូវការជាង *～とか* និង *～なんか* ហើយមានន័យបញ្ជាក់ពីអ្វីផ្សេងទៀតដែលមិនបានរៀបរាប់ ខុសពី *～や* ដែលគ្រាន់តែជាឈ្នាប់ភ្ជាប់នាម។
