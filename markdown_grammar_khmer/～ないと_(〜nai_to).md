# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～ないと (〜nai to)
**កម្រិត JLPT:** JLPT N3

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ **～ないと (〜nai to)** គឺជាកន្សោមភាសានិយាយប្រចាំថ្ងៃ (Colloquial / Spoken Japanese) ដែលប្រើសម្រាប់បង្ហាញពីកាតព្វកិច្ច ការចាំបាច់ ឬអ្វីដែលត្រូវតែធ្វើ។ វាមានន័យស្មើនឹង «ត្រូវតែ...» ឬ «ត្រូវធ្វើ... (have to / must do)» ហើយត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយបំផុតក្នុងការសន្ទនាបែបស្និទ្ធស្នាល និងការរំឭកខ្លួនឯង។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
**～ないと** បង្ហាញពីអារម្មណ៍នៃកាតព្វកិច្ច បន្ទុកភារកិច្ច ឬភាពចាំបាច់ដែលត្រូវអនុវត្តសកម្មភាពណាមួយ។ ជាភាសាខ្មែរអាចបកប្រែបានថា៖
- «ត្រូវតែ...»
- «ត្រូវ...»
- «ខានមិនបាន / បើមិន... មិនកើតទេ»

### ទម្រង់វេយ្យាករណ៍ (Structure)
ទម្រង់នេះកើតឡើងដោយការយកកិរិយាសព្ទបដិសេធធម្មតា (ទម្រង់ ない / Nai-form) រួចភ្ជាប់ជាមួយឈ្នាប់លក្ខខណ្ឌ **と**៖

```
កិរិយាសព្ទ (ទម្រង់ ない) + と
```

*ចំណាំ៖ តាមពិតទៅ ទម្រង់ពេញលេញរបស់វាគឺ **〜ないといけない** ឬ **〜ないとだめだ** ប៉ុន្តែក្នុងការនិយាយប្រចាំថ្ងៃ គេច្រើនលុបពាក្យខាងចុង (いけない / だめだ) ចោល ដោយទុកត្រឹម **〜ないと**។*

### តារាងបំប្លែងទម្រង់ (Formation Table)

| កិរិយាសព្ទដើម (辞書形) | ទម្រង់ ない (ない形) | ＋ と | អត្ថន័យ (ខ្មែរ) |
|---|---|---|---|
| 行く (iku) - ទៅ | 行かない | 行かないと | ត្រូវតែទៅ |
| 食べる (taberu) - ញ៉ាំ | 食べない | 食べないと | ត្រូវតែញ៉ាំ |
| 勉強する (benkyou suru) - រៀន | 勉強しない | 勉強しないと | ត្រូវតែរៀន |
| 起きる (okiru) - ក្រោក | 起きない | 起きないと | ត្រូវតែក្រោក |
| する (suru) - ធ្វើ | しない | しないと | ត្រូវតែធ្វើ |


## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance & Comparative Analysis)

### ឫសគល់នៃទម្រង់លុបចោលក្នុងការសន្ទនា (Conversational Omission)
តាមក្បួនភាសាជប៉ុន ឈ្នាប់ **と** គឺជាឈ្នាប់លក្ខខណ្ឌ (មានន័យថា "ប្រសិនបើ/បើសិន")។ ដូច្នេះតាមន័យត្រង់ **〜ないと** គឺមកពី៖
> **〜ないと [いけない / だめだ]** = «បើមិនធ្វើ [គឺមិនកើត / មិនបានទេ]» ➔ មានន័យស្មើនឹង «ត្រូវតែធ្វើ»។

នៅក្នុងការសន្ទនាជាក់ស្តែង ជនជាតិជប៉ុននិយមនិយាយមិនឲ្យចប់ប្រយោគ ដើម្បីបន្ទន់សម្លេង ឬដោយសារអ្នកស្តាប់យល់ច្បាស់នូវផលវិបាកដែលនឹងកើតឡើងហើយ។ ហេតុនេះ ការកាត់សេចក្តីត្រឹម **〜ないと** បង្ហាញនូវការដាស់តឿនខ្លួនឯង (Soliloquy) ឬប្រាប់ដៃគូសន្ទនាបែបធម្មជាតិថា «ដល់ពេលត្រូវធ្វើហើយ»។

### ការប្រៀបធៀបកម្រិតគួរសម និងទម្រង់កាតព្វកិច្ចនានា

| ទម្រង់ | កម្រិតគួរសម (Register) | បរិបទ និងលក្ខណៈពិសេស |
|---|---|---|
| **～なければなりません** | ផ្លូវការខ្លាំង / សរសេរ (Formal / Written) | ជាកាតព្វកិច្ចផ្អែកលើច្បាប់ សីលធម៌ ឬបទបញ្ជាទូទៅ។ ប្រើក្នុងឯកសារ ការងារ និងការប្រជុំ។ |
| **～なくてはいけません** | ផ្លូវការមធ្យម (Polite Spoken) | បង្ហាញពីភាពចាំបាច់ក្នុងស្ថានភាពជាក់ស្តែង ចំពោះបុគ្គលផ្ទាល់។ |
| **～ないといけません** | គួរសមបែបធម្មជាតិ (Polite Spoken) | ប្រើក្នុងការនិយាយប្រចាំថ្ងៃបែបគួរសម។ |
| **～ないと** | ស្និទ្ធស្នាល / និយាយលេង (Casual Spoken) | កាត់មកពី 〜ないといけない។ ពេញនិយមបំផុតពេលរអ៊ូរទាំតែឯង ឬនិយាយជាមួយមិត្តភក្តិ។ |
| **～なきゃ** | ស្និទ្ធស្នាលខ្លាំង (Very Casual Spoken) | កាត់មកពី 〜なければ (いけない)។ ប្រើទូទៅក្នុងចំណោមមិត្តជិតស្និទ្ធ។ |
| **～なくちゃ** | ស្និទ្ធស្នាល / គួរឱ្យស្រឡាញ់ (Casual / Soft) | កាត់មកពី 〜なくては (いけない)។ ផ្តល់អារម្មណ៍ទន់ភ្លន់ ឬក្មេងជាង 〜なきゃ។ |

#### ឧទាហរណ៍ប្រៀបធៀប៖
1. **行かなければなりません。** (I must go.) — ផ្លូវការ (ឧ. ជម្រាបប្រាប់ប្រធាន ឬដៃគូអាជីវកម្ម)
2. **行かないといけません。** (I have to go.) — គួរសមទូទៅ (ឧ. និយាយជាមួយអ្នកស្គាល់គ្នាទូទៅ)
3. **行かないと。** (I have to go.) — ស្និទ្ធស្នាល/និយាយលេង (ឧ. និយាយជាមួយមិត្តភក្តិ ឬរអ៊ូប្រាប់ខ្លួនឯងថាដល់ម៉ោងត្រូវទៅហើយ)
4. **行かなくちゃ / 行かなきゃ。** (Got to go!) — ស្និទ្ធស្នាលខ្លាំង/ភាសាសាមញ្ញ

## ៤. ឧទាហរណ៍ក្នុងបរិបទ (Examples in Context)

### ប្រយោគគំរូ (Example Sentences)

1. **早く寝ないと。**
   - អាន៖ *Hayaku nenai to.*
   - ន័យ៖ ត្រូវតែចូលគេងឲ្យលឿនហើយ (បើមិនគេងទេ ច្បាស់ជាស្អែកងើបមិនរួច)។

2. **宿題をしないと。**
   - អាន៖ *Shukudai o shinai to.*
   - ន័យ៖ ត្រូវធ្វើកិច្ចការផ្ទះហើយ។

3. **買い物に行かないといけない。**
   - អាន៖ *Kaimono ni ikanai to ikenai.*
   - ន័យ៖ ខ្ញុំត្រូវតែទៅទិញអីវ៉ាន់ (ទម្រង់ពេញលេញ)។

4. **今日中にこのレポートを終わらせないと。**
   - អាន៖ *Kyoujuu ni kono repooto o owarasenai to.*
   - ន័យ៖ ត្រូវតែបញ្ចប់របាយការណ៍នេះឲ្យហើយក្នុងថ្ងៃនេះ។

5. **もう帰らないと。**
   - អាន៖ *Mou kaeranai to.*
   - ន័យ៖ ដល់ម៉ោងត្រូវត្រឡប់ទៅផ្ទះវិញហើយ។

6. **明日テストがあるから、今晩もっと勉強しないと。**
   - អាន៖ *Ashita tesuto ga aru kara, konban motto benkyou shinai to.*
   - ន័យ៖ ដោយសារស្អែកមានប្រឡង យប់នេះត្រូវតែខំរៀនបន្ថែមទៀតហើយ។

## ៥. កំណត់សម្គាល់វប្បធម៌ និងការប្រើប្រាស់ (Cultural Notes)

### កម្រិតនៃការគួរសម (Politeness Dynamics)
នៅក្នុងវប្បធម៌ជប៉ុន កម្រិតនៃភាពគួរសមនិងការរក្សាគម្លាតសង្គមគឺជារឿងសំខាន់ណាស់៖
- **ការប្រើប្រាស់ប្រកបដោយការប្រុងប្រយ័ត្ន**៖ មិនត្រូវប្រើ **～ないと** តែឯងនៅក្នុងបរិយាកាសការងារ អាជីវកម្ម ក្នុងអ៊ីមែល ឬពេលនិយាយជាមួយថ្នាក់លើ/ចាស់ទុំឡើយ ព្រោះវាស្តាប់ទៅកាត់កន្ទុយនិងគ្មានសុជីវធម៌។
- ក្នុងកាលៈទេសៈផ្លូវការ ត្រូវប្រើ **～なければなりません** ឬយ៉ាងហោចណាស់ **～ないといけません**។

### ការនិយាយរអ៊ូដាស់តឿនខ្លួនឯង (Monologue / Self-reminder)
**～ないと** តែងតែត្រូវបានគេប្រើជាពាក្យឧទានផ្ទាល់ខ្លួន (Soliloquy) នៅពេលស្រាប់តែនឹកឃើញអ្វីមួយដែលខកខានមិនបាន ដូចជា៖
- **あっ、忘れないと！** (អា៎ ត្រូវចាំកុំឲ្យភ្លេច!)
- **先生に連絡しないと。** (ត្រូវទាក់ទងទៅលោកគ្រូហើយ។)

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes & Tips)

### កំហុសដែលតែងតែកើតមាន
1. **ការប្រើ ～ないと ក្នុងស្ថានភាពផ្លូវការ**
   - មិនត្រឹមត្រូវ៖ 明日の会議に行かないと。(និយាយទៅកាន់ប្រធានក្រុមហ៊ុន)
   - ត្រឹមត្រូវ៖ 明日の会議に**行かなければなりません**。
   *គន្លឹះ*៖ ក្នុងបរិបទការងារ សូមចងចាំប្រើទម្រង់វែងដែលមាន **〜なりません** ជានិច្ច។

2. **ការច្រឡំរវាងកាតព្វកិច្ច និងប្រយោគលក្ខខណ្ឌបដិសេធពិតប្រាកដ**
   - កាតព្វកិច្ច (លុប いけない ចោល)៖ 行かないと。(ខ្ញុំត្រូវតែទៅ។)
   - លក្ខខណ្ឌបដិសេធ (មានលទ្ធផលនៅឃ្លាទី២)៖ 行かないと、困る。(បើមិនទៅទេ នឹងពិបាក/មានបញ្ហាជាក់ជាមិនខាន។)
   *គន្លឹះ*៖ ពិនិត្យមើលបរិបទ ប្រសិនបើឈប់ត្រឹម **と** នៅចុងបញ្ចប់ប្រយោគ វាមានន័យស្មើនឹង "ត្រូវតែ..."។

### វិធីសាស្ត្រចងចាំ (Mnemonic Strategy)
- គិតថា **～ないと** គឺកាត់មកពី «**បើមិន... ទេ គឺ [មិនកើតឡើយ]**» ➔ ដូច្នេះត្រូវតែធ្វើវា!

## ៧. សង្ខេប និងកម្រងសំណួររំឭកឡើងវិញ (Summary & Review)

### ចំណុចគន្លឹះសំខាន់ៗ
- **～ないと** គឺជាកន្សោមនិយាយកាត់បែបស្និទ្ធស្នាល មានន័យថា «ត្រូវតែ... / have to ~»។
- កើតចេញពីកិរិយាសព្ទ **ទម្រង់ ない + と** (លុប いけない / だめだ)។
- ប្រើសម្រាប់ការសន្ទនាក្នុងចំណោមមិត្តភក្តិ ក្រុមគ្រួសារ ឬការរអ៊ូប្រាប់ខ្លួនឯង។
- បើចង់និយាយជាផ្លូវការ ត្រូវប្តូរទៅប្រើ **～なければなりません**។

### កម្រងសំណួរខ្លីៗ (Quick Recap Quiz)

១. **តើឃ្លា «ខ្ញុំត្រូវតែរៀន» ជាភាសាជប៉ុនដោយប្រើ ～ないと សរសេរដូចម្តេច?**
   ក) 勉強しないと。
   ខ) 勉強したいと。
   គ) 勉強しなければ。

២. **តើទម្រង់មួយណាមានលក្ខណៈផ្លូវការ និងគួរសមជាង?**
   ក) 行かないと。
   ខ) 行かなければなりません。

៣. **ត្រូវ ឬ ខុស៖** យើងអាចប្រើ ～ないと នៅខាងចុងប្រយោគក្នុងអ៊ីមែលអាជីវកម្មផ្ញើទៅអតិថិជនបាន។
   ក) ត្រូវ
   ខ) ខុស

### ចម្លើយ
១. **ក) 勉強しないと。**
២. **ខ) 行かなければなりません。**
៣. **ខ) ខុស** (ក្នុងអ៊ីមែលអាជីវកម្ម ត្រូវប្រើទម្រង់ផ្លូវការដូចជា 〜なければなりません / 〜なければいけません)។
