# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～ように (〜you ni)
**កម្រិត JLPT:** JLPT N3

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ **～ように (〜you ni)** គឺជាកន្សោមពាក្យដ៏មានសារៈសំខាន់ និងមានការប្រើប្រាស់ច្រើនបែបយ៉ាងនៅក្នុងភាសាជប៉ុន ដែលមានអត្ថន័យជាភាសាខ្មែរថា **«ដើម្បីឱ្យ... / ដើម្បីកុំឱ្យ...» (បង្ហាញគោលបំណង), «សូមបួងសួងឱ្យ... / សង្ឃឹមថា...» (បង្ហាញការបួងសួង ឬបំណងប្រាថ្នា), «ណែនាំ ឬផ្តាំផ្ញើឱ្យ...» (ការណែនាំដោយប្រយោល)** និង **«ដូចជា... / តាមរបៀបដូចជា...» (បង្ហាញលក្ខណៈ ឬរបៀបនៃការធ្វើសកម្មភាព)**។

ការយល់ដឹងច្បាស់អំពី **～ように** គឺពិតជាចាំបាច់ខ្លាំងណាស់សម្រាប់កម្រិត JLPT N3 ក្នុងការបង្ហាញអំពីគោលបំណង ការបួងសួង និងការបញ្ជា/ណែនាំដោយប្រយោលប្រកបដោយភាពគួរសម និងទន់ភ្លន់។

---

## ២. ការពន្យល់វេយ្យាករណ៍គោល (Core Grammar Explanation)

### អត្ថន័យ និងការប្រើប្រាស់ (Meaning and Usage)
**～ように** មានមុខងារប្រើប្រាស់សំខាន់ៗដូចខាងក្រោម៖
1. **បង្ហាញគោលបំណង ឬទិសដៅ («ដើម្បីឱ្យ... / ដើម្បីកុំឱ្យ...» - In order that / So that)**
   - ប្រើដើម្បីបញ្ជាក់ពីគោលដៅនៃសកម្មភាពមួយ ដោយ clause ខាងមុខជាទូទៅភ្ជាប់ជាមួយ **កិរិយាសព្ទអសមត្ថភាព/គ្មានចេតនា (Non-volitional Verbs)**, **កិរិយាសព្ទបង្ហាញលទ្ធភាព (Potential Form)** ឬ **កិរិយាសព្ទបដិសេធ (Negative Form: 〜ない)** ដើម្បីបង្កើតស្ថានភាពមួយដែលអ្នកនិយាយចង់ឱ្យកើតឡើង ឬចង់ជៀសវាង។
2. **បង្ហាញការបួងសួង ឬក្តីសង្ឃឹម («សូមបួងសួងឱ្យ... / សង្ឃឹមថា...» - Praying / Wishing)**
   - ប្រើនៅចុងបញ្ចប់នៃល្បះ ដើម្បីបួងសួងដល់ព្រះ ឬបង្ហាញពីសេចក្តីប្រាថ្នាឱ្យរឿងល្អកើតឡើងចំពោះខ្លួនឯង ឬអ្នកដទៃ។
3. **ការណែនាំ ឬការបញ្ជាដោយប្រយោល («សូមឱ្យ... / ផ្តាំថាឱ្យ...» - Indirect Request / Advice)**
   - ប្រើក្នុងទម្រង់ `〜ように言う / 伝える / 頼む` ឬនៅចុងល្បះ `〜ようにしてください` / `〜ように` ដើម្បីផ្តាំផ្ញើ ឬណែនាំដោយគួរសម និងមិនបង្ខិតបង្ខំ។
4. **បង្ហាញលក្ខណៈ ឬរបៀប («ដូចជា... / តាម...» - Manner / Like / As)**
   - ប្រើដើម្បីពិពណ៌នាអំពីការធ្វើសកម្មភាពមួយតាមរបៀបដូចគ្នានឹងនរណាម្នាក់ ឬអ្វីមួយ។

---

### ទម្រង់ និងក្បួនផ្គុំ (Structure and Formation)

#### ១. បង្ហាញគោលបំណង (Purpose / Aim: So that / In order to)
**ក្បួនផ្គុំ៖**
- **កិរិយាសព្ទ (ទម្រង់លទ្ធភាព Potential / អសមត្ថភាព Non-volitional / បដិសេធ 〜ない) + ように**

**ឧទាហរណ៍៖**
- **忘れないように** メモします。
  - _(ខ្ញុំកត់ត្រាទុក **ដើម្បីកុំឱ្យ** ភ្លេច។)_
- **合格できるように** 一生懸命勉強しました。
  - _(ខ្ញុំបានខិតខំរៀនយ៉ាងខ្លាំង **ដើម្បីឱ្យអាច** ប្រឡងជាប់។)_
- 後ろの人にも **聞こえるように** 大きな声で話してください。
  - _(សូមនិយាយឱ្យឮខ្លាំងៗ **ដើម្បីឱ្យ** អ្នកនៅខាងក្រោយអាចស្តាប់ឮផងដែរ។)_

#### ២. បង្ហាញការបួងសួង ឬក្តីសង្ឃឹម (Hopes / Wishes)
**ក្បួនផ្គុំ៖**
- **កិរិយាសព្ទ (ទម្រង់ ます-stem / ទម្រង់លទ្ធភាព / ទម្រង់បដិសេធ) + ように**

**ឧទាហរណ៍៖**
- 明日は晴れ **ますように**。
  - _(សូមបួងសួងឱ្យថ្ងៃស្អែកមេឃស្រឡះល្អ។)_
- 彼が早く良くなり **ますように**。
  - _(សង្ឃឹមថាគាត់នឹងឆាប់ជាសះស្បើយឡើងវិញ។)_
- 家族みんなが健康でいられ **ますように**。
  - _(សូមបួងសួងឱ្យក្រុមគ្រួសារទាំងមូលមានសុខភាពល្អបរិបូរណ៍។)_

#### ៣. ការណែនាំ ឬការបញ្ជាដោយប្រយោល (Indirect Request / Advice)
**ក្បួនផ្គុំ៖**
- **កិរិយាសព្ទ (ទម្រង់វចនានុក្រម / ទម្រង់ 〜ない) + ように (言う / 伝える / 注意する)**

**ឧទាហរណ៍៖**
- 先生に宿題を忘れない **ように言われました**。
  - _(ខ្ញុំត្រូវបានគ្រូប្រាប់ **កុំឱ្យ** ភ្លេចកិច្ចការផ្ទះ។)_
- 明日は遅刻しない **ようにしてください**。
  - _(សូមព្យាយាម **កុំឱ្យ** មកយឺតនៅថ្ងៃស្អែក។)_

#### ៤. បង្ហាញលក្ខណៈ ឬរបៀប (Manner: Like / As)
**ក្បួនផ្គុំ៖**
- **កិរិយាសព្ទ (ទម្រង់ធម្មតា Plain Form) + ように**
- **នាម + の + ように**

**ឧទាហរណ៍៖**
- 彼女は母親 **のように** 優しいです。
  - _(នាងមានចិត្តល្អ និងស្លូតបូត **ដូចជា** ម្តាយរបស់នាងដែរ។)_
- 先生が言った **ように**、頑張ります。
  - _(ខ្ញុំនឹងព្យាយាមធ្វើឱ្យអស់ពីសមត្ថភាព **ដូចអ្វីដែល** លោកគ្រូបានមានប្រសាសន៍។)_

### ដ្យាក្រាមរចនាសម្ព័ន្ធ (Visual Aid: Formation Diagram)

#### ការបង្ហាញគោលបំណង (Expressing Purpose)
```
[កិរិយាសព្ទ (លទ្ធភាព / គ្មានចេតនា / បដិសេធ 〜ない)] + ように + [សកម្មភាពចម្បង]
ឧទាហរណ៍៖
合格できる          ように        毎日勉強する
(អាចប្រឡងជាប់បាន)    (ដើម្បីឱ្យ)    (ខិតខំរៀនរាល់ថ្ងៃ)
```

#### ការបង្ហាញការបួងសួង (Expressing Wishes / Prayers)
```
[ឃ្លាប្រាថ្នា / ស្ថានភាព] + ますように / ように
ឧទាហរណ៍៖
雨が降りません         ように
(ភ្លៀងកុំធ្លាក់មក)      (សូមបួងសួងឱ្យ / សង្ឃឹមថា)
```

#### ការណែនាំដោយប្រយោល (Indirect Request)
```
[កិរិយាសព្ទ (辞書形 / ない形)] + ように + [言う / 頼む / 伝える]
ឧទាហរណ៍៖
早く来る              ように        伝えてください
(មកឱ្យលឿន)          (ឱ្យ...)      (សូមជួយផ្តាំផង)
```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Nuance Analysis)

### ការប្រៀបធៀបស្នូល N3៖ ～ように vs. ～ために
ទាំង **～ように** និង **～ために** សុទ្ធតែប្រើសម្រាប់បញ្ជាក់ពី «គោលបំណង» (ដើម្បី...) ក៏ប៉ុន្តែវេយ្យាករណ៍ទាំងពីរនេះមានលក្ខខណ្ឌវេយ្យាករណ៍ និងអត្ថន័យខុសគ្នាដាច់ស្រឡះ៖

| ចំណុចប្រៀបធៀប | **～ように** | **～ために** |
|---|---|---|
| **ប្រភេទកិរិយាសព្ទភ្ជាប់ខាងមុខ** | កិរិយាសព្ទ**គ្មានចេតនា (Non-volitional)**, កិរិយាសព្ទ**លទ្ធភាព (Potential)** (ឧ. 読める, 見える, 分かる, 合格できる), ឬទម្រង់បដិសេធ (**〜ない**) | កិរិយាសព្ទ**មានចេតនា (Volitional)** (ឧ. 買う, 行く, 留学する, 働く) ឬ **នាម + の** |
| **អត្ថន័យ និងការផ្តោត** | ផ្តោតលើ **«ការបង្កើតលក្ខខណ្ឌ ឬស្ថានភាពមួយឱ្យលេចចេញឡើង»** ដែលច្រើនតែស្ថិតនៅក្រៅការបញ្ជាផ្ទាល់របស់ចិត្ត | ផ្តោតលើ **«គោលដៅ និងឆន្ទៈសកម្មភាពច្បាស់លាស់»** របស់អ្នកនិយាយដែលធ្វើសកម្មភាពឆ្ពោះទៅកាន់គោលដៅនោះ |
| **ប្រធាននៃឃ្លា (Subject Constraint)** | អាចជា **ប្រធានខុសគ្នា** រវាងឃ្លាមុន និងឃ្លាក្រោយ (ឧ. ខ្ញុំធ្វើដើម្បីឱ្យអ្នកដទៃ...) ឬប្រធានតែមួយ | ប្រធាននៃឃ្លាទាំងពីរ **ត្រូវតែជាមនុស្សតែមួយ** (លើកលែងតែករណីនាមដើម្បីប្រយោជន៍អ្នកដទៃ ឧ. 家族のために) |
| **ឧទាហរណ៍ផ្ទុយគ្នា** | 〇 風邪を引かない **ように**、マスクをする。<br>*(ពាក់ម៉ាស់ **ដើម្បីកុំឱ្យ** ផ្តាសាយ - ផ្តាសាយគ្មានចេតនា)* | 〇 日本に留学する **ために**、お金をためている。<br>*(សន្សំប្រាក់ **ដើម្បី** ទៅរៀននៅជប៉ុន - ទៅរៀនមានចេតនា)* |
| **កំហុសទូទៅ** | ✕ 日本語を勉強する **ように** 日本へ行く (ខុស ព្រោះ 勉強する ជាកិរិយាសព្ទមានចេតនា) | ✕ 日本語が話せる **ために** 練習する (ខុស ព្រោះ 話せる ជាកិរិយាសព្ទលទ្ធភាព) |

### ការវិភាគលើមុខងារផ្សេងទៀតនៃ 〜ように
1. **〜ように vs 〜てほしい (ការបួងសួង និងការស្នើសុំ):**
   - `〜ますように` ប្រើសម្រាប់បួងសួងទូទៅ (ច្រើនបែរទៅកាន់ធម្មជាតិ ព្រះ ឬជោគវាសនា)។
   - ចំណែក `〜てほしい / 〜てください` គឺជាការស្នើសុំចំៗតម្រង់ទៅកាន់មនុស្សជាក់លាក់។
2. **ការណែនាំដោយប្រយោល (Indirect Command):**
   - ការប្រើ `〜ように言ってください` (សូមប្រាប់គាត់ឱ្យ...) គឺមានភាពទន់ភ្លន់ និងគួរសមជាងការដកស្រង់សម្តីផ្ទាល់ដូចជា `「〜てください」と言ってください`។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ស្ថានភាពផ្លូវការ (Formal Situations)
- **時間に遅れないように**、早めに出発いたします。
  - _(ខ្ញុំនឹងចេញដំណើរឱ្យបានលឿន **ដើម្បីកុំឱ្យ** យឺតពេលវេលា។)_
- **皆様のご健康とご多幸をお祈り申し上げますように**。
  - _(សូមបួងសួង និងជូនពរឱ្យលោកអ្នកទាំងអស់គ្នាទទួលបាននូវសុខភាពល្អ និងសុភមង្គល។)_
- 事故が起きない **ように**、安全運転を心がけてください。
  - _(សូមយកចិត្តទុកដាក់បើកបរដោយសុវត្ថិភាព **ដើម្បីកុំឱ្យ** មានគ្រោះថ្នាក់កើតឡើង។)_

### ស្ថានភាពក្រៅផ្លូវការ / ក្នុងជីវភាពរស់នៅ (Informal Situations)
- **風邪を引かないように**、暖かくしてね。
  - _(ស្លៀកពាក់ឱ្យកក់ក្តៅណា៎ **ដើម្បីកុំឱ្យ** កើតផ្តាសាយ។)_
- **試験に受かりますように**！
  - _(សូមឱ្យប្រឡងជាប់ផងចុះ!)_
- 忘れ物がない **ように**、カバンの中をチェックした？
  - _(បានពិនិត្យមើលកាតាបហើយឬនៅ **ដើម្បីកុំឱ្យ** ភ្លេចរបស់របរនោះ?)_

### ភាសាសរសេរ (Written Language)
- 私たちの願いが叶います **ように**。
  - _(សូមឱ្យបំណងប្រាថ្នារបស់ពួកយើងបានសម្រេចដូចបំណង។)_
- 世界が平和になります **ように**。
  - _(សូមបួងសួងឱ្យពិភពលោកទាំងមូលមានសន្តិភាព។)_

### ភាសានិយាយ (Spoken Language)
- **ほら、みんなに見えるように**、前に来てください。
  - _(នែ៎ សូមមកខាងមុខបន្តិចមក **ដើម្បីឱ្យ** គ្រប់គ្នាអាចមើលឃើញ។)_
- **彼のように** 上手に歌えるようになりたいな。
  - _(ចង់ចេះច្រៀងបានពិរោះ **ដូចជា** គាត់ណាស់។)_

## ៥. ចំណាំវប្បធម៌ (Cultural Notes)

### ទំនាក់ទំនងវប្បធម៌ជប៉ុន (Cultural Relevance)
នៅក្នុងវប្បធម៌ជប៉ុន ការបង្ហាញពីក្តីសង្ឃឹម និងគោលបំណងដោយប្រយោល និងទន់ភ្លន់ គឺមានសារៈសំខាន់ខ្លាំងណាស់ក្នុងការរក្សានូវភាពសុខដុមរមនា (和 - Wa) និងការគួរសម។ កន្សោមពាក្យ **～ように** ជួយឱ្យអ្នកនិយាយអាចបង្ហាញនូវសេចក្តីប្រាថ្នា ឬការណែនាំដោយមិនមានលក្ខណៈបង្ខិតបង្ខំ ឬបញ្ជាដោយត្រង់ៗពេកឡើយ ដែលស្របតាមទម្លាប់ជប៉ុនក្នុងការជៀសវាងការបង្កើតអារម្មណ៍ទើសទាល់ដល់អ្នកដទៃ។

លើសពីនេះ នៅពេលទៅបួងសួងនៅព្រះវិហារ Shinto ឬវត្តអារាមព្រះពុទ្ធសាសនា ការសរសេរសន្លឹកបួងសួង (絵馬 - Ema) តែងតែបញ្ចប់ដោយពាក្យ **〜ますように** ជានិច្ច។

### កម្រិតនៃការគួរសម (Politeness & Formality)
- **～ように** អាចប្រើបានទាំងក្នុងកម្រិតផ្លូវការ និងមិនផ្លូវការ។
- ក្នុងកិច្ចការបួងសួងជាផ្លូវការ ឬការជូនពរមនុស្សចាស់ គេប្រើកិរិយាសព្ទគួរសម `〜ますように`។

### កន្សោមពាក្យទម្លាប់ប្រើញឹកញាប់ (Idiomatic Expressions)
- **神様、どうか彼女が早く元気になりますように。**
  - _(បពិត្រព្រះជាម្ចាស់ សូមមេត្តាជួយឱ្យនាងឆាប់ជាសះស្បើយឡើងវិញផងចុះ។)_
- **ご冥福をお祈りいたしますように。**
  - _(សូមបួងសួងឱ្យវិញ្ញាណក្ខន្ធបានទៅកាន់សុគតិភព។)_

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### កំហុសទូទៅ (Common Mistakes)
1. **ការប្រើខុសទម្រង់កិរិយាសព្ទ (គោលបំណងអវិជ្ជមាន / វិជ្ជមាន):**
   - **ខុស:** 風邪を引く **ように** マスクをします。
     - *(ពាក់ម៉ាស់ដើម្បីឱ្យកើតផ្តាសាយ - គ្មានន័យសមហេតុផល)*
   - **ត្រូវ:** 風邪を引かない **ように** マスクをします。
     - *(ពាក់ម៉ាស់ **ដើម្បីកុំឱ្យ** កើតផ្តាសាយ)*
2. **ការច្រឡំរវាង ～ように (Non-volitional) និង ～ために (Volitional):**
   - **ខុស:** 家を買う **ように** 貯金する。
   - **ត្រូវ:** 家を買う **ために** 貯金する。 *(ទិញផ្ទះជាសកម្មភាពមានចេតនា ត្រូវប្រើ ために)*
   - **ត្រូវ:** 家が買える **ように** 貯金する。 *(ដើម្បីអាចទិញផ្ទះបាន - ប្រើទម្រង់លទ្ធភាពជាមួយ ように)*
3. **ការច្រឡំរវាង ～ように និង ～みたいに (ការប្រៀបធៀប):**
   - ទាំងពីរមានន័យថា «ដូចជា» ប៉ុន្តែ `〜みたいに` ប្រើក្នុងភាសានិយាយស្និទ្ធស្នាល (Casual Spoken) ចំណែក `〜ように` ប្រើជាលក្ខណៈស្តង់ដារ និងផ្លូវការជាង។

### គន្លឹះ និងយុទ្ធសាស្ត្ររៀន (Learning Strategies)
- **ចងចាំក្បួនកិរិយាសព្ទសម្រាប់គោលបំណង៖**
  - ឃើញ **កិរិយាសព្ទលទ្ធភាព (できる, 見える, 聞こえる)** ឬ **ទម្រង់បដិសេធ (ない)** ភ្លាម ➔ ត្រូវជ្រើសរើស **ように**។
  - ឃើញ **កិរិយាសព្ទមានចេតនាធម្មតា (行く, 買う, 勉強する)** ➔ ត្រូវជ្រើសរើស **ために**។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～ように** ប្រើសម្រាប់៖
  1. បង្ហាញគោលបំណង («ដើម្បីឱ្យ... / ដើម្បីកុំឱ្យ...») ភ្ជាប់ជាមួយកិរិយាសព្ទលទ្ធភាព ឬទម្រង់ ない។
  2. បង្ហាញការបួងសួង ឬក្តីសង្ឃឹម («សូមឱ្យ... / សង្ឃឹមថា...») នៅចុងបញ្ចប់នៃល្បះ (`〜ますように`)។
  3. ការណែនាំដោយប្រយោល (`〜ように言う / 伝える`)។
  4. បង្ហាញរបៀប ឬការប្រៀបធៀប («ដូចជា...» `〜のように`)។
- ខុសដាច់ពី **～ために** ត្រង់ថា **～ように** ប្រើជាមួយសកម្មភាពដែលមិនស្ថិតនៅក្រោមការបញ្ជាដោយផ្ទាល់នៃឆន្ទៈ (Non-volitional / Potential)។

### សំណួរតេស្តខ្លីៗ (Quick Recap Quiz)
១. **តើត្រូវនិយាយជាភាសាជប៉ុនយ៉ាងដូចម្តេច៖ «ខ្ញុំសង្ឃឹមថា/សូមបួងសួងឱ្យយើងអាចជួបគ្នាវិញម្តងទៀត» ដោយប្រើ ～ように?**
   - **ចម្លើយ៖** また会えます **ように**。
២. **នៅពេលបង្ហាញគោលបំណង តើកិរិយាសព្ទប្រភេទណាដែលត្រូវប្រើនៅខាងមុខ ～ように?**
   - **ចម្លើយ៖** កិរិយាសព្ទបង្ហាញលទ្ធភាព (Potential form) ឬកិរិយាសព្ទបដិសេធ (Negative form: 〜ない)។
៣. **ចូរប្រែប្រយោគនេះទៅជាភាសាជប៉ុន៖ «សូមនិយាយឱ្យឮខ្លាំងៗ ដើម្បីឱ្យគ្រប់គ្នាអាចស្តាប់ឮ។»**
   - **ចម្លើយ៖** みんなに聞こえる **ように**、大きな声で話してください。
