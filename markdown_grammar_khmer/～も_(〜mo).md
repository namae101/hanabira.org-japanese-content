# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～も (〜mo)
**កម្រិត JLPT:** JLPT N4

---

## ១. សេចក្តីផ្តើម (Introduction)
ធ្នាក់ **も (mo)** គឺជាធ្នាក់ដ៏សំខាន់ និងប្រើប្រាស់ញឹកញាប់បំផុតមួយក្នុងភាសាជប៉ុន ដែលមានន័យប្រហាក់ប្រហែលនឹងពាក្យថា **«ក៏...ដែរ / ផងដែរ» (also/too)**, **«សូម្បីតែ...» (even)** ឬប្រើសម្រាប់បញ្ជាក់ការសង្កត់ន័យលើបរិមាណដ៏ច្រើនហួសពីការរំពឹងទុក **«រហូតដល់ទៅ...» (as much as / as many as)**។ ការក្តាប់បានច្បាស់ពីការប្រើប្រាស់ **も** នឹងជួយបង្កើនសមត្ថភាពរបស់អ្នកក្នុងការបញ្ចេញមតិទាក់ទងនឹងការបន្ថែមរួមបញ្ចូល (inclusivity) ការបដិសេធទាំងស្រុង និងការសង្កត់ធ្ងន់ក្នុងភាសាជប៉ុន។

---

## ២. ពន្យល់វេយ្យាករណ៍គោល (Core Grammar Explanation)

### ការពន្យល់លម្អិត (Detailed Explanation)
ធ្នាក់ **も** អាចភ្ជាប់នៅពីក្រោយ នាម (Nouns), កិរិយាសព្ទ, គុណនាម, ឬពាក្យបញ្ជាក់បរិមាណ ដើម្បីបង្ហាញថារឿងរ៉ាវនោះអនុវត្តចំពោះកម្មវត្ថុ ឬប្រធានច្រើនជាងមួយ។ វាបង្ហាញពីការបន្ថែមរួមបញ្ចូល ភាពដូចគ្នា ឬការសង្កត់ធ្ងន់។

### អត្ថន័យ និងរបៀបប្រើប្រាស់ (Meaning and Usage)

1. **បង្ហាញន័យ «ក៏...ដែរ / ផងដែរ» (Also / Too):**
   - ប្រើនៅពេលបន្ថែមព័ត៌មានអំពីប្រធាន ឬកម្មវត្ថុមួយទៀតដែលមានលក្ខខណ្ឌ ស្ថានភាព ឬសកម្មភាពដូចគ្នា។
   - **ឧទាហរណ៍៖** ខ្ញុំជាសិស្ស។ **អ្នកក៏ជាសិស្សដែរ។**

2. **បង្ហាញន័យ «សូម្បីតែ...» (Even):**
   - ប្រើដើម្បីសង្កត់ធ្ងន់លើស្ថានភាពហួសពីការស្មាន ឬជ្រុលខ្លាំង (extreme condition)។
   - **ឧទាហរណ៍៖** **សូម្បីតែក្មេង**ក៏អាចដោះស្រាយលំហាត់នេះបានដែរ។

3. **ការបដិសេធរួមបញ្ចូលជាមួយពាក្យសួរ (Inclusive Negation with Interrogative Words):**
   - នៅពេលផ្សំជាមួយពាក្យសួរដូចជា 何 (អ្វី), 誰 (នរណា), どこ (ឯណា/ទីណា) បូកនឹងកិរិយាសព្ទបដិសេធ វាមានន័យថា «គ្មានអ្វីសោះ», «គ្មាននរណាម្នាក់», «គ្មានទីណាឡើយ»។
   - **ឧទាហរណ៍៖** **គ្មាននរណាម្នាក់**បានមកចូលរួមកម្មវិធីជប់លៀងនោះទេ។

4. **សង្កត់ធ្ងន់លើបរិមាណ ឬចំនួនច្រើនហួសពីការរំពឹងទុក «រហូតដល់ទៅ...» (Emphatic Large Amount):**
   - នៅពេលប្រើទម្រង់ **[ចំនួន / ពាក្យរាប់ (Counter)] + も** វាសង្កត់ធ្ងន់ថាបរិមាណនោះច្រើនខ្លាំង គួរឱ្យភ្ញាក់ផ្អើល ឬហួសពីការគិតទុក។
   - **ឧទាហរណ៍៖** 昨日は**10時間も**寝ました。(ម្សិលមិញខ្ញុំគេង**រហូតដល់ទៅ ១០ ម៉ោងឯណោះ**។)

### ទម្រង់វេយ្យាករណ៍ (Structure)

#### រូបមន្តនៃការបង្កើតល្បះ (Formation Diagram)
1. **បន្ថែមន័យ «ក៏...ដែរ / ផងដែរ»:**
   ```
   [នាម / សព្វនាម] + も + [កិរិយាសព្ទ / គុណនាម / ឃ្លាបញ្ចប់]
   ```
2. **សង្កត់ន័យ «សូម្បីតែ...»:**
   ```
   [ពាក្យដែលចង់សង្កត់ន័យ] + も / でも + [កិរិយាសព្ទ / គុណនាម]
   ```
3. **ការបដិសេធទាំងស្រុងជាមួយពាក្យសួរ:**
   ```
   [ពាក្យសួរ (Interrogative Word)] + も + [កិរិយាសព្ទបដិសេធ (Negative Verb)]
   ```
4. **សង្កត់ធ្ងន់ចំនួនច្រើន «រហូតដល់ទៅ...»:**
   ```
   [ចំនួន / ពាក្យរាប់ (Number + Counter)] + も + [កិរិយាសព្ទ / ឃ្លាបញ្ជាក់]
   ```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuance)

### ការប្រៀបធៀបធ្នាក់ も ជាមួយធ្នាក់ は និង が
1. **は (wa):** ធ្នាក់ចង្អុលបង្ហាញប្រធានបទធំនៃល្បះ (Topic Marker) ដោយសង្កត់ធ្ងន់លើព័ត៌មានដែលនៅខាងក្រោយ។
2. **が (ga):** ធ្នាក់ចង្អុលបង្ហាញប្រធានជាក់លាក់នៃកិរិយា (Subject Marker) ដោយសង្កត់ធ្ងន់លើពាក្យដែលនៅខាងមុខ។
3. **も (mo):** ជំនួសធ្នាក់ は, が, ឬ を ដើម្បីបន្ថែមការរួមបញ្ចូល («ក៏...ដែរ») ឬសង្កត់ន័យ («សូម្បីតែ...», «រហូតដល់ទៅ...»)។

| ធ្នាក់ | មុខងារចម្បង | ឧទាហរណ៍ | អត្ថន័យជាភាសាខ្មែរ |
|-------|------------|----------|-------------------|
| **は** | បង្ហាញប្រធានបទ (Topic) | 私**は**学生です。 | ចំពោះខ្ញុំ ខ្ញុំជាសិស្ស។ |
| **が** | បង្ហាញប្រធានជាក់លាក់ (Subject) | 猫**が**好きです。 | ខ្ញុំចូលចិត្តឆ្មា (ឆ្មាជាកម្មវត្ថុនៃចំណូលចិត្ត)។ |
| **も** | បង្ហាញការរួមបញ្ចូល / សង្កត់ន័យ | 私**も**行きます。 | ខ្ញុំ**ក៏**ទៅ**ដែរ**។ |

---

### ន័យស៊ីជម្រៅ៖ ការសង្កត់ធ្ងន់លើចំនួនច្រើន «[ចំនួន] + も» vs បរិមាណអប្បបរមា «1 + Counter + も〜ない» vs «しか〜ない»

នៅកម្រិត JLPT N4 ការប្រើប្រាស់ធ្នាក់ **も** ជាមួយចំនួនមានភាពស៊ីជម្រៅ និងឆ្លុះបញ្ចាំងពីអារម្មណ៍ផ្លូវចិត្តរបស់អ្នកនិយាយយ៉ាងច្បាស់៖

1. **[ចំនួន/កម្រិតធំ] + も (បង្ហាញចំនួនច្រើនហួសពីការរំពឹងទុក - "as much/many as"):**
   - ប្រើជាមួយប្រយោគស្រប ដើម្បីបញ្ជាក់ថាចំនួននោះ **ធំធេង ឬច្រើនគួរឱ្យភ្ញាក់ផ្អើល** លើសពីអ្វីដែលអ្នកនិយាយបានគិតទុក។
   - **ឧទាហរណ៍៖**
     - **昨日は10時間も寝た。** (ម្សិលមិញខ្ញុំគេង**រហូតដល់ទៅ ១០ ម៉ោង**! ➔ បង្ហាញថាគេងច្រើនជ្រុល ហួសពីការគេងធម្មតា ៦-៨ ម៉ោង)។
     - **パーティーに100人も来た。** (មានមនុស្សមកចូលរួមកម្មវិធីជប់លៀង**រហូតដល់ទៅ ១០០ នាក់ឯណោះ**! ➔ ច្រើនលើសពីការរំពឹងទុក)។

2. **[ចំនួនអប្បបរមា (១)] + も + បដិសេធ (Minimum Expectation Negation - "not even one"):**
   - ប្រើទម្រង់ `[1 + ពាក្យរាប់] + も + [កិរិយាសព្ទបដិសេធ]` ដើម្បីសង្កត់ធ្ងន់លើការបដិសេធដាច់ខាត គឺ «សូម្បីតែមួយក៏គ្មាន / មិនបានសូម្បីតែម្តង»។
   - **ឧទាហរណ៍៖**
     - **財布に1円も入っていない。** (នៅក្នុងកាបូប **សូម្បីតែ ១ យ៉េនក៏គ្មានផង**។)
     - **漢字が一つも書けない。** (អក្សរកាន់ជិ **សូម្បីតែមួយតួ ក៏សរសេរមិនចេញដែរ**។)

3. **ការប្រៀបធៀបរវាង «～も» (ច្រើនហួសស្មាន) និង «しか〜ない» (តិចពេក/មិនគ្រប់គ្រាន់):**
   - **[ចំនួន] + も + ស្រប៖** អារម្មណ៍វិជ្ជមាន ឬភ្ញាក់ផ្អើលព្រោះវា **«ច្រើនណាស់ / រហូតដល់ទៅ...»**។
     - 例: **1000円もある。** (មានលុយ**រហូតដល់ទៅ ១០០០ យ៉េនឯណោះ**! ➔ យល់ថាច្រើន អាចទិញអីបានច្រើន)។
   - **[ចំនួន] + しか + បដិសេធ (ない):** អារម្មណ៍មិនសប្បាយចិត្ត ឬខកចិត្តព្រោះវា **«មានតែ...ប៉ុណ្ណោះ / តិចតួចពេក»**។
     - 例: **1000円しかない。** (មានលុយ**តែ ១០០០ យ៉េនប៉ុណ្ណោះ** ➔ យល់ថាតិចពេក មិនគ្រប់គ្រាន់សម្រាប់ចាយវាយឡើយ)។

  - **山田さんも来ます。**
    - *Yamada-san mo kimasu.*
    - **អត្ថន័យ៖** លោកយ៉ាម៉ាដា**ក៏**នឹងមក**ដែរ**។
- **កម្រិតស្និទ្ធស្នាល (Informal):**
  - **僕もそれが好き。**
    - *Boku mo sore ga suki.*
    - **អត្ថន័យ៖** ខ្ញុំ**ក៏**ចូលចិត្តរបស់ហ្នឹង**ដែរ**។

#### ២. បង្ហាញន័យ «សូម្បីតែ...» (Even)
- **កម្រិតគួរសម (Formal):**
  - **初心者でも簡単にできます。**
    - *Shoshinsha de mo kantan ni dekimasu.*
    - **អត្ថន័យ៖** **សូម្បីតែ**អ្នកទើបចាប់ផ្តើមរៀនដំបូង **ក៏**អាចធ្វើវាបានយ៉ាងងាយស្រួលដែរ។
- **កម្រិតស្និទ្ធស្នាល (Informal):**
  - **彼女は夜も働いている。**
    - *Kanojo wa yoru mo hataraite iru.*
    - **អត្ថន័យ៖** នាង**សូម្បីតែ**ពេលយប់**ក៏**នៅធ្វើការដែរ។

#### ៣. ការបដិសេធរួមបញ្ចូល (Inclusive Negation)
- **កម្រិតគួរសម (Formal):**
  - **誰もいませんでした。**
    - *Dare mo imasen deshita.*
    - **អត្ថន័យ៖** មិនមាននរណាម្នាក់នៅទីនោះឡើយ (គ្មានមនុស្សសោះ)។
- **កម្រិតស្និទ្ធស្នាល (Informal):**
  - **何もわからない。**
    - *Nani mo wakaranai.*
    - **អត្ថន័យ៖** ខ្ញុំមិនយល់អ្វីទាំងអស់ (មិនដឹងអីបន្តិចសោះ)។

#### ៤. សង្កត់ន័យបរិមាណច្រើន (Emphatic Large Amount)
- **កម្រិតគួរសម (Formal):**
  - **昨日は日本酒を五杯も飲みました。**
    - *Kinō wa nihonshu o gohai mo nomimashita.*
    - **អត្ថន័យ៖** ម្សិលមិញខ្ញុំបានផឹកស្រាជប៉ុន**រហូតដល់ទៅ ៥ កែវឯណោះ**។
- **កម្រិតស្និទ្ធស្នាល (Informal):**
  - **映画を3回も見ちゃった。**
    - *Eiga o sankai mo michatta.*
    - **អត្ថន័យ៖** ខ្ញុំមើលរឿងហ្នឹង**រហូតដល់ទៅ ៣ ដងឯណោះ**។

### បំរែបំរួលតាមបរិបទ (Context Variations)
- **ភាសាសរសេរ (Written Language):**
  - **環境問題は日本でも重要です。**
    - *Kankyō mondai wa Nihon de mo jūyō desu.*
    - **អត្ថន័យ៖** បញ្ហាបរិស្ថាន គឺពិតជាសំខាន់ណាស់ សូម្បីតែនៅក្នុងប្រទេសជប៉ុនក៏ដោយ។
- **ភាសានិយាយ (Spoken Language):**
  - **明日も雨かな。**
    - *Ashita mo ame kana.*
    - **អត្ថន័យ៖** មិនដឹងថាថ្ងៃស្អែកមេឃភ្លៀងទៀតអត់ទេណ៎?

## ៥. កំណត់សម្គាល់បែបវប្បធម៌ (Cultural Notes)

### ភាពស៊ីសង្វាក់គ្នាក្នុងវប្បធម៌ (Cultural Relevance)
- ការប្រើប្រាស់ **も** ជួយបង្ហាញពី «ការរួបរួមក្នុងក្រុម» (group inclusivity) ដែលជាគុណតម្លៃដ៏សំខាន់មួយក្នុងសង្គម និងវប្បធម៌ជប៉ុន (គំនិត 和 / Wa - ភាពសុខដុមរមនា)។
- វាក៏ជួយឱ្យអ្នកនិយាយបង្ហាញពីការយល់ចិត្ត ការចែករំលែកអារម្មណ៍ និងបទពិសោធន៍ស្រដៀងគ្នាជាមួយអ្នកដទៃផងដែរ (ឧទាហរណ៍៖ 私もそう思います - «ខ្ញុំក៏គិតអញ្ចឹងដែរ» ដើម្បីកុំឱ្យផ្ទុយពីគេ)។

### សម្ដី ឬសុភាសិតពេញនិយម (Idiomatic Expressions)
1. **猫も杓子も (ねこもしゃくしも)**
   - *Neko mo shakushi mo*
   - **អត្ថន័យ៖** នរណាៗក៏ដោយ, ទាំងអស់គ្នាតែម្តង (anyone and everyone / all and sundry)។
   - **ឧទាហរណ៍៖** **猫も杓子もスマホを持っている。**
     - *Neko mo shakushi mo sumaho o motte iru.*
     - *អត្ថន័យ៖* នរណាៗក៏ដោយ សូម្បីតែមនុស្សគ្រប់រូបសុទ្ធតែមានទូរស័ព្ទស្មាតហ្វូនកាន់គ្រប់ៗគ្នា។
2. **十人十色もある (じゅうにんといろもある)**
   - *Jūnin toiro mo aru*
   - **អត្ថន័យ៖** មនុស្សដប់នាក់ គំនិតដប់ (ចិត្តមនុស្សមិនដូចគ្នាទេ / ចំណូលចិត្តរៀងៗខ្លួន)។
   - **ឧទាហរណ៍៖** **考え方は十人十色もある。**
     - *Kangaekata wa jūnin toiro mo aru.*
     - *អត្ថន័យ៖* របៀបនៃការគិត គឺមានច្រើនបែបច្រើនយ៉ាងទៅតាមបុគ្គលម្នាក់ៗ។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
1. **ការប្រើប្រាស់ も លើសកម្រិត ឬខុសកន្លែង (Overusing も at sentence ending):**
   - **ខុស៖** 私も行く**も**。 (*Watashi mo iku mo.*)
   - **ការពន្យល់៖** ធ្នាក់ **も** មិនត្រូវដាក់នៅចុងបញ្ចប់នៃប្រយោគបែបនេះឡើយ។
   - **ត្រឹមត្រូវ៖** **私も行く。** (*Watashi mo iku.* - ខ្ញុំក៏ទៅដែរ។)

2. **ការច្រឡំរវាងធ្នាក់ は និង も (Confusing は with も):**
   - **ខុស៖** 彼は学生です。私**は**先生です。 (ប្រសិនបើចង់មានន័យថា «ខ្ញុំក៏ជាសិស្សដែរ»)
   - **ត្រឹមត្រូវ៖** 彼は学生です。私**も**学生です。 (*Kare wa gakusei desu. Watashi **mo** gakusei desu.* - គាត់ជាសិស្ស។ ខ្ញុំ**ក៏**ជាសិស្ស**ដែរ**។)

3. **ការច្រឡំរវាង [ចំនួន] + も និង [ចំនួន] + しか...ない:**
   - ប្រសិនបើមានលុយច្រើន ត្រូវប្រើ **1万円もある** (មានរហូតដល់ទៅ ១ ម៉ឺនយ៉េនឯណោះ)។
   - ប្រសិនបើមានលុយតិច មិនគ្រប់គ្រាន់ ត្រូវប្រើ **1万円しかない** (មានតែ ១ ម៉ឺនយ៉េនប៉ុណ្ណោះ) មិនត្រូវប្រើ 1万円もない ឡើយ (ព្រោះ 1万円もない មានន័យថា សូម្បី ១ ម៉ឺនយ៉េនក៏មិនដល់/គ្មានផង)។

### យុទ្ធសាស្ត្រនៃការរៀន (Learning Strategies)
- **បច្ចេកទេសភ្ជាប់ពាក្យ (Association Technique):**
  - ភ្ជាប់អក្សរ **も (mo)** ទៅនឹងពាក្យអង់គ្លេសថា **"more"** ដើម្បីងាយស្រួលចងចាំថាវាប្រើសម្រាប់បន្ថែមអ្វីមួយ ឬសង្កត់ធ្ងន់លើបរិមាណច្រើន។
- **ការអនុវត្តជាក់ស្តែង (Practice Makes Perfect):**
  - សាកល្បងបង្កើតល្បះដោយប្រើ **も** ដើម្បីរៀបរាប់ពីចំណុចដូចគ្នារវាងខ្លួនឯង និងមិត្តភក្តិ ឬប្រើប្រាប់ពីបរិមាណដែលអ្នកបានធ្វើអ្វីមួយច្រើនគួរឱ្យភ្ញាក់ផ្អើល។

## ៧. សង្ខេប និងរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **も** មានន័យថា «ក៏...ដែរ / ផងដែរ» (addition), «សូម្បីតែ...» (extreme condition), ឬ «រហូតដល់ទៅ...» (large amount)។
- អាចភ្ជាប់ជាមួយ នាម, កិរិយាសព្ទ, គុណនាម, ពាក្យសួរ និងចំនួនរាប់។
- ពេលប្រើជាមួយពាក្យសួរ + កិរិយាសព្ទបដិសេធ (`誰もいない`, `何もない`) វាមានន័យថា «គ្មាននរណាម្នាក់ / គ្មានអ្វីសោះ»។
- ពេលប្រើ `[ចំនួន/ពាក្យរាប់] + も` វាសង្កត់ធ្ងន់ថាបរិមាណនោះច្រើនខ្លាំង គួរឱ្យភ្ញាក់ផ្អើល។

### កម្រងសំណួរខ្លីៗ (Quick Recap Quiz)
1. **ចូរបំពេញចន្លោះដោយជ្រើសរើសធ្នាក់ត្រឹមត្រូវ៖**
   **彼女___学生です。私も学生です。**
   - **ចម្លើយ៖** は (*Kanojo **wa** gakusei desu.*)
2. **ចូរប្រែប្រយោគខាងក្រោមទៅជាភាសាជប៉ុនដោយប្រើ ～も៖**
   «ខ្ញុំគ្មានលុយសូម្បីតែបន្តិច / គ្មានលុយសោះ។»
   - **ចម្លើយ៖** **お金もない。** (*Okane mo nai.*) ឬ **1円もない。** (*Ichi-en mo nai.*)
3. **ត្រូវ ឬ ខុស (True or False):**
   ការប្រើប្រាស់ពាក្យសួរជាមួយ **も** និងកិរិយាសព្ទបដិសេធ មានន័យថា «មនុស្សគ្រប់គ្នា» ឬ «របស់គ្រប់យ៉ាង»?
   - **ចម្លើយ៖** ខុស / False (វាមានន័យថា «គ្មាននរណាម្នាក់» ឬ «គ្មានអ្វីសោះ» ទៅវិញទេ)។
