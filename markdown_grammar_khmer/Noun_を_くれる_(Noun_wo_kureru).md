Processing keyword: Noun を くれる (Noun wo kureru)
# ចំណុចវេយ្យាករណ៍ជប៉ុន: Noun を くれる (Noun wo kureru)
**កម្រិត JLPT:** JLPT N4

---

## ១. សេចក្តីផ្តើម (Introduction)

នៅក្នុងភាសាជប៉ុន ការបញ្ជាក់អំពីសកម្មភាព "ឱ្យ/ជូន" និង "ទទួល" គឺមានភាពម៉ត់ចត់ខ្លាំង ដោយប្រើប្រាស់កិរិយាសព្ទជាក់លាក់ទៅតាមទិសដៅនៃសកម្មភាពធៀបនឹងអ្នកនិយាយ។ ទម្រង់វេយ្យាករណ៍ **"Noun を くれる"** ត្រូវបានប្រើនៅពេលនរណាម្នាក់ឱ្យអ្វីមួយមកកាន់អ្នកនិយាយ ឬមនុស្សក្នុងរង្វង់ជិតស្និទ្ធរបស់អ្នកនិយាយ (ក្រុមគ្រួសារ ឬមនុស្សក្នុងក្រុមរបស់ខ្លួន - 内 / uchi)។ ការយល់ច្បាស់ពីទម្រង់នេះមានសារៈសំខាន់ណាស់ក្នុងការទំនាក់ទំនងជាភាសាជប៉ុនឱ្យបានត្រឹមត្រូវ និងសមរម្យតាមកាលៈទេសៈ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ និងការប្រើប្រាស់ (Meaning and Usage)
- **くれる (kureru)** មានន័យថា **"ឱ្យ / ឱ្យមក"** ដោយមានន័យស៊ីជម្រៅថា **អ្នកឱ្យគឺជាអ្នកដទៃ (ក្រៅពីរូបខ្ញុំ)** ហើយ **អ្នកទទួលគឺជាអ្នកនិយាយផ្ទាល់ (ខ្ញុំ) ឬមនុស្សដែលស្និទ្ធនឹងខ្ញុំ (ក្រុមគ្រួសារ/មនុស្សខាងខ្ញុំ)**។
- កន្សោមនេះសង្កត់ធ្ងន់ទៅលើទិសដៅនៃអំពើដែលតម្រង់ចូលមករកអ្នកនិយាយ និងបង្កប់នូវអារម្មណ៍ដឹងគុណ ឬការទទួលបានអត្ថប្រយោជន៍ពីទង្វើរបស់អ្នកដទៃ។

### ទម្រង់ប្រយោគ (Structure)
ទម្រង់ពេញលេញនៃប្រយោគគឺ៖
```
[អ្នកឱ្យ/Giver] が [អ្នកទទួល (ជាទូទៅគឺខ្ញុំ)] に Noun を くれる
```
ប៉ុន្តែ ដោយសារតែអ្នកទទួលគឺជាអ្នកនិយាយស្រាប់ ដូច្នេះ **អ្នកទទួល និងធ្នាក់ に (私に)** ត្រូវបានគេលុបចោលជាញឹកញាប់នៅក្នុងការសន្ទនាជាក់ស្តែង៖
```
[អ្នកឱ្យ/Giver] が Noun を くれる
```

### ធាតុផ្សំនៃវេយ្យាករណ៍ (Components)
| ធាតុផ្សំ | ការពន្យល់ |
|---|---|
| **[អ្នកឱ្យ] が** | បុគ្គលដែលជាអ្នកឱ្យ (ភ្ជាប់ដោយធ្នាក់ が ដើម្បីបញ្ជាក់ប្រធាននៃអំពើ) |
| **[អ្នកទទួល] に** | អ្នកទទួល (私に / ខ្ញុំ - ច្រើនតែលុបចោល) |
| **Noun を** | វត្ថុ ឬរបស់របរដែលត្រូវបានឱ្យ (ភ្ជាប់ដោយធ្នាក់ を) |
| **くれる** | កិរិយាសព្ទមានន័យថា "ឱ្យ" (ទម្រង់ធម្មតា / 辞書形) |

### ដ្យាក្រាមទម្រង់ (Formation Diagram)
```
[អ្នកឱ្យ] が + [របស់របរ/នាម] を + くれる
```

**ឧទាហរណ៍:**
```
友だち が 本 を くれる。
Tomodachi ga hon wo kureru.
(មិត្តភក្តិឱ្យសៀវភៅមកខ្ញុំ។)
```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Deep Nuance)

### ទិសដៅនៃសកម្មភាព និងចលនាតម្រង់ចូលក្នុង (Inward-directed Giving)
- ភាសាជប៉ុនបែងចែកយ៉ាងច្បាស់រវាងទស្សនៈ "ខាងក្នុង (内 - uchi)" និង "ខាងក្រៅ (外 - soto)"។
- **くれる** គឺជាកិរិយាសព្ទ **"តម្រង់ចូលក្នុង" (Inward)** ជានិច្ច៖ អំពើកើតចេញពីអ្នកដទៃ (ឬមនុស្សខាងក្រៅ) មកកាន់ខ្ញុំ ឬមនុស្សក្នុងក្រុមគ្រួសារខ្ញុំ។ អ្នកមិនអាចប្រើ `くれる` នៅពេល "ខ្ញុំឱ្យទៅគេ" បានជាដាច់ខាត។

### ការប្រៀបធៀបកម្រិតគួរសមរវាង くれる、くれます និង くださる
ដើម្បីប្រើប្រាស់ឱ្យសមស្របតាមឋានានុក្រមសង្គម និងកម្រិតគួរសម (Politeness/Honorific levels)៖

| កិរិយាសព្ទ | កម្រិតគួរសម / ប្រភេទ | បរិបទ និងរបៀបប្រើប្រាស់ |
|---|---|---|
| **くれる (kureru)** | ទម្រង់ធម្មតា / ស្និទ្ធស្នាល (Plain / Casual) | ប្រើជាមួយមិត្តភក្តិ មនុស្សស្មើគ្នា ប្អូនៗ ឬក្នុងគ្រួសារ។ មិនប្រើចំពោះចៅហ្វាយនាយ ឬគ្រូឡើយ។ |
| **くれます (kuremasu)** | ទម្រង់គួរសមទូទៅ (Polite / ます-form) | ប្រើក្នុងការសន្ទនាប្រចាំថ្ងៃទូទៅប្រកបដោយភាពគួរសម នៅពេលអ្នកឱ្យជាមិត្តរួមការងារ មនុស្សស្មើគ្នា ឬទូទៅ។ |
| **くださる (kudasaru) / くださいます** | ទម្រង់លើកតម្កើង/គោរព (Honorific / 尊敬語) | ប្រើនៅពេលអ្នកឱ្យជាមនុស្សដែលមានឋានៈខ្ពស់ជាង (ចៅហ្វាយនាយ គ្រូបង្រៀន អតិថិជន ឬមនុស្សចាស់)។ |

**ឧទាហរណ៍ប្រៀបធៀប:**
- មិត្តភក្តិឱ្យ៖ 友だちが本を**くれた**。 (ស្និទ្ធស្នាល)
- មិត្តរួមការងារឱ្យ៖ 田中さんが本を**くれました**。 (គួរសម)
- គ្រូបង្រៀនឱ្យ៖ 先生が本を**くださいました**。 (គោរពលើកតម្កើង)

### ការប្រៀបធៀបរវាង くれる、あげる និង もらう
| កិរិយាសព្ទ | អត្ថន័យ | ទិសដៅនៃសកម្មភាព | ចំណុចសំខាន់នៃការផ្តោត (Perspective) |
|---|---|---|---|
| **くれる** | ឱ្យ (មកខ្ញុំ/ខាងខ្ញុំ) | អ្នកដទៃ → ខ្ញុំ (Speaker) | ផ្តោតលើអ្នកឱ្យជាអ្នកធ្វើសកម្មភាពតម្រង់មករកខ្ញុំ |
| **あげる** | ឱ្យ (ទៅអ្នកដទៃ) | ខ្ញុំ/អ្នកដទៃ → អ្នកដទៃ | ផ្តោតលើទិសដៅចេញក្រៅ (មិនប្រើពេលគេឱ្យមកខ្ញុំទេ) |
| **もらう** | ទទួល (ពីនរណាម្នាក់) | អ្នកដទៃ → អ្នកទទួល (ខ្ញុំ/គេ) | ផ្តោតលើអ្នកទទួល (ប្រធានប្រយោគគឺជាអ្នកទទួល が/は) |

- **くれる**: ប្រើនៅពេលដែល "ខ្ញុំ" ឬមនុស្សខាងខ្ញុំជាអ្នកទទួលផលពីអំពើនោះ។
- **あげる**: ប្រើនៅពេល "ខ្ញុំ" ឬនរណាម្នាក់ជាអ្នកឱ្យទៅអ្នកផ្សេងទៀត។
- **もらう**: សង្កត់ធ្ងន់លើទង្វើនៃ "ការទទួល" (ឧ. 私は友だちに本をもらった = ខ្ញុំបានទទួលសៀវភៅពីមិត្តភក្តិ)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទ (Examples in Context)

### ប្រយោគឧទាហរណ៍ជាក់ស្តែង
1. **ការសន្ទនាស្និទ្ធស្នាល (Casual Speech)**
   ```
   母が新しいスマホをくれた。
   Haha ga atarashii sumaho wo kureta.
   (ម្តាយរបស់ខ្ញុំបានឱ្យស្មាតហ្វូនថ្មីមួយមកខ្ញុំ។)
   ```

2. **ការនិយាយបែបគួរសម/លើកតម្កើង (Honorific/Polite Speech)**
   ```
   先生がおすすめの本をくださいました。
   Sensei ga osusume no hon wo kudasaimashita.
   (លោកគ្រូបានផ្តល់សៀវភៅណែនាំដ៏ល្អមួយមកខ្ញុំ។)
   ```

3. **ការលុបអ្នកទទួល (Omitting the Receiver)**
   ```
   友だちが手紙をくれた。
   Tomodachi ga tegami wo kureta.
   (មិត្តភក្តិបានផ្ញើសំបុត្រមកឱ្យខ្ញុំ។)
   ```

4. **ការបញ្ជាក់អ្នកទទួលយ៉ាងច្បាស់ (Explicit Receiver)**
   ```
   彼が私に花をくれた。
   Kare ga watashi ni hana wo kureta.
   (គាត់បានឱ្យផ្កាមកខ្ញុំ។)
   ```

5. **ការប្រើ くれる ក្នុងកាលបច្ចុប្បន្ន (Present/Habitual Tense)**
   ```
   兄が洋服をくれる。
   Ani ga youfuku wo kureru.
   (បងប្រុសតែងតែឱ្យសំលៀកបំពាក់មកខ្ញុំ។)
   ```

6. **បរិបទផ្លូវការតាមបែបការទទួល (Formal Inward Context)**
   ```
   会社から記念品をいただきました。
   Kaisha kara kinenhin wo itadakimashita.
   (ខ្ញុំបានទទួលវត្ថុអនុស្សាវរីយ៍ពីក្រុមហ៊ុន។)
   ```
   *ចំណាំ:* **いただく (itadaku)** គឺជាទម្រង់បន្ទាបខ្លួន (Humble form / 謙譲語) នៃ **もらう**។

### បំរែបំរួលតាមបរិបទផ្សេងៗ (Contextual Variations)
- **ការបង្ហាញការដឹងគុណចំពោះទង្វើ (Expressing Gratitude with ～てくれる)**
  ```
  友人が助けてくれて、本当に感謝しています。
  Yuujin ga tasukete kurete, hontou ni kansha shite imasu.
  (មិត្តភក្តិបានជួយខ្ញុំ ខ្ញុំពិតជាអរគុណខ្លាំងណាស់។)
  ```
- **ការប្រើទម្រង់គួរសមអតីតកាល (Past Polite Form)**
  ```
  祖父が時計をくださいました。
  Sofu ga tokei wo kudasaimashita.
  (លោកតារបស់ខ្ញុំបានឱ្យនាឡិកាមួយមកខ្ញុំ។)
  ```

## ៥. កំណត់សម្គាល់វប្បធម៌ (Cultural Notes)

### កម្រិតនៃភាពគួរសម និងឋានានុក្រម (Levels of Politeness)
- **くれる** ប្រើនៅក្នុងបរិបទក្រៅផ្លូវការ ស្និទ្ធស្នាល ឬជាមួយមនុស្សដែលមានឋានៈស្មើ ឬទាបជាង។
- **くださる** គឺជាទម្រង់គោរពលើកតម្កើង (尊敬語 - Sonkeigo) នៃ **くれる** ប្រើនៅពេលដែលអ្នកឱ្យគឺជាអ្នកមានឋានៈសង្គមខ្ពស់ជាង អាយុច្រើនជាង ឬជាអតិថិជន។
  ```
  部長がアドバイスをくださいました。
  Buchou ga adobaisu wo kudasaimashita.
  (ប្រធានផ្នែកបានផ្តល់ដំបូន្មានដ៏មានតម្លៃមកកាន់ខ្ញុំ។)
  ```

### សារៈសំខាន់នៃវប្បធម៌ជប៉ុន (Cultural Relevance)
- ក្នុងវប្បធម៌ជប៉ុន ភាពបន្ទាបខ្លួន និងការគោរពផ្តល់កិត្តិយសដល់អ្នកដទៃមានសារៈសំខាន់ជាចម្បង។ ការប្រើកម្រិតគួរសមឱ្យត្រូវតាមឋានានុក្រមសង្គម បង្ហាញពីការយល់ដឹងអំពីទំនាក់ទំនងសង្គម និងការរក្សានូវភាពសុខដុម (和 - wa)។
- អំណោយនៅក្នុងប្រទេសជប៉ុនតែងតែបង្កប់នូវអត្ថន័យសង្គមយ៉ាងជ្រាលជ្រៅ ហើយការជ្រើសរើសពាក្យ "ឱ្យ" និង "ទទួល" ឆ្លុះបញ្ចាំងពីចំណងទាក់ទង និងកម្រិតស្និទ្ធស្នាលរវាងបុគ្គលនិងបុគ្គល។

### កន្សោមវេយ្យាករណ៍ពាក់ព័ន្ធ (Related Idiomatic Expressions)
- **កិរិយាសព្ទទម្រង់ て + くれる (～てくれる)**
  ប្រើនៅពេលមាននរណាម្នាក់ធ្វើអំពើល្អ ឬជួយសង្គ្រោះជាប្រយោជន៍ដល់អ្នកនិយាយ៖
  ```
  友だちが宿題を手伝ってくれた。
  Tomodachi ga shukudai wo tetsudatte kureta.
  (មិត្តភក្តិបានជួយធ្វើកិច្ចការផ្ទះរបស់ខ្ញុំ។)
  ```

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### កំហុសដែលតែងតែកើតមាន
1. **ការប្រើ あげる ច្រឡំនឹង くれる**
   - មិនត្រឹមត្រូវ: *友だちが本をあげた。* (ខុសព្រោះគេឱ្យមកខ្ញុំ មិនអាចប្រើ あげる បានទេ)
   - ត្រឹមត្រូវ: *友だちが本をくれた。*
   - **គន្លឹះ:** ចងចាំថា **あげる** ប្រើចេញពីទស្សនៈរបស់អ្នកនិយាយដែលជាអ្នកឱ្យទៅគេ រីឯ **くれる** គឺប្រើនៅពេលអ្នកនិយាយជាអ្នកទទួល។

2. **ការប្រើប្រាស់ធ្នាក់ខុស (Misusing Particles)**
   - មិនត្រឹមត្រូវ: *友だちに本をくれた。*
   - ត្រឹមត្រូវ: *友だちが本をくれた。*
   - **គន្លឹះ:** អ្នកដែលជាអ្នកឱ្យត្រូវភ្ជាប់ដោយធ្នាក់ **が** (ឬ は) ហើយអ្នកទទួល (ដែលច្រើនតែលុបចោល) ត្រូវភ្ជាប់ដោយធ្នាក់ **に**។

### យុទ្ធសាស្ត្រក្នុងការរៀន (Learning Strategies)
- **វិធីសាស្ត្រចងចាំ (Mnemonic Device):** គិតថា **"Come to me"** សម្រាប់ពាក្យ **くれる** — សកម្មភាពធ្វើដំណើរ "តម្រង់មករកអ្នកនិយាយ" ជានិច្ច។
- អនុវត្តដោយការផ្លាស់ប្តូរទស្សនៈ (Switching perspectives):
  - ពីទស្សនៈរបស់អ្នក (គេឱ្យមកយើង): **友だちがくれる。** (មិត្តភក្តិឱ្យមកខ្ញុំ)
  - ពីទស្សនៈទៅកាន់មិត្តភក្តិ (យើងឱ្យទៅគេ): **私は友だちにあげる。** (ខ្ញុំឱ្យទៅមិត្តភក្តិ)

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **くれる** ត្រូវបានប្រើនៅពេលនរណាម្នាក់ឱ្យអ្វីមួយមកកាន់ **អ្នកនិយាយ (ខ្ញុំ)** ឬមនុស្សស្និទ្ធស្នាលក្នុងក្រុមរបស់អ្នកនិយាយ។
- អ្នកឱ្យត្រូវបានសម្គាល់ដោយធ្នាក់ **が** ហើយរបស់របរដែលត្រូវបានឱ្យត្រូវសម្គាល់ដោយធ្នាក់ **を**។
- ប្រើ **くださる** ក្នុងបរិបទគួរសម/លើកតម្កើង នៅពេលអ្នកឱ្យជាអ្នកមានឋានៈខ្ពស់ជាង។

### កម្រងសំណួររំលឹកឡើងវិញ (Quick Recap Quiz)
១. តើនិយាយប្រយោគ "លោកគ្រូបានផ្តល់កិច្ចការផ្ទះមកខ្ញុំ" ជាទម្រង់គួរសម/លើកតម្កើងយ៉ាងដូចម្តេច?  
   **ចម្លើយ:**
   ```
   先生が宿題をくださいました。
   ```

២. ចូរជ្រើសរើសធ្នាក់ដែលត្រឹមត្រូវ: 友だち ___ プレゼントをくれた。  
   **ចម្លើយ:**
   ```
   友だちがプレゼントをくれた。
   ```

៣. តើទម្រង់លើកតម្កើង (Honorific) នៃកិរិយាសព្ទ くれる គឺជាពាក្យអ្វី?  
   **ចម្លើយ:**
   ```
   くださる (kudasaru)
   ```
