# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～うとした (〜uto shita)
**កម្រិត JLPT:** JLPT N3

---

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងមេរៀននេះ យើងនឹងសិក្សាអំពីចំណុចវេយ្យាករណ៍ភាសាជប៉ុន **～うとした (〜uto shita)**។ ទម្រង់នេះត្រូវបានប្រើប្រាស់ដើម្បីបញ្ជាក់ថា នរណាម្នាក់ **រៀបនឹងធ្វើអ្វីមួយ** ឬ **បានព្យាយាម / ប៉ុនប៉ងធ្វើអ្វីមួយ** ប៉ុន្តែសកម្មភាពនោះមិនបានសម្រេច ឬត្រូវបានរារាំង/កាត់ផ្ដាច់ដោយព្រឹត្តិការណ៍ផ្សេង។ វាជាទម្រង់វេយ្យាករណ៍ដ៏មានសារៈសំខាន់ក្នុងការពណ៌នាអំពីចេតនា ឬសកម្មភាពដែលបានចាប់ផ្តើមធ្វើឡើង ប៉ុន្តែចុងក្រោយមិនបានសម្រេចផលឡើយ («រៀបនឹង... តែ...», «បម្រុងនឹង... ស្រាប់តែ...», «ប្រុងតែ... ក៏...» ជាដើម)។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
ទម្រង់វេយ្យាករណ៍ **～うとした** បង្ហាញពីអត្ថន័យស្នូលចំនួន ២៖
1. **សកម្មភាពប៉ុនប៉ងតែមិនសម្រេច (Attempted Action)**៖ បញ្ជាក់ថាបុគ្គលម្នាក់បានប្រឹងប្រែង ឬព្យាយាមធ្វើអ្វីមួយក្នុងអតីតកាល ប៉ុន្តែមិនបានសម្រេច ឬបរាជ័យ។
2. **បម្រុងនឹងធ្វើអ្វីមួយភ្លាមៗ (Immediate Intended Action / Interrupted Inception)**៖ បង្ហាញថាកំពុងតែរៀបនឹងធ្វើសកម្មភាពអ្វីមួយភ្លាមៗ ស្រាប់តែមានព្រឹត្តិការណ៍ ឬឧបសគ្គផ្សេងមួយទៀតកើតឡើងកាត់ផ្ដាច់ (ជាពិសេសក្នុងទម្រង់ `〜うとしたとき / 〜うとしたら`)។

### រចនាសម្ព័ន្ធវេយ្យាករណ៍ (Structure)
ទម្រង់នេះផ្សំឡើងដោយ **កិរិយាសព្ទបំលែងជាទម្រង់បំណង (Volitional Form / 意向形)** បូកជាមួយ **とした** (ឬទម្រង់គួរសម **としました**)។

```
[កិរិយាសព្ទ ទម្រង់បំណង (Volitional Form)] + とした / としたとき(に) / としたが...
```

#### តារាងបំលែងទម្រង់បំណង (Volitional Form Formation)

| ប្រភេទកិរិយាសព្ទ | ការបំលែងទម្រង់បំណង | ឧទាហរណ៍កិរិយាសព្ទដើម | ទម្រង់បំណង (Volitional) | ភ្ជាប់ជាមួយ とした |
|---|---|---|---|---|
| **កិរិយាសព្ទក្រុមទី១ (Godan)** | ប្តូរសំឡេងចុង `-u` ទៅជា `-ō` (う → おう) | 書く (*kaku* - សរសេរ) | 書こう (*kakō*) | 書こうとした |
| | | 行く (*iku* - ទៅ) | 行こう (*ikō*) | 行こうとした |
| | | 飲む (*nomu* - ផឹក) | 飲もう (*nomō*) | 飲もうとした |
| **កិរិយាសព្ទក្រុមទី២ (Ichidan)** | កាត់ `-ru` ចេញ ជំនួសដោយ `-yō` (る → よう) | 食べる (*taberu* - ញ៉ាំ) | 食べよう (*tabeyō*) | 食べようとした |
| | | 見る (*miru* - មើល) | 見よう (*miyō*) | 見ようとした |
| **កិរិយាសព្ទមិនទៀងទាត់ (Irregular)** | ទម្រង់ពិសេស (Special Forms) | する (*suru* - ធ្វើ) | しよう (*shiyō*) | しようとした |
| | | 来る (*kuru* - មក) | 来よう (*koyō*) | 来ようとした |

### ការពន្យល់លម្អិតបន្ថែម (Detailed Explanation)
1. **ទម្រង់បំណង (Volitional Form / 意向形)**៖ ជាទម្រង់ដែលបង្ហាញពីឆន្ទៈ បំណងប្រាថ្នា ឬការប្តេជ្ញាចិត្តផ្ទាល់ខ្លួនក្នុងការធ្វើសកម្មភាពណាមួយ។
2. **ការបន្ថែម とした**៖ ពាក្យ `とした` គឺជាទម្រង់អតីតកាលនៃកិរិយាសព្ទជំនួយ `とする` (ដែលក្នុងបរិបទនេះមានន័យថា ព្យាយាម ឬរៀបចំធ្វើ)។ នៅពេលភ្ជាប់គ្នា `[ទម្រង់បំណង] + とした` វាកំណត់ថាសកម្មភាព ឬការប៉ុនប៉ងនោះបានកើតឡើងកាលពីអតីតកាលរួចហើយ ហើយសកម្មភាពនោះ **មិនបានបញ្ចប់ទៅដោយជោគជ័យពេញលេញនោះទេ**។
   - ឧទាហរណ៍៖ **行こうとした** → «បានព្យាយាមទៅ» ឬ «បម្រុងនឹងទៅហើយ (តែមានរឿងរារាំង)»។

---

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative & Nuance Analysis)

ដើម្បីយល់ច្បាស់ពីចំណុចវេយ្យាករណ៍នេះ ចាំបាច់ត្រូវប្រៀបធៀប **～うとした** ជាមួយទម្រង់ស្រដៀងគ្នាដទៃទៀតដូចជា **～うとする**, **～ところだった**, និង **～うと思う**៖

### ក. ប្រៀបធៀបរវាង 〜うとした vs. 〜うとする
- **～うとした (អតីតកាល - Past / Thwarted Attempt)**៖
  - បង្ហាញពីសកម្មភាពដែលបានប៉ុនប៉ងធ្វើរួចហើយក្នុងអតីតកាល ប៉ុន្តែត្រូវបានរារាំង បរាជ័យ ឬមិនបានសម្រេច។
  - ជាញឹកញាប់បញ្ចប់ដោយឈ្នាប់ផ្ទុយ `が` / `けど` ឬភ្ជាប់ជាមួយ `ときに` (ឧទាហរណ៍៖ «កំពុងតែរៀបនឹងចេញពីផ្ទះ ស្រាប់តែភ្លៀងធ្លាក់» - `家を出ようとしたときに...`)។
- **～うとする (បច្ចុប្បន្នកាល / កំពុងព្យាយាម - Attempt in Progress or Habitual Attempt)**៖
  - បង្ហាញពីសកម្មភាពដែលបុគ្គលម្នាក់កំពុងព្យាយាមធ្វើនៅចំពោះមុខ (In progress) ឬបម្រុងនឹងធ្វើភ្លាមៗនៅពេលនេះ។
  - ឧទាហរណ៍៖ **出かけようとする** («កំពុងតែរៀបចំចេញទៅក្រៅ», «កំពុងព្យាយាមចេញទៅក្រៅ») ឬពណ៌នាអំពីអាកប្បកិរិយារបស់អ្នកដទៃ/សត្វដែលកំពុងព្យាយាមធ្វើអ្វីមួយ (ឧទាហរណ៍៖ `猫が木に登ろうとしている` - ឆ្មាកំពុងប្រឹងឡើងដើមឈើ)។

### ខ. ប្រៀបធៀបរវាង 〜うとした vs. 〜ところだった
- **～うとした (មានឆន្ទៈ/ចេតនាពិតប្រាកដក្នុងការធ្វើ - Volitional Effort Thwarted)**៖
  - ផ្អែកលើ **ចេតនា ឬការប្រឹងប្រែងផ្ទាល់ខ្លួន (Volition)** របស់អ្នកធ្វើសកម្មភាព (ប្រើជាមួយទម្រង់បំណង)។
  - មានន័យថា៖ បុគ្គលនោះបានផ្តួចផ្តើម ឬបម្រុងនឹងធ្វើសកម្មភាពនោះដោយខ្លួនឯង តែមានឧបសគ្គមករារាំង។
  - ឧទាហរណ៍៖ **電車に乗ろうとしたが、ドアが閉まってしまった。** (ខ្ញុំបានប្រឹងប្រញាប់ឡើងជិះរថភ្លើង តែទ្វាររថភ្លើងបែរជាបិទបាត់ - មានចេតនាឡើងជិះ)។
- **～ところだった (ស្ទើរតែកើតឡើង / ច្រៀម - Narrowly Escaped / Almost Happened)**៖
  - ប្រើជាមួយកិរិយាសព្ទ **ទម្រង់ដើមវចនានុក្រម (Dictionary Form)** មិនមែនទម្រង់បំណងឡើយ។
  - សង្កត់ធ្ងន់លើ **ស្ថានភាពគ្រោះថ្នាក់ ឬព្រឹត្តិការណ៍អាក្រក់ដែលស្ទើរតែបានកើតឡើង** ទៅហើយ តែសំណាងល្អរួចផុតមកវិញ (Close call) ដោយមិនអាស្រ័យលើឆន្ទៈចង់ធ្វើនោះទេ។
  - ឧទាហរណ៍៖ **もう少しで車に轢かれるところだった。** (បន្តិចទៀតស្ទើរតែត្រូវឡានបុកទៅហើយ - គ្មានចេតនាចង់ឲ្យឡានបុកទេ តែជាស្ថានភាពស្ទើរតែកើតឡើង)។

### គ. ប្រៀបធៀបរវាង 〜うとした vs. 〜うと思う
- **～うとした**៖ សង្កត់ធ្ងន់លើ **ការចុះដៃធ្វើជាក់ស្តែង (Action Attempted)** តែមិនសម្រេច។
- **～うと思う (〜うとおもう)**៖ សង្កត់ធ្ងន់ត្រឹមតែ **ការគិត ចេតនា ឬគម្រោងក្នុងចិត្ត (Mental Intention/Plan)** សម្រាប់ពេលអនាគតប៉ុណ្ណោះ មិនទាន់មានការចុះដៃធ្វើនៅឡើយទេ។
  - ឧទាហរណ៍៖ **勉強しようと思う** (ខ្ញុំគិតថានឹងរៀន / ខ្ញុំមានបំណងថានឹងរៀន)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ប្រយោគគំរូទូទៅ (Sample Sentences)

1. **家を出ようとしたときに雨が降り始めた。**
   - *រ៉ូម៉ាជី*: Ie o deyō to shita toki ni ame ga furihajimeta.
   - *ប្រែសម្រួល*: ពេលដែលខ្ញុំបម្រុងនឹងចេញពីផ្ទះ ស្រាប់តែមេឃចាប់ផ្តើមធ្លាក់ភ្លៀង។

2. **電車に乗ろうとしたが、ドアが閉まってしまった。**
   - *រ៉ូម៉ាជី*: Densha ni norō to shita ga, doa ga shimatte shimatta.
   - *ប្រែសម្រួល*: ខ្ញុំបានព្យាយាមឡើងជិះរថភ្លើងដែរ តែទ្វារបែរជាបិទជិតបាត់ទៅហើយ។

3. **彼女は何か言おうとしたが、言葉が出なかった。**
   - *រ៉ូម៉ាជី*: Kanojo wa nanika iō to shita ga, kotoba ga denakatta.
   - *ប្រែសម្រួល*: នាងបម្រុងនឹងនិយាយអ្វីម្យ៉ាង តែនិយាយអ្វីមិនចេញឡើយ។

4. **昨夜早く寝ようとしたが、結局遅くまで起きていた。**
   - *រ៉ូម៉ាជី*: Sakuya hayaku neyō to shita ga, kekkyoku osoku made okite ita.
   - *ប្រែសម្រួល*: យប់មិញខ្ញុំបានតាំងចិត្តចូលគេងពីព្រលប់ដែរ តែចុងក្រោយនៅតែចូលគេងយប់ជ្រៅដដែល។

5. **その質問に答えようとしたときに、電話が鳴った。**
   - *រ៉ូម៉ាជី*: Sono shitsumon ni kotaeyō to shita toki ni, denwa ga natta.
   - *ប្រែសម្រួល*: ពេលដែលខ្ញុំរៀបនឹងឆ្លើយសំណួរនោះ ស្រាប់តែទូរសព្ទរោទ៍ឡើង។

### បរិបទផ្លូវការ និងមិនផ្លូវការ (Formal and Informal Usage)

- **បរិបទផ្លូវការ / គួរសម (Formal Context)**:
  - **面接室に入ろうとしたとき、緊張で足がすくんだ。**
    - *ប្រែសម្រួល*: នៅពេលដែលខ្ញុំរៀបនឹងឈានជើងចូលបន្ទប់សម្ភាសន៍ ជើងរបស់ខ្ញុំស្រាប់តែទន់អស់ដោយសារភាពតានតឹងភ័យខ្លាច។
  - **資料を提出しようとしましたが、締め切り時間を過ぎてしまいました。**
    - *ប្រែសម្រួល*: ខ្ញុំបានព្យាយាមដាក់បញ្ជូនឯកសារដែរ ប៉ុន្តែបានហួសកាលបរិច្ឆេទកំណត់បាត់ទៅហើយ។

- **បរិបទសន្ទនាទូទៅ / ស្និទ្ធស្នាល (Informal Context)**:
  - **友達に電話しようとしたけど、番号を忘れちゃった。**
    - *ប្រែសម្រួល*: ខ្ញុំប្រុងតែខលទៅមិត្តភក្តិដែរ តែភ្លេចលេខទូរសព្ទបាត់។

## ៥. កំណត់សម្គាល់វប្បធម៌ (Cultural Notes)

### ទំនាក់ទំនងជាមួយវប្បធម៌ជប៉ុន (Cultural Relevance)
នៅក្នុងវប្បធម៌ជប៉ុន ការបង្ហាញពីការខិតខំប្រឹងប្រែងដោយភាពគួរសមមានសារៈសំខាន់ខ្លាំងណាស់។ ការប្រើប្រាស់ទម្រង់ **～うとした** ជួយឲ្យអ្នកនិយាយអាចបញ្ជាក់បង្ហាញអំពី «ការប្រឹងប្រែង» ឬ «ចេតនាល្អ» របស់ខ្លួនបាន ដោយមិនចាំបាច់អួតអាងអំពីលទ្ធផលជោគជ័យឡើយ ដែលនេះស្របគ្នានឹងគុណតម្លៃនៃភាពសុភាពរាបសារ (謙虚 - Kenkyo) នៅក្នុងសង្គមជប៉ុន។

### កម្រិតគួរសម (Politeness Levels)
- ទម្រង់បំណងតែឯកឯងមានកម្រិតអព្យាក្រឹត ប៉ុន្តែគេអាចកែប្រែកម្រិតគួរសមបានតាមរយៈកិរិយាសព្ទបញ្ចប់៖
  - ទម្រង់គួរសម (Polite form): **行こうとしました**
  - ទម្រង់ទូទៅ/សាមញ្ញ (Casual form): **行こうとした**

### ឃ្លាឃ្លោងទម្លាប់និយមប្រើ (Idiomatic Expressions)
- **逃げようとしたが、逃げられなかった。**
  - *ប្រែសម្រួល*: បានព្យាយាមរត់គេចដែរ តែរត់មិនរួច។
- **笑おうとしたけど、うまく笑えなかった。**
  - *ប្រែសម្រួល*: ប្រឹងញញឹមដែរ តែញញឹមមិនសមសោះ។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
- **ច្រឡំប្រើទម្រង់កិរិយាសព្ទខុស (Incorrect Verb Form)**៖ ប្រើទម្រង់វចនានុក្រមជំនួសឲ្យទម្រង់បំណង។
  - ❌ ខុស៖ **食べるとした**
  -  ត្រូវ៖ **食べようとした**
- **ច្រឡំកាល (Confusing Tenses)**៖ ច្រឡំរវាង **～うとする** (បច្ចុប្បន្នកាល / កំពុងព្យាយាម) និង **～うとした** (អតីតកាល / ព្យាយាមរួចតែមិនសម្រេច)។
  - **～うとする**៖ កំពុងព្យាយាម ឬរៀបនឹងធ្វើនៅពេលនេះ។
  - **～うとした**៖ បានព្យាយាមធ្វើកាលពីអតីតកាលតែមិនបានសម្រេច។

### គន្លឹះក្នុងការរៀនសូត្រ (Learning Strategies)
- **ចងចាំការបំលែងទម្រង់បំណងឲ្យច្បាស់**៖ អនុវត្តការបំលែងកិរិយាសព្ទទាំង ៣ ក្រុមទៅជាទម្រង់បំណងឲ្យបានស្ទាត់ជំនាញ។
- **ភ្ជាប់ន័យជាមួយពាក្យខ្មែរថា «រៀបនឹង... តែ...», «បម្រុងនឹង... ស្រាប់តែ...», «ប្រឹង... តែមិន...»** ដើម្បីងាយយល់បរិបទភ្លាមៗ។
- **បង្កើតប្រយោគផ្ទាល់ខ្លួន**៖ អនុវត្តបង្កើតប្រយោគដោយភ្ជាប់ព្រឹត្តិការណ៍ពិតក្នុងជីវិតប្រចាំថ្ងៃ (ឧទាហរណ៍៖ បម្រុងនឹងញ៉ាំបាយ ស្រាប់តែមានភ្ញៀវមក)។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～うとした** ប្រើសម្រាប់បង្ហាញសកម្មភាពដែលបានប៉ុនប៉ងធ្វើ ឬរៀបនឹងធ្វើឡើង ប៉ុន្តែមិនបានសម្រេចទៅដល់ទីបញ្ចប់។
- បង្កើតឡើងដោយការផ្សំ **[កិរិយាសព្ទ ទម្រង់បំណង] + とした**។
- សំខាន់បំផុតគឺត្រូវប្រើប្រាស់ទម្រង់បំណងឲ្យបានត្រឹមត្រូវតាមក្រុមនៃកិរិយាសព្ទនីមួយៗ។

### សំណួររំលឹកឡើងវិញខ្លីៗ (Quick Recap Quiz)
1. **តើកិរិយាសព្ទ 書く (kaku) បំលែងទៅជាទម្រង់បំណងដូចម្តេច?**
   - *ចម្លើយ*: 書こう (kakō)
2. **ចូរប្រែប្រយោគនេះទៅជាភាសាជប៉ុនដោយប្រើ ～うとした៖ "ពេលដែលខ្ញុំបម្រុងនឹងចាប់ផ្តើមរៀន ស្រាប់តែមិត្តភក្តិរបស់ខ្ញុំមកដល់។"**
   - *ចម្លើយ*: 勉強しようとしたときに友達が来た。
3. **តើអ្វីជាភាពខុសគ្នាសំខាន់រវាង ～うとした និង ～うと思った?**
   - *ចម្លើយ*: **～うとした** បញ្ជាក់ពីសកម្មភាពជាក់ស្តែងដែលបានព្យាយាមធ្វើឡើងតែមិនសម្រេច រីឯ **～うと思った** បង្ហាញត្រឹមតែការគិត ឬបំណងនៅក្នុងចិត្តរបស់បុគ្គលនោះប៉ុណ្ណោះ។
