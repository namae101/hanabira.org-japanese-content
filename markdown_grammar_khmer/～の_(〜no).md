# ចំណុចវេយ្យាករណ៍ភាសាញ៉បុ៉ន: ～の (〜no)
**កម្រិត JLPT:** JLPT N5

---

## ១. សេចក្តីផ្តើម (Introduction)
ធ្នាក់ **の (no)** គឺជាធ្នាក់ដ៏សំខាន់ បត់បែន និងត្រូវបានប្រើប្រាស់ញឹកញាប់បំផុតមួយក្នុងភាសាញ៉បុ៉ន។ វាបំពេញមុខងារវេយ្យាករណ៍ជាច្រើន រួមមាន៖ បង្ហាញពីកម្មសិទ្ធិ (ភាពជាម្ចាស់), ភ្ជាប់នាមនិងនាម, ធ្វើនាមរូបកម្ម (កម្លាយកិរិយាសព្ទ និងគុណនាមទៅជានាម), ដើរតួជាសព្វនាមជំនួសនាម (Pronoun / Noun substitute), និងបន្ថែមអត្ថន័យពន្យល់ហេតុផលនៅចុងល្បះ។ ការយល់ដឹងច្បាស់អំពីរបៀបប្រើប្រាស់ **の** នឹងជួយបង្កើនសមត្ថភាពរបស់អ្នកក្នុងការបង្កើតប្រយោគភាសាញ៉បុ៉នឱ្យកាន់តែត្រឹមត្រូវ ក្បោះក្បាយ និងមានលក្ខណៈធម្មជាតិ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ និងមុខងារនៃការប្រើប្រាស់ ～の
**の** អាចត្រូវបានប្រើប្រាស់ក្នុងទម្រង់ និងមុខងារសំខាន់ៗដូចខាងក្រោម៖
1. **ធ្នាក់បញ្ជាក់កម្មសិទ្ធិ (Possessive Particle)**: បង្ហាញពីភាពជាម្ចាស់ ឬការជារបស់នរណាម្នាក់ (មានន័យស្មើនឹង "របស់..." ឬ "'s" ក្នុងភាសាអង់គ្លេស)។
2. **ធ្នាក់ភ្ជាប់នាម (Noun Connector)**: ភ្ជាប់នាមពីរចូលគ្នា ដោយនាមទីមួយធ្វើការពង្រីកន័យ ឬបញ្ជាក់លក្ខណៈឱ្យនាមទីពីរ។
3. **ការកម្លាយជានាម (Nominalizer) និង សព្វនាមជំនួសនាម (Noun Substitute)**: បំប្លែងកិរិយាសព្ទ ឬគុណនាមឱ្យទៅជាកន្សោមនាម ឬប្រើជំនួសនាមដែលបានលើកឡើងរួច ("អាមួយ...", "មួយដែល...", "របស់...")។
4. **កន្សោមពន្យល់ហេតុផល (Explanatory Particle)**: ដាក់នៅចុងល្បះដើម្បីបន្ថែមការសង្កត់ន័យ សុំការពន្យល់ ឬបញ្ជាក់ហេតុផល។

---

### ទម្រង់ និងក្បួនវេយ្យាករណ៍ (Structure and Formation)

#### ១. ធ្នាក់បញ្ជាក់កម្មសិទ្ធិ (Possessive Particle)
- **ទម្រង់:**  
  `នាម A + の + នាម B`
- **អត្ថន័យ:**  
  នាម B ជាកម្មសិទ្ធិរបស់ នាម A (នាម B របស់ នាម A)។
- **ឧទាហរណ៍:**
  | ភាសាញ៉បុ៉ន | ការបញ្ចេញសំឡេង | បកប្រែជាភាសាខ្មែរ |
  |---|---|---|
  | 私の本 | *watashi no hon* | សៀវភៅរបស់ខ្ញុំ |
  | 先生の車 | *sensei no kuruma* | ឡានរបស់គ្រូ |
  | 友達の家 | *tomodachi no ie* | ផ្ទះរបស់មិត្តភក្តិ |

#### ២. ធ្នាក់ភ្ជាប់នាម (Noun Connector)
- **ទម្រង់:**  
  `នាមពន្យល់ន័យ + の + នាមគោល`
- **អត្ថន័យ:**  
  នាមទីមួយបញ្ជាក់ប្រភេទ ប្រភព ទីតាំង ឬលក្ខណៈរបស់នាមទីពីរ។
- **ឧទាហរណ៍:**
  | ភាសាញ៉បុ៉ន | ការបញ្ចេញសំឡេង | បកប្រែជាភាសាខ្មែរ |
  |---|---|---|
  | 日本の文化 | *nihon no bunka* | វប្បធម៌ជប៉ុន |
  | 冬の夜 | *fuyu no yoru* | យប់រដូវរងា |
  | 東京のレストラン | *toukyou no resutoran* | ភោជនីយដ្ឋាននៅតូក្យូ |

#### ៣. ការកម្លាយជានាម (Nominalizer) និង សព្វនាមជំនួសនាម (Noun Substitute)
- **ទម្រង់ជាមួយកិរិយាសព្ទ:**  
  `កិរិយាសព្ទ (ទម្រង់ធម្មតា / ដើម) + の`
- **ទម្រង់ជាមួយគុណនាម:**  
  `គុណនាម い + の`  
  `គុណនាម な + な + の`
- **អត្ថន័យ:**  
  - បំប្លែងកិរិយាសព្ទ ឬគុណនាមទៅជាកន្សោមនាម (ការធ្វើ... / អំពើ...) ដើម្បីធ្វើជាប្រធាន ឬកម្មបទក្នុងល្បះ។  
  - ដើរតួជាសព្វនាមជំនួសនាមសំដៅលើ "មួយ..." ("the one", "mine", "yours") ដើម្បីកុំឱ្យជាន់ពាក្យដដែលៗ។
- **ឧទាហរណ៍:**
  | ភាសាញ៉បុ៉ន | ការបញ្ចេញសំឡេង | បកប្រែជាភាសាខ្មែរ |
  |---|---|---|
  | 食べるのが好きです。 | *taberu no ga suki desu.* | ខ្ញុំចូលចិត្តការញ៉ាំ (ចូលចិត្តញ៉ាំអាហារ)។ |
  | 読むのは楽しい。 | *yomu no wa tanoshii.* | ការអានសៀវភៅគឺសប្បាយរីករាយ។ |
  | 新しいのを買いました。 | *atarashii no o kaimashita.* | ខ្ញុំបានទិញអាថ្មីមួយ (ទិញមួយថ្មី)។ |
  | 静かなのが好きです。 | *shizuka na no ga suki desu.* | ខ្ញុំចូលចិត្តកន្លែង/អាដែលស្ងប់ស្ងាត់។ |

#### ៤. កន្សោមពន្យល់ហេតុផលនៅចុងល្បះ (Explanatory Particle)
- **ទម្រង់:**  
  `ល្បះ (ទម្រង់ធម្មតា) + の` (ការសន្ទនាទូទៅ/ស្និទ្ធស្នាល)  
  *(ចំណាំ៖ ចំពោះគុណនាម な និងនាម ក្នុងទម្រង់បច្ចុប្បន្នស្រប ត្រូវប្រើ `な + の`)*
- **អត្ថន័យ:**  
  បន្ថែមទឹកដមសំឡេងពន្យល់ហេតុផល បង្ហាញការចង់ដឹង ឬសុំការបញ្ជាក់បន្ថែម (ស្រដៀងនឹង "គឺថាមកពី...", "តើមែនទេ?")។
- **ឧទាហរណ៍:**
  | ភាសាញ៉បុ៉ន | ការបញ្ចេញសំឡេង | បកប្រែជាភាសាខ្មែរ |
  |---|---|---|
  | どうしたの？ | *doushita no?* | តើឯងកើតអីហ្នឹង? / មានរឿងអីកើតឡើងមែនទេ? |
  | これが欲しかったの。 | *kore ga hoshikatta no.* | គឺមួយនេះហើយដែលខ្ញុំចង់បាន។ |
  | 行かないの？ | *ikanai no?* | ឯងមិនទៅទេអ្ហ៎? |
  | 雨が降っているの。 | *ame ga futte iru no.* | គឺថាមកពីកំពុងភ្លៀងហ្នឹងណា។ |

### តារាងសង្ខេបជំនួយការចងចាំ (Visual Aid: Usage Summary)
| មុខងារនៃការប្រើប្រាស់ | ទម្រង់វេយ្យាករណ៍ | ឧទាហរណ៍ | បកប្រែជាភាសាខ្មែរ |
|---|---|---|---|
| **កម្មសិទ្ធិ (Possession)** | នាម A + の + នាម B | 私の猫 (*watashi no neko*) | ឆ្មារបស់ខ្ញុំ |
| **ភ្ជាប់នាម (Noun Connector)** | នាម A + の + នាម B | 桜の花 (*sakura no hana*) | ផ្កាសាគូរ៉ា |
| **សព្វនាមជំនួស (Noun Substitute)** | គុណនាម / នាម + の | 赤いのは私のです (*akai no wa watashi no desu*) | អាពណ៌ក្រហមគឺជាអា/របស់ខ្ញុំ |
| **កម្លាយកិរិយាសព្ទជានាម** | កិរិយាសព្ទ + の | 見るのが好き (*miru no ga suki*) | ចូលចិត្តការមើល |
| **កម្លាយគុណនាមជានាម** | គុណនាម + の | 面白いのです (*omoshiroi no desu*) | គឺវាគួរឱ្យចាប់អារម្មណ៍ |
| **ពន្យល់ហេតុផល (Explanatory)** | ប្រយោគ + の | 行くの？ (*iku no?*) | តើឯងទៅមែនទេ? |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuances)

### ១. ការវិភាគស៊ីជម្រៅអំពីមុខងារជាសព្វនាមជំនួសនាម (Noun Substitute / Possessive Pronoun)
នៅក្នុងកម្រិត N5 ចំណុចសំខាន់មួយដែលអ្នករៀនត្រូវយល់ឱ្យបានច្បាស់ គឺការប្រើ **の** ជំនួសឱ្យនាមដែលបានដឹង ឬនិយាយរួចហើយ ដើម្បីកុំឱ្យនិយាយពាក្យដដែលៗ៖
- **មុខងារជំនួសនាម (One / The one):**  
  នៅពេលមាននាមមួយត្រូវបានលើកឡើងក្នុងបរិបទរួចហើយ យើងអាចជំនួសនាមនោះដោយ **の** (មានន័យស្មើនឹង "one" ក្នុងភាសាអង់គ្លេស ឬ "អាមួយ...", "មួយដែល..." ក្នុងភាសាខ្មែរ)។  
  - ឧទាហរណ៍៖  
    - A:「どのペンがいいですか。」 (*Dono pen ga ii desu ka.* - "តើអ្នកចង់បានប៊ិចមួយណា?")  
    - B:「**赤いのは私のです**。」 (*Akai no wa watashi no desu.*)  
      - ត្រង់នេះ **赤いの** មានន័យថា "អាពណ៌ក្រហម" (赤いペン)។  
      - ចំណែកឯ **私のです** មានន័យថា "ជារបស់ខ្ញុំ" (私のペンです - mine)។  
      - ប្រយោគទាំងមូលបកប្រែថា៖ **"អាពណ៌ក្រហម គឺជា(ប៊ិច)របស់ខ្ញុំ"**។
- **មុខងារជាសព្វនាមកម្មសិទ្ធិ (Possessive Pronoun: Mine, Yours, His, Hers):**  
  - `នាម/សព្វនាម + の` អាចបញ្ចប់នៅត្រឹមនេះដោយពុំបាច់មាននាមនៅពីក្រោយឡើយ ប្រសិនបើអ្នកស្តាប់យល់ច្បាស់នូវអ្វីដែលកំពុងនិយាយ។  
    - **私の** (*watashi no*) = របស់ខ្ញុំ (mine)  
    - **あなたの** (*anata no*) = របស់អ្នក (yours)  
    - **田中さんの** (*Tanaka-san no*) = របស់លោកតាណាកា (Tanaka's)  
  - ឧទាហរណ៍៖  
    - この傘は誰のですか。 (*Kono kasa wa dare no desu ka.* - តើឆ័ត្រនេះជារបស់នរណា?)  
    - **私のです**。 (*Watashi no desu.* - ជារបស់ខ្ញុំ / Mine.)

### ២. ការប្រៀបធៀបរវាង ～の និង ～こと ក្នុងការកម្លាយជានាម (Nominalizers)
ទោះបីជាទាំង **の** និង **こと** អាចប្រើដើម្បីកម្លាយកិរិយាសព្ទទៅជានាម ("ការធ្វើ...") ក៏ដោយ ក៏ពួកវាមានន័យស៊ីជម្រៅ និងបរិបទប្រើប្រាស់ខុសគ្នា៖

| លក្ខណៈវិនិច្ឆ័យ | ～の (no) | ～こと (koto) |
|---|---|---|
| **អត្ថន័យ និងការប្រើប្រាស់** | សំដៅលើសកម្មភាពផ្ទាល់ជាក់ស្តែង ញាណដឹង និងអារម្មណ៍ផ្ទាល់ខ្លួន (Subjective / Perceptual) | សំដៅលើគំនិតទូទៅ អរូបី ឬការពិតជាទូទៅ (Objective / Conceptual / Fact) |
| **ការប្រើប្រាស់ជាក់លាក់** | **ត្រូវតែប្រើជាមួយកិរិយាសព្ទញាណដឹង និងសកម្មភាពផ្ទាល់:**<br>- មើលឃើញ / ឮ: 見る, 聞こえる<br>- រង់ចាំ / ជួយ: 待つ, 手伝う, 止める | **ត្រូវតែប្រើជាមួយទម្រង់វេយ្យាករណ៍កំណត់:**<br>- សមត្ថភាព: ～ことができる<br>- ចំណូលចិត្តទូទៅ/បទពិសោធន៍: ～ことがある<br>- គោលបំណង/ច្បាប់ទម្លាប់: ～ことにする |
| **កម្រិតផ្លូវការ** | ស្និទ្ធស្នាល ប្រើក្នុងការសន្ទនាប្រចាំថ្ងៃ (Conversational / Casual) | ផ្លូវការជាង និងមានលក្ខណៈអព្យាក្រឹត (Formal / Written) |
| **ឧទាហរណ៍** | 歌う**の**が好きです。<br>*(ខ្ញុំចូលចិត្តការច្រៀងចម្រៀង - បង្ហាញពីអារម្មណ៍ផ្ទាល់ខ្លួន)* | 歌う**こと**は楽しい。<br>*(ការច្រៀងគឺជារឿងសប្បាយ - ជាការពិតទូទៅ)* |

- **គន្លឹះចងចាំ:**  
  - ប្រើ **の** នៅពេលបង្ហាញពីអារម្មណ៍ចូលចិត្ត/ស្អប់ផ្ទាល់ខ្លួន (`～のが好き／嫌い`) ឬនៅពេលឃើញ/ឮសកម្មភាពផ្ទាល់ (`～のを見る／聞く`)។  
  - ប្រើ **こと** នៅពេលនិយាយអំពីការពិតទូទៅ ឬប្រើក្នុងទម្រង់វេយ្យាករណ៍ថេរដូចជា `～ことができる` (អាចធ្វើបាន)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ការនិយាយផ្លូវការ ឬគួរសម (Formal / Polite Speech)
1. **私は日本の歴史を研究しています。**  
   *Watashi wa Nihon no rekishi o kenkyuu shite imasu.*  
   ខ្ញុំកំពុងស្រាវជ្រាវអំពីប្រវត្តិសាស្ត្ររបស់ប្រទេសជប៉ុន។
2. **先生のご意見をお聞かせください。**  
   *Sensei no go-iken o okikase kudasai.*  
   សូមលោកគ្រូ/អ្នកគ្រូមេត្តាផ្តល់មតិយោបល់ឱ្យខ្ញុំបានដឹងផង។

### ការនិយាយក្រៅផ្លូវការ ឬស្និទ្ធស្នាល (Informal / Casual Speech)
1. **今日のパーティーに行くの？**  
   *Kyou no paatii ni iku no?*  
   តើឯងទៅកម្មវិធីជប់លៀងថ្ងៃនេះដែរទេ?
2. **彼が作ったケーキの味はどう？**  
   *Kare ga tsukutta keeki no aji wa dou?*  
   តើរសជាតិនំខេកដែលគាត់បានធ្វើនោះយ៉ាងម៉េចដែរ?

### ការសន្ទនាផ្ទាល់មាត់ (Spoken Conversations)
1. **どうして来なかったの？**  
   *Doushite konakatta no?*  
   ហេតុអីបានជាឯងមិនមកអញ្ចឹង?
2. **それは僕のじゃないよ。**  
   *Sore wa boku no ja nai yo.*  
   អាហ្នឹងមិនមែនជារបស់ខ្ញុំទេ។

### អត្ថបទសរសេរ (Written Texts)
1. **これは日本の伝統的な建物です。**  
   *Kore wa Nihon no dentouteki na tatemono desu.*  
   នេះគឺជាសំណង់អគារបែបប្រពៃណីរបស់ប្រទេសជប៉ុន។
2. **読書の趣味は素晴らしいですね。**  
   *Dokusho no shumi wa subarashii desu ne.*  
   ចំណង់ចំណូលចិត្តក្នុងការអានសៀវភៅពិតជាអស្ចារ្យណាស់មែនទេ?

## ៥. កំណត់សម្គាល់បែបវប្បធម៌ (Cultural Notes)

### កម្រិតគួរសម និងយេនឌ័រ (Politeness and Formality)
- ការបញ្ចប់ល្បះដោយប្រើ **の** ក្នុងការសន្ទនាធម្មតា ផ្តល់នូវទឹកដមសំឡេងស្រទន់ ដែលជារឿយៗត្រូវបានប្រើប្រាស់ដោយស្ត្រី ឬកុមារ ឬការនិយាយគ្នាយ៉ាងស្និទ្ធស្នាល។  
- បុរសជាទូទៅតែងតែប្រើ **のだ (no da)** (ទម្រង់ធម្មតា) ឬ **のです (no desu) / んです (n desu)** (ទម្រង់គួរសម) ជំនួសវិញ ដើម្បីកុំឱ្យសំឡេងស្តាប់ទៅស្រទន់ពេក។
  - **ការនិយាយបែបស្រទន់/ស្និទ្ធស្នាល (Female/Casual):**  
    **これを知っているの？** (*Kore o shitte iru no?*)  
    តើឯងស្គាល់/ដឹងរឿងនេះទេ?
  - **ការនិយាយគួរសម/ផ្លូវការ (Polite/Formal):**  
    **これを知っているのですか？** (*Kore o shitte iru no desu ka?*)  
    តើលោក/អ្នកជ្រាបពីរឿងនេះដែរឬទេ?

### ទឹកដមសំឡេងបែបពន្យល់ (Explanatory Tone)
- ការប្រើ **の** នៅចុងល្បះឆ្លុះបញ្ចាំងពីទម្លាប់នៃការប្រាស្រ័យទាក់ទងរបស់ជនជាតិជប៉ុន ដែលចូលចិត្តផ្តល់បរិបទ ពន្យល់សាវតារឿង ឬសួរដេញដោលដោយប្រយោលប្រកបដោយភាពទន់ភ្លន់ជាជាងការសួរចំៗ។

### កន្សោមឃ្លា idioms ដែលទាក់ទង
- **～のに (no ni)**: ទាំងដែល..., បែរជា... (បង្ហាញពីការខកចិត្ត ឬភាពផ្ទុយពីការរំពឹងទុក)  
  - **雨なのに出かけます。** (*Ame na no ni dekakemasu.*)  
    ទោះបីជាកំពុងភ្លៀងក៏ដោយ ក៏នៅតែចេញទៅក្រៅដែរ។
- **～のだから / ～んだから (no da kara / n da kara)**: ពីព្រោះតែ..., ដោយសារតែ...  
  - **時間がないのだから急ぎましょう。** (*Jikan ga nai no da kara isogimashou.*)  
    ដោយសារតែគ្មានពេលច្រើនទេ ចូរយើងប្រញាប់ឡើង។

## ៦. កំហុសទូទៅ និងគន្លឹះដោះស្រាយ (Common Mistakes and Tips)

### ការវិភាគកំហុសឆ្គង (Error Analysis)
1. **ការច្រឡំលំដាប់លំដោយនៃភាពជាម្ចាស់ (Possession Order):**
   - **ខុស:** 本の私 (*hon no watashi* - សៀវភៅរបស់ខ្ញុំ ❌)  
   - **ត្រូវ:** **私の本** (*watashi no hon* - សៀវភៅរបស់ខ្ញុំ ✔️)  
   - *ការពន្យល់:* ក្នុងភាសាញ៉បុ៉ន ម្ចាស់ត្រូវនៅពីមុខ ឯរបស់ដែលជាកម្មសិទ្ធិត្រូវនៅពីក្រោយជានិច្ច (`ម្ចាស់ + の + របស់`)។
2. **ការប្រើ の ជាមួយកិរិយាសព្ទគួរសម (Polite Verbs):**
   - **ខុស:** 話しますのが好きです。❌  
   - **ត្រូវ:** **話すのが好きです**。 (*Hanasu no ga suki desu.* - ខ្ញុំចូលចិត្តការជជែកលេង ✔️)  
   - *គន្លឹះ:* នៅពីមុខ **の** ត្រូវតែជាកិរិយាសព្ទ**ទម្រង់ធម្មតា (Plain form/Dictionary form)** ជានិច្ច មិនអាចប្រើទម្រង់ ます បានឡើយ។

### យុទ្ធសាស្ត្រសិក្សា (Learning Strategies)
- **ការចងចាំបញ្ជាក់កម្មសិទ្ធិ:** ចូរគិតថា **の** ប្រៀបដូចជាសញ្ញា **'s** ក្នុងភាសាអង់គ្លេស (A's B) ឬពាក្យ **"របស់"** ក្នុងភាសាខ្មែរ ដោយគ្រាន់តែដាក់ម្ចាស់នៅពីមុខ។
- **ជំនួសនាមយ៉ាងរហ័ស:** នៅពេលចង់និយាយថា "អាមួយក្រហម", "អាមួយធំ", "របស់ខ្ញុំ" ចូរនឹកឃើញដល់ `គុណនាម + の` ឬ `ម្ចាស់ + の` ភ្លាម។
- **អនុវត្តជាមួយឧទាហរណ៍ផ្ទាល់ខ្លួន:** បង្កើតប្រយោគផ្ទាល់ខ្លួនដោយប្រើមុខងារនីមួយៗរបស់ **の** ដើម្បីឱ្យស៊ាំនឹងការបត់បែននៃធ្នាក់នេះ។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ
- **の** គឺជាធ្នាក់ពហុមុខងារដ៏សំខាន់៖ បញ្ជាក់កម្មសិទ្ធិ, ភ្ជាប់នាម, ជំនួសនាម, កម្លាយកិរិយាសព្ទ/គុណនាមជានាម, និងបន្ថែមន័យពន្យល់ហេតុផល។
- ត្រូវប្រុងប្រយ័ត្នចំពោះកម្រិតគួរសម និងយេនឌ័រ នៅពេលប្រើ **の** បញ្ចប់ល្បះ។
- ត្រូវចងចាំភាពខុសគ្នារវាង **の** (សកម្មភាពផ្ទាល់/អារម្មណ៍ផ្ទាល់ខ្លួន) និង **こと** (គំនិតទូទៅ/ការពិតអរូបី) នៅពេលកម្លាយកិរិយាសព្ទជានាម។

### កម្រងសំណួររំលឹកឡើងវិញ (Quick Recap Quiz)
1. **ចូរបកប្រែឃ្លានេះដោយប្រើ ～の**: "សៀវភៅរបស់ម៉ារី (Mary's book)"  
   - **ចម្លើយ:** **メアリーの本** (*Mearii no hon*)
2. **ចូរជ្រើសរើសពាក្យកម្លាយនាមឱ្យបានត្រឹមត្រូវ**: "ការហែលទឹកគឺជារឿងសប្បាយ។" (ការពិតទូទៅ)  
   - **ចម្លើយ:** 泳ぐ**こと**は楽しい。 (*Oyogu koto wa tanoshii.*)
3. **ចូររកកំហុសក្នុងប្រយោគនេះ**: 私は音楽を聞く**こと**が好きです。  
   - **កែតម្រូវ:** 私は音楽を聞く**の**が好きです。 (*Watashi wa ongaku o kiku no ga suki desu.* - ពីព្រោះបង្ហាញពីចំណូលចិត្តផ្ទាល់ខ្លួន)
4. **ចូរពន្យល់ពីមុខងាររបស់ ～の ក្នុងប្រយោគនេះ**: **どうしたの？**  
   - **ចម្លើយ:** **の** ត្រូវបានប្រើជាកន្សោមពន្យល់ហេតុផលនៅចុងល្បះ ដើម្បីសួរសំណួរដោយស្និទ្ធស្នាលថា "តើឯងកើតអីហ្នឹង? / មានរឿងអីកើតឡើងមែនទេ?"។
5. **ចូរបកប្រែប្រយោគនេះជាភាសាខ្មែរ**: **赤いのは私のです。**  
   - **ចម្លើយ:** "អាពណ៌ក្រហម គឺជា(របស់)ខ្ញុំ។" (の ទីមួយដើរតួជាសព្វនាមជំនួសនាម "អាមួយ...", ហើយ の ទីពីរដើរតួជាសព្វនាមកម្មសិទ្ធិ "របស់ខ្ញុំ")។

ការយល់ដឹង និងការអនុវត្តជាក់ស្តែងនូវមុខងារចម្រុះរបស់ **の** នឹងជួយឱ្យអ្នកអាចបញ្ជាក់ពីភាពជាម្ចាស់ ភ្ជាប់គំនិត និងបន្ថែមន័យស៊ីជម្រៅក្នុងការសន្ទនាភាសាញ៉បុ៉នរបស់អ្នក។ សូមបន្តការហ្វឹកហាត់បន្ថែមទៀត!
