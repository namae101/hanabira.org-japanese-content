# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～限り (〜kagiri)
**កម្រិត JLPT:** JLPT N2

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងមេរៀននេះ យើងនឹងសិក្សាអំពីទម្រង់វេយ្យាករណ៍កម្រិត JLPT N2 ដ៏សំខាន់មួយគឺ **～限り (〜kagiri)**។ កន្សោមនេះត្រូវបានប្រើប្រាស់ជាទូទៅដើម្បីបង្ហាញពីដែនកំណត់ វិសាលភាព ឬលក្ខខណ្ឌបន្ត ដែលជារឿយៗបកប្រែមកជាភាសាខ្មែរថា **«ដរាបណា... / ឱ្យតែ...»** ឬ **«តាមតែ... / តាមដែនកំណត់ដែល...»**។ ការយល់ដឹងច្បាស់អំពីរបៀបប្រើប្រាស់ ～限り នឹងជួយឱ្យអ្នកអាចកំណត់ព្រំដែននៃលក្ខខណ្ឌ និងវិសាលភាពនៃការគិត ឬសកម្មភាពបានយ៉ាងត្រឹមត្រូវ និងស៊ីជម្រៅក្នុងភាសាជប៉ុន។

---
## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)
### អត្ថន័យ (Meaning)
**～限り** បង្ហាញថារឿងរ៉ាវ ឬស្ថានភាពមួយនឹងនៅតែបន្ត ឬជាការពិត ក្នុងកំឡុងពេល ឬក្នុងដែនកំណត់ដែលលក្ខខណ្ឌជាក់លាក់មួយនៅតែមានសុពលភាព។ វាសង្កត់ធ្ងន់លើ **ដែនកំណត់ (Limit)** ឬ **វិសាលភាព (Scope/Extent)** នៃលក្ខខណ្ឌនោះ។
- **ដរាបណា... / ឱ្យតែ... (As long as...)**
- **ក្នុងកំឡុងពេលដែល... (While / so long as...)**
- **តាមតែ... / តាមវិសាលភាពដែល... (To the extent that... / As far as...)**

### ទម្រង់តភ្ជាប់ (Structure)
ការតភ្ជាប់របស់ **～限り** ប្រែប្រួលអាស្រ័យលើប្រភេទពាក្យដែលនៅខាងមុខវា៖

| ប្រភេទពាក្យខាងមុខ | របៀបតភ្ជាប់ | ឧទាហរណ៍ |
|-------------------------|--------------------------|------------------------------|
| កិរិយាសព្ទ (Verb) | Verb (ទម្រង់ធម្មតា / វចនានុក្រម / ている / ない) + **限り** | 生きる**限り** (ដរាបណានៅរស់) |
| នាម (Noun) | Noun + **である** + **限り** | 学生**である限り** (ដរាបណានៅជានិស្សិត) |
| គុណនាម い (い-adjective) | Adj-い + **限り** / Adj-い + **い限り** | 元気な**限り** / 若い**限り** (ដរាបណានៅក្មេង) |
| គុណនាម な (な-adjective) | Adj-な + **な限り** / Adj-な + **である限り** | 静か**である限り** (ដរាបណានៅតែស្ងប់ស្ងាត់) |

### ដ្យាក្រាមទម្រង់ (Formation Diagram)
```
[កិរិយាសព្ទ ទម្រង់វចនានុក្រម / ている / ない] + 限り
[នាម] + である + 限り
[គុណនាម い] + 限り
[គុណនាម な] + な / である + 限り
```

### ការពន្យល់លម្អិតតាមទម្រង់នីមួយៗ (Detailed Explanation)
១. **កិរិយាសព្ទ + 限り**
   ប្រើនៅពេលដែលលក្ខខណ្ឌត្រូវបានពិពណ៌នាដោយកិរិយាសព្ទ (សកម្មភាព ឬស្ថានភាព)។
   - **ឧទាហរណ៍**៖ 努力する**限り**、成功できる。
     - *ដរាបណាយើងនៅតែខិតខំប្រឹងប្រែង យើងនឹងអាចទទួលបានជោគជ័យ។*
២. **នាម + である + 限り**
   ប្រើនៅពេលដែលលក្ខខណ្ឌជាឋានៈ តួនាទី ឬអត្តសញ្ញាណជានាម។
   - **ឧទាហរណ៍**៖ 学生**である限り**、図書館を利用できます。
     - *ដរាបណាអ្នកនៅជានិស្សិត អ្នកអាចចូលប្រើប្រាស់បណ្ណាល័យបាន។*
៣. **គុណនាម い + 限り**
   ប្រើជាមួយគុណនាម い ដើម្បីបង្ហាញពីលក្ខខណ្ឌនៃគុណភាព ឬស្ថានភាព។
   - **ឧទាហរណ៍**៖ 体が健康な**限り**（元気である限り）、なんでもできる。
     - *ដរាបណាសុខភាពរាងកាយនៅតែល្អមាំមួន យើងអាចធ្វើអ្វីៗបានទាំងអស់។*
៤. **គុណនាម な + である／な + 限り**
   ប្រើជាមួយគុណនាម な។
   - **ឧទាហរណ៍**៖ 静か**である限り**、ここにいてもいい。
     - *ឱ្យតែនៅស្ងប់ស្ងាត់ អ្នកអាចនៅទីនេះបាន។*

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Nuance Analysis)

នៅក្នុងកម្រិត JLPT N2 វេយ្យាករណ៍ពាក់ព័ន្ធនឹងពាក្យ **限り (Kagiri - ព្រំដែន/ដែនកំណត់)** មានមុខងារសំខាន់ៗចំនួន ៣ ដែលអ្នកសិក្សាត្រូវបែងចែកឱ្យបានច្បាស់លាស់៖

### ក. មុខងារទាំង ៣ នៃ ～限り ក្នុងកម្រិត N2

១. **លក្ខខណ្ឌបន្តឥតដាច់ (Continuous Condition: «ដរាបណា... / ឱ្យតែ...»)**
   - **ទម្រង់**៖ `[Verb-辞書形 / ている / ない] + 限り` ឬ `[Noun / な-Adj] + である限り`
   - **អត្ថន័យ**៖ បង្ហាញថាក្នុងកំឡុងពេល ឬក្នុងដែនកំណត់ដែលស្ថានភាព A នៅតែបន្តកើតមាន នោះស្ថានភាព B ក៏នឹងនៅតែបន្តកើតមានដូចគ្នា។ ប្រសិនបើស្ថានភាព A ប្រែប្រួល នោះ B ក៏នឹងប្រែប្រួលភ្លាមៗដែរ។
   - **ឧទាហរណ៍**៖
     - このチームに**いる限り**、全力を尽くします。
       *(ដរាបណាខ្ញុំនៅតែស្ថិតក្នុងក្រុមនេះ ខ្ញុំនឹងលះបង់ឱ្យអស់ពីកម្លាំងកាយចិត្ត។)*
     - 雨が**降らない限り**、試合は行われます。
       *(ដរាបណាគ្មានភ្លៀងធ្លាក់ទេ ការប្រកួតនឹងដំណើរការតាមការគ្រោងទុក។)*

២. **ដែនកំណត់អតិបរមានៃសមត្ថភាព ឬកម្លាំង (Limit / Extent of Capability: «តាមតែ... / អស់ពី...»)**
   - **ទម្រង់**៖ `[Verb-辞書形 / 可能形] + 限り` ឬ `[Noun] + の限り`
   - **អត្ថន័យ**៖ ធ្វើសកម្មភាពមួយរហូតដល់កម្រិតអតិបរមា ឬព្រំដែនខ្ពស់បំផុតដែលសមត្ថភាព ឬកម្លាំងអាចធ្វើទៅបាន («to the utmost limit / as far as possible»)។
   - **កន្សោមទូទៅដែលនិយមប្រើ**៖
     - **力の限り** (chikara no kagiri)៖ អស់ពីទំហំកម្លាំង
     - **声の限り** (koe no kagiri)៖ ស្រែកអស់ពីទំហំសំឡេង
     - **できる限り** (dekiru kagiri) / **可能な限り** (kanou na kagiri)៖ តាមតែអាចធ្វើទៅបាន / ឱ្យអស់ពីលទ្ធភាព
   - **ឧទាហរណ៍**៖
     - 最後の１秒まで、**力の限り**戦った。
       *(យើងបានតស៊ូប្រយុទ្ធអស់ពីទំហំកម្លាំងកាយរហូតដល់វិនាទីចុងក្រោយ។)*
     - **できる限り**早く返信してください。
       *(សូមឆ្លើយតបឱ្យបានលឿនបំផុតតាមដែលអាចធ្វើទៅបាន។)*

៣. **វិសាលភាពនៃព័ត៌មាន ឬការសង្កេត (Evidential Scope: «តាមដែល... / តាមវិសាលភាពដែល...»)**
   - **ទម្រង់**៖ `[Verb-ている / た / 見る / 聞く / 知る / 調べる] + 限り(では)`
   - **អត្ថន័យ**៖ កំណត់ព្រំដែននៃការវិនិច្ឆ័យ ឬយោបល់របស់អ្នកនិយាយ ដោយបញ្ជាក់ថាការសន្និដ្ឋាននេះពិតត្រឹមតែក្នុងវិសាលភាពនៃព័ត៌មាន ចំណេះដឹង ឬការអង្កេតផ្ទាល់ខ្លួនប៉ុណ្ណោះ («as far as I know / based on my observation» — ហួសពីវិសាលភាពនេះ ខ្លួនមិនហ៊ានធានាឡើយ)។
   - **ឧទាហរណ៍**៖
     - 私が**知っている限りでは**、彼はそんな嘘をつく人ではない。
       *(តាមដែលខ្ញុំដឹង គាត់មិនមែនជាមនុស្សដែលនិយាយកុហកបែបនោះទេ។)*
     - 警察の**調べた限りでは**、事件の手がかりはまだ見つかっていない。
       *(តាមដែលប៉ូលិសបានស៊ើបអង្កេត តម្រុយនៃរឿងក្តីនេះនៅមិនទាន់រកឃើញនៅឡើយទេ។)*

### ខ. ការប្រៀបធៀបរវាង ～限り vs. ～間 (Aida) vs. ～だけ (Dake)

| ចំណុចវេយ្យាករណ៍ | លក្ខណៈពិសេស និងន័យស៊ីជម្រៅ | ឧទាហរណ៍ប្រៀបធៀប |
|---|---|---|
| **～限り (Kagiri)** | **សង្កត់ធ្ងន់លើលក្ខខណ្ឌ និងព្រំដែន (Condition / Boundary)**<br>បង្ហាញពីដែនកំណត់នៃលក្ខខណ្ឌដែលធ្វើឱ្យលទ្ធផលបន្តមានសុពលភាព ឬដែនកំណត់សមត្ថភាពខ្ពស់បំផុត។ បើលក្ខខណ្ឌផ្លាស់ប្តូរ លទ្ធផលនឹងចប់ភ្លាម។ | **君がいる限り**、僕は幸せだ。<br>*(ដរាបណាមានអូននៅក្បែរ បងមានសេចក្តីសុខ។ → បើអូនចាកចេញ សេចក្តីសុខនឹងរលាយបាត់)* |
| **～間 (Aida)** | **សង្កត់ធ្ងន់លើចន្លោះពេលវេលា (Time Duration)**<br>បង្ហាញពីសកម្មភាពស្របគ្នាដែលកើតឡើងក្នុងអំឡុងពេលដែលស្ថានភាពមួយកំពុងដំណើរការ ដោយមិនផ្តោតលើលក្ខខណ្ឌចងភ្ជាប់នោះឡើយ។ | **君がいる間**、僕は部屋を片付ける。<br>*(ក្នុងអំឡុងពេលដែលអូននៅទីនេះ បងនឹងរៀបចំបន្ទប់។ → ផ្តោតតែលើកាលវេលា)* |
| **～だけ (Dake)** | **សង្កត់ធ្ងន់លើបរិមាណ ឬកម្រិតសមភាព (Extent / Quantity / Cap)**<br>ផ្តោតលើការបំពេញសកម្មភាពទៅតាមកម្រិតចំណង់ ឬបរិមាណដែលអាចធ្វើបាន (`V-たいだけ` = តាមតែចង់, `できるだけ` = ឱ្យអស់ពីលទ្ធភាព) ប៉ុន្តែគ្មានអត្ថន័យជា «លក្ខខណ្ឌបន្ត (as long as)» ដូច `限り` ឡើយ។ | **好きなだけ**食べてください。<br>*(សូមពិសាតាមតែការចូលចិត្ត / ឱ្យអស់ចិត្តចុះ។)* |

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)
### ប្រយោគគំរូ (Sentence Examples)
#### ឧទាហរណ៍ ១
- **日本にいる限り、日本語を使う機会が多い。**
  - *ដរាបណាយើងនៅប្រទេសជប៉ុន ឱកាសក្នុងការប្រើប្រាស់ភាសាជប៉ុនគឺមានច្រើន។*
#### ឧទាហរណ៍ ២

  - *តាមដែលខ្ញុំដឹង គាត់គឺជាមនុស្សម៉ត់ចត់និងស្មោះត្រង់ម្នាក់។*
#### ឧទាហរណ៍ ៣
- **雨が降らない限り、試合は予定通り行われます。**
  - *ដរាបណាគ្មានភ្លៀងធ្លាក់ ការប្រកួតនឹងប្រព្រឹត្តទៅតាមកាលវិភាគដែលបានគ្រោងទុក។*
#### ឧទាហរណ៍ ៤
- **法律が許す限り、この計画を進めたい。**
  - *ដរាបណាច្បាប់នៅតែអនុញ្ញាត ខ្ញុំចង់បន្តអនុវត្តផែនការនេះទៅមុខទៀត។*
#### ឧទាហរណ៍ ៥
- **体力が続く限り、走り続ける。**
  - *ដរាបណាកម្លាំងកាយនៅតែទ្រាំទ្របាន ខ្ញុំនឹងបន្តរត់ទៅមុខទៀត។*

## ៥. កំណត់សម្គាល់វប្បធម៌ (Cultural Notes)
### ទំនាក់ទំនងវប្បធម៌ (Cultural Relevance)
- នៅក្នុងវប្បធម៌ជប៉ុន ការកំណត់លក្ខខណ្ឌ និងព្រំដែនដោយប្រើពាក្យសំដីគួរសមមានសារៈសំខាន់ខ្លាំងណាស់ក្នុងការរក្សាសុខដុមរមនា (和 - Wa) ក្នុងទំនាក់ទំនងសង្គម។
- **～限り** អនុញ្ញាតឱ្យអ្នកនិយាយកំណត់ព្រំដែន ឬវិសាលភាពនៃការទទួលខុសត្រូវ និងការសន្យារបស់ខ្លួនបានយ៉ាងច្បាស់លាស់ ដោយមិនបញ្ចេញឥរិយាបថរឹងត្អឹង ឬប្រឈមមុខដាក់គ្នាដោយផ្ទាល់ឡើយ។ ឧទាហរណ៍ ការប្រើ `私の知る限りでは` (តាមដែលខ្ញុំដឹង...) បង្ហាញពីភាពបន្ទាបខ្លួន និងការប្រុងប្រយ័ត្នថាយោបល់របស់ខ្លួនផ្អែកលើព័ត៌មានមានកម្រិត មិនមែនជាការអះអាងដាច់ខាតឡើយ។

### កម្រិតគួរសម និងផ្លូវការ (Levels of Politeness and Formality)
- វេយ្យាករណ៍ **～限り** ខ្លួនឯងមានកម្រិតកណ្តាល (Neutral)។
- កម្រិតគួរសមត្រូវបានកំណត់ដោយកិរិយាសព្ទបញ្ចប់ប្រយោគ និងការប្រើប្រាស់ពាក្យគួរសម (敬語 - Keigo)៖
  - **ផ្លូវការ (Formal)**៖ ប្រើជាមួយទម្រង់ です・ます ឬពាក្យលើកតម្កើង/បន្ទាបខ្លួន (尊敬語・謙譲語)។
  - **ស្និទ្ធស្នាល (Informal)**៖ ប្រើជាមួយទម្រង់ធម្មតា (Plain form)។

### កន្សោមទូទៅដែលពេញនិយម (Idiomatic Expressions)
- **私の知る限り (watashi no shiru kagiri)**៖ *តាមដែលខ្ញុំដឹង*
- **見た限りでは (mita kagiri de wa)**៖ *តាមដែលបានឃើញ*
- **聞く限りでは (kiku kagiri de wa)**៖ *តាមដែលបានឮមក*
- **できる限りの努力 (dekiru kagiri no doryoku)**៖ *ការខិតខំប្រឹងប្រែងអស់ពីលទ្ធភាពដែលអាចធ្វើទៅបាន*

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)
### ការវិភាគកំហុស (Error Analysis)
១. **ការប្រើប្រាស់ទម្រង់តភ្ជាប់ខុសចំពោះនាម**
   - **ខុស**៖ 学生**が**ある限り、勉強を続けます。
   - **ត្រូវ**៖ 学生**である限り**、勉強を続けます。
     - *ដរាបណាខ្ញុំនៅជានិស្សិត ខ្ញុំនឹងបន្តការសិក្សា។ (នាមត្រូវប្រើ である限り)*
២. **ការច្រឡំរវាង ～間 និង ～限り**
   - **កំហុស**៖ ការប្រើ **～間** ជំនួសឱ្យ **～限り** នៅពេលចង់បង្ហាញពីលក្ខខណ្ឌកំណត់។
     - **ខុស**៖ 雨が降らない**間**、試合をします。
     - **ត្រូវ**៖ 雨が降らない**限り**、試合をします。
       - *ដរាបណាគ្មានភ្លៀងធ្លាក់ ការប្រកួតនឹងបន្តដំណើរការ។*
៣. **ការច្រឡំទម្រង់អវិជ្ជមាន ～ない限り (Nai kagiri)**
   - `Verb-ない限り` មានន័យស្មើនឹង «ប្រសិនបើមិន... ទេនោះ គឺ... មិនអាចទៅរួចឡើយ» (Unless...)។ ប្រយោគខាងក្រោយច្រើនតែជាទម្រង់អវិជ្ជមាន ឬការហាមឃាត់។
     - ឧទាហរណ៍៖ パスポートを**見せない限り**、入国できません。*(បើមិនបង្ហាញលិខិតឆ្លងដែនទេ គឺមិនអាចចូលប្រទេសបានឡើយ។)*

### យុទ្ធសាស្ត្រនៃការរៀន (Learning Strategies)
- **គន្លឹះចងចាំតាមអត្ថន័យពាក្យ (Mnemonic Device)**
  - ពាក្យ **限り (Kagiri)** មានប្រភពមកពីកិរិយាសព្ទ **限る (Kakiru - កំណត់ព្រំដែន)**។ ចូរសម្គាល់ថា ឱ្យតែឃើញ `限り` គឺមានន័យទាក់ទងនឹង «ព្រំដែន / ដែនកំណត់» ជានិច្ច មិនថាជាដែនកំណត់ពេលវេលា លក្ខខណ្ឌ ឬសមត្ថភាពនោះឡើយ។
- **អនុវត្តជាមួយឃ្លាដែលប្រើញឹកញាប់**
  - ចូរទន្ទេញចាំមាត់នូវឃ្លាប្រចាំថ្ងៃដូចជា **私の知る限りでは** (តាមដែលខ្ញុំដឹង) និង **できる限り** (ឱ្យអស់ពីលទ្ធភាព) ដើម្បីប្រើប្រាស់វេយ្យាករណ៍នេះឱ្យមានភាពរលូន។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)
### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～限り** បង្ហាញពីលក្ខខណ្ឌ ឬវិសាលភាពដែនកំណត់ ដែលមានន័យថា «ដរាបណា...» «តាមតែ...» ឬ «អស់ពី...»។
- ទម្រង់តភ្ជាប់ប្រែប្រួលតាមប្រភេទពាក្យ៖ កិរិយាសព្ទប្រើទម្រង់ធម្មតា, នាមប្រើ `である限り`, គុណនាម な ប្រើ `な / である限り`។
- ក្នុងកម្រិត JLPT N2 វាមានមុខងារសំខាន់ ៣៖ (១) លក្ខខណ្ឌបន្ត, (២) ដែនកំណត់អតិបរមានៃកម្លាំង/សមត្ថភាព (`力の限り`, `できる限り`), និង (៣) វិសាលភាពនៃការដឹង/អង្កេត (`知る限りでは`)។

### កម្រងសំណួររំលឹកឡើងវិញខ្លីៗ (Quick Recap Quiz)
១. **ចូរជ្រើសរើសចម្លើយត្រឹមត្រូវដើម្បីបំពេញចន្លោះ៖**
   雨が降らない____、試合は中止になりません。
   a) 間  
   b) 限り  
   c) まで  

២. **ពិត ឬ មិនពិត (True or False):**
   **～限り** អាចប្រើប្រាស់ដើម្បីបង្ហាញទាំងលក្ខខណ្ឌបន្ត (Conditional limit) និងវិសាលភាពអតិបរមានៃសមត្ថភាព (Limit of capability)។

---
### ចម្លើយ (Answers)
១. **b) 限り**
   雨が降らない**限り**、試合は中止になりません。
   *(ដរាបណាគ្មានភ្លៀងធ្លាក់ ការប្រកួតនឹងមិនត្រូវលុបចោលឡើយ។)*
២. **ពិត (True)**
   **～限り** មិនត្រឹមតែបង្ហាញពីលក្ខខណ្ឌបន្ត «ដរាបណា» ប៉ុណ្ណោះទេ ប៉ុន្តែថែមទាំងបង្ហាញពីកម្រិតអតិបរមាដូចជា `力の限り` (អស់ពីកម្លាំង) ឬ `できる限り` (ឱ្យអស់ពីលទ្ធភាព) ផងដែរ។
