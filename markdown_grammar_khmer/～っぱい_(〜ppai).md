# ចំណុចវេយ្យាករណ៍ជប៉ុន: ～っぽい (〜ppai / 〜ppoi)
**កម្រិត JLPT:** JLPT N3

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងមេរៀននេះ យើងនឹងសិក្សាអំពីចំណុចវេយ្យាករណ៍ភាសាជប៉ុន **～っぽい (〜ppoi / 〜ppai)**។ បច្ច័យ (suffix) នេះត្រូវបានប្រើប្រាស់ជាទូទៅក្នុងការពិពណ៌នាអំពីអ្វីមួយដែលមានលក្ខណៈ ឬមានទំនោរទៅរកអ្វីមួយ ស្រដៀងគ្នានឹងពាក្យ "-ish" ឬ "like" ក្នុងភាសាអង់គ្លេស ឬមានន័យជាភាសាខ្មែរថា **«រាងដូច... / មានចរិតដូច... / ងាយនឹង... / ឆាប់... / ធុំក្លិន... / ហាក់ដូច...»**។ ការយល់ដឹងច្បាស់អំពីរបៀបប្រើ **～っぽい** នឹងជួយឱ្យអ្នកអាចបង្ហាញនូវកម្រិតន័យស៊ីជម្រៅ (nuances) ក្នុងការពិពណ៌នារូបរាង លក្ខណៈខាងក្រៅ និងបុគ្គលិកលក្ខណៈរបស់មនុស្សបានយ៉ាងត្រឹមត្រូវ និងរលូន។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
**～っぽい** ត្រូវបានភ្ជាប់នៅពីក្រោយនាម, គុណនាម, និងកិរិយាសព្ទ ដើម្បីបង្ហាញថា៖
- **មានលក្ខណៈ ឬចរិតលក្ខណៈស្រដៀងនឹងអ្វីមួយផ្សេងទៀត** (ទាំងដែលធាតុពិតមិនមែនជារបស់នោះ)។
- **មានទំនោរងាយនឹងបង្ហាញឥរិយាបថ ឬសកម្មភាពអ្វីមួយ** (ឧ. ឆាប់ខឹង, ភ្លេចភ្លាំងច្រើន)។
- **មានរូបរាង លក្ខណៈ ឬចំណាប់អារម្មណ៍ហាក់ដូចជាបែបនោះ** (ច្រើនផ្អែកលើការយល់ឃើញ និងចំណាប់អារម្មណ៍ផ្ទាល់ខ្លួន ជាជាងការពិតជាក់ស្តែង)។
- បន្ទាប់ពីភ្ជាប់រួច ពាក្យដែលកើតចេញពី **～っぽい** នឹងដើរតួជា **គុណនាម い (い-adjective)** (ឧ. っぽくない, っぽかった, っぽく見える)។

### ទម្រង់ផ្សំ (Structure)
ការផ្សំនៃ **～っぽい** អាស្រ័យទៅលើប្រភេទពាក្យដែលវាតភ្ជាប់ជាមួយ៖

| ប្រភេទពាក្យ (Word Type) | ទម្រង់ផ្សំ (Formation) | ឧទាហរណ៍ (Example) |
|---|---|---|
| **នាម (Noun)** | នាម + っぽい | 子供 (ក្មេង) ➔ 子供っぽい (កូនក្មេង / រាងកូនក្មេង) |
| **កិរិយាសព្ទ (Verb Stem)** | កិរិយាសព្ទ ទម្រង់ ます (កាត់ ます ចោល) + っぽい | 忘れます ➔ 忘れっぽい (ឆាប់ភ្លេច / ភ្លេចច្រើន) |
| **គុណនាម い (い-Adj Stem)** | គុណនាម い (កាត់ い ចោល) + っぽい | 安い (ថោក) ➔ 安っぽい (មើលទៅរាងថោក / គ្មានតម្លៃ) |
| **គុណនាម な (な-Adj Stem)** | គុណនាម な (កាត់ な ចោល) + っぽい | 派手な (ឆើតឆាយ) ➔ 派手っぽい (រាងឆើតឆាយ) |

*ចំណាំចំពោះពណ៌:* ពណ៌មួយចំនួនត្រូវបានប្រើជាមួយ っぽい ញឹកញាប់ ដូចជា 白っぽい (រាងស / ស្រដៀងពណ៌ស), 黒っぽい (រាងខ្មៅ / ខ្មៅស្រអាប់), 赤っぽい (រាងក្រហម)។

### ដ្យាក្រាមទម្រង់ (Formation Diagram)
```
[ នាម / កិរិយាសព្ទ (Verb Stem) / គុណនាម (Adj Stem) ] + っぽい
```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Deep Nuances)

### ការប្រៀបធៀបរវាង **～っぽい** vs. **～らしい** vs. **～みたい**

| ចំណុចវេយ្យាករណ៍ | ការប្រើប្រាស់ និងកម្រិតន័យស៊ីជម្រៅ (Usage & Nuance) | ឧទាហរណ៍ប្រៀបធៀប | ន័យស្តែងចេញ |
|---|---|---|---|
| **～っぽい** | • សំដៅលើការយល់ឃើញផ្ទាល់ខ្លួន (Subjective impression) ថាមានលក្ខណៈដូចអ្វីមួយ。<br>• **ធាតុពិតមិនមែនជារបស់នោះទេ** (ឧ. មនុស្សចាស់តែធ្វើចរិតដូចក្មេង)។<br>• ច្រើនបង្កប់ **ន័យអវិជ្ជមាន ឬការរិះគន់** (Negative connotation)។<br>• បង្ហាញពីទំនោរចរិត (ងាយនឹងធ្វើអ្វីមួយ)។ | **子供っぽい**<br>(កូនក្មេង / childish) | មនុស្សធំ ឬយុវជន ប៉ុន្តែមានចរិត ឬអាកប្បកិរិយាមិនទាន់ចាស់ទុំដូចក្មេង (បង្កប់ន័យរិះគន់)។ |
| **～らしい** | • បង្ហាញពី **លក្ខណៈពិតប្រាកដ ឬធាតុពិតដ៏ស័ក្តិសម** ដែលគួរតែមានតាមធម្មជាតិ (True nature / Ideal essence)។<br>• **ធាតុពិតគឺជាវត្ថុ ឬបុគ្គលនោះមែន** (ឧ. ក្មេងធ្វើខ្លួនសមជាក្មេង)។<br>• បង្កប់ **ន័យវិជ្ជមាន និងការសរសើរ** (Positive / Praiseworthy)។ | **子供らしい**<br>(សមជាក្មេង / childlike) | កុមារដែលមានភាពស្លូតត្រង់ រីករាយ និងលេងច្រើន ស័ក្តិសមទៅនឹងវ័យកុមារពិតៗ (ន័យសរសើរ)។ |
| **～みたい** | • ប្រើសម្រាប់ **ការប្រៀបធៀបរូបរាងខាងក្រៅសុទ្ធសាធ (Simile / Appearance)**។<br>• មានន័យថា «ដូចជា...» ដោយមើលទៅឃើញស្រដៀង ឬដូចបេះបិទ។<br>• អាចប្រើទាំងចំពោះមនុស្ស និងវត្ថុទូទៅ ដោយគ្មានបង្កប់ន័យអវិជ្ជមានជាក់លាក់ឡើយ។ | **子供みたい**<br>(ដូចក្មេង / like a child) | មើលទៅដូចកូនក្មេង (ឧ. មុខដូចក្មេង រូបរាងតូចដូចក្មេង ឬគេងលក់ដូចកូនក្មេង)។ |

### ចំណុចសំខាន់បន្ថែមអំពីទំនោរនៃកិរិយាសព្ទ (Tendency / Prone to)
នៅពេលភ្ជាប់ជាមួយ **កិរិយាសព្ទ Stem (Stem + っぽい)** វាមិនមែនមានន័យថា "មើលទៅដូច" ទៀតទេ ប៉ុន្តែមានន័យថា **«មានទំនោរងាយនឹង... / ឆាប់... / ញឹកញាប់...»** ដែលភាគច្រើនជាទម្លាប់ ឬចរិតមិនសូវល្អ (ឧទាហរណ៍៖ 怒りっぽい = ឆាប់ខឹង/កំហឹងច្រើន, 忘れっぽい = ឆាប់ភ្លេច/ភ្លេចច្រើន, 飽きっぽい = ឆាប់ធុញ/គ្មានការអត់ធ្មត់)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទ (Examples in Context)

### ឧទាហរណ៍ ១
- **ភាសាជប៉ុន:** 彼は忘れっぽいので、メモを取ります。
- **រ៉ូម៉ាជី:** Kare wa wasureppoi node, memo o torimasu.
- **ភាសាខ្មែរ:** គាត់ជាមនុស្សឆាប់ភ្លេចភ្លាំងច្រើន ដូច្នេះហើយគាត់តែងតែកត់ត្រាទុក។

### ឧទាហរណ៍ ២
- **ភាសាជប៉ុន:** この服は安っぽく見える。
- **រ៉ូម៉ាជី:** Kono fuku wa yasuppoku mieru.
- **ភាសាខ្មែរ:** ខោអាវនេះមើលទៅរាងថោក (គ្មានតម្លៃ)។

### ឧទាហរណ៍ ៣
- **ភាសាជប៉ុន:** 最近、怒りっぽくなってきた。
- **រ៉ូម៉ាជី:** Saikin, okorippoku natte kita.
- **ភាសាខ្មែរ:** មួយរយៈចុងក្រោយនេះ ខ្ញុំហាក់ដូចជាឆាប់ខឹងមួម៉ៅខ្លាំងណាស់។

### ឧទាហរណ៍ ៤
- **ភាសាជប៉ុន:** 彼女の話し方は男っぽい。
- **រ៉ូម៉ាជី:** Kanojo no hanashikata wa otokoppoi.
- **ភាសាខ្មែរ:** របៀបនិយាយរបស់នាងរាងដូចមនុស្សប្រុស (មានចរិតដូចប្រុសៗ)។

### ឧទាហរណ៍ ៥
- **ភាសាជប៉ុន:** あの人は飽きっぽい性格です。
- **រ៉ូម៉ាជី:** Ano hito wa akippoi seikaku desu.
- **ភាសាខ្មែរ:** មនុស្សម្នាក់នោះមានចរិតឆាប់ធុញទ្រាន់ណាស់ (មិនសូវចេះអត់ធ្មត់ធ្វើអ្វីបានយូរទេ)។

## ៥. ចំណាំវប្បធម៌ និងការប្រើប្រាស់ (Cultural Notes)

### កម្រិតគួរសម និងការប្រើប្រាស់ (Politeness & Formality)
- **～っぽい** ត្រូវបានប្រើប្រាស់ជាទូទៅនៅក្នុង **ការសន្ទនាប្រចាំថ្ងៃ និងបរិបទក្រៅផ្លូវការ (Casual / Spoken Japanese)**។ មិនស័ក្តិសមសម្រាប់ប្រើក្នុងលិខិតផ្លូវការ ឬការសន្ទនាបែបធុរកិច្ចឡើយ។
- ជាញឹកញាប់ វាបង្កប់នូវ **ន័យអវិជ្ជមាន (Negative connotation)** ដោយបង្ហាញពីភាពមិនទាន់ចាស់ទុំ ភាពមិនល្អឥតខ្ចោះ ឬទំនោរអវិជ្ជមានណាមួយ។ ដូច្នេះ គួរបង្ការកុំប្រើវាពិពណ៌នាចំពោះចៅហ្វាយនាយ ឬមនុស្សចាស់ជាង។

### កន្សោមពាក្យពេញនិយម (Idiomatic Expressions)
- **女っぽい (onnappoi):** ដូចមនុស្សស្រី / ទន់ភ្លន់រាងនារី (ច្រើនប្រើពិពណ៌នាអំពីបុរសដែលមានចរិត ឬកាយវិការដូចមនុស្សស្រី)។
- **古っぽい (furuppoi):** មើលទៅរាងចាស់ / បុរាណ / ហួសសម័យ។
- **水っぽい (mizuppoi):** រាវ / មានជាតិទឹកច្រើន / សាប (ដូចជាម្ហូបដែលខ្វះរសជាតិ ធ្លាយទឹកច្រើន)។
- **油っぽい / 脂っぽい (aburappoi):** ឡើងខ្លាញ់ / ខ្លាញ់ច្រើន / ធុញទ្រាន់ជាតិប្រេង។
- **熱っぽい (netsuppoi):** ស្រៀវស្រាញខ្លួន / ហាក់ដូចចង់ក្តៅខ្លួន។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
- **កំហុស:** ប្រើច្រឡំរវាង **～っぽい** និង **～らしい** ដោយមិនបានគិតដល់កម្រិតន័យស៊ីជម្រៅ (nuance)។
  - *ខុស:* 田中さんは先生っぽい。(ប្រសិនបើតាណាកាពិតជាគ្រូបង្រៀនមែន ហើយអ្នកចង់សរសើរថាគាត់មានបុគ្គលិកលក្ខណៈស័ក្តិសមជាគ្រូ នោះមិនត្រូវប្រើ っぽい ឡើយ)
  - *កែតម្រូវ:* 田中さんは**先生らしい**。(លោកតាណាកាពិតជាស័ក្តិសមជាគ្រូបង្រៀនមែន)។ ចូរចាំថា **～っぽい** ផ្អែកលើចំណាប់អារម្មណ៍ផ្ទាល់ខ្លួន និងច្រើនបង្កប់ **គុណវិបត្តិ ឬន័យរិះគន់** ចំណែកឯ **～らしい** បង្ហាញថាមនុស្ស ឬវត្ថុនោះមានគុណសម្បត្តិដ៏ល្អស័ក្តិសមទៅនឹងឋានៈ ឬធម្មជាតិពិតរបស់ខ្លួន។

### យុទ្ធសាស្ត្ររៀនសូត្រ (Learning Strategies)
- **គន្លឹះចងចាំ:** ចូរគិតថា **～っぽい** ស្មើនឹងកន្ទុយពាក្យ **"-ish"** ក្នុងភាសាអង់គ្លេស។ ឧទាហរណ៍ ការបែងចែករវាង "childish" (កូនក្មេង គ្មានការគិត - 子供っぽい) និង "childlike" (បរិសុទ្ធសមជាក្មេង - 子供らしい) នឹងជួយឱ្យអ្នកយល់យ៉ាងច្បាស់អំពីភាពខុសគ្នារវាង **子供っぽい** និង **子供らしい**។
- **ការអនុវត្ត:** សាកល្បងបង្កើតប្រយោគដោយប្រើ **～っぽい** ដើម្បីពិពណ៌នាអំពីទំនោរផ្ទាល់ខ្លួន (ឧ. ឆាប់ខឹង ឆាប់ភ្លេច) ឬពណ៌នារូបរាងសម្ភារៈជុំវិញខ្លួនអ្នក។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～っぽい** ប្រើដើម្បីបង្ហាញថាអ្វីមួយ **មានលក្ខណៈដូច**, **មានទំនោរងាយនឹង...**, ឬ **មើលទៅហាក់ដូចជា** អ្វីមួយ។
- វាអាចភ្ជាប់ជាមួយ **នាម**, **កិរិយាសព្ទ (Verb stem)**, និង **គុណនាម (Adj stem)**។
- ត្រូវប្រុងប្រយ័ត្នចំពោះ **ន័យអវិជ្ជមាន (Negative connotation)** ដែលបង្កប់នៅក្នុងពាក្យនេះ។
- ចេះបែងចែកឱ្យច្បាស់រវាង **～っぽい** (រាងដូច/មានចរិតដូច [ធាតុពិតមិនមែន/រិះគន់]), **～らしい** (ស័ក្តិសមជា [ធាតុពិតមែន/សរសើរ]), និង **～みたい** (ដូចជា [ការប្រៀបធៀបរូបរាងខាងក្រៅ])។

### សំណួររំលឹកឡើងវិញខ្លីៗ (Quick Recap Quiz)
១. តើការប្រើប្រាស់ចម្បងរបស់ **～っぽい** គឺជាអ្វី?  
២. តើ **子供っぽい** និង **子供らしい** មានអត្ថន័យខុសគ្នាយ៉ាងដូចម្តេចខ្លះ?  
៣. ចូរបង្កើតប្រយោគមួយដោយប្រើ **～っぽい** ដើម្បីពិពណ៌នាអំពីមនុស្សម្នាក់ដែលឆាប់ភ្លេចភ្លាំង។

**ចម្លើយ:**  
១. ប្រើដើម្បីបង្ហាញថាអ្វីមួយមានលក្ខណៈ ឬទំនោរដូចអ្វីមួយផ្សេងទៀត ដោយផ្អែកលើចំណាប់អារម្មណ៍ និងការយល់ឃើញផ្ទាល់ខ្លួន។  
២. **子供っぽい** មានន័យថា "កូនក្មេង / childish" ជាមួយសំឡេងបង្កប់ន័យអវិជ្ជមាន (មនុស្សធំតែចរិតក្មេង) រីឯ **子供らしい** មានន័យថា "សមជាក្មេង / childlike" ក្នុងន័យវិជ្ជមាន និងស័ក្តិសមតាមធម្មជាតិរបស់កុមារ។  
៣. ឧទាហរណ៍ចម្លើយ: 彼は忘れっぽいから、注意が必要だ。(ដោយសារតែគាត់ជាមនុស្សឆាប់ភ្លេចភ្លាំង ដូច្នេះចាំបាច់ត្រូវតែប្រយ័ត្នប្រយែង។)
