# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ ～ても (〜temo)
**កម្រិត JLPT:** JLPT N3

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ **～ても (〜temo)** ឬ **～でも (〜demo)** គឺជាកន្សោមវេយ្យាករណ៍ដ៏សំខាន់ និងសម្បូរបែបមួយក្នុងភាសាជប៉ុន ដែលមានន័យស្មើនឹង «ទោះបីជា... ក៏ដោយ / ទោះជា... ក៏ដោយ / ទោះ... ក៏» (even if / even though / no matter...)។ វាត្រូវបានប្រើសម្រាប់បង្ហាញអំពីលក្ខខណ្ឌផ្ទុយ (concessive condition) ដោយបញ្ជាក់ថាលទ្ធផល ឬអង្គហេតុនៅក្នុងឃ្លាស្នូល (main clause) នៅតែបន្តកើតឡើង ឬមិនមានការប្រែប្រួលឡើយ ទោះបីជាមានលក្ខខណ្ឌ ឬស្ថានភាពដែលបានលើកឡើងនៅខាងដើមក៏ដោយ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **អត្ថន័យជាភាសាខ្មែរ**៖ «ទោះបីជា... ក៏ដោយ», «ទោះបីជា... ក៏ដោយ ក៏នៅតែ...», «ទោះជា... យ៉ាងណាក៏ដោយ»
- **ការប្រើប្រាស់**៖ ប្រើដើម្បីបង្ហាញថាលទ្ធផលមិនរងឥទ្ធិពល ឬមិនប្រែប្រួលដោយសារលក្ខខណ្ឌខាងដើមនោះឡើយ។

### ទម្រង់ផ្សំ (Structure)
ការផ្សំទម្រង់ **～ても / ～でも** អាស្រ័យលើប្រភេទថ្នាក់ពាក្យ (កិរិយាសព្ទ, គុណនាម, ឬនាម)។

#### តារាងនៃការផ្សំទម្រង់ (Formation Table)
| ថ្នាក់ពាក្យ (Part of Speech) | ការបំប្លែងទម្រង់ (Stem Modification) | ទម្រង់បញ្ចប់ (+ ても / でも) | ឧទាហរណ៍ (Example) |
|---|---|---|---|
| **កិរិយាសព្ទ (Verb)** | **ទម្រង់ て (Te-form)** | + **も** | 行く → 行って + も → **行っても** |
| | **ទម្រង់បដិសេធ ない** → **なくて** | + **も** | 行かない → 行かなくて + も → **行かなくても** |
| **គុណនាម い (い-Adjective)** | កាត់ **い** ចេញ ជំនួសដោយ **くて** | + **も** | 高い → 高くて + も → **高くても** |
| | បដិសេធ៖ **〜くなくて** | + **も** | 高くない → 高くなくて + も → **高くなくても** |
| **គុណនាម な (な-Adjective)** | ឫសគុណនាម (កាត់ **な** ចេញ) | + **でも** | 静か[な] → **静かでも** |
| | បដិសេធ៖ **〜ではなくて / じゃなくて** | + **も** | 静かじゃない → **静かじゃなくても** |
| **នាម (Noun)** | **នាម** ផ្ទាល់ | + **でも** | 雨 → **雨でも** |
| | បដិសេធ៖ **〜ではなくて / じゃなくて** | + **も** | 日曜日じゃない → **日曜日じゃなくても** |

*(ចំណាំ៖ ចំពោះកិរិយាសព្ទដែលទម្រង់ て បញ្ចប់ដោយ **で** ដូចជា 飲む → 飲んで នោះត្រូវបន្ថែម **も** ក្លាយជា **飲んでも (nondemo)**)*។

### របៀបនៃការបង្កើតទម្រង់លម្អិត (How to Form)
1. **កិរិយាសព្ទ (Verbs)**
   - បំប្លែងកិរិយាសព្ទទៅជា **ទម្រង់ て (te-form)** រួចបន្ថែម **も**។
   - ឧទាហរណ៍៖
     - **行く** (iku - ទៅ) → **行って** (itte) + **も** → **行っても** (ittemo: ទោះបីជាទៅក៏ដោយ)
     - **食べる** (taberu - ញ៉ាំ) → **食べて** (tabete) + **も** → **食べても** (tabetemo: ទោះបីជាញ៉ាំក៏ដោយ)
     - **飲む** (nomu - ផឹក) → **飲んで** (nonde) + **も** → **飲んでも** (nondemo: ទោះបីជាផឹកក៏ដោយ)
2. **គុណនាម い (い-Adjectives)**
   - បំប្លែងគុណនាម い ទៅជាទម្រង់ て ដោយលុប **い** ចេញ រួចជំនួសដោយ **くて** ហើយបន្ថែម **も**។
   - ឧទាហរណ៍៖
     - **高い** (takai - ថ្លៃ) → **高くて** (takakute) + **も** → **高くても** (takakutemo: ទោះបីជាថ្លៃក៏ដោយ)
     - **いい / よい** (ii / yoi - ល្អ) → **よくて** (yokute) + **も** → **よくても** (yokutemo: ទោះបីជាល្អក៏ដោយ)
3. **គុណនាម な និង នាម (な-Adjectives and Nouns)**
   - បន្ថែម **でも** ដោយផ្ទាល់បន្ទាប់ពីនាម ឬបន្ទាប់ពីឫសនៃគុណនាម な (ដោយមិនបាច់មាន な ឡើយ)។
   - ឧទាហរណ៍៖
     - **静か** (shizuka - ស្ងប់ស្ងាត់) → **静かでも** (shizukademo: ទោះបីជាស្ងប់ស្ងាត់ក៏ដោយ)
     - **雨** (ame - ភ្លៀង) → **雨でも** (amedemo: ទោះបីជាភ្លៀងធ្លាក់ក៏ដោយ)

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuance)

ក្នុងកម្រិត JLPT N3 ការយល់ដឹងអំពីលក្ខខណ្ឌសម្បទាន (Concessive Condition - «ទោះបីជា... ក៏ដោយ») មានសារៈសំខាន់ខ្លាំងណាស់។ ខាងក្រោមនេះជាការវិភាគស៊ីជម្រៅលើការប្រើប្រាស់ គូកន្សោមគុណកិរិយា និងការប្រៀបធៀបជាមួយទម្រង់ស្រដៀងគ្នា៖

### ក. ការផ្គួបគូជាមួយគុណកិរិយាបញ្ជាក់ន័យ (Paired Adverbs / 呼応表現)
ក្នុងកម្រិត N3 ទម្រង់ `〜ても / 〜でも` តែងតែដើរទន្ទឹមគ្នាជាមួយគុណកិរិយាជាក់លាក់ ដើម្បីបញ្ជាក់ទម្ងន់ន័យសម្បទានឲ្យកាន់តែច្បាស់៖
1. **たとえ (Tatoe) 〜 ても / でも** («ទោះបីជាឧបមាថា... ក៏ដោយ / ទោះបីជា... យ៉ាងណាក៏ដោយ»)
   - សង្កត់ធ្ងន់លើការសន្មត ឬឧបមាស្ថានភាពមួយដ៏ធ្ងន់ធ្ងរ ឬអាក្រក់ជាមុន ប៉ុន្តែលទ្ធផលនៅតែដដែល។
   - *ឧទាហរណ៍*៖ **たとえ**両親に反対され**ても**、私は彼と結婚します。(ទោះបីជាត្រូវឪពុកម្តាយជំទាស់យ៉ាងណាក៏ដោយ ក៏ខ្ញុំនៅតែរៀបការជាមួយគាត់ដែរ។)
2. **いくら (Ikura) 〜 ても / でも** («ទោះជា... ប៉ុនណា/កម្រិតណា/យ៉ាងណាក៏ដោយ»)
   - បង្ហាញអំពីបរិមាណ កម្រិត ឬការខិតខំប្រឹងប្រែងធ្វើម្តងហើយម្តងទៀត តែលទ្ធផលមិនប្រែប្រួល។
   - *ឧទាហរណ៍*៖ **いくら**頼まれ**ても**、それは引き受けられない。(ទោះបីជាត្រូវបានគេសុំអង្វរប៉ុនណាក៏ដោយ ក៏ខ្ញុំមិនអាចទទួលធ្វើរឿងនោះបានដែរ។)
3. **どんなに (Donna ni) / どう (Dou) 〜 ても / でも** («ទោះជា... ដល់កម្រិតណា/យ៉ាងណាក៏ដោយ»)
   - សង្កត់ធ្ងន់លើកម្រិតនៃគុណនាម ឬវិធីសាស្ត្រ។
   - *ឧទាហរណ៍*៖ **どんなに**辛く**ても**、最後まで諦めない。(ទោះបីជាលំបាកវេទនាដល់កម្រិតណាក៏ដោយ ក៏មិនបោះបង់រហូតដល់ទីបញ្ចប់។)

### ខ. ការប្រៀបធៀប៖ ～ても vs. ～のに
| ចំណុចប្រៀបធៀប | ～ても / ～でも | ～のに |
|---|---|---|
| **លក្ខណៈនៃលក្ខខណ្ឌ** | **លក្ខខណ្ឌសន្មត ឬទូទៅ (Hypothetical / General Concession)** | **អង្គហេតុពិតជាក់ស្តែង (Actual / Realized Fact)** |
| **អត្ថន័យ** | «ទោះបីជា (ប្រសិនបើ)... ក៏ដោយ» (សង្កត់លើលទ្ធផលមិនប្រែប្រួល) | «ទាំងដែល... / សោះតែ... បែរជា...» (សង្កត់លើការផ្ទុយពីការរំពឹងទុក) |
| **អារម្មណ៍របស់អ្នកនិយាយ** | មិនបង្ហាញការខកចិត្តផ្ទាល់ខ្លួនទេ (បង្ហាញការតាំងចិត្ត ឬការពិតធម្មតា) | បង្កប់នូវអារម្មណ៍ **មិនពេញចិត្ត ខកចិត្ត ភ្ញាក់ផ្អើល ឬស្តីបន្ទោស** |
| **ឃ្លាខាងក្រោយ (Main clause)** | អាចប្រើប្រយោគបញ្ជា សំណូមពរ ការតាំងចិត្ត ឬអនាគតកាលបាន (〜てください, 〜つもりだ, 〜う) | មិនអាចប្រើប្រយោគបញ្ជា ឬសំណូមពរបានឡើយ (ត្រូវតែជាអង្គហេតុពិត) |
| **ឧទាហរណ៍ប្រៀបធៀប** | **雨が降っても、行きます。**<br>(ទោះបីជាភ្លៀងធ្លាក់ ក៏ខ្ញុំនៅតែទៅដែរ។ ➔ ការតាំងចិត្ត) | **雨が降っているのに、傘をささない。**<br>(ទាំងដែលកំពុងភ្លៀងសោះ បែរជាមិនព្រមបាំងឆត្រទៅវិញ។ ➔ ភ្ញាក់ផ្អើល/ស្តីបន្ទោស) |

### គ. ការប្រៀបធៀប៖ ～ても vs. ～たら
- **～ても (ទោះជា... ក៏ដោយ)**៖ ជាលក្ខខណ្ឌសម្បទាន ដែលបញ្ជាក់ថាលទ្ធផលចុងក្រោយនៅតែដដែល មិនផ្លាស់ប្តូរតាមលក្ខខណ្ឌឡើយ។
  - *ឧទាហរណ៍*៖ 雨が降っ**ても**行きます。(ទោះបីជាភ្លៀង ក៏ខ្ញុំទៅដែរ។)
- **～たら (ប្រសិនបើ/កាលណា... នោះនឹង...)**៖ ជាលក្ខខណ្ឌសន្មតធម្មតា ដែលលទ្ធផលខាងក្រោយកើតឡើងអាស្រ័យលើលក្ខខណ្ឌខាងមុខត្រូវបានបំពេញ។
  - *ឧទាហរណ៍*៖ 雨が降っ**たら**行きません。(ប្រសិនបើភ្លៀង ខ្ញុំនឹងមិនទៅទេ។)

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ការសន្ទនាផ្លូវការ / គួរសម (Formal Speech)
1. **どんなに忙しくても、健康を大切にしてください。**
   - *Donna ni isogashikute mo, kenkou o taisetsu ni shite kudasai.*
   - ទោះបីជារវល់យ៉ាងណាក៏ដោយ សូមមេត្តាថែរក្សាសុខភាពផង។
2. **試験が難しくても、あきらめません。**
   - *Shiken ga muzukashikute mo, akiramemasen.*
   - ទោះបីជាការប្រឡងពិបាកយ៉ាងណាក៏ដោយ ក៏ខ្ញុំមិនបោះបង់ដែរ។

### ការសន្ទនាមិនផ្លូវការ / ស្និទ្ធស្នាល (Informal Speech)
1. **雨でもサッカーをしよう。**
   - *Ame demo sakkaa o shiyou.*
   - ទោះបីជាភ្លៀង ក៏តោះយើងលេងបាល់ទាត់ដែរ។
2. **彼が来なくても、パーティーは楽しいよ。**
   - *Kare ga konakute mo, paatii wa tanoshii yo.*
   - ទោះបីជាគាត់មិនមក ក៏ពិធីជប់លៀងនៅតែសប្បាយដែរណា៎!

### បរិបទភាសាសរសេរ (Written Context)
1. **この本は高くても買う価値がある。**
   - *Kono hon wa takakute mo kau kachi ga aru.*
   - សៀវភៅនេះ ទោះបីជាថ្លៃក៏ដោយ ក៏មានតម្លៃសមនឹងទិញដែរ។
2. **結果がどうであっても、全力を尽くすべきだ。**
   - *Kekka ga dou de atte mo, zenryoku o tsukusu beki da.*
   - ទោះបីជាលទ្ធផលចេញមកបែបណាក៏ដោយ ក៏យើងគួរតែខិតខំប្រឹងប្រែងឲ្យអស់ពីសមត្ថភាពដែរ។

### បរិបទភាសានិយាយទូទៅ (Spoken Context)
1. **時間がなくても連絡してね。**
   - *Jikan ga nakute mo renraku shite ne.*
   - ទោះបីជាគ្មានពេល ក៏ជួយទាក់ទងមកផងណា៎។
2. **好きじゃなくても食べてみて。**
   - *Suki ja nakute mo tabete mite.*
   - ទោះបីជាមិនចូលចិត្ត ក៏សាកញ៉ាំមើលសិនទៅ។

## ៥. ចំណាំវប្បធម៌ និងការប្រើប្រាស់ (Cultural Notes)

### កម្រិតគួរសម និងការប្រើប្រាស់ (Politeness and Formality)
- ទម្រង់ **～ても / ～でも** ខ្លួនឯងមិនកំណត់កម្រិតគួរសមទេ វាអាចប្រើបានទាំងក្នុងបរិបទស្និទ្ធស្នាល និងផ្លូវការ។
- កម្រិតនៃភាពគួរសម (Formality) ត្រូវបានកំណត់ដោយទម្រង់បញ្ចប់នៃឃ្លាស្នូល (main clause) នៅចុងប្រយោគ ដូចជាការប្រើប្រាស់ទម្រង់ です / ます ឬពាក្យគួរសម/លើកតម្កើង (Keigo)។

### កន្សោមសំនួនវោហារពេញនិយម (Idiomatic Expressions)
1. **何をしても無駄だ。**
   - *Nani o shite mo muda da.*
   - ទោះជាធ្វើអ្វីក៏ឥតប្រយោជន៍ដែរ (គ្មានផលអ្វីឡើយ)។
2. **いくら食べても太らない。**
   - *Ikura tabete mo futoranai.*
   - ទោះជាញ៉ាំច្រើនប៉ុនណាក៏ដោយ ក៏មិនធាត់ដែរ។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### កំហុសដែលតែងតែកើតមាន (Common Mistakes)
1. **ការបំប្លែងទម្រង់គុណនាម ឬកិរិយាសព្ទខុស៖**
   - មិនត្រឹមត្រូវ៖ 高いても (កាត់ い ចេញមិនត្រឹមត្រូវ)
   - ត្រឹមត្រូវ៖ **高くても** (ត្រូវបំប្លែង い ទៅជា くて ជាមុនសិន)
2. **ការច្រឡំរវាង ～ても និង ～ては៖**
   - **～ても** បង្ហាញពី «ទោះបីជា... ក៏ដោយ» (លទ្ធផលមិនប្រែប្រួល)។
   - ចំណែកឯ **～ては** (〜te wa) បង្ហាញអំពីលក្ខខណ្ឌដែលនាំឲ្យមានលទ្ធផលអវិជ្ជមាន ឬការហាមឃាត់ ដូចជា 〜てはいけない («បើ... គឺមិនបានទេ / មិនត្រូវ... ឡើយ»)។
3. **ការច្រឡំរវាង ても និង でも៖**
   - កិរិយាសព្ទ និងគុណនាម い ប្រើជាមួយ **〜ても** (លើកលែងតែកិរិយាសព្ទបញ្ចប់ដោយ んで ដូចជា 飲んでも)។
   - ចំណែកគុណនាម な និង នាម ត្រូវប្រើជាមួយ **〜でも** (ឧ. 静かでも, 雨でも)។

### គន្លឹះជំនួយការចងចាំ (Tips & Mnemonic Device)
- **គន្លឹះចងចាំ**៖ គិតថាវាជា **«ទម្រង់ て (Te-form) + も (ដែលប្រែថា "ក៏ / ផងដែរ")»**។ ដូច្នេះវាមានន័យថា «ទោះបីជាមានសកម្មភាព X កើតឡើង "ផងដែរ" ក៏រឿង Y នៅតែកើតឡើងដដែល»។
- **ការអនុវត្ត**៖ សាកល្បងបង្កើតប្រយោគដោយប្រើសកម្មភាពប្រចាំថ្ងៃ ដូចជាការហូបចុក អាកាសធាតុ ឬការរៀនសូត្រ ដើម្បីឲ្យកាន់តែស្ទាត់ជំនាញនឹងទម្រង់នេះ។

## ៧. សង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចសំខាន់ៗដែលត្រូវចងចាំ (Key Takeaways)
- **～ても / ～でも** ប្រើសម្រាប់បង្ហាញថាលទ្ធផលចុងក្រោយមិនប្រែប្រួលឡើយ ទោះបីស្ថិតក្នុងលក្ខខណ្ឌណាក៏ដោយ («ទោះបីជា... ក៏ដោយ»)។
- ការផ្សំទម្រង់អាស្រ័យលើថ្នាក់ពាក្យ៖ កិរិយាសព្ទ និងគុណនាម い ប្រើជាមួយ **ទម្រង់ て + も** ចំណែកឯនាម និងគុណនាម な ប្រើជាមួយ **ឫស + でも**។
- ក្នុងកម្រិត N3 តែងតែប្រើទន្ទឹមគ្នាជាមួយគុណកិរិយា **たとえ**, **いくら**, និង **どんなに**។

### កម្រងសំណួររំលឹកឡើងវិញខ្លីៗ (Quick Recap Quiz)
1. **តើត្រូវបំប្លែងទម្រង់ ～ても ជាមួយគុណនាម い យ៉ាងដូចម្តេច?**
   - *ចម្លើយ*៖ ត្រូវកាត់ **い** ចេញ រួចជំនួសដោយ **くて** ហើយបន្ថែម **も** (ឧទាហរណ៍៖ 高い → 高くても)។
2. **ចូរប្រែប្រយោគនេះទៅជាភាសាជប៉ុន៖ «ទោះបីជាថ្លៃ ក៏ខ្ញុំទិញដែរ។»**
   - *ចម្លើយ*៖ 高くても買います。 (Takakute mo kaimasu.)
3. **ចូរបំពេញចន្លោះ៖ 「__がなくても大丈夫です。」 (ទោះបីជាគ្មាន __ ក៏មិនអីដែរ។)**
   - *ចម្លើយគំរូ*៖ **時間** (jikan - ពេលវេលា) ➔ 時間がなくても大丈夫です。
