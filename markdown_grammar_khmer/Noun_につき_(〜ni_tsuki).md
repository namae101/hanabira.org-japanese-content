# ចំណុចវេយ្យាករណ៍ជប៉ុន: Noun につき (〜ni tsuki)
**កម្រិត JLPT:** JLPT N2

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងមេរៀននេះ យើងនឹងសិក្សាអំពីចំណុចវេយ្យាករណ៍ភាសាជប៉ុនកម្រិត N2 គឺ **「Noun につき」** (〜ni tsuki)។ ទម្រង់នេះត្រូវបានប្រើប្រាស់ជាទូទៅនៅក្នុងភាសាសរសេរផ្លូវការ ដូចជា សេចក្តីជូនដំណឹង បដាប្រកាសជាសាធារណៈ ស្លាកសញ្ញា និងលិខិតផ្លូវការផ្សេងៗ។ ការយល់ដឹងច្បាស់អំពីចំណុចវេយ្យាករណ៍នេះ នឹងជួយឱ្យអ្នកអាចអានយល់ និងប្រើប្រាស់ទម្រង់ភាសាផ្លូវការបានយ៉ាងត្រឹមត្រូវ និងសមរម្យ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ និងការប្រើប្រាស់ (Meaning and Usage)
ទម្រង់ **「Noun につき」** មានមុខងារ និងអត្ថន័យចម្បងពីរ៖

1. **ដោយសារតែ... / អាស្រ័យដោយ... (Due to ~ / Because of ~)**  
   ប្រើសម្រាប់បញ្ជាក់អំពីមូលហេតុ ឬហេតុផលផ្លូវការនៃស្ថានភាព ឬសកម្មភាពណាមួយ (ជាទូទៅឃើញលើសេចក្តីជូនដំណឹង ឬស្លាកប្រកាសជាសាធារណៈ)។
2. **ក្នុងមួយ... / សម្រាប់ម្នាក់ៗ ឬមួយឯកតា... (Per ~ / Each ~)**  
   ប្រើសម្រាប់បញ្ជាក់អំពីអត្រា ឬបរិមាណធៀបនឹងឯកតានីមួយៗ (Ratio / Per-unit rate)។

### ទម្រង់ផ្សំ (Structure)

#### រូបមន្ត (Formation)
1. **បញ្ជាក់មូលហេតុ/ហេតុផល (Reason/Cause)**
   ```
   នាម (Noun) + につき
   ```
2. **បញ្ជាក់ឯកតា/អត្រាក្នុងមួយឯកតា (Unit/Rate)**
   ```
   នាមបញ្ជាក់ឯកតា (Noun - Unit/Quantity) + につき
   ```

#### ឧទាហរណ៍ខ្លីៗ (Examples)
1. **មូលហេតុ/ហេតុផល (Reason/Cause)**
   - **雨天**につき、中止いたします。  
     (ដោយសារតែមេឃភ្លៀង កម្មវិធីនឹងត្រូវលុបចោល។)
2. **ឯកតា/អត្រា (Unit/Rate)**
   - お一人**につき**一枚限り。  
     (កំណត់ត្រឹមមួយសន្លឹកប៉ុណ្ណោះក្នុងមនុស្សម្នាក់។)

### តារាងរៀបចំទម្រង់ (Formation Diagram)

#### មូលហេតុ/ហេតុផល (Reason/Cause)
| នាមបញ្ជាក់មូលហេតុ (Noun) | につき | លទ្ធផល / សកម្មភាព (Result/Action) |
|---|---|---|
| メンテナンス (ការថែទាំប្រព័ន្ធ) | につき | サービスを停止します。 (យើងខ្ញុំសូមផ្អាកសេវាកម្មជាបណ្តោះអាសន្ន។) |
| 工事中 (កំពុងជួសជុល) | につき | 立入禁止。 (ហាមចូលដោយដាច់ខាត។) |

#### ឯកតា/អត្រា (Unit/Rate)
| នាមបញ្ជាក់ឯកតា (Noun - Unit) | につき | បរិមាណ / តម្លៃ (Quantity/Rate) |
|---|---|---|
| お一人 (ម្នាក់) | につき | 500円の料金です。 (គិតថ្លៃសេវា ៥០០ យ៉េន។) |
| 1時間 (មួយម៉ោង) | につき | 1,000円を頂戴します。 (គិតថ្លៃ ១,០០០ យ៉េន។) |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative & Nuance Analysis)

ទម្រង់ **「Noun につき」** គឺជាវេយ្យាករណ៍ផ្លូវការកម្រិត N2 ដែលបង្កប់នូវមុខងារទ្វេ (Dual Functions) យ៉ាងជាក់លាក់៖

### ១. មុខងារបញ្ជាក់មូលហេតុផ្លូវការ (Formal Notice Reason/Cause: "Due to / Because of")
- **លក្ខណៈពិសេស:** ភ្ជាប់ដោយផ្ទាល់ជាមួយនាម (ភាគច្រើនជានាមកិរិយាសព្ទពីរសទិសសូរ/កានជីពីរតួ ដូចជា `工事中`, `清掃中`, `準備中`, `雨天`, `改装`, `研修`) ដោយមិនបាច់ប្រើធ្នាក់ `の` ឡើយ។
- **កម្រិតភាសា (Register):** ជាភាសាសរសេរបែបជូនដំណឹងសាធារណៈផ្លូវការខ្លាំង (Public Signs, Notices, Business announcements) ដែលមានភាពគួរសម ខ្លី ខ្លឹម និងប្រកាសជាផ្លូវការ។
- **ការប្រៀបធៀបជាមួយ 〜のため (no tame):**
  - **につき:** ប្រើជាទូទៅនៅលើស្លាកសញ្ញា បដា ឬសេចក្តីប្រកាសខ្លីៗ (Short signs/Bulletins) ដូចជា `工事中につき通り抜けできません` (កំពុងជួសជុល មិនអាចឆ្លងកាត់បានទេ)។ វាមិនប្រើក្នុងប្រយោគសន្ទនាប្រចាំថ្ងៃឡើយ។
  - **のため:** ក៏ជាទម្រង់ផ្លូវការបញ្ជាក់ហេតុផលដែរ ប៉ុន្តែមានលក្ខណៈទូលំទូលាយជាង អាចប្រើទាំងក្នុងភាសាសរសេរ អត្ថបទរៀបរាប់ និងការថ្លែងសន្ទនាផ្លូវការ (Speech/News) ហើយអាចភ្ជាប់ជាមួយកិរិយាសព្ទ និងគុណនាមបាន (`V-plain / Adj + ため`) ខណៈដែល `につき` ភ្ជាប់តែជាមួយនាមខ្លីៗប៉ុណ្ណោះ។
- **ការប្រៀបធៀបជាមួយ ので (node) និង だから (dakara):**
  - `ので / だから` ប្រើក្នុងការសន្ទនាប្រចាំថ្ងៃ ឬការលើកហេតុផលទូទៅ។
  - ឧទាហរណ៍៖
    - ផ្លូវការលើស្លាកសេចក្តីជូនដំណឹង: 会議中**につき**、入室禁止。 (កំពុងប្រជុំ ហាមចូល។)
    - ក្នុងការសន្ទនាទូទៅ: 今会議中**なので**、入れません。 (ដោយសារឥឡូវកំពុងប្រជុំ អ្នកមិនអាចចូលបានទេ។)

### ២. មុខងារបញ្ជាក់អត្រាក្នុងមួយឯកតា (Ratio / Per-unit rate: "Per / For each")
- **លក្ខណៈពិសេស:** ប្រើបន្ទាប់ពីពាក្យបញ្ជាក់ចំនួន ឬឯកតារាប់ (`1人につき`, `1時間につき`, `1回につき`) ដើម្បីកំណត់លក្ខខណ្ឌ កម្រិតកំណត់ ឬអត្រាតម្លៃ។
- **ការប្រៀបធៀបជាមួយ あたり (atari):**
  - **につき:** ផ្តល់នូវអារម្មណ៍ផ្លូវការ តឹងរ៉ឹង និងជាលក្ខខណ្ឌកំណត់ច្បាស់លាស់ (បទបញ្ជា ឬលក្ខខណ្ឌលក់ដូរជាផ្លូវការ) ដូចជា `お一人様につき2点まで` (កំណត់យ៉ាងច្រើនត្រឹម ២ មុខក្នុងម្នាក់)។
  - **あたり:** ប្រើជាទូទៅក្នុងជីវភាពរស់នៅ ការគិតគណនាជាមធ្យម ឬការសន្ទនាទូទៅ ដូចជា `1人あたりケーキを2個食べた` (ម្នាក់ៗបានញ៉ាំនំខេក ២ ដុំ)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### បរិបទភាសាសរសេរផ្លូវការ (Formal Written Contexts)

#### មុខងារបញ្ជាក់មូលហេតុ/ហេតុផល (Reason/Cause Usage)
1. **休業のお知らせ (សេចក្តីជូនដំណឹងអំពីការឈប់សម្រាក)**
   ```
   社員研修につき、本日休業いたします。
   ```
   **អត្ថន័យ**: ដោយសារតែមានការបណ្តុះបណ្តាលបុគ្គលិក យើងខ្ញុំសូមឈប់សម្រាកនៅថ្ងៃនេះ។
2. **電車内のアナウンス・掲示 (សេចក្តីប្រកាសក្នុងរថភ្លើង)**
   ```
   強風につき、電車が遅延しております。
   ```
   **អត្ថន័យ**: ដោយសារតែមានខ្យល់បក់ខ្លាំង ខ្សែរថភ្លើងកំពុងមានការពន្យារពេល។
3. **図書館の掲示 (សេចក្តីជូនដំណឹងនៅបណ្ណាល័យ)**
   ```
   システム更新につき、午後は利用できません。
   ```
   **អត្ថន័យ**: ដោយសារតែមានការធ្វើបច្ចុប្បន្នភាពប្រព័ន្ធ បណ្ណាល័យនឹងមិនអាចចូលប្រើប្រាស់បានទេនៅពេលរសៀល។
4. **ការដ្ឋាន និងអគារសាធារណៈ (Public Construction/Facility Signs)**
   ```
   工事中につき、ご迷惑をおかけいたします。
   ```
   **អត្ថន័យ**: អាស្រ័យដោយការដ្ឋានកំពុងដំណើរការសាងសង់ សូមអភ័យទោសចំពោះការរំខាន ឬការរអាក់រអួលទាំងឡាយ។
   ```
   清掃中につき、足元にご注意ください。
   ```
   **អត្ថន័យ**: ដោយសារតែកំពុងបោសសម្អាត សូមប្រុងប្រយ័ត្នចំពោះការរអិលជើង។

#### មុខងារបញ្ជាក់ឯកតា/អត្រា (Unit/Rate Usage)
1. **チケット販売 (ការលក់សំបុត្រ)**
   ```
   一名様につきチケット2枚まで購入可能です。
   ```
   **អត្ថន័យ**: មនុស្សម្នាក់ៗអាចទិញសំបុត្របានយ៉ាងច្រើនបំផុតត្រឹម ២ សន្លឹកប៉ុណ្ណោះ។
2. **駐車場の料金表 (តារាងតម្លៃចំណតរថយន្ត)**
   ```
   1時間につき300円の料金がかかります。
   ```
   **អត្ថន័យ**: គិតថ្លៃសេវា ៣០០ យ៉េន ក្នុងរយៈពេលមួយម៉ោង។
3. **商品の割引・特典 (ការបញ្ចុះតម្លៃ និងការផ្តល់ជូនពិសេស)**
   ```
   3個につき1個無料。
   ```
   **អត្ថន័យ**: ទិញរាល់ ៣ ឯកតា ថែមជូន ១ ឯកតាដោយឥតគិតថ្លៃ (ទិញ ៣ ថែម ១)។

### បរិបទភាសានិយាយ (Spoken Language Contexts)
ទោះបីជា **「につき」** ត្រូវបានប្រើប្រាស់ជាចម្បងក្នុងភាសាសរសេរ និងសេចក្តីជូនដំណឹងផ្លូវការក៏ដោយ ប៉ុន្តែការយល់ដឹងអំពីទម្រង់នេះមានសារៈសំខាន់ខ្លាំងក្នុងការស្តាប់យល់នូវសេចក្តីប្រកាសជាសាធារណៈ (តាមស្ថានីយរថភ្លើង ផ្សារទំនើប ឬព្រលានយន្តហោះ) ក៏ដូចជាការថ្លែងសន្ទនាផ្លូវការក្នុងអង្គប្រជុំអាជីវកម្ម។

## ៥. កំណត់សម្គាល់វប្បធម៌ និងទម្លាប់ប្រើប្រាស់ (Cultural Notes)

### កម្រិតគួរសម និងភាពផ្លូវការក្នុងសង្គមជប៉ុន (Formality in Japanese Language)
- **ការប្រើប្រាស់ក្នុងស្ថានភាពផ្លូវការ:** **「につき」** គឺជាទម្រង់ភាសាផ្លូវការដែលគេប្រទះឃើញញឹកញាប់បំផុតនៅលើបដាជូនដំណឹងសាធារណៈ សេចក្តីប្រកាសរបស់ក្រុមហ៊ុន និងឯកសាររដ្ឋបាល។
- **កម្រិតនៃភាពគួរសម:** ការប្រើប្រាស់ **「につき」** បង្ហាញពីវិជ្ជាជីវៈខ្ពស់ ភាពហ្មត់ចត់ និងការគោរពតាមបទដ្ឋានផ្លូវការ ដូច្នេះហើយគេមិនប្រើប្រាស់វាក្នុងការសន្ទនាធម្មតា ឬលេងសើចជាមួយមិត្តភក្តិនោះឡើយ។
- **ការស្វែងយល់ពីសេចក្តីជូនដំណឹងសាធារណៈ:** ភាពស៊ាំនឹងកន្សោមពាក្យនេះជួយឱ្យអ្នកអាចរស់នៅ និងធ្វើដំណើរក្នុងប្រទេសជប៉ុនបានយ៉ាងរលូន ជាពិសេសនៅតាមស្ថានីយរថភ្លើង អគាររដ្ឋបាល និងកន្លែងប្រារព្ធព្រឹត្តិការណ៍ផ្សេងៗ។

### កន្សោមពាក្យទម្លាប់ប្រើជាញឹកញាប់ (Idiomatic Expressions)
- **特別価格につき** (ដោយសារតែជាតម្លៃពិសេស / លក់ក្នុងតម្លៃពិសេស)  
  ប្រើក្នុងផ្ទាំងផ្សាយពាណិជ្ជកម្ម ដើម្បីបញ្ជាក់អំពីលក្ខខណ្ឌលក់បញ្ចុះតម្លៃពិសេស។
- **新発売につき** (ដោយសារតែទើបចេញលក់ថ្មី)  
  ប្រើដើម្បីផ្សព្វផ្សាយផលិតផលទើបនឹងដាក់លក់លើទីផ្សារដំបូង។
- **好評につき** (ដោយសារតែទទួលបានការគាំទ្រយ៉ាងខ្លាំង)  
  ឧទាហរណ៍៖ 好評につき期間延長 (ដោយសារទទួលបានការគាំទ្រខ្លាំង កម្មវិធីត្រូវបានពន្យារពេលបន្ថែម)។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### កំហុសដែលតែងតែកើតមាន (Common Mistakes)
1. **ការយក 「につき」 ទៅប្រើក្នុងការសន្ទនាធម្មតា**
   - *ខុស*: 明日暇**につき**、映画に行こう。  
   - *ត្រូវ*: 明日暇**だから**、映画に行こう。  
     (ដោយសារថ្ងៃស្អែកទំនេរ តោះទៅមើលកុនទាំងអស់គ្នា!)  
   **គន្លឹះ**: សូមប្រើ **「だから」** ឬ **「ので」** សម្រាប់ការសន្ទនាធម្មតាប្រចាំថ្ងៃ។
2. **ការច្រឡំរវាង 「につき」 និង 「について」 (Nitsuite)**
   - *ខុស*: 日本の文化**につき**勉強しています。  
   - *ត្រូវ*: 日本の文化**について**勉強しています。  
     (ខ្ញុំកំពុងសិក្សា**អំពី**វប្បធម៌ជប៉ុន។)  
   **គន្លឹះ**: **「について」** មានន័យថា "អំពី / ទាក់ទងនឹង" (About / Regarding) ដែលខុសគ្នាស្រឡះពី **「につき」** ដែលមានន័យថា "ដោយសារតែ..." ឬ "ក្នុងមួយឯកតា..."។

### វិធីសាស្ត្ររៀនឱ្យឆាប់ចាំ (Learning Strategies)
- **ភ្ជាប់ទំនាក់ទំនងជាមួយស្លាកសញ្ញាផ្លូវការ:** ចងចាំថា **「につき」** គឺសម្រាប់ភាសាសរសេរលើស្លាកប្រកាស ឬសេចក្តីជូនដំណឹងផ្លូវការ។
- **អនុវត្តការអានស្លាកសញ្ញាជាក់ស្តែង:** យកចិត្តទុកដាក់សង្កេតស្លាកសញ្ញា និងសេចក្តីជូនដំណឹងសាធារណៈនៅពេលរៀន ឬពេលស្ថិតនៅក្នុងប្រទេសជប៉ុន។
- **បង្កើតប្រយោគគំរូដោយខ្លួនឯង:** សាកល្បងសរសេរសេចក្តីជូនដំណឹងផ្លូវការដោយប្រើ **「につき」** ដូចជាសេចក្តីជូនដំណឹងអំពីការឈប់សម្រាក ឬលក្ខខណ្ឌលក់ទំនិញ ដើម្បីឱ្យឆាប់ស៊ាំនឹងការប្រើប្រាស់។

## ៧. សង្ខេបមេរៀន និងកម្រងសំណួររំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **「Noun につき」** គឺជាទម្រង់វេយ្យាករណ៍ផ្លូវការកម្រិត N2 ដែលមានន័យថា "ដោយសារតែ..." ឬ "ក្នុងមួយ..."។
- ប្រើជាចម្បងក្នុងភាសាសរសេរផ្លូវការ ជាពិសេសលើសេចក្តីជូនដំណឹង បដាប្រកាស និងលិខិតផ្លូវការ។
- មានមុខងារសំខាន់ពីរយ៉ាង៖ បញ្ជាក់មូលហេតុ/ហេតុផលផ្លូវការ និងបញ្ជាក់អត្រាក្នុងមួយឯកតា។
- មិនត្រូវបានប្រើប្រាស់ក្នុងការសន្ទនាធម្មតាប្រចាំថ្ងៃឡើយ។

### កម្រងសំណួររហ័ស (Quick Recap Quiz)

១. **តើឃ្លា 「雨天につき、中止」 មានន័យដូចម្តេច?**  
   ក) ព្រោះតែមេឃកំពុងភ្លៀង តោះយើងលុបចោលវាទៅ។  
   ខ) ដោយសារតែមេឃភ្លៀង កម្មវិធីត្រូវបានលុបចោល។  
   គ) ដោយសារតែមេឃមិនភ្លៀង កម្មវិធីត្រូវបានលុបចោល។  
   **ចម្លើយត្រឹមត្រូវ**: ខ) ដោយសារតែមេឃភ្លៀង កម្មវិធីត្រូវបានលុបចោល។

២. **តើប្រយោគមួយណាដែលសមស្របបំផុតសម្រាប់ការសន្ទនាធម្មតា?**  
   ក) 暑さにつき、休みます。  
   ខ) 暑いので、休みます。  
   **ចម្លើយត្រឹមត្រូវ**: ខ) 暑いので、休みます。

៣. **ចូរជ្រើសរើសពាក្យបំពេញចន្លោះឱ្យបានត្រឹមត្រូវ និងគួរសមបំផុត៖**
