# វេយ្យាករណ៍ភាសាញប៉ុន: ～だけしか (～dake shika)
**កម្រិត JLPT:** JLPT N3

---

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងមេរៀននេះ យើងនឹងស្វែងយល់អំពីទម្រង់វេយ្យាករណ៍ភាសាញប៉ុន **～だけしか (dake shika)** ដែលត្រូវបានប្រើប្រាស់ដើម្បីសង្កត់ធ្ងន់យ៉ាងខ្លាំងទៅលើ "ការកម្រិតផ្ដាច់មុខ" (strong exclusivity) ឬការកំណត់ព្រំដែនតឹងរ៉ឹងបំផុត។ ការយល់ដឹងពីទម្រង់នេះ នឹងជួយឱ្យអ្នកអាចសង្កត់ធ្ងន់ថា _ពិតជាគ្មានអ្វីផ្សេងទាល់តែសោះ_ ក្រៅតែពីអ្វីដែលបានលើកឡើង ដោយបន្ថែមនូវអត្ថន័យស៊ីជម្រៅ និងភាពច្បាស់លាស់ដល់ការប្រាស្រ័យទាក់ទងជាភាសាញប៉ុនរបស់អ្នក។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **～だけしか** មានន័យថា **"មានតែ...ប៉ុណ្ណោះ (គ្មានអ្វីក្រៅពីនេះទាល់តែសោះ)"** ឬ **"ពិតជាមានតែ...មួយគត់"**។
- វាត្រូវបានប្រើដើម្បីសង្កត់ធ្ងន់ថា _ដាច់ខាតគ្មានអ្វីផ្សេងទៀតឡើយ_ ក្រៅពីកម្មវត្ថុ ឬរឿងរ៉ាវដែលបានបញ្ជាក់។

### ទម្រង់ (Structure)
ទម្រង់នៃការប្រើប្រាស់ ～だけしか គឺ៖
```
[នាម (Noun)] + だけしか + [កិរិយាសព្ទអវិជ្ជមាន (Negative Verb)]
```

### តារាងទម្រង់វេយ្យាករណ៍ (Formation Diagram)
| ធាតុផ្សំ (Component) | មុខងារ (Function) | ឧទាហរណ៍ (Example) |
|---|---|---|
| **[នាម (Noun)]** | ប្រធាន / កម្មបទ (Subject/Object) | 彼 (គាត់) |
| **だけ** | "ត្រឹមតែ / គ្រាន់តែ" (only) | だけ |
| **しか** | "ក្រៅពី... (ប្រើជាមួយអវិជ្ជមាន)" (only with neg.) | しか |
| **[កិរិយាសព្ទអវិជ្ជមាន]** | សកម្មភាព / ស្ថានភាពអវិជ្ជមាន (Negative Verb) | いない (គ្មាន / មិននៅ) |

- ទាំង **だけ** និង **しか** សុទ្ធតែមានន័យទាក់ទងនឹង "តែ/ប៉ុណ្ណោះ" ប៉ុន្តែ **しか** ត្រូវតែបញ្ចប់ដោយកិរិយាសព្ទអវិជ្ជមានជានិច្ច។
- នៅពេលផ្គុំពាក្យទាំងពីរចូលគ្នា (**だけ + しか**) វានឹងបង្កើតបានជាការសង្កត់ន័យទ្វេដង បង្ហាញពីភាពដាច់ខាត និងផ្ដាច់មុខកាន់តែខ្លាំងក្លា។

### គំនូសបំព្រួញរូបភាព (Visual Aid)
```
[ប្រធាន / កម្មបទ] + だけしか + [កិរិយាសព្ទអវិជ្ជមាន (〜ない / 〜ません)]
```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuance)

### ការប្រៀបធៀបទម្រង់ស្រដៀងគ្នា (Comparison with Similar Grammar Points)
| ទម្រង់វេយ្យាករណ៍ | រចនាសម្ព័ន្ធ (Structure) | អត្ថន័យ (Meaning) | ឧទាហរណ៍ (Example) |
|---|---|---|---|
| **だけ** | នាម + だけ | ត្រឹមតែ... (Only) | 私は水だけ飲みます。<br>*ខ្ញុំផឹកតែទឹកប៉ុណ្ណោះ។* |
| **しか** | នាម + しか + កិរិយាសព្ទអវិជ្ជមាន | ក្រៅពី...គឺមិន... (Only / Nothing but) | 私は水しか飲みません。<br>*ខ្ញុំមិនផឹកអ្វីក្រៅពីទឹកនោះទេ។* |
| **だけしか** | នាម + だけしか + កិរិយាសព្ទអវិជ្ជមាន | ពិតជាមានតែ...មួយគត់ (Strictly only / absolutely nothing else) | 私は水だけしか飲みません。<br>*ខ្ញុំពិតជាផឹកតែទឹកមួយមុខគត់ (ដាច់ខាតមិនផឹកអ្វីផ្សេងឡើយ)។* |

### ការវិភាគស៊ីជម្រៅ (Deep Nuance Breakdown)
- **だけ (កម្រិតព្រំដែនសត្យានុម័ត - Objective Limitation):** ប្រើជាទូទៅជាមួយកិរិយាសព្ទស្រប គ្រាន់តែបញ្ជាក់ពីទំហំ ឬបរិមាណដែលមានព្រំដែនត្រឹមប៉ុណ្ណោះ ដោយមិនបង្កប់នូវអារម្មណ៍ខ្វះខាតខ្លាំងនោះឡើយ។
- **しか〜ない (អារម្មណ៍ខ្វះខាត ឬមិនគ្រប់គ្រាន់ - Insufficiency & Scarcity):** តម្រូវឱ្យប្រើជាមួយកិរិយាសព្ទអវិជ្ជមានជានិច្ច ដោយបង្ហាញពីការសោកស្ដាយ អារម្មណ៍ថាបរិមាណនោះតិចតួចពេក ឬគ្មានជម្រើសផ្សេង។
- **だけしか〜ない (ការសង្កត់ន័យស្ទួនបែបផ្ដាច់មុខ - Pleonastic Emphatic Restriction):** នេះជាការរួមបញ្ចូលគ្នារវាង **だけ** (កម្រិតកំណត់) និង **しか〜ない** (ការបដិសេធអ្វីៗក្រៅពីនោះ)។ ក្នុងភាសាវិទ្យា នេះជាទម្រង់ Pleonasm (ការប្រើពាក្យស្ទួនដើម្បីសង្កត់ន័យ) បង្កើតបានជាអារម្មណ៍ **"Intense Psychological Scarcity"** (អារម្មណ៍តានតឹង ឬខ្វះខាតផ្លូវចិត្តយ៉ាងខ្លាំង)។ អ្នកនិយាយចង់គូសបញ្ជាក់យ៉ាងម៉ឺងម៉ាត់ថា "មានត្រឹមតែចំណុចនេះមួយគត់ ហើយដាច់ខាតគ្មានអ្វីផ្សេងលើសពីនេះបន្តិចណាឡើយ"។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ភាសាផ្លូវការ (Formal Speech)
1. **会員だけしか入れません。**  
   *Kaiin dake shika hairemasen.*  
   មានតែសមាជិកប៉ុណ្ណោះដែលអាចចូលបាន (ក្រៅពីសមាជិកគឺដាច់ខាតមិនអនុញ្ញាតឡើយ)។
2. **この資料は社内だけしか閲覧できません。**  
   *Kono shiryō wa shanai dake shika etsuran dekimasen.*  
   ឯកសារនេះអាចមើលបានតែនៅក្នុងផ្ទៃក្នុងក្រុមហ៊ុនប៉ុណ្ណោះ។

### ភាសាក្រៅផ្លូវការ / ស្និទ្ធស្នាល (Informal Speech)
3. **君だけしか信じられない。**  
   *Kimi dake shika shinjirarenai.*  
   ខ្ញុំអាចទុកចិត្តបានតែឯងម្នាក់គត់ (គ្មានអ្នកណាផ្សេងក្រៅពីឯងឡើយ)។
4. **今日はコーヒーだけしか飲んでない。**  
   *Kyō wa kōhī dake shika nonde nai.*  
   ថ្ងៃនេះខ្ញុំទើបតែបានផឹកកាហ្វេតែមួយមុខគត់។

### ភាសាសរសេរ (Written Language)
5. **このサービスは国内だけしか利用できません。**  
   *Kono sābisu wa kokunai dake shika riyō dekimasen.*  
   សេវាកម្មនេះអាចប្រើប្រាស់បានតែនៅក្នុងស្រុកប៉ុណ្ណោះ។

### ភាសានិយាយ (Spoken Language)
6. **時間があと10分だけしかないよ。**  
   *Jikan ga ato jūppun dake shika nai yo.*  
   យើងនៅសល់ពេលតែ ១០ នាទីទៀតប៉ុណ្ណោះណា៎!

## ៥. កំណត់សម្គាល់អំពីវប្បធម៌ (Cultural Notes)

### ភាពពាក់ព័ន្ធក្នុងវប្បធម៌ជប៉ុន (Cultural Relevance)
- ការសង្កត់ធ្ងន់លើកម្រិតព្រំដែន ឬការកំណត់ គឺជាទម្លាប់ទូទៅក្នុងសង្គមជប៉ុន ដើម្បីបង្ហាញពីភាពគួរសម និងការគ្រប់គ្រងការរំពឹងទុករបស់អ្នកដទៃ (Managing Expectations)។
- ការប្រើប្រាស់ **～だけしか** ជួយជម្រាបជូនដៃគូសន្ទនាដោយច្បាស់លាស់ និងម៉ឺងម៉ាត់អំពីដែនកំណត់ដ៏តឹងរ៉ឹង ឬលក្ខខណ្ឌផ្ដាច់មុខ ដោយមិនឱ្យមានការយល់ច្រឡំ។

### កម្រិតគួរសម និងការប្រើប្រាស់ (Levels of Politeness and Formality)
- **ផ្លូវការ (Formal):** ប្រើប្រាស់ក្នុងបរិបទជំនួញ ឬការងាររដ្ឋបាល ដើម្បីកំណត់ព្រំដែន ច្បាប់ទម្លាប់ និងសិទ្ធិប្រើប្រាស់ឱ្យបានច្បាស់លាស់។
- **ក្រៅផ្លូវការ (Informal):** ប្រើប្រាស់ក្នុងចំណោមមិត្តភក្តិ ឬក្រុមគ្រួសារ ដើម្បីបង្ហាញពីអារម្មណ៍ផ្ដាច់មុខដ៏ជ្រាលជ្រៅ (ឧទាហរណ៍៖ ការទុកចិត្តលើនរណាម្នាក់) ឬអារម្មណ៍ត្អូញត្អែរអំពីភាពខ្វះខាតខ្លាំង។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
1. **ការប្រើប្រាស់កិរិយាសព្ទស្របជាមួយ しか**
   - ខុស៖ *彼は日本語だけしか話します。*
   - ត្រូវ៖ *彼は日本語だけしか話しません。*
   - **គន្លឹះ:** ត្រូវចងចាំជានិច្ចថា នៅពេលមានវត្តមានរបស់ **しか** កិរិយាសព្ទខាងចុងត្រូវតែជា **កិរិយាសព្ទអវិជ្ជមាន (Negative Verb)**។
2. **ការប្រើពាក្យបដិសេធស្ទួនដែលមិនត្រឹមត្រូវ (Redundant Negation)**
   - ខុស៖ *誰もだけしか来なかった。*
   - ត្រូវ៖ *誰も来なかった。* (គ្មាននរណាម្នាក់មកទេ) ឬ *彼だけしか来なかった。* (មានតែគាត់ម្នាក់គត់ដែលបានមក)។
   - **គន្លឹះ:** ចៀសវាងការប្រើពាក្យអវិជ្ជមានមិនច្បាស់លាស់ដូចជា 誰も ជាមួយ **だけしか** ពីព្រោះ だけしか ប្រើសម្រាប់តែបញ្ជាក់នាមជាក់លាក់ណាមួយប៉ុណ្ណោះ។

### យុទ្ធសាស្ត្រសិក្សា (Learning Strategies)
- **វិធីសាស្ត្រជួយចងចាំ (Mnemonic):** គិតថា **"មានតែ... (だけ) ហើយគ្មានអ្វីក្រៅពីនេះទៀតឡើយ (しか〜ない)"** ដើម្បីចងចាំថាពាក្យទាំងពីរបូកបញ្ចូលគ្នាដើម្បីពង្រឹងភាពផ្ដាច់មុខកម្រិតអតិបរមា។
- **អនុវត្តទម្រង់អវិជ្ជមាន:** ដោយសារ **しか** ទាមទារកិរិយាសព្ទអវិជ្ជមានជានិច្ច ចូររំលឹក និងហ្វឹកហាត់បំប្លែងកិរិយាសព្ទទៅជាទម្រង់អវិជ្ជមាន (〜ない / 〜ません) ឱ្យបានស្ទាត់ជំនាញ។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～だけしか** ត្រូវបានប្រើដើម្បីសង្កត់ធ្ងន់ថា **ពិតជាគ្មានអ្វីផ្សេងទាល់តែសោះ** ក្រៅពីអ្វីដែលបានលើកឡើង។
- វាជាការផ្គុំបញ្ចូលគ្នារវាង **だけ** ("តែ/ប៉ុណ្ណោះ") និង **しか** ("ក្រៅពី...គឺមិន...") ដើម្បីបង្កើនកម្រិតសង្កត់ន័យឱ្យកាន់តែខ្លាំង។
- រចនាសម្ព័ន្ធគឺ៖ **[នាម (Noun)] + だけしか + [កិរិយាសព្ទអវិជ្ជមាន (Negative Verb)]**។
- **しか** ត្រូវតែដើរទន្ទឹមគ្នាជាមួយ **កិរិយាសព្ទអវិជ្ជមាន** ជានិច្ច។

### កម្រងសំណួរខ្លីៗរំលឹកមេរៀន (Quick Recap Quiz)
1. **ចូរជ្រើសរើសចម្លើយត្រឹមត្រូវដើម្បីបំពេញចន្លោះ៖**  
   私にはあなた_____しかいません。  
   *ខ្ញុំគ្មាននរណាក្រៅពីអ្នកនោះទេ។*  
   a) だけ  
   b) を  
   c) が  

2. **តើប្រយោគនេះត្រឹមត្រូវដែរឬទេ? ប្រសិនបើមិនត្រឹមត្រូវ ចូរកែតម្រូវ៖**  
   - *彼女は音楽だけしか好きです。*  

3. **ចូរបកប្រែប្រយោគខាងក្រោមនេះជាភាសាញប៉ុនដោយប្រើ ～だけしか៖**  
   - "ពួកយើងមានជម្រើសតែមួយគត់ (គ្មានជម្រើសផ្សេងទៀតឡើយ)។"  

#### ចម្លើយ (Answers):
1. **a) だけ**  
   *私にはあなた**だけしか**いません。*
2. **មិនត្រឹមត្រូវទេ។**  
   ប្រយោគត្រឹមត្រូវគឺ៖ *彼女は音楽だけしか好き**ではありません**。*  
   **ការពន្យល់:** ដោយសារវត្តមានរបស់ **しか** ទាមទារឱ្យប្រើទម្រង់អវិជ្ជមាន (好きではありません / 好きじゃない)។
3. *私たちには選択肢が一つだけしかありません。*
