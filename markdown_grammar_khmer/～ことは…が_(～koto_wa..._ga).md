# ចំណុចវេយ្យាករណ៍ភាសាជប៉ុន៖ ～ことは…が (～koto wa... ga)
**កម្រិត JLPT:** JLPT N3

---

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ **～ことは…が (～koto wa... ga)** ត្រូវបានប្រើប្រាស់ដើម្បីទទួលស្គាល់ ឬយល់ស្របលើការពិតណាមួយសិន ប៉ុន្តែបន្ទាប់មកក៏បង្ហាញពីការស្ទាក់ស្ទើរ ការកម្រិត ឬចំណុចផ្ទុយពីការពិតនោះ។ ជាទូទៅ វាមានន័យស្មើនឹង៖ **«ពិតមែនតែ... ប៉ុន្តែ...»**, **«ថា... ក៏ថាបានដែរ តែ...»**, ឬ **«វាពិតជា... មែន ប៉ុន្តែ...»**។ ទម្រង់នេះជួយឱ្យអ្នកនិយាយអាចយល់ស្របឬបន្ទន់ជំហរលើចំណុចណាមួយ មុននឹងលើកឡើងនូវចំណុចផ្ទុយ ឬចំណុចអវិជ្ជមានដែលនៅសេសសល់។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **ការទទួលស្គាល់ដោយមានការកម្រិត ឬការស្ទាក់ស្ទើរ (Acknowledgment with Reservations)**៖ ទម្រង់នេះប្រើសម្រាប់ទទួលស្គាល់ថា រឿងរ៉ាវ ឬលក្ខណៈណាមួយពិតជាត្រឹមត្រូវមែន ប៉ុន្តែមានលក្ខខណ្ឌ កម្រិតកំណត់ ឬបញ្ហាផ្សេងទៀតដែលធ្វើឱ្យវាមិនល្អឥតខ្ចោះ ១០០% នោះឡើយ។

### ទម្រង់វេយ្យាករណ៍ (Structure)
ទម្រង់មូលដ្ឋានគឺការប្រើពាក្យដដែលឡើងវិញ (Repetition Pattern)៖
```
[ទម្រង់ធម្មតានៃកិរិយាសព្ទ/គុណនាម A] + ことは + [ទម្រង់ធម្មតានៃកិរិយាសព្ទ/គុណនាម A ដដែល] + が / けれど
```

**ក្បួនផ្សំតាមប្រភេទពាក្យ៖**
- **កិរិយាសព្ទ (Verbs)**:
  - ទម្រង់ធម្មតា (Plain Form) + ことは + ទម្រង់ធម្មតា/ទម្រង់គួរសម + が / けれど
  - ឧទាហរណ៍៖ 食べる**ことは**食べる**が**、あまり好きではない。  
    (_ហូបពិតជាហូបមែន ប៉ុន្តែមិនសូវចូលចិត្តប៉ុន្មានទេ។_)
- **គុណនាម い (い-adjectives)**:
  - [គុណនាម い] + **ことは** + [គុណនាម い] + **が / けれど**
  - ឧទាហរណ៍៖ 高い**ことは**高い**が**、とても美味しい。  
    (_ថ្លៃពិតជាថ្លៃមែន ប៉ុន្តែឆ្ងាញ់ខ្លាំងណាស់។_)
- **គុណនាម な (な-adjectives)**:
  - [គុណនាម な + な / である] + **ことは** + [គុណនាម な + だ / です] + **が / けれど**
  - ឧទាហរណ៍៖ 便利な**ことは**便利**だが**、高すぎる。  
    (_ងាយស្រួលប្រើប្រាស់ពិតជាមែនហើយ ប៉ុន្តែវាថ្លៃហួសហេតុពេក។_)
- **នាម (Nouns)**:
  - [នាម + である] + **ことは** + [នាម + だ / である] + **が / けれど**

### តារាងរចនាសម្ព័ន្ធ (Formation Diagram)
| ផ្នែក (Part) | មុខងារ (Function) |
|---|---|
| កិរិយាសព្ទ/គុណនាម (Plain form A) | លើកឡើងនូវការពិតដែលត្រូវទទួលស្គាល់ |
| ことは | កន្សោមធ្វើជានាម (Nominalizer: こと) + ឈ្នាប់បញ្ជាក់ប្រធានបទ/សង្កត់ន័យ (Topic/Contrast marker: は) |
| កិរិយាសព្ទ/គុណនាម (Plain form A ដដែល) | បញ្ជាក់ និងសង្កត់ធ្ងន់លើការពិតនោះឡើងវិញ |
| が / けれど | ឈ្នាប់តភ្ជាប់មានន័យថា «ប៉ុន្តែ / តែ» |
| ឃ្លាបន្ទាប់ (Following Clause) | បង្ហាញពីចំណុចកម្រិត ការស្ទាក់ស្ទើរ ឬចំណុចផ្ទុយ |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance & Comparative Analysis)

### លក្ខណៈពិសេសនៃទម្រង់សម្បទានដដែលៗ (Concession Repetition Pattern: [A] ことは [A] が/けれど)
ចំណុចស្នូលនៃវេយ្យាករណ៍នេះ គឺលំនាំពាក្យដដែលៗ៖ `[ពាក្យ A] ことは [ពាក្យ A] が` (ឧទាហរណ៍៖ `高いことは高いが、美味しい` - "ពិតជាថ្លៃមែន ប៉ុន្តែឆ្ងាញ់")។
- **ចិត្តសាស្ត្រនៃការសន្ទនា (Conversational Psychology)**៖ នៅពេលដៃគូសន្ទនាសួរ ឬលើកឡើងពីលក្ខណៈ A (ឧ. "តើម្ហូបនេះថ្លៃទេ?"), ការឆ្លើយភ្លាមៗថា "ថ្លៃ តែឆ្ងាញ់" អាចស្ដាប់ទៅសាមញ្ញ។ ប៉ុន្តែការប្រើ `高いことは高いが` បង្ហាញពីជំហរទទួលស្គាល់ដោយស្មោះត្រង់ថា៖ «បើយើងនិយាយពីថ្លៃ... ខ្ញុំទទួលស្គាល់ថាវាថ្លៃមែន ប៉ុន្តែចំណុចសំខាន់ពិតប្រាកដដែលខ្ញុំចង់បញ្ជាក់ គឺវានៅតែឆ្ងាញ់អស្ចារ្យ»។
- **ការផ្ទេរទម្ងន់នៃប្រយោគ (Focus Shift)**៖ ឃ្លាមុន `ことは` គ្រាន់តែជាការទទួលស្គាល់សម្បទានជាទូទៅប៉ុណ្ណោះ រីឯទម្ងន់ និងបំណងសំខាន់របស់អ្នកនិយាយ គឺស្ថិតនៅលើ **ឃ្លាខាងក្រោយ `が`** ទៅវិញទេ។

### ការប្រៀបធៀបជាមួយទម្រង់ស្រដៀងគ្នា (Comparison with Similar Expressions)

1. **～けど / が (ទម្រង់ផ្ទុយធម្មតា)**:
   - គ្រាន់តែភ្ជាប់ឃ្លាពីរដែលមានន័យផ្ទុយគ្នាជាទូទៅ ដោយគ្មានការសង្កត់ធ្ងន់លើការទទួលស្គាល់ជាមុននោះឡើយ។
   - ឧទាហរណ៍៖ 行きたい**けど**、時間がない。(ចង់ទៅដែរ តែគ្មានពេល។)
   - ភាពខុសគ្នា៖ មិនមានការប្រើពាក្យដដែលៗដើម្បីបញ្ជាក់ការយល់ស្របដូច `～ことは...が` ទេ។

2. **～には～が (ទម្រង់សម្បទានកម្រិតសន្ទនា)**:
   - ប្រើទម្រង់ដដែលៗដូចគ្នា៖ `[A] には [A] が`។
   - ឧទាហរណ៍៖ おいしい**には**おいしい**が**、量が少ない。(ឆ្ងាញ់ពិតជាឆ្ងាញ់មែន តែបរិមាណតិចពេក។)
   - ភាពខុសគ្នា៖ `～には～が` ជារឿយៗប្រើក្នុងភាសានិយាយសាមញ្ញ និងក្រៅផ្លូវការជាង ហើយជួនកាលបង្កប់នូវអារម្មណ៍មិនសូវពេញចិត្តខ្លាំងចំពោះចំណុចខ្វះខាត។ ចំណែក `～ことは...が` អាចប្រើបានទាំងក្នុងភាសានិយាយ និងភាសាសរសេរផ្លូវការ ហើយការសង្កត់ន័យទៅលើការទទួលស្គាល់ការពិតមានទម្ងន់ច្បាស់លាស់ជាង។

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ប្រយោគគំរូ (Example Sentences)

1. **ទម្រង់ផ្លូវការ / ភាសាសរសេរ (Formal / Written)**
   - この本は**面白いことは面白いが**、専門的すぎて理解しにくい。
   - _សៀវភៅនេះបើនិយាយពីល្អមើលពិតជាល្អមើលមែន ប៉ុន្តែដោយសារវាមានលក្ខណៈបច្ចេកទេសពេក ទើបពិបាកយល់។_

2. **ទម្រង់ក្រៅផ្លូវការ / ភាសានិយាយ (Informal / Spoken)**
   - 彼に**会うことは会ったけど**、忙しくてゆっくり話せなかった。
   - _ជួបគាត់ពិតជាបានជួបមែន ប៉ុន្តែដោយសាររវល់ពេក ក៏មិនបានជជែកគ្នាលម្អិតដែរ។_

3. **ទម្រង់គួរសម (Polite Form)**
   - 日本語を**勉強したことは勉強しましたが**、まだ上手に話せません。
   - _រៀនភាសាជប៉ុនគឺពិតជាបានរៀនមែន ប៉ុន្តែខ្ញុំនៅមិនទាន់ចេះនិយាយបានស្ទាត់នៅឡើយទេ។_

4. **ទម្រង់បដិសេធ (Negative Form)**
   - 試験を**受けなかったことはないが**、合格する自信はあまりない。
   - _មិនមែនថាខ្ញុំមិនបានប្រឡងនោះទេ (ពិតជាបានប្រឡងមែន) ប៉ុន្តែខ្ញុំមិនសូវមានទំនុកចិត្តថានឹងជាប់នោះឡើយ។_

## ៥. កំណត់សម្គាល់វប្បធម៌ (Cultural Notes)

### ទំនាក់ទំនងវប្បធម៌ជប៉ុន (Cultural Relevance)
នៅក្នុងការប្រាស្រ័យទាក់ទងបែបជប៉ុន ការបញ្ចេញមតិ ឬបដិសេធដោយចំៗត្រូវបានចាត់ទុកថាជាការមិនសូវសមរម្យ។ ជនជាតិជប៉ុនតែងតែឱ្យតម្លៃខ្ពស់លើការរក្សាសុខដុមរមនា (和 - *wa*) និងភាពទន់ភ្លន់។ ការប្រើប្រាស់ទម្រង់ **～ことは…が** គឺជាមធ្យោបាយដ៏ប្រសើរមួយក្នុងការ «បន្ទន់ពាក្យសម្ដី» ដោយទទួលស្គាល់ និងផ្តល់តម្លៃដល់ការលើកឡើង ឬការពិតជាមុនសិន មុននឹងបន្តលើកឡើងនូវការស្ទាក់ស្ទើរ ការរិះគន់ ឬចំណុចផ្ទុយ។

### កន្សោមប្រើប្រាស់ជាក់ស្តែង (Idiomatic / Daily Expressions)
- **元気なことは元気です (が…)**
  - _សុខទុក្ខពិតជាសុខសប្បាយធម្មតាមែន (ប៉ុន្តែ...)_
  - ជារឿយៗប្រើប្រាស់នៅពេលនរណាម្នាក់មិនសូវស្រួលខ្លួនទាំងស្រុង ឬមានរឿងរំខានចិត្តខ្លះៗ ប៉ុន្តែមិនចង់ឱ្យដៃគូសន្ទនាមានការព្រួយបារម្ភច្រើន។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
1. **ការភ្លេចប្រើពាក្យដដែលៗ (Omitting the Repetition)**៖ ច្រឡំភ្លេចប្រើកិរិយាសព្ទ ឬគុណនាមដដែលឡើងវិញនៅពីមុខ `が`។
   - មិនត្រឹមត្រូវ ❌: 行くことは**が**、時間がない。
   - ត្រឹមត្រូវ ⭕: 行くことは**行くが**、時間がない。(ទៅពិតជាទៅមែន តែគ្មានពេលទេ។)

2. **ការប្រើខុសទម្រង់កិរិយាសព្ទ/គុណនាម (Using the Wrong Form)**៖ ប្រើទម្រង់គួរសមនៅមុខ `ことは` ដែលខុសវេយ្យាករណ៍។
   - មិនត្រឹមត្រូវ ❌: 行き**ます**ことは行きますが、時間がない。
   - ត្រឹមត្រូវ ⭕: 行く**ことは**行きますが、時間がない。 / 行く**ことは**行くが、時間がない。

### យុទ្ធសាស្ត្ររៀន និងចងចាំ (Learning Strategies)
- **រូបមន្តចងចាំ (Mnemonic Device)**៖ ចងចាំរូបមន្ត `[A] ことは [A] が [B]` ស្មើនឹង «វាពិតជា A មែន ប៉ុន្តែ B»។
- **ការអនុវត្តបង្កើតប្រយោគ**៖ ព្យាយាមបង្កើតប្រយោគដោយចាប់ផ្តើមពីការទទួលស្គាល់គុណសម្បត្តិ ឬសកម្មភាពណាមួយ រួចភ្ជាប់ជាមួយ `が` ដើម្បីបង្ហាញពីចំណុចខ្វះខាត ឬចំណុចផ្ទុយ។

## ៧. សេចក្តីសង្ខេប និងលំហាត់រំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **ការប្រើប្រាស់**៖ ～ことは…が ប្រើដើម្បីទទួលស្គាល់ការពិតណាមួយ មុននឹងលើកឡើងនូវចំណុចផ្ទុយ ឬការកម្រិត។
- **រចនាសម្ព័ន្ធ**៖ [កិរិយាសព្ទ/គុណនាម Plain form] + ことは + [កិរិយាសព្ទ/គុណនាមដដែល] + が / けれど
- **ទស្សនៈវប្បធម៌**៖ ឆ្លុះបញ្ចាំងពីទម្លាប់និយាយបែបប្រយោល និងការរក្សាភាពគួរសមទន់ភ្លន់របស់ជនជាតិជប៉ុន។

### លំហាត់សាកល្បងរហ័ស (Quick Recap Quiz)
១. ចូរជ្រើសរើសបំពេញចន្លោះ៖
   - 高いことは ______ が、品質がいいです。
២. តើប្រយោគខាងក្រោមនេះត្រឹមត្រូវដែរឬទេ? ប្រសិនបើខុស ចូរកែតម្រូវឱ្យបានត្រឹមត្រូវ៖
   - 便利なこと便利だが、デザインが好きではない。

**ចម្លើយ (Answers)**:
១. 高いことは **高い** が、品質がいいです。  
២. មិនត្រឹមត្រូវទេ (ខ្វះឈ្នាប់ `は`)។ ប្រយោគត្រឹមត្រូវគឺ៖  
   - 便利なこと**は**便利だが、デザインが好きではない。
