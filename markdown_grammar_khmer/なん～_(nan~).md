# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ なん～ (nan~)
**កម្រិត JLPT:** JLPT N5

---

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងមេរៀននេះ យើងនឹងសិក្សាអំពីចំណុចវេយ្យាករណ៍ភាសាជប៉ុន **なん～ (nan~)**។ បុព្វបទ ឬទម្រង់នេះមានប្រភពចេញពីពាក្យសួរ 「なに (nani)」 ដែលមានន័យថា «អ្វី»។ នៅក្នុងកម្រិតដំបូង (JLPT N5) **なん～** ត្រូវបានប្រើជាទូទៅបំផុតជាពាក្យសួរផ្សំជាមួយរាប់ចំនួន (Counters) ដូចជា «ម៉ោងប៉ុន្មាន», «ប៉ុន្មាននាក់» ជាដើម។ ក្រៅពីនេះ នៅពេលវារួមផ្សំជាមួយធ្នាក់ ឬពាក្យដទៃទៀត (ដូចជា なんて, なんか, なんと) វាក៏អាចប្រើដើម្បីបញ្ជាក់ពីអារម្មណ៍ភ្ញាក់ផ្អើល កោតសរសើរ ការបន្ទាបខ្លួន ឬការនិយាយបែបសាមញ្ញៗផងដែរ។ ការយល់ច្បាស់ពីទម្រង់ **なん～** នឹងជួយឱ្យអ្នកប្រើប្រាស់ពាក្យសួរ និងការបញ្ចេញមនោសញ្ចេតនាជាភាសាជប៉ុនបានយ៉ាងត្រឹមត្រូវ និងធម្មជាតិ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យទូទៅ (General Meanings)
ទម្រង់ **なん～ (nan~)** មានការប្រើប្រាស់សំខាន់ៗដូចខាងក្រោម៖
1. **ជាពាក្យសួរសួរចំនួន ឬកាលបរិច្ឆេទ (JLPT N5 Interrogative Prefix):** «ប៉ុន្មាន...?», «អ្វី...?» (ឧទាហរណ៍៖ 何時 - ម៉ោងប៉ុន្មាន, 何人 - ប៉ុន្មាននាក់, 何曜日 - ថ្ងៃអ្វី)។
2. **បង្ហាញការភ្ញាក់ផ្អើល ឬមិននឹកស្មានដល់ (Surprise/Disbelief):** «...ដល់ថ្នាក់ហ្នឹង!», «មិនគួរឱ្យជឿថា...» (なんて)
3. **ការបន្ទាបខ្លួន ឬការលើកឧទាហរណ៍សាមញ្ញ (Downplaying/Modesty/Casual examples):** «ដូចជា...ជាដើម», «មនុស្សដូចជា...» (なんか)
4. **សង្កត់ន័យលើការកោតសរសើរ ឬអារម្មណ៍ខ្លាំងក្លា (Admiration/Strong emotion):** «ពិតជា...មែន!», «អស្ចារ្យអ្វីម៉្លេះ!» (なんと)

---

### ទម្រង់ និងក្បួនបង្កើត (Structure & Formations)

#### ក. ការប្រើប្រាស់ក្នុងកម្រិត N5៖ បុព្វបទសួរចំនួន និងរាប់ (Interrogative Prefix + Counters)
- **何 (なん) + រាប់ចំនួន/នាម (Counter/Noun)**
- ឧទាហរណ៍៖
  - 何時 (なんじ - nanji) : ម៉ោងប៉ុន្មាន?
  - 何人 (なんにん - nannin) : ប៉ុន្មាននាក់?
  - 何曜日 (なんようび - nanyōbi) : ថ្ងៃអ្វី? (ថ្ងៃនៃសប្តាហ៍)
  - 何歳 (なんさい - nansai) : អាយុប៉ុន្មាន?
  - 何ですか (なんですか - nan desu ka) : តើជាអ្វីដែរ?

#### ខ. ទម្រង់ពង្រីកមនោសញ្ចេតនា (Emotional/Nuance Expressions)
1. **なんて (nante)**
   - បញ្ជាក់ការភ្ញាក់ផ្អើល កោតសរសើរ ឬមិនគួរឱ្យជឿ។
   - **ក្បួនបង្កើត៖** នាម / កិរិយាសព្ទ (ទម្រង់ធម្មតា) / គុណនាម (ទម្រង់ធម្មតា) + **なんて**
2. **なんか (nanka)**
   - ប្រើដើម្បីបន្ទាបតម្លៃ បង្ហាញការបន្ទាបខ្លួន ឬលើកឧទាហរណ៍បែបសាមញ្ញមិនផ្លូវការ។
   - **ក្បួនបង្កើត៖** នាម / កិរិយាសព្ទ (ទម្រង់ធម្មតា) + **なんか**
3. **なんと (nanto)**
   - បញ្ជាក់ពីអារម្មណ៍ខ្លាំងក្លា ច្រើនដាក់នៅដើមប្រយោគ។
   - **ក្បួនបង្កើត៖** **なんと** + គុណនាម / កិរិយាសព្ទ / នាម

---

### ដ្យាក្រាមទម្រង់ (Formation Diagrams)

#### **何 (なん) + Counter (N5)**
```plaintext
何 (なん) + [ពាក្យរាប់ចំនួន / Counter]
```

#### **なんて (nante)**
```plaintext
[ពាក្យ / ឃ្លា (ទម្រង់ធម្មតា)] + なんて
```

#### **なんか (nanka)**
```plaintext
[នាម / កិរិយាសព្ទ (ទម្រង់ធម្មតា)] + なんか
```

#### **なんと (nanto)**
```plaintext
なんと + [កន្សោមពាក្យ / គុណនាម / កិរិយាសព្ទ]
```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuance)

### ក. ការប្រៀបធៀបស៊ីជម្រៅ៖ 「なん (nan)」 vs 「なに (nani)」
អក្សរកានជី「何」អាចអានបានពីររបៀបគឺ **なん (nan)** និង **なに (nani)** ដែលអ្នករៀនកម្រិត N5 តែងតែមានការភាន់ច្រឡំ។ ក្បួនខ្នាតក្នុងការបែងចែកមានដូចខាងក្រោម៖

1. **នៅពេលអានថា 「なん (nan)」:**
   - **នៅពីមុខព្យញ្ជនៈជួរ d, t, n (សូរសំឡេងធ្មេញ/អណ្តាត - Dental/Alveolar sounds):**
     - នៅពីមុខ です (desu) / だ (da)៖ **何ですか** (nandesu ka - មិនមែន nanidesu ka ទេ)
     - នៅពីមុខធ្នាក់ で (de)៖ **何で** (nande - ហេតុអ្វី / ដោយសារអ្វី)
     - នៅពីមុខធ្នាក់ と (to)៖ **何と** (nanto - ថាដូចម្តេច)
   - **នៅពីមុខពាក្យរាប់ចំនួន (Counters):**
     - 何時 (なんじ - nanji) : ម៉ោងប៉ុន្មាន
     - 何人 (なんにん - nannin) : ប៉ុន្មាននាក់
     - 何歳 (なんさい - nansai) : អាយុប៉ុន្មាន
     - 何曜日 (なんようび - nanyōbi) : ថ្ងៃអ្វី
     - 何年 (なんねん - nannen) : ឆ្នាំណា / ប៉ុន្មានឆ្នាំ
     - 何回 (なんかい - nankai) : ប៉ុន្មានដង
     - 何分 (なんぷん - nanpun) : ប៉ុន្មាននាទី

2. **នៅពេលអានថា 「なに (nani)」:**
   - **នៅមុខធ្នាក់ដទៃទៀតដូចជា を (o), が (ga), に (ni), も (mo):**
     - **何を**していますか (nani o shiteimasu ka - កំពុងធ្វើអ្វី?)
     - **何が**好きですか (nani ga suki desu ka - ចូលចិត្តអ្វី?)
     - **何に**しますか (nani ni shimasu ka - ជ្រើសរើសយកអ្វី?)
     - **何も**ありません (nani mo arimasen - គ្មានអ្វីទាំងអស់)
   - **នៅពេលឈរទោលឯករាជ្យ៖**
     - 何？ (nani? - អីហ្នឹង? / ស្អីគេ?)

---

### ខ. ការប្រៀបធៀប៖ なんて vs. とは (to wa)
- **なんて**: ប្រើក្នុងការសន្ទនាទូទៅ មិនផ្លូវការ សង្កត់ធ្ងន់លើអារម្មណ៍ផ្ទាល់ខ្លួន (ភ្ញាក់ផ្អើល ហួសចិត្ត)។
- **とは**: ផ្លូវការខ្លាំង ច្រើនប្រើក្នុងភាសាសរសេរ ឬការថ្លែងជាផ្លូវការ។

*ឧទាហរណ៍៖*
- **なんて**:
  ```plaintext
  彼が犯人なんて信じられない。
  (Kare ga hannin nante shinjirarenai.)
  ```
  *មិនគួរឱ្យជឿទាល់តែសោះថាមនុស្សដូចគាត់ជាជនល្មើសនោះ!*
- **とは**:
  ```plaintext
  彼が犯人とは信じがたい。
  (Kare ga hannin to wa shinjigatai.)
  ```
  *វាពិតជាពិបាកជឿណាស់ដែលគាត់គឺជាជនល្មើស។*

---

### គ. ការប្រៀបធៀប៖ なんか vs. とか (toka)
- **なんか**: ប្រើក្នុងកម្រិតស្និទ្ធស្នាល បង្ហាញការបន្ទាបតម្លៃ (មិនសូវសំខាន់) ឬលើកឧទាហរណ៍បែបមិនច្បាស់លាស់។
- **とか**: លើកឧទាហរណ៍ជាច្រើនស្របគ្នា ក្នុងលក្ខណៈអព្យាក្រឹត (កណ្តាល)។

*ឧទាហរណ៍៖*
- **なんか**:
  ```plaintext
  お茶なんかどう？
  (Ocha nanka dō?)
  ```
  *ញ៉ាំតែ ឬអ្វីមួយបន្តិចទេ? (លើកឡើងបែបសាមញ្ញៗ)*
- **とか**:
  ```plaintext
  お茶とかコーヒーはいかがですか？
  (Ocha toka kōhī wa ikaga desu ka?)
  ```
  *តើលោកអ្នកពិសាតែ ឬកាហ្វេដែរឬទេ? (លើកជម្រើសឡើងជាផ្លូវការ/គួរសម)*

---

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ក. ការប្រើប្រាស់ជាពាក្យសួរ N5 (Interrogative Prefix / Counters)
1. **何時 (ម៉ោងប៉ុន្មាន)**
   ```plaintext
   今、何時ですか。
   (Ima, nanji desu ka.)
   ```
   *ឥឡូវនេះ តើម៉ោងប៉ុន្មានហើយ?*

2. **何人 (ប៉ុន្មាននាក់)**
   ```plaintext
   ご家族は何人ですか。
   (Gokazoku wa nannin desu ka.)
   ```
   *តើគ្រួសាររបស់អ្នកមានសមាជិកប៉ុន្មាននាក់?*

3. **何曜日 (ថ្ងៃអ្វី)**
   ```plaintext
   今日は何曜日ですか。
   (Kyō wa nanyōbi desu ka.)
   ```
   *តើថ្ងៃនេះជាថ្ងៃអ្វីដែរ?*

4. **何歳 (អាយុប៉ុន្មាន)**
   ```plaintext
   田中さんは何歳ですか。
   (Tanaka-san wa nansai desu ka.)
   ```
   *តើលោកតាណាកាមានអាយុប៉ុន្មានឆ្នាំហើយ?*

---

### ខ. ការប្រើប្រាស់ なんて (nante)
1. **ការភ្ញាក់ផ្អើល / មិននឹកស្មានដល់ (Surprise/Disbelief)**
   ```plaintext
   あの静かな彼が怒るなんて珍しい。
   (Ano shizuka na kare ga okoru nante mezurashii.)
   ```
   *មនុស្សស្ងៀមស្ងាត់ដូចគាត់ខឹងឡើងបែបនេះ ពិតជាកម្រឃើញណាស់។*

2. **ការកោតសរសើរ (Admiration)**
   ```plaintext
   彼女がピアノをあんなに上手に弾けるなんて素晴らしい。
   (Kanojo ga piano o anna ni jōzu ni hikeru nante subarashii.)
   ```
   *នាងអាចលេងព្យាណូបានពូកែយ៉ាងនេះ ពិតជាអស្ចារ្យមែន។*

---

### គ. ការប្រើប្រាស់ なんか (nanka)
1. **ការបន្ទាបខ្លួន (Downplaying / Modesty)**
   ```plaintext
   私なんか、まだまだ勉強が足りない。
   (Watashi nanka, madamada benkyō ga tarinai.)
   ```
   *មនុស្សដូចជាខ្ញុំនេះ នៅខ្វះការរៀនសូត្រច្រើនណាស់។*

2. **ការលើកឧទាហរណ៍ធម្មតាៗ (Casual Examples)**
   ```plaintext
   映画なんか見に行かない？
   (Eiga nanka mi ni ikanai?)
   ```
   *តើយើងទៅមើលកុន ឬធ្វើអីលេងៗជាមួយគ្នាទេ?*

---

### ឃ. ការប្រើប្រាស់ なんと (nanto)
1. **ការបញ្ជាក់អារម្មណ៍ខ្លាំងក្លា (Strong Emotion)**
   ```plaintext
   なんと美しい景色だろう！
   (Nanto utsukushii keshiki darō!)
   ```
   *ពិតជាទេសភាពដ៏ស្រស់ស្អាតអស្ចារ្យអ្វីម៉្លេះ!*

2. **ការភ្ញាក់ផ្អើលខ្លាំង (Astonishment)**
   ```plaintext
   なんと彼は一人でその仕事を終わらせた。
   (Nanto kare wa hitori de sono shigoto o owaraseta.)
   ```
   *មិនគួរឱ្យជឿទាល់តែសោះ គាត់បានបញ្ចប់ការងារនោះតែម្នាក់ឯង!*

---

## ៥. កត់សម្គាល់ខាងវប្បធម៌ (Cultural Notes)

### ទំនាក់ទំនងវប្បធម៌ (Cultural Relevance)
- **ការបន្ទាបខ្លួន និងសុភាពរាបសារ (Self-Deprecation and Humility):** ការប្រើ **なんか** ជាមួយខ្លួនឯង (ដូចជា *私なんか*) ឆ្លុះបញ្ចាំងពីគុណតម្លៃនៃការបន្ទាបខ្លួន (謙遜 - kenson) ដែលជាចរិតលក្ខណៈដ៏សំខាន់ក្នុងសង្គមជប៉ុន។
- **ការបញ្ចេញអារម្មណ៍ដោយប្រយោល (Expressing Emotions Indirectly):** ទំនៀមទម្លាប់ជប៉ុនចូលចិត្តភាពទន់ភ្លន់ មិននិយាយត្រង់ៗពេក។ ការប្រើ **なんて** ឬ **なんと** ជួយឱ្យអ្នកនិយាយអាចបង្ហាញអារម្មណ៍ភ្ញាក់ផ្អើល ឬស្ងើចសរសើរបានដោយធម្មជាតិ និងមិនឆ្គង។

### សំនួនវោហារសព្ទពេញនិយម (Idiomatic Expressions)
- **何となく (nantonaku)**: *ដោយមិនដឹងមូលហេតុច្បាស់, ស្រាប់តែ...*
  ```plaintext
  何となく今日は気分がいい。
  (Nantonaku kyō wa kibun ga ii.)
  ```
  *ថ្ងៃនេះមិនដឹងយ៉ាងម៉េច ស្រាប់តែមានអារម្មណ៍ល្អ។*

- **何とかなる (nantoka naru)**: *គង់តែមានផ្លូវដោះស្រាយ, មិនអីទេ*
  ```plaintext
  心配しないで、何とかなるよ。
  (Shinpai shinaide, nantoka naru yo.)
  ```
  *កុំបារម្ភអី គង់តែមានផ្លូវដោះស្រាយរួចរាល់ទេ។*

---

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
1. **ការច្រឡំរវាង なんて និង なんか**
   - **កំហុស៖** ប្រើ **なんて** ដើម្បីបន្ទាបខ្លួនឯង។
     - *មិនត្រឹមត្រូវ:* 私なんてまだまだです。
   - **កែតម្រូវ៖** គួរប្រើ **なんか** សម្រាប់ការបន្ទាបខ្លួន។
     - *ត្រឹមត្រូវ:* 私なんかまだまだです。 (មនុស្សដូចខ្ញុំនៅខ្សោយណាស់)
2. **ការប្រើ なんか ក្នុងបរិបទផ្លូវការ**
   - **កំហុស៖** ប្រើ **なんか** ក្នុងសំណេរ ឬសុន្ទរកថាផ្លូវការ។
   - **គន្លឹះ៖** ត្រូវជំនួសដោយពាក្យ **など (nado)** វិញដើម្បីរក្សាភាពគួរសម និងផ្លូវការ។
     - *ឧទាហរណ៍:* 本や資料**など**を参考にしてください。 (សូមពិគ្រោះឯកសារ ដូចជាសៀវភៅជាដើម)
3. **ការច្រឡំអាន なん និង なに នៅពីមុខ Counters**
   - **កំហុស៖** អាន *なにじ* ឬ *なににん*។
   - **គន្លឹះ៖** នៅពីមុខពាក្យរាប់ចំនួន ត្រូវអានថា **なん** ជានិច្ច ដូចជា **なんじ (何時)**, **なんにん (何人)**។

### យុទ្ធសាស្ត្ររៀនសូត្រ (Learning Strategies)
- **ហាត់អនុវត្តតាមបរិបទ៖** ព្យាយាមប្រើសំនួរ 何時, 何人 ក្នុងការសន្ទនាប្រចាំថ្ងៃ។
- **ស្តាប់ការសន្ទនាផ្ទាល់៖** ស្តាប់ការសន្ទនាក្នុងខ្សែភាពយន្ត ឬ Podcast ជប៉ុន ដើម្បីចាប់យកសូរសៀងនៃពាក្យ なんて និង なんか។
- **បង្កើត Flashcards៖** ធ្វើបណ្ណពាក្យរវាង «何 (なん) + Counter» និង «何 (なに) + Particle» ដើម្បីកុំឱ្យច្រឡំ។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **何 (なん - nan)**: ប្រើជាបុព្វបទសួរជាមួយពាក្យរាប់ចំនួន (何時, 何人, 何歳) និងនៅពីមុខសំឡេងជួរ d, t, n (何ですか)។
- **なんて (nante)**: ប្រើបញ្ជាក់ការភ្ញាក់ផ្អើល កោតសរសើរ ឬមិនគួរឱ្យជឿ។
- **なんか (nanka)**: ប្រើបន្ទាបតម្លៃ បន្ទាបខ្លួន ឬលើកឧទាហរណ៍បែបសាមញ្ញ។
- **なんと (nanto)**: បញ្ជាក់អារម្មណ៍ខ្លាំងក្លា ភាគច្រើនប្រើនៅដើមប្រយោគ។
- **កម្រិតផ្លូវការមានសារៈសំខាន់៖** ត្រូវជ្រើសរើសប្រើឱ្យត្រូវតាមកាលៈទេសៈ (ផ្លូវការប្រើ など / ក្រៅផ្លូវការប្រើ なんか)។

---

### កម្រងសំណួររំលឹកមេរៀន (Quick Recap Quiz)

1. **ចូរជ្រើសរើស なんて, なんか, ឬ なんと បំពេញចន្លោះ៖**
   a. この問題が解ける ______ 彼は天才だ。
   b. 私 ______ まだまだ未熟です。
   c. ______ 綺麗な花でしょう！

2. **ត្រូវ ឬ ខុស (True or False):**
   a. **なんか** អាចប្រើក្នុងសំណេរផ្លូវការបានយ៉ាងត្រឹមត្រូវ។
   b. **なんて** អាចប្រើដើម្បីបង្ហាញពីការមិនគួរឱ្យជឿ (Disbelief) បាន។
   c. នៅពីមុខ です (desu) យើងត្រូវអាន 何 ថា **なに**។

### ចម្លើយ (Answers):
1. 
   - a. **なんて**
   - b. **なんか**
   - c. **なんと**
2. 
   - a. **ខុស (False)** (ត្រូវប្រើ など វិញ)
   - b. **ត្រូវ (True)**
   - c. **ខុស (False)** (ត្រូវអានថា **なん** គឺ 何ですか - nan desu ka)
