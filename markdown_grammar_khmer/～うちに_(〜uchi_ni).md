# ចំណុចវេយ្យាករណ៍ជប៉ុន: ～うちに (〜uchi ni)
**កម្រិត JLPT:** JLPT N3

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងមេរៀននេះ យើងនឹងសិក្សាអំពីចំណុចវេយ្យាករណ៍ភាសាជប៉ុន **～うちに (〜uchi ni)** ដែលត្រូវបានប្រើប្រាស់ជាទូទៅដើម្បីសម្តែងន័យថា "ឆ្លៀតពេល/ក្នុងអំឡុងពេល..." ឬ "មុនពេល..." នៅក្នុងភាសាខ្មែរ។ ទម្រង់វេយ្យាករណ៍នេះជួយបញ្ជាក់អំពីសកម្មភាព ឬការផ្លាស់ប្តូរដែលកើតឡើងដោយឯកឯង (ធម្មជាតិ) ឬសកម្មភាពដែលគួរតែធ្វើឱ្យហើយក្នុងចន្លោះពេល ឬលក្ខខណ្ឌណាមួយ មុនពេលស្ថានភាពនោះផ្លាស់ប្តូរទៅជាផ្សេង។

---
## ២. ការពន្យល់វេយ្យាករណ៍គោល (Core Grammar Explanation)
### អត្ថន័យ (Meaning)
**～うちに (〜uchi ni)** អាចបកប្រែជាភាសាខ្មែរថា៖
- "ក្នុងអំឡុងពេល / ឆ្លៀតពេល..."
- "មុនពេល... (មុនពេលស្ថានភាពផ្លាស់ប្តូរ)"
- "ខណៈពេល / កំពុងតែ... ស្រាប់តែ..."

ទម្រង់នេះបញ្ជាក់ថា សកម្មភាពមួយគួរតែធ្វើ **នៅពេលដែលលក្ខខណ្ឌជាក់លាក់ណាមួយនៅតែបន្តមាន** ឬ **មុនពេលស្ថានភាពណាមួយផ្លាស់ប្តូរ**។

### របៀបប្រើប្រាស់ (Usage)
**～うちに** មានមុខងារស្នូលសំខាន់ចំនួន ២៖
1. **ឆ្លៀតធ្វើសកម្មភាពមុនពេលស្ថានភាពផ្លាស់ប្តូរ (Intentional Action):** ធ្វើអ្វីមួយឆ្លៀតពេលឱកាស ឬស្ថានភាពអំណោយផលនៅមាន (ដូចជា ឆ្លៀតពេលនៅក្តៅ, ឆ្លៀតពេលនៅក្មេង, ធ្វើមុនពេលភ្លៀងធ្លាក់)។
2. **ការផ្លាស់ប្តូរដោយឯកឯងដែលមិនបានព្រាងទុក (Unintended / Natural Change):** នៅក្នុងអំឡុងពេលដែលកំពុងបន្តសកម្មភាព ឬស្ថានភាពណាមួយ ស្រាប់តែមានការផ្លាស់ប្តូរថ្មីមួយកើតឡើងដោយឯកឯង ឬមិនបានដឹងខ្លួន (ដូចជា កំពុងស្តាប់ភ្លេងស្រាប់តែគេងលក់, អានសៀវភៅយូរៗទៅស្រាប់តែមេឃងងឹតបាត់)។

### ទម្រង់ផ្សំ (Formation)
#### តារាងទម្រង់វេយ្យាករណ៍
| ប្រភេទពាក្យ | របៀបភ្ជាប់ជាមួយ ～うちに |
|---|---|
| **កិរិយាសព្ទ (ទម្រង់វចនានុក្រម / 辞書形)** | 〇 កិរិយាសព្ទ + うちに |
| **កិរិយាសព្ទ (ទម្រង់ ない / 否定形)** | 〇 កិរិយាសព្ទ ない + うちに |
| **កិរិយាសព្ទ (ទម្រង់ ている / 進行形)** | 〇 កិរិយាសព្ទ ている + うちに |
| **គុណនាម い (い形容詞)** | 〇 គុណនាម い + うちに |
| **គុណនាម な (な形容詞)** | 〇 គុណនាម な + **な** + うちに |
| **នាម (名詞)** | 〇 នាម + **の** + うちに |

#### ឧទាហរណ៍នៃការផ្សំទម្រង់
- **កិរិយាសព្ទ (ទម្រង់វចនានុក្រម) + うちに**
  ```
  食べる + うちに → 食べるうちに (កំពុងតែញ៉ាំស្រាប់តែ...)
  ```
- **កិរិយាសព្ទ (ទម្រង់ ない) + うちに**
  ```
  忘れない + うちに → 忘れないうちに (មុនពេលភ្លេច...)
  ```
- **កិរិយាសព្ទ (ទម្រង់ ている) + うちに**
  ```
  雨が降っている + うちに → 雨が降っているうちに (ក្នុងពេលកំពុងភ្លៀង...)
  ```
- **គុណនាម い + うちに**
  ```
  若い + うちに → 若いうちに (ឆ្លៀតពេលនៅក្មេង / កាលនៅក្មេង...)
  ```
- **គុណនាម な + な + うちに**
  ```
  元気な + うちに → 元気なうちに (ឆ្លៀតពេលនៅមានសុខភាពល្អ/រឹងមាំ...)
  ```
- **នាម + の + うちに**
  ```
  午前中 + の + うちに → 午前中のうちに (ក្នុងអំឡុងពេលព្រឹក...)
  ```

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Nuance Analysis)

### មុខងារស្នូលទាំងពីរនៃ 〜うちに
1. **មុខងារទី ១: ឆ្លៀតធ្វើសកម្មភាពមុនពេលលក្ខខណ្ឌផ្លាស់ប្តូរ (Action before state change)**
   - ប្រយោគខាងក្រោយ (Clause B) ជាសកម្មភាពចេតនា (Intentional action, បញ្ជា, ស្នើសុំ ឬបំណងប្រាថ្នា)។
   - គំនិតស្នូល៖ "ឱកាសមានកំណត់! បើមិនធ្វើឥឡូវនេះទេ ស្ថានភាពនឹងផ្លាស់ប្តូរ ហើយមិនអាចធ្វើបានទៀតឡើយ"។
   - ឧទាហរណ៍៖ `熱いうちに食べてください` (សូមពិសាពេលនៅក្តៅ - បើទុកយូរនឹងត្រជាក់ លែងឆ្ងាញ់)។
   - នៅពេលប្រើជាមួយទម្រង់បដិសេធ `〜ないうちに` វាមានន័យស្មើនឹង "មុនពេល..." (Before something happens) ដូចជា `暗くならないうちに帰ろう` (តោះត្រឡប់ទៅផ្ទះមុនពេលមេឃងងឹត)។

2. **មុខងារទី ២: កំពុងតែ... ស្រាប់តែមានការផ្លាស់ប្តូរដោយឯកឯង (Natural / Unintended change)**
   - ប្រយោគខាងក្រោយ (Clause B) ជាការផ្លាស់ប្តូរដែលកើតឡើងដោយឯកឯង មិនមែនជាចេតនារបស់មនុស្សឡើយ (Non-volitional / Natural transition)។
   - ច្រើនប្រើជាមួយកិរិយាសព្ទ `〜ている` ឬកិរិយាសព្ទដដែលៗ។
   - គំនិតស្នូល៖ "នៅក្នុងអំឡុងពេលកំពុងធ្វើ A ដោយមិនដឹងខ្លួន ស្រាប់តែស្ថានភាព B កើតឡើង"។
   - ឧទាហរណ៍៖ `テレビを見ているうちに寝てしまった` (កំពុងតែមើលទូរទស្សន៍ ស្រាប់តែគេងលក់បាត់ទៅ)។

### ការប្រៀបធៀបចំណុចវេយ្យាករណ៍ប្រហាក់ប្រហែល (Similar Grammar Points)

#### ១. ～うちに (〜uchi ni) vs. ～間に (〜aida ni)
- **ភាពដូចគ្នា:** ទាំងពីរអាចបកប្រែថា "ក្នុងអំឡុងពេល..." បានដូចគ្នា។
- **ភាពខុសគ្នាដ៏សំខាន់ (Crucial Contrast):**
  - **〜間に:** សំដៅលើចន្លោះពេលជាក់លាក់មួយដែលមានចំណុចចាប់ផ្តើម និងចំណុចបញ្ចប់ច្បាស់លាស់ (Time span)។ ប្រយោគខាងក្រោយអាចជាសកម្មភាពចេតនាធម្មតា ដោយមិនមានអារម្មណ៍ប្រញាប់ប្រញាល់ ឬខ្លាចបាត់បង់ឱកាសនោះទេ។
    - ឧទាហរណ៍៖ `夏休みの間に本を３冊読んだ。` (ខ្ញុំបានអានសៀវភៅ ៣ ក្បាលនៅក្នុងអំឡុងពេលវិស្សមកាលរដូវក្តៅ — ជាចន្លោះពេលកំណត់ច្បាស់លាស់)។
  - **〜うちに:** សង្កត់ធ្ងន់ខ្លាំងលើ **"ការផ្លាស់ប្តូរនៃស្ថានភាព"** (State change or urgency)។
    - ប្រសិនបើជាចេតនា វាបង្កប់ន័យថា "ត្រូវប្រញាប់ធ្វើ មុនពេលឱកាស ឬស្ថានភាពបច្ចុប្បន្នបាត់បង់" (Sense of urgency / limited window)។
    - ប្រសិនបើជាអចេតនា វាបង្ហាញពីការផ្លាស់ប្តូរដែលកើតឡើងជាបណ្តើរៗដោយមិនដឹងខ្លួន។
    - មិនអាចប្រើ `〜間に` ជំនួស `〜うちに` ក្នុងន័យ "ឆ្លៀតពេលនៅក្មេង" ឬ "ឆ្លៀតពេលនៅក្តៅ" បានទេ ព្រោះ `若いうちに` / `熱いうちに` បង្ហាញពីលក្ខខណ្ឌដែលនឹងបាត់បង់ទៅវិញ (មិនមែនជាចន្លោះពេលកំណត់ច្បាស់លាស់លើប្រតិទិនទេ)។

#### ២. ～うちに (〜uchi ni) vs. ～ながら (〜nagara)
- **〜ながら:** ប្រើនៅពេលដែល **ប្រធានតែមួយ** ធ្វើសកម្មភាពពីរដំណាលគ្នាក្នុងពេលតែមួយ (ឧទាហរណ៍៖ ដើរបណ្តើរ ស្តាប់ចម្រៀងបណ្តើរ `音楽を聞きながら歩く`)។
- **〜うちに:** មិនមែនសំដៅលើការធ្វើសកម្មភាពពីរដំណាលគ្នាដោយចេតនានោះទេ តែជាការឆ្លៀតធ្វើក្នុងកាលៈទេសៈណាមួយ ឬកំពុងធ្វើសកម្មភាពមួយស្រាប់តែមានរឿងមួយទៀតកើតឡើង។

## ៤. ឧទាហរណ៍ក្នុងបរិបទ (Examples in Context)

### ប្រយោគគំរូ (Example Sentences)
1. **若いうちに、たくさん旅行したい。**
   *Wakai uchi ni, takusan ryokō shitai.*
   *ខ្ញុំចង់ដើរលេងកម្សាន្តឱ្យបានច្រើន ឆ្លៀតពេលនៅក្មេង។*
2. **雨が降らないうちに、帰りましょう。**
   *Ame ga furanai uchi ni, kaerimashō.*
   *តោះយើងត្រឡប់ទៅផ្ទះវិញ មុនពេលមេឃធ្លាក់ភ្លៀង។*
3. **熱いうちに、どうぞ召し上がってください。**
   *Atsui uchi ni, dōzo meshiagatte kudasai.*
   *សូមអញ្ជើញពិសាពេលនៅក្តៅៗ។*
4. **音楽を聞いているうちに、眠ってしまった。**
   *Ongaku o kiite iru uchi ni, nemutte shimatta.*
   *កំពុងតែស្តាប់តន្ត្រី ស្រាប់តែគេងលក់បាត់ទៅ។*
5. **忘れないうちに、メモしておきます。**
   *Wasurenai uchi ni, memo shite okimasu.*
   *ខ្ញុំនឹងកត់ត្រាទុក មុនពេលខ្ញុំភ្លេច។*

### បរិបទផ្សេងៗ (Context Variations)
- **បរិបទផ្លូវការ (Formal Context)**
  **会議が始まらないうちに、資料を準備してください。**
  *Kaigi ga hajimaranai uchi ni, shiryō o junbi shite kudasai.*
  *សូមមេត្តារៀបចំឯកសារឱ្យបានរួចរាល់ មុនពេលកិច្ចប្រជុំចាប់ផ្តើម។*
- **បរិបទក្រៅផ្លូវការ / ស្និទ្ធស្នាល (Informal Context)**
  **明るいうちに帰ろう。**
  *Akarui uchi ni kaerō.*
  *តោះទៅផ្ទះ ឆ្លៀតពេលមេឃនៅភ្លឺ។*
- **ភាសាសរសេរ (Written Language)**
  **桜が散らないうちに、お花見に行きましょう。**
  *Sakura ga chiranai uchi ni, ohanami ni ikimashō.*
  *តោះយើងទៅទស្សនាផ្កាសាគូរ៉ា មុនពេលផ្ការុះរោយអស់។*
- **ភាសានិយាយ (Spoken Language)**
  **元気なうちに、たくさん運動したほうがいいよ。**
  *Genki na uchi ni, takusan undō shita hō ga ii yo.*
  *ឆ្លៀតពេលនៅមានកម្លាំងរឹងមាំ គួរតែហាត់ប្រាណឱ្យបានច្រើនណា៎។*

## ៥. ចំណាំវប្បធម៌ (Cultural Notes)
### ទំនាក់ទំនងវប្បធម៌ (Cultural Relevance)
នៅក្នុងវប្បធម៌ជប៉ុន មានការឱ្យតម្លៃខ្ពស់ទៅលើ **"ការក្តាប់យកឱកាស"** និង **"ការឱ្យតម្លៃលើបច្ចុប្បន្នភាព"** (ដូចជាទស្សនវិជ្ជា 一期一会 - អ៊ីឈីហ្គោ អ៊ីឈីអេ) ដែលផ្នត់គំនិតនេះត្រូវបានឆ្លុះបញ្ចាំងយ៉ាងច្បាស់តាមរយៈការប្រើប្រាស់ **～うちに**។ វេយ្យាករណ៍នេះលើកទឹកចិត្តឱ្យមនុស្សឆាប់ធ្វើសកម្មភាពភ្លាមៗ ឆ្លៀតក្នុងខណៈពេលដែលកាលៈទេសៈ និងលក្ខខណ្ឌនៅតែអំណោយផលល្អ។

### កម្រិតគួរសម (Levels of Politeness)
- **ទម្រង់គួរសម (Polite Form):** ប្រើប្រាស់ក្នុងបរិយាកាសផ្លូវការ ឬការងារ ដោយបញ្ចប់កន្សោមប្រយោគដោយ ます/です។
  **熱いうちに、召し上がってください。**
  *សូមអញ្ជើញពិសាពេលនៅក្តៅៗ។*
- **ទម្រង់សាមញ្ញ (Casual Form):** ប្រើប្រាស់ជាមួយមិត្តភក្តិ ឬក្រុមគ្រួសារ។
  **暗くならないうちに、帰るね。**
  *ខ្ញុំទៅផ្ទះហើយណា៎ មុនពេលមេឃងងឹត។*

### សុភាសិត / កន្សោមពាក្យទាក់ទង (Idiomatic Expressions)
- **思い立ったが吉日（おもいたったがきちじつ）**
  *Omoitatta ga kichijitsu*
  *"ថ្ងៃដែលគិតចង់ធ្វើ គឺជាថ្ងៃមង្គលល្អបំផុត" (គ្មានពេលណាប្រសើរជាងពេលបច្ចុប្បន្ននេះទេ)*
  - ទោះបីជាឃ្លានេះមិនប្រើពាក្យ **～うちに** ផ្ទាល់ ប៉ុន្តែវាមានអត្ថន័យស្របគ្នាអំពីការធ្វើសកម្មភាពឱ្យបានរហ័សទាន់ចិត្ត មិនត្រូវពន្យារពេលឡើយ។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)
### ការវិភាគកំហុស (Error Analysis)
1. **ការប្រើប្រាស់ ～うちに ជាមួយកិរិយាសព្ទអតីតកាល (Past Tense):**
   - មិនត្រឹមត្រូវ: **食べたうちに、寝ました。** ❌
   - ត្រឹមត្រូវ: **食べているうちに、寝ました。** ⭕
   *កំពុងតែញ៉ាំស្រាប់តែគេងលក់បាត់ទៅ។*
   - **គន្លឹះ:** កុំប្រើ **～うちに** ជាមួយកិរិយាសព្ទទម្រង់អតីតកាល (た形) ពីព្រោះវាសំដៅលើស្ថានភាព ឬលក្ខខណ្ឌដែលកំពុងបន្តកើតមាននៅឡើយ។
2. **ការភាន់ច្រឡំជាមួយ ～間に:**
   - សូមចងចាំថា **～うちに** សង្កត់ធ្ងន់លើ "ការផ្លាស់ប្តូរដែលកើតឡើងដោយមិនដឹងខ្លួន" ឬ "ភាពបន្ទាន់ដែលត្រូវឆ្លៀតធ្វើមុនពេលស្ថានភាពផ្លាស់ប្តូរ" ចំណែកឯ **～間に** គ្រាន់តែបញ្ជាក់ពីចន្លោះពេលនៃពេលវេលាប៉ុណ្ណោះ។

### យុទ្ធសាស្ត្ររៀន (Learning Strategies)
- **វិធីសាស្ត្រជួយចងចាំ (Mnemonic):** គិតអំពីពាក្យ **うち** ថាមានន័យស្មើនឹង "ខាងក្នុង / ក្នុងរង្វង់" នៃកាលកំណត់ ឬលក្ខខណ្ឌមួយ។ ដូច្នេះ `〜うちに` គឺ "នៅក្នុងរង្វង់លក្ខខណ្ឌនោះ (បើផុតពីហ្នឹងគឺលែងបានហើយ)"។
- **ការអនុវត្តបង្កើតល្បះ:** អនុវត្តបង្កើតប្រយោគដោយប្រើទម្រង់កិរិយាសព្ទផ្សេងៗគ្នា (ដូចជា គុណនាម + うちに, ない + うちに, ている + うちに) ដើម្បីឱ្យកាន់តែស៊ាំនឹងការប្រើប្រាស់។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)
### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **～うちに (〜uchi ni)** ប្រើដើម្បីបញ្ជាក់ពីសកម្មភាពដែលត្រូវធ្វើ "ឆ្លៀតពេល" ឬ "មុនពេល" ស្ថានភាពផ្លាស់ប្តូរ ឬការផ្លាស់ប្តូរដែលកើតឡើងដោយមិនដឹងខ្លួន។
- អាចភ្ជាប់ជាមួយទម្រង់កិរិយាសព្ទជាច្រើន (ទម្រង់ដើម, ない, ている), គុណនាម い, គុណនាម な (+ な), និង នាម (+ の)។
- ហាមប្រើជាមួយកិរិយាសព្ទទម្រង់អតីតកាល (た形) ជាដាច់ខាត។
- យល់ដឹងពីភាពខុសគ្នារវាងវា និងទម្រង់ស្រដៀងគ្នាដូចជា **～間に** និង **～ながら**។

### កម្រងសំណួររំលឹកឡើងវិញខ្លីៗ (Quick Recap Quiz)
១. តើអ្នកអាចនិយាយប្រយោគ "អ្នកគួរតែអានសៀវភៅនេះ ឆ្លៀតពេលដែលអ្នកមានពេល" ដោយប្រើ **～うちに** យ៉ាងដូចម្តេច?
   - **ចម្លើយ:** **時間があるうちに、この本を読んだほうがいい。**
២. តើភាពខុសគ្នាដ៏សំខាន់រវាង **～うちに** និង **～ながら** គឺជាអ្វី?
   - **ចម្លើយ:** **～うちに** សំដៅលើការឆ្លៀតធ្វើសកម្មភាពខណៈពេលដែលលក្ខខណ្ឌមួយកំពុងមាន ឬមានការផ្លាស់ប្តូរដោយឯកឯង ចំណែកឯ **～ながら** បង្ហាញពីសកម្មភាពពីរដែលត្រូវបានអនុវត្តដំណាលគ្នាក្នុងពេលតែមួយដោយប្រធានតែមួយ។
៣. រកកំហុសក្នុងប្រយោគនេះ៖ **寝ているうちに、電話が鳴った。**
   - **ចម្លើយ:** គ្មានកំហុសទេ ប្រយោគនេះត្រឹមត្រូវតាមក្បួនវេយ្យាករណ៍ (ក្នុងអំឡុងពេលកំពុងគេង ស្រាប់តែទូរស័ព្ទរោទ៍ឡើង)។
