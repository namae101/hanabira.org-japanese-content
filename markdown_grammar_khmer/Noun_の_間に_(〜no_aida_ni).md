# វេយ្យាករណ៍ភាសាញ៉បុ៉ន: Noun の 間に (〜no aida ni)
**កម្រិត JLPT:** JLPT N4

---

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងមេរៀននេះ យើងនឹងសិក្សាអំពីទម្រង់វេយ្យាករណ៍ភាសាញ៉បុ៉នកម្រិត N4 ដ៏សំខាន់មួយ គឺ **Noun の 間に (〜のあいだに)**។ ទម្រង់វេយ្យាករណ៍នេះត្រូវបានប្រើប្រាស់ដើម្បីបង្ហាញអំពីគំនិតថា **"អំឡុងពេល..."**, **"កំឡុងពេល..."**, ឬ **"ក្នុងចន្លោះពេល..."** នៃព្រឹត្តិការណ៍ ឬកាលវេលាណាមួយ។ 

ចំណុចសំខាន់បំផុតនៃទម្រង់នេះ គឺការបញ្ជាក់ថាសកម្មភាព ឬព្រឹត្តិការណ៍មួយបានកើតឡើងនៅ**ខណៈពេលណាមួយ (momentary event / one-time action)** នៅក្នុងចន្លោះពេលនៃនាមខាងមុខ មិនមែនជាសកម្មភាពដែលកើតឡើងជាប់រហូតពេញមួយរយៈពេលនោះឡើយ។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
- **Noun の 間に** ប្រែជាភាសាខ្មែរថា **"ក្នុងអំឡុងពេល [នាម]"**, **"កំឡុងពេល [នាម]"**, ឬ **"នៅពេល [នាម]"**។
- ទម្រង់នេះបញ្ជាក់ថា មានសកម្មភាព ឬហេតុការណ៍អ្វីមួយបានកើតឡើង**នៅក្នុងរង្វង់ពេលវេលា** ឬ**ចន្លោះពេល**នៃនាមដែលនៅខាងមុខវា។

### ទម្រង់វេយ្យាករណ៍ (Structure)
```plaintext
នាម (Noun) + の + 間に (あいだに)
```

- **នាម (Noun)**: ជានាមដែលតំណាងឱ្យពេលវេលា រយៈពេល កម្មវិធី ឬសកម្មភាពដែលមានរយៈពេលជាក់លាក់មួយ (ឧទាហរណ៍៖ 昼休み - ម៉ោងសម្រាកថ្ងៃត្រង់, 夏休み - វិស្សមកាលរដូវក្តៅ, 授業 - ម៉ោងរៀន, 留守 - ពេលអវត្តមាន/មិននៅផ្ទះ)។
- **の**: ធ្នាក់ភ្ជាប់រវាងនាម និងពាក្យ 間に។
- **間に (あいだに)**: ផ្សំឡើងពីពាក្យ 間 (ចន្លោះ/អំឡុងពេល) + ធ្នាក់ に (បញ្ជាក់ចំណុចពេលវេលាកើតឡើង) មានន័យថា "ក្នុងអំឡុងពេល / នៅចន្លោះពេល"។

### តារាងរៀបចំទម្រង់ (Formation Diagram)
| ធាតុផ្សំ | មុខងារវេយ្យាករណ៍ | ឧទាហរណ៍ |
|---|---|---|
| **នាម (Noun)** | បញ្ជាក់កាលវេលា / ព្រឹត្តិការណ៍ | 映画 (*eiga* - ភាពយន្ត) |
| **の** | ធ្នាក់ភ្ជាប់នាម | の (*no*) |
| **間に** | បង្ហាញចំណុចពេលវេលានៅក្នុងចន្លោះនោះ ("អំឡុងពេល") | 間に (*aida ni*) |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuances)

ចំណុចគន្លឹះដែលអ្នករៀនភាសាញ៉បុ៉នកម្រិត N4 តែងតែច្រឡំ គឺភាពខុសគ្នារវាង **「Noun の 間」** (គ្មាន に) និង **「Noun の 間に」** (មាន に)។

### ១. ការប្រៀបធៀបយ៉ាងតឹងរ៉ឹងរវាង の間 និង の間に:

| ចំណុចប្រៀបធៀប | Noun の 間に (មាន に) | Noun の 間 (គ្មាន に) |
|---|---|---|
| **លក្ខណៈនៃសកម្មភាព** | **សកម្មភាពភ្លាមៗ / មួយភ្លែត (Momentary / Point action)** | **សកម្មភាព ឬស្ថានភាពបន្តបន្ទាប់ (Continuous state / action)** |
| **រយៈពេលកើតឡើង** | កើតឡើងនៅ**ចំណុចណាមួយ**ក្នុងអំឡុងពេលនោះ (មិនពេញម៉ោងទេ) | កើតឡើង**ជាប់រហូតពេញមួយរយៈពេល** តាំងពីដើមដល់ចប់ |
| **ប្រភេទកិរិយាសព្ទនៅខាងក្រោយ** | កិរិយាសព្ទសកម្មភាពតែមួយលើក, ហេតុការណ៍ភ្លាមៗ (鳴る, 買う, 終わる, 出会う, 寝てしまう) | កិរិយាសព្ទសភាព ឬទម្រង់បន្តបន្ទាប់ 〜ている (ずっと泣いていた, 待っていた, 降っていた) |
| **ឧទាហរណ៍ជាក់ស្តែង** | 映画の**間に**、電話が鳴りました。<br>*(ទូរស័ព្ទបានរោទ៍ឡើង**នៅក្នុងអំឡុងពេល**ទស្សនាភាពយន្ត - រោទ៍តែមួយភ្លែត)* | 映画の**間**、ずっと泣いていました。<br>*(ខ្ញុំបានយំ**ពេញមួយកំឡុងពេល**ទស្សនាភាពយន្ត - យំជាប់រហូតតាំងពីដើមដល់ចប់)* |

### ២. ន័យស៊ីជម្រៅសំខាន់ៗ (Detailed Semantic Nuances):
1. **តួនាទីរបស់ធ្នាក់ に:**
   - ក្នុងភាសាញ៉បុ៉ន ធ្នាក់ **に (ni)** ដើរតួជា "ម្ជុលចង្អុលពេលវេលាជាក់លាក់ (Specific point in time)"។ ដូច្នេះ នៅពេលដាក់ **間に** វាមានន័យថាក្នុងចន្លោះពេលដ៏វែងមួយ មានចំណុចមួយដែលសកម្មភាពខាងក្រោយបានកើតឡើង។
   - ចំណែកឯគ្មាន **に** (ពោលគឺ **間** សុទ្ធ) គឺចាត់ទុកចន្លោះពេលនោះទាំងមូលជា "រយៈពេលសរុប (Duration)" ទើបតម្រូវឱ្យសកម្មភាពខាងក្រោយមានលក្ខណៈបន្តរហូត (Continuous state)។

2. **ការប្រៀបធៀបជាមួយ うちに (Uchi ni):**
   - **間に** គ្រាន់តែបញ្ជាក់ពីព្រឹត្តិការណ៍ដែលកើតឡើងក្នុងចន្លោះពេលពីចំណុច A ដល់ចំណុច B តាមលក្ខណៈបរានុម័ត (Objective time frame)។
   - ចំណែកឯ **うちに** បង្កប់ន័យថា "ឆ្លៀតពេល / មុនពេលស្ថានភាពផ្លាស់ប្តូរ" ដោយផ្តោតលើអារម្មណ៍បន្ទាន់ ឬការឆ្លៀតឱកាសរបស់អ្នកនិយាយ (ឧទាហរណ៍៖ ក្តៅៗញ៉ាំឱ្យហើយ)។

## ៤. ឧទាហរណ៍ក្នុងបរិបទ (Examples in Context)

### ឧទាហរណ៍ប្រយោគទូទៅ (Sentence Examples)
1. **昼休みの間に、銀行へ行ってきます。**
   - *Hiru yasumi no aida ni, ginkō e itte kimasu.*
   - **ការបកប្រែ:** ខ្ញុំនឹងទៅធនាគារក្នុងអំឡុងពេលសម្រាកថ្ងៃត្រង់។
   - **ការពន្យល់:** ម៉ោងសម្រាកថ្ងៃត្រង់មានរយៈពេល ១ ម៉ោង ហើយការទៅធនាគារគឺជាសកម្មភាពមួយដែលធ្វើឡើងនៅចន្លោះពេលនោះ។

2. **雨の間に、傘を買いました。**
   - *Ame no aida ni, kasa o kaimashita.*
   - **ការបកប្រែ:** ខ្ញុំបានទិញឆ័ត្រមួយកំឡុងពេលមេឃកំពុងភ្លៀង។
   - **ការពន្យល់:** ការទិញឆ័ត្រជាសកម្មភាពមួយភ្លែតដែលកើតឡើងនៅពេលមេឃកំពុងតែភ្លៀង។

3. **旅行の間に、新しい友達と出会った。**
   - *Ryokō no aida ni, atarashii tomodachi to deatta.*
   - **ការបកប្រែ:** ខ្ញុំបានជួបមិត្តភក្តិថ្មីៗនៅក្នុងអំឡុងពេលធ្វើដំណើរកម្សាន្ត។
   - **ការពន្យល់:** ការជួបមិត្តភក្តិកើតឡើងនៅពេលណាមួយក្នុងដំណើរកម្សាន្ត។

4. **彼は講義の間に寝てしまった。**
   - *Kare wa kōgi no aida ni nete shimatta.*
   - **ការបកប្រែ:** គាត់បានគេងលក់បាត់ទៅហើយនៅអំឡុងពេលនៃការបង្រៀន/ការបាឋកថា។
   - **ការពន្យល់:** ការចាប់ផ្តើមគេងលក់គឺជាចំណុចហេតុការណ៍ដែលកើតឡើងកណ្តាលម៉ោងបង្រៀន។

5. **子供の間に、ピアノを習っていました。**
   - *Kodomo no aida ni, piano o naratte imashita.*
   - **ការបកប្រែ:** ខ្ញុំបានរៀនព្យាណូកាលពីកំឡុងពេលនៅកុមារភាព។

### បរិបទផ្លូវការ និងមិនផ្លូវការ (Formal and Informal Contexts)
- **ការនិយាយបែបផ្លូវការ / គួរសម (Formal Speech):**
  - **試験の間に、静かにしてください。**
  - *Shiken no aida ni, shizuka ni shite kudasai.*
  - "សូមមេត្តារក្សាភាពស្ងប់ស្ងាត់ក្នុងអំឡុងពេលប្រឡង។"
- **ការនិយាយបែបសាមញ្ញ / ស្និទ្ធស្នាល (Informal Speech):**
  - **待ってる間に、コーヒーでも飲もう。**
  - *Matteru aida ni, kōhī demo nomō.*
  - "ឆ្លៀតពេលកំពុងរង់ចាំ តោះយើងញ៉ាំកាហ្វេអីបន្តិចទៅ!"

## ៥. កំណត់សម្គាល់វប្បធម៌ (Cultural Notes)

### ទំនាក់ទំនងវប្បធម៌ជប៉ុន (Cultural Relevance)
នៅក្នុងវប្បធម៌ជប៉ុន ការគោរពពេលវេលា និងការរក្សាមារយាទឱ្យបានត្រឹមត្រូវទៅតាមកាលៈទេសៈគឺជាគុណតម្លៃខ្ពស់បំផុត។ ការប្រើប្រាស់ **の間に** ឱ្យបានត្រឹមត្រូវបង្ហាញពីការយល់ដឹងអំពីព្រំដែនពេលវេលា និងការគោរពទំនួលខុសត្រូវក្នុងសង្គម ដូចជាការបំពេញការងារផ្ទាល់ខ្លួនឱ្យទាន់ពេលវេលាក្នុងម៉ោងកំណត់ ឬការមិនបង្កការរំខានដល់អ្នកដទៃ។

### ឃ្លាសព្វវចនៈ និងទម្រង់ពេញនិយម (Idiomatic Expressions)
- **留守の間に (rusu no aida ni)**: "កំឡុងពេលអវត្តមាន / កំឡុងពេលមិននៅផ្ទះ"
  - **彼の留守の間に、部屋を掃除した。**
  - "ខ្ញុំបានបោសសម្អាតបន្ទប់ក្នុងអំឡុងពេលដែលគាត់មិននៅផ្ទះ។"
  
- **忙しい間に (isogashii aida ni)**: "ក្នុងពេលកំពុងរវល់ខ្លាំង"
  - ប្រើសម្រាប់ការសម្តែងការដឹងគុណចំពោះការលះបង់ពេលវេលារបស់នរណាម្នាក់៖
  - **お忙しい間に、ありがとうございます。**
  - "សូមអរគុណយ៉ាងជ្រាលជ្រៅចំពោះពេលវេលាដ៏មានតម្លៃរបស់លោក/លោកស្រី នៅក្នុងអំឡុងពេលដ៏រវល់នេះ។"

---

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
1. **ការភ្លេចប្រើធ្នាក់ の (Forgetting the particle の):**
   - **ខុស:** 休み間に、旅行しました。 ❌
   - **ត្រូវ:** 休み**の**間に、旅行しました。 ⭕
   - **គន្លឹះ:** ត្រូវចាំថា 間 (aida) ជានាម ដូច្នេះកាលណាភ្ជាប់នាមជាមួយនាម គឺត្រូវតែមានធ្នាក់ **の** ជានិច្ច។

2. **ការប្រើ 間 ជំនួស 間に ពេលសកម្មភាពមិនមែនជាការបន្តរហូត:**
   - **ខុស:** 映画の間、電話が鳴りました。 ❌ (ស្តាប់ទៅដូចជាទូរស័ព្ទរោទ៍ជាប់រហូតមិនឈប់តាំងពីដើមរឿងដល់ចប់រឿង)
   - **ត្រូវ:** 映画の**間に**、電話が鳴りました。 ⭕ (ទូរស័ព្ទរោទ៍ឡើងនៅពេលណាមួយក្នុងរឿង)

### យុទ្ធសាស្ត្ររៀនសូត្រ (Learning Strategies)
- **ចងចាំរូបភាព "ចំណុចមួយនៅចន្លោះ":** ចូរគិតថា **間に** គឺជាចំណុចព្រឹត្តិការណ៍មួយដែលលេចឡើង (pop up) ភ្លាមៗនៅក្នុងប្រអប់ពេលវេលាណាមួយ។
- **អនុវត្តជាមួយសកម្មភាពប្រចាំថ្ងៃ:** បង្កើតប្រយោគជាមួយទម្លាប់ប្រចាំថ្ងៃរបស់អ្នក៖
  - **朝ご飯の間に、ニュースを見ます。**
  - "ខ្ញុំមើលព័ត៌មានកំឡុងពេលញ៉ាំអាហារពេលព្រឹក។"

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **Noun の 間に** ប្រើសម្រាប់បង្ហាញសកម្មភាពដែលកើតឡើង**នៅចំណុចណាមួយក្នុងអំឡុងពេល**នៃព្រឹត្តិការណ៍ ឬកាលវេលាជាក់លាក់។
- ធ្នាក់ **の** គឺមិនអាចខ្វះបានឡើយក្នុងការភ្ជាប់នាមទៅកាន់ 間に។
- ប្រើ **間に** សម្រាប់សកម្មភាពភ្លាមៗមួយលើក (Momentary action) ហើយប្រើ **間** (គ្មាន に) សម្រាប់សកម្មភាព ឬស្ថានភាពដែលបន្តរហូតពេញមួយរយៈពេល (Continuous state)។

### សំណួររំលឹកមេរៀនរហ័ស (Quick Recap Quiz)
១. តើប្រយោគ "ខ្ញុំបានអានសៀវភៅក្នុងអំឡុងពេលជិះយន្តហោះ" និយាយជាភាសាញ៉បុ៉នយ៉ាងដូចម្តេច?  
២. តើអ្វីជាភាពខុសគ្នាជាចម្បងរវាង **間** និង **間に**?  
៣. ចូរកែកំហុសក្នុងប្រយោគនេះ៖ *映画間に、電話しないでください。*  

**ចម្លើយ:**  
១. **飛行機の間に、本を読みました。** (*Hikōki no aida ni, hon o yomimashita.*)  
២. **間** សម្គាល់សកម្មភាពបន្តរហូតពេញមួយរយៈពេល; ចំណែក **間に** សម្គាល់សកម្មភាពដែលកើតឡើងតែនៅចំណុចណាមួយក្នុងចន្លោះពេលនោះប៉ុណ្ណោះ។  
៣. ប្រយោគដែលកែរួច៖ **映画**の**間に、電話しないでください。** (*Eiga no aida ni, denwa shinai de kudasai.*)
