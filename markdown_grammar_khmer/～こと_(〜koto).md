# ចំណុចវេយ្យាករណ៍ជប៉ុន: ～こと (〜koto)
**កម្រិត JLPT:** JLPT N3

## ១. សេចក្តីផ្តើម (Introduction)
ទម្រង់វេយ្យាករណ៍ជប៉ុន **～こと (koto)** គឺជាពាក្យដ៏សម្បូរបែបមួយដែលមានមុខងារជាច្រើននៅក្នុងភាសាជប៉ុន។ ជាទូទៅ វាត្រូវបានប្រើប្រាស់សម្រាប់៖
- **ធ្វើឱ្យកិរិយាសព្ទ និងគុណនាមក្លាយជានាម (Nominalization)** ពោលគឺបំប្លែងកិរិយាសព្ទ ឬគុណនាមឱ្យទៅជាកន្សោមនាម។
- **បង្ហាញអំពីបទពិសោធន៍ (Expressing experiences)** ដើម្បីបញ្ជាក់ថាតើនរណាម្នាក់ធ្លាប់ ឬមិនធ្លាប់ធ្វើអ្វីមួយពីមុនមក។
- **កំណត់បទបញ្ជា បទប្បញ្ញត្តិ ឬកាតព្វកិច្ច (Stating rules or obligations)** ដែលជាញឹកញាប់ត្រូវបានគេប្រទះឃើញនៅលើសេចក្តីជូនដំណឹង ឬគោលការណ៍ណែនាំនានា។
- **សង្កត់ធ្ងន់លើព័ត៌មាន ឬអារម្មណ៍ (Emphasis & Exclamation)** នៅក្នុងបរិបទនៃការសន្ទនា ឬការសរសេរ។

ការយល់ដឹងច្បាស់អំពីរបៀបប្រើប្រាស់ **～こと** នឹងជួយបង្កើនសមត្ថភាពរបស់អ្នកក្នុងការយល់ដឹង និងការបញ្ចេញមតិ ឬគំនិតស្មុគស្មាញជាភាសាជប៉ុនឱ្យកាន់តែមានប្រសិទ្ធភាព។

---

## ២. ការពន្យល់វេយ្យាករណ៍ស្នូល (Core Grammar Explanation)

### អត្ថន័យ និងការប្រើប្រាស់ (Meaning and Usage)
ពាក្យ **こと** (koto) ជាទូទៅមានន័យថា "រឿង", "បញ្ហា", "ការ...", ឬ "អំពើ..."។ នៅក្នុងវេយ្យាករណ៍ វាមានមុខងារសំខាន់ៗដូចខាងក្រោម៖
1. **ការធ្វើឱ្យក្លាយជានាម (Nominalization)**: បំប្លែងកិរិយាសព្ទ និងគុណនាមឱ្យទៅជានាម។
2. **ការបង្ហាញបទពិសោធន៍ (Expressing Experience)**: បញ្ជាក់ពីបទពិសោធន៍ធ្លាប់បានធ្វើអ្វីមួយកាលពីអតីតកាល។
3. **ការកំណត់បទបញ្ជា ឬកាតព្វកិច្ច (Stating Rules / Regulations)**: ប្រើនៅចុងល្បះដើម្បីផ្តល់ការណែនាំ បទបញ្ជា ឬបំរាម។
4. **ការសង្កត់ធ្ងន់ ឬឧទានបង្ហាញអារម្មណ៍ (Emphasis / Exclamation)**: សង្កត់ធ្ងន់លើការពិតជាក់លាក់ ឬឧទានបង្ហាញពីទំហំនៃអារម្មណ៍។

---

### រចនាសម្ព័ន្ធ និងទម្រង់ផ្សំ (Structure and Formation)

#### ១. ការធ្វើឱ្យក្លាយជានាម (Nominalization)
- **កិរិយាសព្ទ (ទម្រង់វចនានុក្រម / 辞書形) + こと**
  បំប្លែងកិរិយាសព្ទឱ្យក្លាយជាកន្សោមនាម (ការ... / អំពើ...)៖
  ```markdown
  食べる + こと = 食べること (taberu koto) - ការទទួលទាន / ការញ៉ាំ
  ```
- **គុណនាម い + こと**
  បំប្លែងគុណនាម い ឱ្យក្លាយជានាម (ភាព... / ការពិតដែល...)៖
  ```markdown
  速い + こと = 速いこと (hayai koto) - ភាពលឿន / ការពិតដែលថា [អ្វីមួយ] លឿន
  ```
- **គុណនាម な + な + こと**
  បំប្លែងគុណនាម な ឱ្យក្លាយជានាម៖
  ```markdown
  静か + な + こと = 静かなこと (shizuka na koto) - ភាពស្ងប់ស្ងាត់ / ការពិតដែលថា [ទីកន្លែងនោះ] ស្ងប់ស្ងាត់
  ```

#### ២. ការបង្ហាញបទពិសោធន៍ (Expressing Experience)
- **កិរិយាសព្ទ (ទម្រង់ た / た形) + ことがある**
  បង្ហាញថាធ្លាប់មានបទពិសោធន៍ធ្វើសកម្មភាពអ្វីមួយពីមុនមក៖
  ```markdown
  行った + ことがある = 行ったことがある (itta koto ga aru) - ធ្លាប់បានទៅ [កន្លែងណាមួយ]
  ```

#### ៣. ការកំណត់បទបញ្ជា ឬកាតព្វកិច្ច (Stating Rules, Regulations or Directives - N3)
- **កិរិយាសព្ទ (ទម្រង់វចនានុក្រម / 辞書形) + こと**
  ប្រើនៅចុងប្រយោគដើម្បីចេញបញ្ជាជាផ្លូវការ បទប្បញ្ញត្តិ ឬការណែនាំ ("ត្រូវតែ...", "ចូរ...")៖
  ```markdown
  時間を守る + こと = 時間を守ること (jikan o mamoru koto) - ត្រូវគោរពពេលវេលា។
  ```
- **កិរិយាសព្ទ (ទម្រង់ ない / ない形) + こと**
  បង្ហាញពីបំរាម ឬការហាមឃាត់ជាផ្លូវការ ("ហាម...", "កុំ...")៖
  ```markdown
  入らない + こと = 入らないこと (hairanai koto) - ហាមចូល / មិនត្រូវចូលឡើយ។
  ```

#### ៤. ឧទានបង្ហាញអារម្មណ៍យ៉ាងខ្លាំង (Emotional Exclamation - ことか)
- **កិរិយាសព្ទ (ទម្រង់ដើម/た形) / គុណនាម + ことか**
  ប្រើជាមួយពាក្យបញ្ជាក់កម្រិតដូចជា どんなに, どれほど, 何度 ដើម្បីឧទានបង្ហាញពីទំហំអារម្មណ៍ដ៏ជ្រាលជ្រៅ ("...យ៉ាងណាទៅហ្ន៎!", "...ខ្លាំងណាស់ណា!")៖
  ```markdown
  うれしかった + ことか = うれしかったことか (ureshikatta koto ka) - ពិតជាសប្បាយរីករាយខ្លាំងណាស់ណា!
  ```

### តារាងសង្ខេបទម្រង់វេយ្យាករណ៍ (Formation Table)

| មុខងារ (Function) | រចនាសម្ព័ន្ធ (Structure) | ឧទាហរណ៍ (Example) |
|---|---|---|
| ធ្វើឱ្យក្លាយជានាម (Nominalization) | កិរិយាសព្ទ (辞書形) + こと | 食べること (taberu koto) - ការញ៉ាំ |
| បង្ហាញបទពិសោធន៍ (Experience) | កិរិយាសព្ទ (た形) + ことがある | 行ったことがある (itta koto ga aru) - ធ្លាប់ទៅ |
| បទបញ្ជា/បទប្បញ្ញត្តិ (Rules/Regulations) | កិរិយាសព្ទ (辞書形/ない形) + こと | 勉強すること (benkyō suru koto) - ត្រូវរៀន<br>遅刻しないこと (chikoku shinai koto) - ហាមមកយឺត |

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Nuance and Comparative Analysis)

### ១. ការប្រៀបធៀបរវាង こと vs. の ក្នុងការធ្វើជានាម (Nominalization)
ទោះបីជាទាំង **こと** និង **の** អាចបំប្លែងកិរិយាសព្ទឱ្យទៅជានាមបានដូចគ្នាក៏ដោយ ក៏វាមានភាពខុសគ្នាយ៉ាងជាក់លាក់លើកម្រិតន័យ៖
- **こと**: សំដៅទៅលើសកម្មភាព គំនិត ឬការពិតក្នុងន័យអរូបី (abstract), ជាទូទៅ (general), ឬជាទស្សនៈផ្លូវការ។ ត្រូវតែប្រើ `こと` ជាមួយកិរិយាសព្ទមួយចំនួនដូចជា `話す` (និយាយរឿង), `約束する` (សន្យាថា...), `祈る` (បួងសួងឱ្យ...)។
  ```markdown
  音楽を聞くことが好きです。
  (Ongaku o kiku koto ga suki desu.)
  ខ្ញុំចូលចិត្តការស្តាប់តន្ត្រី។ (និយាយជាទូទៅអំពីចំណូលចិត្ត)
  ```
- **の**: មានលក្ខណៈជាក់ស្តែង បច្ចុប្បន្នភាព និងផ្ទាល់ខ្លួនជាង ជាពិសេសទាក់ទងនឹងសកម្មភាពរូបវន្ត ឬញាណដឹងផ្ទាល់ (ការមើលឃើញ ការឮ ការរង់ចាំ ការបញ្ឈប់សកម្មភាពជាក់ស្តែង)។
  ```markdown
  音楽を聞くのが聞こえる。
  (Ongaku o kiku no ga kikoeru.)
  ខ្ញុំឮសំឡេងនរណាម្នាក់កំពុងស្តាប់តន្ត្រី។ (ញាណដឹងជាក់ស្តែងតាមត្រចៀក)
  ```

### ២. ន័យស៊ីជម្រៅកម្រិត N3: បទបញ្ជា និងច្បាប់ទម្លាប់ (Formal Command / Regulation: ～こと)
នៅកម្រិត N3 ការប្រើ **[កិរិយាសព្ទ 辞書形 / ない形] + こと** នៅចុងល្បះ គឺជាទម្រង់ចេញបញ្ជា ឬកំណត់គោលការណ៍យ៉ាងសំខាន់៖
- **កម្រិតគួរសម និងបរិបទ (Register & Context):** នេះមិនមែនជាការបញ្ជាផ្ទាល់មាត់ក្នុងការសន្ទនាធម្មតានោះទេ (បើនិយាយផ្ទាល់មាត់ គេច្រើនប្រើ `〜てください` ឬ `〜しなさい`)។ ផ្ទុយទៅវិញ `～こと` ត្រូវបានប្រើប្រាស់ជាលាយលក្ខណ៍អក្សរផ្លូវការ ដូចជា **នៅលើក្តារខៀនសេចក្តីជូនដំណឹង បទបញ្ជាផ្ទៃក្នុងសាលា ឬកន្លែងធ្វើការ ក្រឹត្យក្រម ឬសន្លឹកកិច្ចការប្រឡង**។
- **លក្ខណៈពិសេស:** វាបង្ហាញពីច្បាប់ទូទៅដែលមនុស្សគ្រប់រូបត្រូវតែអនុវត្តតាម ដោយគ្មានការលើកលែង។
  - **遅刻しないこと。** (Chikoku shinai koto.) = ហាមយឺតយ៉ាវជាដាច់ខាត / មិនត្រូវមកយឺតឡើយ (បទបញ្ជាផ្លូវការ)។
  - **名前を書くこと。** (Namae o kaku koto.) = ត្រូវសរសេរឈ្មោះឱ្យបានត្រឹមត្រូវ។

---

### ៣. ន័យស៊ីជម្រៅកម្រិត N3: ឧទានបង្ហាញអារម្មណ៍ជ្រាលជ្រៅ (Emotional Exclamation: ～ことか)
រចនាសម្ព័ន្ធ **[កិរិយាសព្ទ / គុណនាម] + ことか** គឺជាទម្រង់ N3 សម្រាប់បង្ហាញពីការឧទានដ៏រំជួលចិត្ត៖
- **លក្ខណៈវេយ្យាករណ៍:** ច្រើនប្រើរួមគ្នាជាមួយពាក្យជំនួយបញ្ជាក់ទំហំដូចជា **どんなに** (យ៉ាងណាទៅហ្ន៎), **どれほど** (កម្រិតណាទៅ), **何度** (ប៉ុន្មានដងមកហើយ)។
- **ន័យស៊ីជម្រៅ:** វាបង្ហាញថាអ្នកនិយាយមានអារម្មណ៍រំជួលចិត្តយ៉ាងជ្រាលជ្រៅ ឬជួបប្រទះស្ថានភាពនោះក្នុងកម្រិតធំធេងលើសពីការស្មាន។
  ```markdown
  合格を知った時、どんなにうれしかったことか。
  (Gōkaku o shitta toki, donna ni ureshikatta koto ka.)
  នៅពេលដែលដឹងថាប្រឡងជាប់ តើអ្នកដឹងទេថាខ្ញុំសប្បាយចិត្តខ្លាំងយ៉ាងណាទៅហ្ន៎! (បង្ហាញពីអារម្មណ៍សប្បាយរីករាយឥតឧបមា)
  ```

---

### ៤. ការប្រៀបធៀបរវាង ことがある vs. たことがある
- **កិរិយាសព្ទ (ទម្រង់វចនានុក្រម / 辞書形) + ことがある**: បង្ហាញពីទម្លាប់ ឬហេតុការណ៍ដែលជួនកាលកើតឡើងម្តងម្កាល ("ជួនកាល...ដែរ", "ម្តងម្កាល...ដែរ")។
  ```markdown
  彼は遅刻することがある。
  (Kare wa chikoku suru koto ga aru.)
  គាត់ជួនកាលមកយឺតដែរ។ (ទម្លាប់ម្តងម្កាល)
  ```
- **កិរិយាសព្ទ (ទម្រង់ た / た形) + ことがある**: បង្ហាញពីបទពិសោធន៍ដែលធ្លាប់បានកើតឡើងកាលពីអតីតកាល ("ធ្លាប់...")។
  ```markdown
  彼は遅刻したことがある。
  (Kare wa chikoku shita koto ga aru.)
  គាត់ធ្លាប់មកយឺតពីមុនមក។ (បទពិសោធន៍ពីអតីតកាល)
  ```

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### ១. ការធ្វើឱ្យក្លាយជានាម (Nominalization)
- **漢字を勉強することは大切です。**
  - *Kanji o benkyō suru koto wa taisetsu desu.*
  - ការរៀនអក្សរកាន់ជិ (Kanji) គឺពិតជាសំខាន់ណាស់។
- **走ることが趣味です。**
  - *Hashiru koto ga shumi desu.*
  - ការរត់ប្រណាំង គឺជាចំណូលចិត្តរបស់ខ្ញុំ។

### ២. ការបង្ហាញបទពិសោធន៍ (Expressing Experience)
- **日本料理を食べたことがありますか。**
  - *Nihon ryōri o tabeta koto ga arimasu ka.*
  - តើអ្នកធ្លាប់ទទួលទានម្ហូបជប៉ុនពីមុនមកដែរឬទេ?
- **一度も行ったことがありません。**
  - *Ichido mo itta koto ga arimasen.*
  - ខ្ញុំមិនដែលធ្លាប់បានទៅទីនោះសូម្បីតែម្តងណាឡើយ។

### ៣. ការកំណត់បទបញ្ជា ឬកាតព្វកិច្ច (Rules and Regulations - N3)
- **ここでタバコを吸わないこと。**
  - *Koko de tabako o suwanai koto.*
  - ហាមជក់បារីនៅទីនេះជាដាច់ខាត។ (សេចក្តីណែនាំ/បំរាមលើស្លាកសញ្ញា)
- **レポートは金曜日までに提出すること。**
  - *Repōto wa kin'yōbi made ni teishutsu suru koto.*
  - ត្រូវប្រគល់របាយការណ៍ឱ្យបានមុន ឬត្រឹមថ្ងៃសុក្រ។

### ៤. ការសង្កត់ធ្ងន់ និងការឧទានអារម្មណ៍ (Emphasis & Exclamation)
- **大事なことだから、忘れないでください。**
  - *Daiji na koto dakara, wasurenaide kudasai.*
  - ដោយសារតែវាជារឿងសំខាន់ សូមកុំភ្លេចឱ្យសោះណា។
- **日本での生活はどれほど大変だったことか。**
  - *Nihon de no seikatsu wa dore hodo taihen datta koto ka.*
  - ជីវិតរស់នៅក្នុងប្រទេសជប៉ុនកាលណោះ ពិតជាលំបាកខ្លាំងណាស់ណា!

## ៥. កត់សម្គាល់ខាងវប្បធម៌ និងកន្សោមពាក្យពិសេស (Cultural Notes & Idiomatic Expressions)

### ទស្សនៈវប្បធម៌ជប៉ុន (Cultural Relevance)
- **ការប្រើប្រាស់ こと ក្នុងបទបញ្ជា និងច្បាប់ទម្លាប់សាធារណៈ**
  នៅក្នុងសង្គមជប៉ុន បទបញ្ជា ក្រមប្រតិបត្តិ និងសេចក្តីជូនដំណឹងជាសាធារណៈច្រើនប្រើប្រាស់ទម្រង់ **こと**។ ការប្រើបែបនេះផ្តល់នូវសម្លេងផ្លូវការ មិនលម្អៀង និងមិនចង្អុលមុខចំៗទៅលើបុគ្គលណាជាក់លាក់ឡើយ ប៉ុន្តែវាជាកាតព្វកិច្ចទូទៅដែលសមាជិកសង្គមគ្រប់រូបត្រូវគោរព ដើម្បីរក្សាសណ្តាប់ធ្នាប់ និងភាពចុះសម្រុងរួម (和 - Wa)។
  ```markdown
  傘は入口に置くこと。
  (Kasa wa iriguchi ni oku koto.)
  ត្រូវទុកឆ័ត្រនៅឯច្រកចូល។
  ```

### កន្សោមពាក្យទាក់ទងនឹង こと ដែលគួរចងចាំ (Idiomatic Expressions)
- **ことになる (Koto ni naru)**: ត្រូវបានសម្រេចថា... / មានការកំណត់ថា... (ជាការសម្រេចចិត្តពីខាងក្រៅ ឬអង្គភាព មិនមែនការសម្រេចចិត្តផ្ទាល់ខ្លួនឡើយ)
  ```markdown
  来月から大阪に転勤することになりました。
  (Raigetsu kara Ōsaka ni tenkin suru koto ni narimashita.)
  ខ្ញុំត្រូវបានគេសម្រេចផ្ទេរការងារឱ្យទៅធ្វើនៅអូសាកាចាប់ពីខែក្រោយ។
  ```
- **ことにする (Koto ni suru)**: សម្រេចចិត្តថា... (ជាការប្តេជ្ញាចិត្ត ឬការសម្រេចចិត្តផ្ទាល់ខ្លួនរបស់អ្នកនិយាយ)
  ```markdown
  毎日運動することにします。
  (Mainichi undō suru koto ni shimasu.)
  ខ្ញុំបានសម្រេចចិត្តថានឹងហាត់ប្រាណជារៀងរាល់ថ្ងៃ។
  ```

## ៦. កំហុសទូទៅ និងគន្លឹះជំនួយស្មារតី (Common Mistakes and Tips)

### ការវិភាគកំហុស (Error Analysis)
- **ការភ័ន្តច្រឡំរវាង こと និង の**
  អ្នករៀនច្រើនតែច្រឡំក្នុងការបំប្លែងកិរិយាសព្ទជានាម។ សូមចងចាំថា៖
  - ប្រើ **こと** សម្រាប់សកម្មភាពទូទៅ មេរៀន ទស្សនៈអរូបី ឬពេលចង់បង្ហាញគោលការណ៍។
  - ប្រើ **の** នៅពេលសំដៅលើសកម្មភាពជាក់ស្តែងដែលកំពុងកើតឡើងនៅចំពោះមុខ ឬមានការដឹងតាមរយៈញាណ (ការមើល ការស្តាប់)។
- **ការប្រើខុសទម្រង់កិរិយាសព្ទជាមួយ ことがある**
  នៅពេលចង់បង្ហាញពី "បទពិសោធន៍" ត្រូវតែប្រើកិរិយាសព្ទ **ទម្រង់ た (た形)** នៅពីមុខ `ことがある`៖
  - ❌ ខុស: **行くことがある。** (មានន័យថា "ជួនកាលខ្ញុំទៅដែរ" មិនមែនមានន័យថាធ្លាប់ទៅនោះទេ)
  -  ត្រឹមត្រូវ: **行ったことがある。** ("ខ្ញុំធ្លាប់បានទៅ")

### យុទ្ធសាស្ត្រនៃការរៀន (Learning Strategies)
- **អនុវត្តជាមួយកិរិយាសព្ទប្រចាំថ្ងៃ:** សាកល្បងបង្កើតល្បះផ្ទាល់ខ្លួនដោយប្រើ `〜こと` ជាមួយសកម្មភាពប្រចាំថ្ងៃ ដូចជាការសិក្សា ការងារ ឬចំណង់ចំណូលចិត្ត។
- **ស្រមៃមើលបរិបទជាក់ស្តែង:** ស្រមៃមើលស្លាកសញ្ញាបទបញ្ជានៅតាមស្ថានីយរថភ្លើង ឬការិយាល័យ (`〜こと`) ឬរំលឹកពីបទពិសោធន៍ផ្ទាល់ខ្លួនកាលពីមុន (`〜たことがある`)។
- **គន្លឹះទន្ទេញចាំ:**
  - `〜ことにする` = "ខ្ញុំធ្វើឱ្យវាក្លាយជារឿងត្រូវធ្វើ" ➔ សម្រេចចិត្តធ្វើដោយខ្លួនឯង។
  - `〜ことになる` = "រឿងនោះបានក្លាយជាបែបនោះ" ➔ ការសម្រេចចិត្តពីខាងក្រៅ ឬកាលៈទេសៈកំណត់។

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចគន្លឹះសំខាន់ៗ (Key Takeaways)
- **こと** ជាពាក្យពហុមុខងារដ៏សំខាន់៖ បំប្លែងកិរិយាសព្ទ/គុណនាមជានាម, បង្ហាញបទពិសោធន៍, ចេញបទបញ្ជាជាលាយលក្ខណ៍អក្សរ, និងឧទានបង្ហាញអារម្មណ៍។
- បែងចែកឱ្យច្បាស់រវាង **こと** (អរូបី/ទូទៅ/ច្បាប់) និង **の** (ជាក់ស្តែង/ញាណដឹងផ្ទាល់)។
- នៅកម្រិត N3 សូមយកចិត្តទុកដាក់ខ្ពស់លើទម្រង់បទបញ្ជាជាលាយលក្ខណ៍អក្សរ (`辞書形/ない形 + こと`) និងទម្រង់ឧទានអារម្មណ៍ (`〜ことか`)។

### កម្រងសំណួររំលឹកមេរៀន (Quick Recap Quiz)
១. **ការបង្ហាញបទពិសោធន៍ (Expressing Experience)**
   តើប្រយោគ "ខ្ញុំធ្លាប់បានរៀនភាសាជប៉ុនពីមុនមក" និយាយជាភាសាជប៉ុនយ៉ាងដូចម្តេច?
   - **ចម្លើយ**: 日本語を勉強したことがあります。
     - *Nihongo o benkyō shita koto ga arimasu.*

២. **ការកំណត់បទបញ្ជា (Stating a Rule)**
   ចូរផ្លាស់ប្តូរប្រយោគ "ហាមរត់នៅតាមផ្លូវដើរ/ច្រករបៀង" ជាភាសាជប៉ុនដោយប្រើ **こと**៖
   - **ចម្លើយ**: 廊下を走らないこと。
     - *Rōka o hashiranai koto.*

៣. **ការធ្វើឱ្យក្លាយជានាម (Nominalization)**
   ចូរបំប្លែងកិរិយាសព្ទ "ហែលទឹក" (泳ぐ) ឱ្យក្លាយជានាមដោយប្រើ **こと**៖
   - **ចម្លើយ**: 泳ぐこと
