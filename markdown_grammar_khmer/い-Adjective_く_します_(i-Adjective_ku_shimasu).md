# ចំណុចវេយ្យាករណ៍ជប៉ុន៖ い-Adjective く します (i-Adjective ku shimasu)
**កម្រិត JLPT:** JLPT N5

---

## ១. សេចក្តីផ្តើម (Introduction)
នៅក្នុងភាសាជប៉ុន ទម្រង់វេយ្យាករណ៍ **〜くします** ត្រូវបានប្រើប្រាស់ដើម្បីបង្ហាញអំពីការធ្វើសកម្មភាពដោយចេតនា ដើម្បីផ្លាស់ប្តូរអ្វីមួយឱ្យទៅជាសភាពណាមួយដែលពិពណ៌នាដោយ **គុណនាម い (い-adjective)**។ ក្នុងភាសាខ្មែរ វាមានន័យស្មើនឹង «ធ្វើឱ្យ... [គុណនាម]» ឬ «កែប្រែឱ្យ... [គុណនាម]»។ នេះជាទម្រង់វេយ្យាករណ៍ដ៏មានសារៈសំខាន់ និងប្រើប្រាស់ញឹកញាប់សម្រាប់បញ្ជាក់ពីការកែសម្រួលស្ថានភាព វត្ថុ ឬបរិយាកាសជុំវិញខ្លួន។

---

## ២. ការពន្យល់វេយ្យាករណ៍គោល (Core Grammar Explanation)

### អត្ថន័យ (Meaning)
ទម្រង់ **គុណនាម い + くします** មានន័យថា «ធ្វើឱ្យ... (គុណនាម)» ឬ «ផ្លាស់ប្តូរ... ឱ្យទៅជា (គុណនាម)» ដោយផ្តោតលើឥទ្ធិពលនៃសកម្មភាពដែលបង្កើតឡើងដោយមនុស្ស។

### ទម្រង់ក្បួន (Structure)
របៀបបង្កើតទម្រង់នេះ៖
1. យក **គុណនាម い (い-adjective)**។
2. លុបកន្ទុយ **〜い** ចេញ រួចជំនួសដោយ **〜く**។
3. បន្ថែម **します** (ឬទម្រង់ផ្សេងៗរបស់កិរិយាសព្ទ する ដូចជា して, しました, してください) នៅខាងចុង។

### ដ្យាក្រាមទម្រង់ (Formation Diagram)
```
[គុណនាម い] (លុប い)  +  く  +  します
```

### ឧទាហរណ៍នៃការបំប្លែង (Example Formation)
- **大きい** (*ōkii* - ធំ) ➔ **大き** + **く** + **します** ➔ **大きくします** (*ōkiku shimasu* - ធ្វើឱ្យធំឡើង / បង្កើនទំហំ ឬកម្រិតសំឡេង)
- **早い** (*hayai* - លឿន/ព្រលឹម) ➔ **早** + **く** + **します** ➔ **早くします** (*hayaku shimasu* - ធ្វើឱ្យលឿន / ប្រញាប់)
- **いい / 良い** (*ii / yoi* - ល្អ) ➔ **良** + **く** + **します** ➔ **良くします** (*yoku shimasu* - ធ្វើឱ្យល្អប្រសើរឡើង)

## ៣. ការវិភាគប្រៀបធៀប និង ន័យស៊ីជម្រៅ (Comparative Analysis & Nuance)

### ការប្រៀបធៀបរវាង «〜くします» និង «〜くなります» (ចេតនារបស់មនុស្ស vs ការប្រែប្រួលតាមធម្មជាតិ)
ចំណុចសំខាន់បំផុតនៃការយល់ដឹងវេយ្យាករណ៍នេះ គឺការបែងចែកឱ្យដាច់ស្រឡះរវាង **〜くします** និង **〜くなります**៖

| លក្ខណៈ | 〜くします (ku shimasu) | 〜くなります (ku narimasu) |
| :--- | :--- | :--- |
| **ប្រភេទនៃការផ្លាស់ប្តូរ** | ការផ្លាស់ប្តូរដោយ**ចេតនារបស់មនុស្ស** (Deliberate human action / Causation) | ការផ្លាស់ប្តូរ**តាមធម្មជាតិ ឬឯកឯង** (Natural change / Spontaneous state) |
| **កិរិយាសព្ទគោល** | **します** (ធ្វើ - សកម្មភាពមានកម្មបទ) | **なります** (ក្លាយជា - ការប្រែប្រួលសភាព) |
| **ធ្នាក់ (Particles)** | ជាទូទៅប្រើធ្នាក់ **を (o)** ជាមួយវត្ថុរងអំពើ (`[នាម] を [គុណនាម い] くします`) | ជាទូទៅប្រើធ្នាក់ **が (ga)** ឬ **は (wa)** (`[នាម] が [គុណនាម い] くなります`) |
| **ឧទាហរណ៍ជាក់ស្តែង** | **部屋を明るくします。**<br>*(ខ្ញុំបើកភ្លើង/បើកវាំងនន) ធ្វើឱ្យបន្ទប់ភ្លឺ។ (មានអ្នកធ្វើសកម្មភាព)* | **部屋が明るくなりました。**<br>*បន្ទប់ភ្លឺឡើងហើយ (ឧ. ព្រះអាទិត្យរះឡើង បន្ទប់ក៏ភ្លឺដោយឯកឯង)។* |
| **អត្ថន័យ** | «ធ្វើឱ្យ...» | «ប្រែជា... / ក្លាយជា...» |

### ភាពខុសគ្នារវាងប្រភេទពាក្យដទៃទៀត (い-Adjectives vs な-Adjectives & Nouns)
- **គុណនាម い (い-adjective)**៖ ប្រើ **〜くします**
  - **安くします** (*yasuku shimasu*) = បញ្ចុះតម្លៃ / ធ្វើឱ្យថោក
- **គុណនាម な (な-adjective)**៖ ប្រើ **〜にします**
  - **静かにします** (*shizuka ni shimasu*) = ធ្វើឱ្យស្ងាត់ស្ងៀម / រក្សាភាពស្ងប់ស្ងាត់
  - **きれいにします** (*kirei ni shimasu*) = សម្អាតឱ្យស្អាត / ធ្វើឱ្យស្អាត
- **នាម (Noun)**៖ ប្រើ **〜にします**
  - **半分にします** (*hanbun ni shimasu*) = ពុះ/កាត់ជាពីរ (ធ្វើឱ្យសល់ពាក់កណ្តាល)

## ៤. ឧទាហរណ៍ក្នុងបរិបទជាក់ស្តែង (Examples in Context)

### កាលៈទេសៈផ្លូវការ និងការងារ (Formal Situations)
1. **音量を小さくします。**
   - *Onryō o chīsaku shimasu.*
   - ខ្ញុំនឹងបន្ថយកម្រិតសំឡេងឱ្យតូច។
2. **部屋を明るくしました。**
   - *Heya o akaruku shimashita.*
   - ខ្ញុំបានធ្វើឱ្យបន្ទប់នេះភ្លឺឡើង (ដោយបើកភ្លើង ឬបើកបង្អួច)។
3. **会議の資料をわかりやすくします。**
   - *Kaigi no shiryō o wakariyasuku shimasu.*
   - ខ្ញុំនឹងធ្វើឱ្យឯកសារប្រជុំងាយស្រួលយល់ជាងមុន។

### ការសន្ទនាប្រចាំថ្ងៃ និងស្និទ្ធស្នាល (Informal Conversations)
1. **テレビの音を大きくして。**
   - *Terebi no oto o ōkiku shite.*
   - ជួយបើកសំឡេងទូរទស្សន៍ឱ្យឮ/ធំជាងហ្នឹងបន្តិចមើល៍!
2. **髪を短くしたよ。**
   - *Kami o mijikaku shita yo.*
   - ខ្ញុំកាត់សក់ឱ្យខ្លីហើយតើ។

### បរិបទភាសាសរសេរ (Written Context)
1. **生活習慣を健康的にし、体を強くします。**
   - *Seikatsu shūkan o kenkō-teki ni shi, karada o tsuyoku shimasu.*
   - តាមរយៈការកែប្រែទម្លាប់រស់នៅឱ្យមានសុខភាពល្អ យើងនឹងពង្រឹងរាងកាយឱ្យរឹងមាំឡើង។

### បរិបទភាសានិយាយ និងការស្នើសុំ (Spoken Context & Requests)
1. **このスープ、もっと熱くしてください。**
   - *Kono sūpu, motto atsuku shite kudasai.*
   - សូមជួយកម្តៅស៊ុបនេះឱ្យក្តៅជាងនេះបន្តិចមក។
2. **もうすこし安くしてくれませんか。**
   - *Mō sukoshi yasuku shite kuremasen ka.*
   - តើអាចជួយចុះថ្លៃឱ្យធូរជាងនេះបន្តិចបានទេ?

## ៥. កំណត់សម្គាល់បែបវប្បធម៌ (Cultural Notes)

### ភាពគួរសម និងកម្រិតនៃការប្រើប្រាស់ (Politeness and Formality)
- ទម្រង់បញ្ចប់ដោយ **〜くします** គឺជាទម្រង់គួរសមទូទៅ (丁寧語 - Teineigo) ដែលស័ក្តិសមប្រើទាំងក្នុងកន្លែងធ្វើការ ក្នុងសង្គម និងការប្រាស្រ័យទាក់ទងទូទៅ។
- នៅពេលស្នើសុំឱ្យអ្នកដទៃធ្វើការផ្លាស់ប្តូរអ្វីមួយ ការបន្ថែម **〜てください** (ទៅជា **〜くしてください**) គឺជាទម្រង់ស្នើសុំយ៉ាងគួរសម។

### កន្សោមពាក្យពេញនិយម (Idiomatic Expressions)
- **早くしてください。** (*Hayaku shite kudasai.*)
  - «សូមប្រញាប់ឡើង / សូមធ្វើឱ្យលឿនឡើង។»
  - ជាកន្សោមពាក្យដែលប្រើជាទូទៅនៅពេលចង់ដាស់តឿន ឬជំរុញឱ្យនរណាម្នាក់រួសរាន់ធ្វើកិច្ចការ។

## ៦. កំហុសទូទៅ និងគន្លឹះចងចាំ (Common Mistakes and Tips)

### កំហុសដែលតែងតែកើតឡើង (Common Errors)
1. **ភ្លេចលុប «い» ហើយប្តូរជា «く»៖**
   - ខុស៖ ❌ **寒いします**
   - ត្រូវ៖ ✅ **寒くします** (ធ្វើឱ្យត្រជាក់)
2. **ច្រឡំប្រើ «〜くします» ជាមួយគុណនាម な (な-adjective)៖**
   - ខុស៖ ❌ **静かくします**
   - ត្រូវ៖ ✅ **静かにします** (ធ្វើឱ្យស្ងប់ស្ងាត់ / នៅឱ្យស្ងៀម)
3. **ច្រឡំរវាង «〜くします» (ធ្វើឱ្យ...) និង «〜くなります» (ប្រែជា...)៖**
   - ខុស៖ ❌ **部屋が暗くしました。** (ប្រើ が ជាមួយ します ក្នុងន័យនេះមិនត្រឹមត្រូវទេ)
   - ត្រូវ៖ ✅ **部屋を暗くしました。** (ខ្ញុំបានធ្វើឱ្យបន្ទប់ងងឹត - សកម្មភាពផ្ទាល់)
   - ត្រូវ៖ ✅ **部屋が暗くなりました。** (បន្ទប់ប្រែជាងងឹត - ឧ. ពេលមេឃងងឹត)

### គន្លឹះជួយចងចាំ (Learning Strategies)
- **រូបមន្តផ្លាស់ប្តូរ**៖ ចងចាំថាគុណនាម い ត្រូវតែប្តូរ **い ➔ く** មុននឹងភ្ជាប់ជាមួយកិរិយាសព្ទ។ ដូច្នេះ `い ➔ く + します`។
- **កត់ចំណាំគូប្រៀបធៀប**៖
  - **を ... くします** = ធ្វើឱ្យ... (មានមនុស្សទៅកែប្រែ)
  - **が ... くなります** = ក្លាយជា... / ប្រែជា... (ប្រែប្រួលដោយឯកឯង)

---

## ៧. សេចក្តីសង្ខេប និងការរំលឹកឡើងវិញ (Summary and Review)

### ចំណុចសំខាន់ៗដែលត្រូវចងចាំ (Key Takeaways)
- ប្រើ **គុណនាម い (លុប い) + くします** ដើម្បីបង្ហាញពីការធ្វើសកម្មភាពកែប្រែ ឬផ្លាស់ប្តូរអ្វីមួយឱ្យស្ថិតក្នុងសភាពណាមួយ។
- ត្រូវលុប **〜い** នៅខាងចុងគុណនាម い ហើយជំនួសដោយ **〜く** មុននឹងបន្ថែម **します**។
- ចំពោះ **គុណនាម な** និង **នាម** ត្រូវប្រើ **〜にします** ជំនួសវិញ។
- ខុសពី **〜くなります** (ការប្រែប្រួលដោយឯកឯង/ធម្មជាតិ), **〜くします** សម្តៅលើចេតនារបស់មនុស្សក្នុងការធ្វើឱ្យមានការផ្លាស់ប្តូរ។

### កម្រងសំណួររំលឹកខ្លីៗ (Quick Recap Quiz)
១. តើពាក្យ «ធ្វើឱ្យបន្ទប់កក់ក្តៅ» និយាយជាភាសាជប៉ុនយ៉ាងដូចម្តេច?
   - **ចម្លើយ៖** 部屋を暖かくします。(Heya o atatakaku shimasu.)
២. ចូរជ្រើសរើសពាក្យបំពេញចន្លោះ៖ 音を_______してください。(«សូមជួយបន្ថយសំឡេងឱ្យតូច/ស្រាលបន្តិច។»)
   - **ចម្លើយ៖** 小さく (chīsaku)
៣. ត្រូវ ឬខុស៖ គុណនាម **きれい** ត្រូវប្រើជាមួយ **〜くします** នៅក្នុងទម្រង់វេយ្យាករណ៍នេះ?
   - **ចម្លើយ៖** ខុស (ព្រោះ **きれい** គឺជាគុណនាម な ដូច្នេះត្រូវប្រើ **きれいにします**។)
