## 4. Translation Guidelines & Linguistic Conventions
1. **Linguistic Terms in Khmer:**
   - Noun: នាម
   - Verb: កិរិយាសព្ទ (辞書形 = ទម្រង់វចនានុក្រម / ទម្រង់ដើម, て形 = ទម្រង់て, た形 = ទម្រង់អតីតកាល)
   - Adjective: គុណនាម (い-Adjective = គុណនាម い, な-Adjective = គុណនាម な)
   - Particle / Conjunction: ឈ្នាប់ / ធ្នាក់
   - Formality / Nuance: កម្រិតផ្លូវការ, ន័យស៊ីជម្រៅ និងការប្រើប្រាស់ជាក់ស្តែង
2. **Metadata Injection:**
   - Add `**កម្រិត JLPT:** JLPT N...` directly below the main title of each Markdown document.
3. **Multi-Agent Batching:**
   - Translation tasks are decomposed into subagent workloads to process files safely with full traceability and zero data corruption.
